🧵 Строки и коллекции

s = "Python"
s.upper()          # "PYTHON"
s.lower()          # "python"
s.strip()          # убрать пробелы по краям
s.split()          # список слов
" ".join(["a", "b"])  # "a b"
f"{s} — язык"      # f-строка

lst = [3, 1, 2]
lst.append(4)      # добавить в конец
sorted(lst)        # новый отсортированный список
len(lst)           # длина
lst[1:3]           # срез
d = {"a": 1}
d.get("b", 0)      # безопасное чтение

💻 Команды терминала

python script.py            # запуск программы
python -m venv .venv       # создать окружение
.venv\Scripts\activate     # Windows: активировать
source .venv/bin/activate   # macOS/Linux
pip install requests        # установить пакет
pip freeze > requirements.txt  # сохранить зависимости
python -m pip install -r requirements.txt  # установить все

git init / git add . / git commit -m "текст"
git push origin main
python manage.py runserver  # Django

📚 Глоссарий

Аннотация типов
указание типов у параметров и возврата: def f(x: int) -> str
Асинхронность
выполнение задач без блокировки потока (asyncio, async/await)
Генератор
функция с yield, отдающая значения по одному
GIL
глобальная блокировка интерпретатора CPython для потоков
Декоратор
функция, оборачивающая другую функцию для расширения поведения
Докстринг
строка-документация сразу после def/class
Итератор
объект с __iter__/__next__
Контекстный менеджер
объект для with (__enter__/__exit__)
Корутина
асинхронная функция, объявленная через async def
Lambda
анонимная функция: lambda x: x * 2
Магический метод
метод вида __str__, __eq__, …
Модуль
файл .py с кодом; импортируется через import
Mypy
статический проверщик типов
ORAC
объектно-реляционное отображение: таблицы ↔ классы
Пакет
папка с __init__.py и модулями
Пессымизация
улучшение производительности
Срез
взятие части последовательности: lst[1:4]
F-строка
строка с подстановкой: f"{x}"
Функция-обёртка
внутренняя функция, возвращаемая декоратором
Шаблон (template)
файл с разметкой и подстановками (Jinja2, Django templates)
