Однослойная линейная модель умеет только прямые линии. Нейросеть — это композиция таких слоёв с нелинейными активациями: именно нелинейность позволяет моделировать любые гладкие зависимости. С математической точки зрения нейросеть с одним скрытым слоем уже может приблизить любую непрерывную функцию с любой точностью — вопрос лишь в количестве нейронов и качестве обучения.

## Из чего состоит нейронет

Каждый нейрон — это линейная комбинация входов плюс сдвиг: `z = w1·x1 + ... + wn·xn + b`. Затем применяется функция активации — обычно ReLU: `relu(z) = max(0, z)`. Она вносит нелинейность; без неё стопка линейных слоёв осталась бы одним линейным слоем. Совокупность нейронов, работающих параллельно, называется слоем. Слой, что принимает данные, — входной, выходной слой даёт предсказание, промежуточные — скрытые.

## Модуль nn.Module

В PyTorch сеть — это класс, наследник `nn.Module`. Два обязательных метода: `__init__`, где объявляются слои (`nn.Linear(in_features, out_features)`), и `forward`, где описано, как данные проходят через сеть. Созданный экземпляр вызывается как функция: `model(x)`. Параметры модели доступны через `model.parameters()` — их-то и будет обновлять оптимизатор.

## Функция потерь

Для регрессии берём среднюю квадратичную ошибку: `F.mse_loss(pred, target)`. Для классификации с несколькими классами — кросс-энтропию `F.cross_entropy(logits, labels)`: она ждёт «сырые» оценки классов (logits), а softmax применяет сама.

## Оптимизатор

`torch.optim` содержит готовые алгоритмы: SGD и его вариант с импульсом, Adam и другие. Оптимизатор создаётся от параметров модели: `optim.Adam(model.parameters(), lr=0.01)`. Метод `step()` делает один шаг обновления, `zero_grad()` очищает накопленные градиенты. Типичный цикл обучения: обнулить градиенты, посчитать предсказание и потерю, вызвать `backward()` и `step()`.

## Практический пример: аппроксимация синуса

Научим двухслойную сеть предсказывать синус по известному x. Данные синтетические, обучаем на них же — для нас важно увидеть механику, а не обобщение. Обрати внимание: между слоями стоит ReLU, при обучении мы используем Adam, а потерю печатаем несколько раз за обучение.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)

x = torch.linspace(-3, 3, 300).reshape(-1, 1)
y = torch.sin(x) + 0.1 * torch.randn_like(x)

class TwoLayerNet(nn.Module):
    def __init__(self, hidden=64):
        super().__init__()
        self.fc1 = nn.Linear(1, hidden)
        self.fc2 = nn.Linear(hidden, 1)

    def forward(self, x):
        h = torch.relu(self.fc1(x))
        return self.fc2(h)

model = TwoLayerNet()
opt = torch.optim.Adam(model.parameters(), lr=0.02)

for epoch in range(2000):
    opt.zero_grad()
    pred = model(x)
    loss = F.mse_loss(pred, y)
    loss.backward()
    opt.step()

    if epoch % 500 == 0:
        print(f"epoch={epoch:4d}  loss={loss.item():.4f}")
```

Запусти код: потеря будет убывать, и к 2000-й эпохе модель практически точно повторит синусоиду, что на самом деле представлено в данных с шумом.

## Сколько эпох и какой размер сети

Число эпох и размер сети подбирают экспериментально: если потеря почти не падает, увеличивают сеть или снижают скорость обучения; если падает слишком медленно — увеличивают lr. В следующем уроке этот же цикл мы применим к настоящим изображениям.

Полное решение:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)

x = torch.linspace(-3, 3, 300).reshape(-1, 1)
y = torch.sin(x) + 0.1 * torch.randn_like(x)

class ThreeLayerNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(1, 16)
        self.fc_mid = nn.Linear(16, 32)
        self.fc2 = nn.Linear(32, 1)

    def forward(self, x):
        h = torch.relu(self.fc1(x))
        h = torch.relu(self.fc_mid(h))
        return self.fc2(h)

model = ThreeLayerNet()
opt = torch.optim.Adam(model.parameters(), lr=0.02)

for epoch in range(2000):
    opt.zero_grad()
    pred = model(x)
    loss = F.mse_loss(pred, y)
    loss.backward()
    opt.step()

    if epoch % 500 == 0:
        print(f"epoch={epoch:4d}  loss={loss.item():.4f}")
```

Разбор шагов. Класс `ThreeLayerNet` — это уже три `nn.Linear`: первый слой превращает один вход в 16 чисел, средний — 16 в 32, выходной — 32 в один ответ. Каждый скрытый слой заканчивается ReLU: без неё три линейных слоя можно было бы сжать в один, и сеть не смогла бы выучить кривую синусоиду.

Число параметров выросло: `1·16 + 16 + 16·32 + 32 + 32·1 + 1 = 625` весов и сдвигов. Это больше, чем у двухслойной сети (193), поэтому у модели больше «свободы» — но при том же количестве данных она не должна переобучиться, потому что задача аппроксимации синуса гладкая, а шум мал.

В выводе мы увидим, что потеря падает быстрее и в конце заметно меньше, чем у двухслойной сети: у более широкой и глубокой архитектуры больше возможностей точно повторить форму кривой. Если увеличить lr до 0.05, обучение ускорится ещё, но при слишком большой скорости потеря начнёт скакать — попробуй поэкспериментировать.
