Однослойная линейная модель умеет только прямые линии. Нейросеть — это композиция таких слоёв с нелинейными активациями: именно нелинейность позволяет моделировать любые гладкие зависимости. С математической точки зрения нейросеть с одним скрытым слоем уже может приблизить любую непрерывную функцию с любой точностью — вопрос лишь в количестве нейронов и качестве обучения.

## Из чего состоит нейронет

Каждый нейрон — это линейная комбинация входов плюс сдвиг: `z = w1·x1 + ... + wn·xn + b`. Затем применяется функция активации — обычно ReLU: `relu(z) = max(0, z)`. Она вносит нелинейность; без неё стопка линейных слоёв осталась бы одним линейным слоем. Совокупность нейронов, работающих параллельно, называется слоем. Слой, что принимает данные, — входной, выходной слой даёт предсказание, промежуточные — скрытые.

## Модуль nn.Module

В PyTorch сеть — это класс, наследник `nn.Module`. Два обязательных метода: `__init__`, где объявляются слои (`nn.Linear(in_features, out_features)`), и `forward`, где описано, как данные проходят через сеть. Созданный экземпляр вызывается как функция: `model(x)`. Параметры модели доступны через `model.parameters()` — их-то и будет обновлять оптимизатор.

## Функция потерь

Для регрессии берём среднюю квадратичную ошибку: `F.mse_loss(pred, target)`. Для классификации с несколькими классами — кросс-энтропию `F.cross_entropy(logits, labels)`: она ждёт «сырые» оценки классов (logits), а softmax применяет сама.

## Оптимизатор

`torch.optim` содержит готовые алгоритмы: SGD и его вариант с импульсом, Adam и другие. Оптимизатор создаётся от параметров модели: `optim.Adam(model.parameters(), lr=0.01)`. Метод `step()` делает один шаг обновления, `zero_grad()` очищает накопленные градиенты. Типичный цикл обучения: обнулить градиенты, посчитать предсказание и потерю, вызвать `backward()` и `step()`.

## Практический пример: аппроксимация синуса

Научим двухслойную сеть предсказывать синус по известному x. Данные синтетические, обучаем на них же — для нас важно увидеть механику, а не обобщение. Обрати внимание: между слоями стоит ReLU, при обучении мы используем Adam, а потерю печатаем несколько раз за обучение.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)

x = torch.linspace(-3, 3, 300).reshape(-1, 1)
y = torch.sin(x) + 0.1 * torch.randn_like(x)

class TwoLayerNet(nn.Module):
    def __init__(self, hidden=64):
        super().__init__()
        self.fc1 = nn.Linear(1, hidden)
        self.fc2 = nn.Linear(hidden, 1)

    def forward(self, x):
        h = torch.relu(self.fc1(x))
        return self.fc2(h)

model = TwoLayerNet()
opt = torch.optim.Adam(model.parameters(), lr=0.02)

for epoch in range(2000):
    opt.zero_grad()
    pred = model(x)
    loss = F.mse_loss(pred, y)
    loss.backward()
    opt.step()

    if epoch % 500 == 0:
        print(f"epoch={epoch:4d}  loss={loss.item():.4f}")
```

Запусти код: потеря будет убывать, и к 2000-й эпохе модель практически точно повторит синусоиду, что на самом деле представлено в данных с шумом.

## Сколько эпох и какой размер сети

Число эпох и размер сети подбирают экспериментально: если потеря почти не падает, увеличивают сеть или снижают скорость обучения; если падает слишком медленно — увеличивают lr. В следующем уроке этот же цикл мы применим к настоящим изображениям.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)

x = torch.linspace(-3, 3, 300).reshape(-1, 1)
y = torch.sin(x) + 0.1 * torch.randn_like(x)

class ThreeLayerNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(1, 16)
        self.fc_mid = nn.Linear(16, 32)
        self.fc2 = nn.Linear(32, 1)

    def forward(self, x):
        h = torch.relu(self.fc1(x))
        h = torch.relu(self.fc_mid(h))
        return self.fc2(h)

model = ThreeLayerNet()
opt = torch.optim.Adam(model.parameters(), lr=0.02)

for epoch in range(2000):
    opt.zero_grad()
    pred = model(x)
    loss = F.mse_loss(pred, y)
    loss.backward()
    opt.step()

    if epoch % 500 == 0:
        print(f"epoch={epoch:4d}  loss={loss.item():.4f}")
```

Класс `ThreeLayerNet` — это уже три `nn.Linear`: первый слой превращает один вход в 16 чисел, средний — 16 в 32, выходной — 32 в один ответ. Каждый скрытый слой заканчивается ReLU: без неё три линейных слоя можно было бы сжать в один, и сеть не смогла бы выучить кривую синусоиду. Число параметров выросло: `1·16 + 16 + 16·32 + 32 + 32·1 + 1 = 625` весов и сдвигов. Это больше, чем у двухслойной сети (193), поэтому у модели больше «свободы» — но при том же количестве данных она не должна переобучиться, потому что задача аппроксимации синуса гладкая, а шум мал. В выводе мы увидим, что потеря падает быстрее и в конце заметно меньше, чем у двухслойной сети: у более широкой и глубокой архитектуры больше возможностей точно повторить форму кривой. Если увеличить lr до 0.05, обучение ускорится ещё, но при слишком большой скорости потеря начнёт скакать — попробуй поэкспериментировать.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)

x = torch.linspace(-3, 3, 300).reshape(-1, 1)
y = torch.sin(x) + 0.1 * torch.randn_like(x)

class TwoLayerNet(nn.Module):
    def __init__(self, hidden=64):
        super().__init__()
        self.fc1 = nn.Linear(1, hidden)
        self.fc2 = nn.Linear(hidden, 1)

    def forward(self, x):
        h = torch.relu(self.fc1(x))
        return self.fc2(h)

def train(model):
    opt = torch.optim.Adam(model.parameters(), lr=0.02)
    for epoch in range(2000):
        opt.zero_grad()
        loss = F.mse_loss(model(x), y)
        loss.backward()
        opt.step()
    return loss.item()

loss_small = train(TwoLayerNet(hidden=8))
loss_wide = train(TwoLayerNet(hidden=128))
print("hidden=8:", round(loss_small, 4))
print("hidden=128:", round(loss_wide, 4))
```

Функция `train` инкапсулирует цикл обучения и возвращает финальную потерю — это удобно для экспериментов. Узкая сеть с 8 нейронами имеет всего `1·8 + 8 + 8·1 + 1 = 25` параметров: ей хватает возможностей нарисовать грубый «зигзаг» из 16 полуплоскостей, но точная кривая не получается — потеря около 0.02–0.04. Широкая сеть со 128 нейронами (~385 параметров) может расставить больше изломов и доводит потерю до 0.010–0.015, останавливаясь на уровне шума. Заметь: дальнейшее увеличение ширины почти не улучшит результат, потому что нижняя граница — это дисперсия шума (0.01). Так выглядит типичный эксперимент с ёмкостью модели: сначала рост помогает, потом упирается в шум данных.

### Разбор 3
Решение:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)

x = torch.linspace(-3, 3, 300).reshape(-1, 1)
y = torch.sin(x) + 0.1 * torch.randn_like(x)

class TwoLayerNet(nn.Module):
    def __init__(self, use_relu=True):
        super().__init__()
        self.use_relu = use_relu
        self.fc1 = nn.Linear(1, 64)
        self.fc2 = nn.Linear(64, 1)

    def forward(self, x):
        h = self.fc1(x)
        if self.use_relu:
            h = torch.relu(h)
        return self.fc2(h)

def train(model):
    opt = torch.optim.Adam(model.parameters(), lr=0.02)
    for epoch in range(2000):
        opt.zero_grad()
        loss = F.mse_loss(model(x), y)
        loss.backward()
        opt.step()
    return loss.item()

loss_linear = train(TwoLayerNet(use_relu=False))
loss_relu = train(TwoLayerNet(use_relu=True))
print("без ReLU:", round(loss_linear, 4))
print("с ReLU:", round(loss_relu, 4))
```

Параметр `use_relu` позволяет одним классом собрать обе версии. Линейная сеть — это просто матрица 1×64, за которой следует матрица 64×1; их произведение снова линейно, поэтому вся «глубокая» сеть эквивалентна одной прямой. Лучшая прямая в данных с синусом объясняет лишь часть изменчивости, и финальная потеря остаётся около 0.15. Сеть с ReLU из тех же 64 нейронов строит кусочно-линейную кривую и опускает потерю до ≈ 0.01. Этот эксперимент — прямое доказательство главного тезиса урока: без нелинейной активации глубина слоёв бессмысленна. Именно ReLU и подобные функции превращают стопку слоёв в универсальный аппроксиматор.

### Разбор 4
Решение:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)

x = torch.linspace(-3, 3, 300).reshape(-1, 1)
y = torch.sin(x) + 0.1 * torch.randn_like(x)

x_train, y_train = x[:210], y[:210]
x_val, y_val = x[210:], y[210:]

class TwoLayerNet(nn.Module):
    def __init__(self, hidden=64):
        super().__init__()
        self.fc1 = nn.Linear(1, hidden)
        self.fc2 = nn.Linear(hidden, 1)

    def forward(self, x):
        return self.fc2(torch.relu(self.fc1(x)))

model = TwoLayerNet()
opt = torch.optim.Adam(model.parameters(), lr=0.02)

for epoch in range(2000):
    opt.zero_grad()
    loss = F.mse_loss(model(x_train), y_train)
    loss.backward()
    opt.step()

train_loss = F.mse_loss(model(x_train), y_train).item()
val_loss = F.mse_loss(model(x_val), y_val).item()
print("MSE на обучении:", round(train_loss, 4))
print("MSE на валидации:", round(val_loss, 4))
```

Мы разделили данные на обучающую часть (210 точек) и валидационную (90 точек), которые не участвуют в обучении вовсе. После 2000 эпох модель обучена только на первых 210 точках, а ошибка на отложенных 90 показывает, насколько хорошо сеть обобщается. Обе ошибки близки (около 0.01–0.02) — это сигнал отсутствия переобучения: модель выучила именно форму синусоиды, а не конкретные точки. Если бы сеть была очень большой, а данных мало, валидационная ошибка стала бы заметно выше обучающей — именно такой разрыв и есть ранний признак переобучения. Валидационные выборки — обязательная часть реальных ML-проектов.

Этот приём — вызвать обученную модель на новых данных — и есть практическое применение всего цикла обучения.
