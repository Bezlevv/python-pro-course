Этот модуль — точка перехода: от программ, которые выполняют правила, к программам, которые сами выводят правила из данных. Такие программы называют машинным обучением (machine learning) — разделом искусственного интеллекта, где алгоритм учится на примерах. На этом основаны переводчики, лента рекомендаций, распознавание лиц и голосовые помощники.

## Почему не просто правила

В классическом программировании человек описывает правила явно: «если чек больше 1000 рублей — скидка 10%». Компьютер лишь исполняет инструкции. Но есть задачи, которые невозможно описать правилами. Как по фотографии определить, что на ней кот? Правило «есть уши и хвост» развалится на первом же снимке. Машинное обучение работает иначе: вместо правил мы показываем алгоритму тысячи размеченных примеров, и он сам находит скрытые закономерности.

## Основные термины

Множество примеров, на которых учится алгоритм, называется обучающей выборкой. Каждый пример описывают признаки (features) — числа, которые характеризуют объект: для покупателя это возраст и сумма покупок, для картинки — яркость пикселей. То, что мы хотим предсказать, называется меткой (label). Модель — это функция, которая по признакам считает предсказание. Обучение — подбор параметров модели так, чтобы её ответы совпадали с метками. Предсказание — применение обученной модели к новым данным.

## Виды обучения

Когда в данных есть метки, говорят об обучении с учителем (supervised learning). Если метка — число, задача называется регрессией (например, предсказать цену квартиры). Если метка — одна из категорий — классификацией (кот или собака). Когда меток нет и нужно найти группы похожих объектов, это обучение без учителя (unsupervised learning): так сегментируют покупателей. Отдельно стоит обучение с подкреплением: агент действует и получает награду за хорошие решения — так обучаются игровые боты.

## Обучающая и тестовая выборки

Мало обучить модель — надо проверить, что она работала на данных, которых не видела. Поэтому выборку делят на обучающую и тестовую части. На первой модели подбирают параметры, на второй оценивают качество. Если модель идеально отвечает на обучающих примерах, но ошибается на новых — это переобучение. Эта идея будет проходить через весь модуль.

## Первый алгоритм: k ближайших соседей

Метод kNN почти ничего не обучает: он запоминает примеры и классифицирует по соседям. Чтобы предсказать метку нового объекта, находим k ближайших к нему обучающих примеров. Для классификации берём самую частую метку среди них, для регрессии — среднее значение. k — гиперпараметр: его задаём мы, а не алгоритм.

```python
import numpy as np

# Данные: рост (см) и вес (кг)
X = np.array([[155, 50], [160, 58], [165, 60],
              [170, 65], [175, 70], [180, 78]])
y = np.array([0, 0, 0, 1, 1, 1])  # 0 — футболка S, 1 — футболка L

def knn_predict(X_train, y_train, x_new, k=3):
    # Евклидовы расстояния до всех обучающих примеров
    distances = np.sqrt(((X_train - x_new) ** 2).sum(axis=1))
    idx = np.argsort(distances)[:k]        # k ближайших
    return int(round(y_train[idx].mean()))  # самая частая метка

print(knn_predict(X, y, np.array([168, 63])))  # 0
print(knn_predict(X, y, np.array([177, 75])))  # 1
```

Разбор примера: для человека с ростом 168 см и весом 63 кг ближайшие соседи — это примеры (165, 60), (170, 65) и (160, 58), все с меткой 0, поэтому ответ 0. Для рослого посетителя соседи оказываются из класса 1.

### Разбор 2
Решение:

```python
import numpy as np

X = np.array([[155, 50], [160, 58], [165, 60],
              [170, 65], [175, 70], [180, 78]])
y = np.array([0, 0, 0, 1, 1, 1])

def knn_classify(X_train, y_train, x_new, k=3):
    distances = np.sqrt(((X_train - x_new) ** 2).sum(axis=1))
    idx = np.argsort(distances)[:k]
    labels = y_train[idx]
    return np.bincount(labels).argmax()

print(knn_classify(X, y, np.array([168, 63])))  # 0
print(knn_classify(X, y, np.array([177, 75])))  # 1
```

Сначала считаем евклидовы расстояния от новой точки до всех обучающих примеров: разности возводим в квадрат, суммируем по признакам и извлекаем корень. `np.argsort` возвращает индексы примеров, отсортированных по возрастанию расстояния, а срез `[:k]` оставляет k ближайших. Дальше выбираем их метки и через `np.bincount` подсчитываем, сколько раз встречается каждая метка: `argmax` возвращает номер самой частой. Для человека (168, 63) ближайшие соседи — примеры (165, 60), (170, 65) и (160, 58) с метками 0, 1, 0, поэтому ответ 0; для (177, 75) все три ближайших соседа из класса 1.

### Разбор 3
Решение:

```python
import numpy as np

X = np.array([[0, 500], [2, 500], [1, 0], [1, 1000]])
y = np.array([0, 0, 1, 1])
x_new = np.array([1, 510])

def knn_classify(X_train, y_train, x_new, k=3):
    distances = np.sqrt(((X_train - x_new) ** 2).sum(axis=1))
    idx = np.argsort(distances)[:k]
    return np.bincount(y_train[idx]).argmax()

def normalize(X):
    return (X - X.mean(axis=0)) / X.std(axis=0)

print("Без нормировки:", knn_classify(X, y, x_new))

X_n = normalize(X)
x_new_n = (x_new - X.mean(axis=0)) / X.std(axis=0)
print("С нормировкой:", knn_classify(X_n, y, x_new_n))
```

Без нормировки расстояния почти целиком определяются вторым признаком: разница 10 по нему даёт вклад 100 в сумму квадратов, тогда как разница 1 по первому признаку — вклад 1. Для точки (1, 510) ближайшие соседи — оба примера класса 0 (расстояния ≈ 10.05), поэтому ответ 0. После нормировки оба признака имеют единичный разброс, и вклад первого признака перестаёт теряться: ближайшими становятся примеры класса 1 (расстояния ≈ 1.4 против ≈ 1.44 у класса 0), и ответ меняется на 1. Это ключевой урок: когда признаки измерены в разных единицах, kNN обязан нормировать данные.

### Разбор 4
Решение:

```python
import numpy as np

X = np.array([150, 155, 160, 165, 170, 175, 180, 185, 190, 195, 200, 205,
              157, 163, 172, 178, 188, 198])
y = np.array([48, 52, 55, 60, 65, 70, 76, 80, 86, 92, 97, 103,
              54, 61, 68, 74, 84, 95])

X_train, y_train = X[:12], y[:12]
X_test, y_test = X[12:], y[12:]

def knn_regression(X_train, y_train, x_new, k=1):
    idx = np.argsort(np.abs(X_train - x_new))[:k]
    return y_train[idx].mean()

train_mae = np.abs([knn_regression(X_train, y_train, x) for x in X_train] - y_train).mean()
test_mae = np.abs([knn_regression(X_train, y_train, x) for x in X_test] - y_test).mean()
print("MAE на обучении =", round(train_mae, 4))
print("MAE на тесте =", round(test_mae, 4))
```

При k = 1 предсказание для каждой обучающей точки равно её собственной метке: расстояние до себя равно нулю, поэтому эта точка всегда попадает в число ближайших. Из-за этого MAE на обучающей выборке равна нулю — модель «запомнила» данные. Но на тестовых примерах, которых модель не видела, ошибка уже около 2.0. Именно так выглядит запоминание вместо обучения: нулевая ошибка на обучении и заметная ошибка на новых данных. Это первый шаг к пониманию переобучения — темы, к которой мы ещё вернёмся.

### Разбор 5
Решение:

```python
import numpy as np

X = np.array([150, 155, 160, 165, 170, 175, 180, 185, 190, 195, 200, 205,
              157, 163, 172, 178, 188, 198])
y = np.array([48, 52, 55, 60, 65, 70, 76, 80, 86, 92, 97, 103,
              54, 61, 68, 74, 84, 95])

X_train, y_train = X[:12], y[:12]
X_test, y_test = X[12:], y[12:]

def knn_regression(X_train, y_train, x_new, k):
    idx = np.argsort(np.abs(X_train - x_new))[:k]
    return y_train[idx].mean()

for k in (1, 3, 5):
    preds = np.array([knn_regression(X_train, y_train, x, k) for x in X_test])
    mae = np.abs(preds - y_test).mean()
    print(f"k={k}  MAE={mae:.4f}")
```

Цикл по k прогоняет обучение и оценку трижды. При k = 1 предсказание — это метка ближайшей точки, ошибка получается «резкой», но на наших данных MAE = 2.0. При k = 3 усреднение трёх соседей даёт тот же результат 2.0, а при k = 5 ошибка чуть вырастает до 2.07: пятый сосед уже заметно дальше и вносит лишний сдвиг. Вывод: слишком маленькое k делает модель чувствительной к шуму, слишком большое — слишком сглаженной; правильное k подбирают экспериментом. Здесь разница невелика, потому что данные гладкие и без выбросов, но на реальных шумных данных выбор k может менять результат сильнее.
