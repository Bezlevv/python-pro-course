В прошлом уроке мы научились предсказывать метки по соседям. Но у kNN есть слабое место: он не строит никакой внутренней модели и хранит все данные, а предсказание — это набор локальных усреднений. Линейная регрессия — другой подход: мы задаём форму зависимости заранее и подбираем её параметры по данным.

## Форма модели

Линейная регрессия предполагает, что метка y — это линейная комбинация признаков x1, x2, ..., xn плюс константа — сдвиг b (его называют ещё bias или свободный член):

```
y = w1·x1 + w2·x2 + ... + wn·xn + b
```

Числа wi — веса: они показывают, насколько сильно каждый признак влияет на ответ. Если вес положительный, рост признака увеличивает ответ, если отрицательный — уменьшает.

## Функция потерь

Задача обучения — найти такие веса, чтобы предсказания как можно меньше отличались от настоящих меток. Разницу меряют функцией потерь. Стандартный выбор для регрессии — средняя квадратичная ошибка, MSE: это среднее квадратов разностей между предсказанными и истинными значениями. Квадрат нужен, чтобы ошибки в обе стороны не гасили друг друга. Чем меньше MSE, тем лучше модель.

## Матричная форма

Удобно записать модель сразу для всех примеров одной формулой. Пусть X — матрица, где строки — примеры, а столбцы — признаки; w — вектор весов. Тогда предсказания для всей выборки — это векторное произведение `X @ w` (плюс сдвиг). Чтобы сдвиг тоже был в формуле, добавляем к X столбец из единиц и рассматриваем сдвиг как ещё один вес. В таком виде решение находится явно: `w = inv(XᵀX)·Xᵀy` — это нормальное уравнение. На практике чаще используют псевдообратную матрицу `np.linalg.pinv`.

## Реализация на NumPy

Сгенерируем искусственные данные: точки на прямой с шумом — будто зависимость на самом деле линейная, но измерения неточны. Затем составим матрицу X со столбцом из единиц и решим нормальное уравнение. Сравним найденные веса с истинными.

```python
import numpy as np

rng = np.random.default_rng(42)
n = 100

# Истинная зависимость: y = 2x + 1 + шум
x = rng.uniform(0, 10, n)
true_w, true_b = 2.0, 1.0
y = true_w * x + true_b + rng.normal(0, 1.0, n)

# Матрица признаков: столбец единиц + столбец x
X = np.column_stack([np.ones(n), x])

# Нормальное уравнение через псевдообратную матрицу
w = np.linalg.pinv(X) @ y
print("Сдвиг b =", round(w[0], 3))
print("Вес w =", round(w[1], 3))

y_pred = X @ w
mse = ((y - y_pred) ** 2).mean()
print("MSE =", round(mse, 3))
```

Запусти код — ты увидишь, что найденный сдвиг близок к 1.0, вес — к 2.0, а MSE близок к 1.0 (это дисперсия добавленного шума). Модель «угадала» настоящую зависимость.

## Интерпретация

Коэффициент при x — это наклон: на сколько в среднем меняется y при увеличении x на единицу. Сдвиг — значение y, когда все признаки равны нулю. После обучения полезно посмотреть и на качество: MSE сама по себе зависит от масштаба, поэтому её сравнивают с разбросом данных или считают долю объяснённой дисперсии — коэффициент детерминации R².

<!--SOLUTION-->
Полное решение:

```python
import numpy as np

def train_linear(X, y):
    return np.linalg.pinv(X) @ y

rng = np.random.default_rng(7)
n = 200
x1 = rng.uniform(0, 5, n)
x2 = rng.uniform(0, 5, n)
y = 3 + 2 * x1 - x2 + rng.normal(0, 0.5, n)

X = np.column_stack([np.ones(n), x1, x2])

w = train_linear(X, y)
print("Коэффициенты:", np.round(w, 3))

y_pred = X @ w
mse = ((y - y_pred) ** 2).mean()
print("MSE =", round(mse, 4))
```

Разбор шагов. Функция `train_linear` — это одна строка: псевдообратная матрица умножается на вектор меток. Почему `pinv`, а не точное `np.linalg.inv(X.T @ X) @ X.T @ y`? Псевдообратная матрица даёт решение методом наименьших квадратов даже тогда, когда X не квадратная или плохо обусловлена, и работает быстрее — её можно использовать всегда.

Дальше мы строим данные: истинные коэффициенты 3, 2 и −1, шум со стандартным отклонением 0.5. Дисперсия шума равна 0.25, поэтому MSE обученной модели должен быть близок к 0.25 — это нижняя граница, дальше которой модель «подгоняться» не может, ведь часть разброса — это неустранимый шум. Найденные коэффициенты отличаются от истинных на сотые: это статистическая ошибка оценки, которая уменьшается с ростом числа примеров n.

Заметь: никакого обучения в смысле циклов здесь нет — мы получили ответ за одну операцию. Это главное преимущество нормального уравнения перед итерационными методами, но оно доступно только для линейных моделей.
