Звук, вибрации, ЭКГ, цена акций — всё это дискретные сигналы: последовательности чисел, измеренные через равные промежутки времени. Главный инструмент анализа сигналов — преобразование Фурье: оно раскладывает сигнал на синусоиды разных частот. Быстрая реализация — FFT (fast Fourier transform) — живёт в `numpy.fft`, а `scipy.signal` добавляет фильтры и поиск пиков.

## Дискретный сигнал и частота дискретизации

Пусть мы измеряем сигнал с частотой дискретизации fs = 1000 Гц — 1000 отсчётов в секунду:

```python
import numpy as np

fs = 1000
t = np.arange(1000) / fs          # 0, 0.001, ..., 0.999 с
signal = np.sin(2 * np.pi * 50 * t)  # 50 Гц
```

Теорема Котельникова–Найквиста говорит: чтобы различать частоту f, нужно дискретизировать с частотой больше 2f. Здесь предел — 500 Гц, поэтому 50 Гц видно отлично.

## Прямое преобразование: numpy.fft.fft

```python
from numpy.fft import fft, fftfreq

spectrum = fft(signal)
freqs = fftfreq(len(signal), 1 / fs)
```

`spectrum` — массив комплексных чисел; его модуль — амплитуда каждой частоты. `fftfreq(n, d)` возвращает сетку частот: положительные до 500 Гц, затем отрицательные. Амплитудный спектр симметричен, поэтому полезная информация — в первой половине.

Найдём доминирующую частоту:

```python
magnitudes = np.abs(spectrum)
peak_idx = np.argmax(magnitudes[:len(magnitudes)//2])
print(freqs[peak_idx])   # 50.0
```

## Окна и утечка спектра

Если частота сигнала не совпадает ровно с бином сетки, энергия «размазывается» по соседним частотам — это утечка спектра. Бороться с ней помогают оконные функции. `np.hanning(n)` обнуляет сигнал на краях, уменьшая разрыв при периодическом продолжении:

```python
windowed = signal * np.hanning(len(signal))
```

## Реконструкция: ifft

Обратное преобразование возвращает исходный сигнал:

```python
from numpy.fft import ifft

restored = np.real(ifft(spectrum))
print(np.max(np.abs(restored - signal)))   # ~1e-15
```

Это удобная проверка в тестах: прямое и обратное преобразования взаимно обратны.

## Фильтрация: scipy.signal

Зашумлённый сигнал очищают фильтрами. Фильтр Баттерворта задаётся через `butter`, применяется двунаправленно через `filtfilt` (без фазового сдвига):

```python
from scipy.signal import butter, filtfilt

noisy = signal + 0.5 * rng.normal(0, 1, len(signal))
b, a = butter(4, 120, btype="low", fs=fs)
clean = filtfilt(b, a, noisy)
```

`butter(4, 120, btype="low", fs=fs)` — фильтр 4-го порядка, пропускающий частоты ниже 120 Гц (fs передаётся, чтобы частоты понимались в герцах). После фильтрации шум сверх 120 Гц ослаблен.

## Поиск пиков: find_peaks

Для периодических сигналов полезно находить экстремумы:

```python
from scipy.signal import find_peaks

peaks, _ = find_peaks(signal, height=0.5)
print(len(peaks))   # 5 пиков за 1 секунду на 5 Гц
```

`find_peaks` возвращает индексы пиков; параметр `height` отсекает ложные пики шума.

## Спектрограмма

Если частота сигнала меняется во времени, используют спектрограмму — «тепловую карту» частот по времени:

```python
from scipy.signal import spectrogram

f, t_spec, Sxx = spectrogram(signal, fs)
```

Это уже визуальный анализ: художники, медики и инженеры смотрят на такие карты.

## Практический рецепт анализа сигнала

Реальная обработка сигнала почти всегда проходит три шага. Сначала — посмотреть на спектр: `fft` покажет, где полезная энергия, а где шум. Потом — отфильтровать то, что не нужно: `butter` + `filtfilt`. И наконец — найти особенности уже очищенного сигнала: `find_peaks` или оценить частоту по максимуму спектра. Если сигнал нестационарен (частота меняется во времени), вместо простого FFT используют спектрограмму — `spectrogram` раскладывает сигнал на окна и считает спектр в каждом из них, превращая одномерный сигнал в двумерную «карту»: время × частота × амплитуда. Именно так работают распознавание речи, эхокардиография и анализ вибраций машин.

Важная деталь: нулевой элемент спектра — постоянная составляющая (постоянный сдвиг сигнала). При поиске доминирующей частоты его пропускают, как мы сделали в задаче 1. Если сигнал содержит постоянное смещение, в спектре появится огромный пик на нуле — он не имеет отношения к колебаниям.

Всё вместе — стандартный конвейер анализа: дискретизация → спектр → фильтрация → поиск особенностей. Теперь сделаем это руками.

fs = 1000

spectrum = fft(signal)

### Разбор 4
Файл `signal_lab.py`:

```python
import numpy as np
from numpy.fft import fft, fftfreq

def make_tone(freq, fs=1000, n=1000):
    t = np.arange(n) / fs
    return np.sin(2 * np.pi * freq * t)

def dominant_frequency(signal, fs):
    spectrum = fft(signal)
    freqs = fftfreq(len(signal), 1 / fs)
    magnitudes = np.abs(spectrum)
    half = magnitudes[1:len(magnitudes) // 2]
    return freqs[np.argmax(half) + 1]
```

Файл `test_signal_lab.py`:

```python
import numpy as np
from numpy.fft import fft, ifft
from signal_lab import make_tone, dominant_frequency

def test_dominant_frequency():
    assert dominant_frequency(make_tone(50), 1000) == 50.0

def test_roundtrip():
    s = make_tone(50)
    restored = np.real(ifft(fft(s)))
    assert np.max(np.abs(restored - s)) < 1e-8
```

Результат: `2 passed`. Что здесь происходит? Первый тест проверяет весь конвейер спектрального анализа. Второй — математическое свойство: FFT и обратное FFT взаимно обратны, и ошибка реконструкции на уровне 1e-15 (машинная точность). Такой «круговой» тест — стандартный способ проверить любой преобразователь.

### Разбор 5
Добавим в `signal_lab.py`:

```python
from scipy.signal import butter, filtfilt

def lowpass_filter(signal, cutoff, fs):
    b, a = butter(4, cutoff, btype="low", fs=fs)
    return filtfilt(b, a, signal)
```

Дополним тесты:

```python
def test_noise_suppressed():
    rng = np.random.default_rng(11)
    s = make_tone(50)
    noisy = s + rng.normal(0, 0.3, 1000)
    clean = lowpass_filter(noisy, 120, 1000)
    assert np.std(clean - s) < 0.1
```

Результат: `3 passed`. Что здесь происходит? Тест проверяет главное назначение фильтра: очистить сигнал от шума. Остаток после фильтрации — то, что фильтр не смог убрать; его стандартное отклонение ≈ 0.018, что намного меньше порога 0.1. Обрати внимание: мы проверяем не «похожесть на глаз», а численный критерий подавления шума.
