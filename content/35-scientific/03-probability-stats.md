Статистика — это наука о том, как делать выводы по данным в условиях неопределённости. Python даёт для этого две мощные связки: генератор случайных чисел NumPy (`numpy.random`) для симуляций и `scipy.stats` для теоретических распределений и тестов. В этом уроке мы соединим их.

## Случайные числа: numpy.random

Современный способ генерировать случайность — объект-генератор с явным сидом:

```python
import numpy as np

rng = np.random.default_rng(42)
a = rng.normal(0, 1, 1000)      # 1000 чисел из N(0, 1)
b = rng.uniform(0, 1, 1000)     # 1000 чисел из U(0, 1)
c = rng.integers(1, 7, size=12) # 12 бросков кубика (1..6)
```

Сид `42` фиксирует последовательность: при одинаковом сиде и одинаковых вызовах результаты повторяются. Это критично для воспроизводимых экспериментов.

## Описательная статистика

Разобраться в выборке помогают простые метрики:

```python
print(a.mean(), a.std(), np.median(a))
print(np.percentile(a, [25, 50, 75]))
```

В `scipy.stats` есть функция `describe`, которая собирает всё сразу:

```python
from scipy.stats import describe

res = describe(a)
print(res.nobs, res.mean, res.variance)
print(res.skewness, res.kurtosis)
```

## Распределения: scipy.stats

Для каждой теоретической модели есть класс с четырьмя ключевыми методами:

- `pdf(x)` — плотность (для непрерывных) или `pmf(k)` — вероятность точки (для дискретных);
- `cdf(x)` — функция распределения: P(X ≤ x);
- `ppf(q)` — обратная функция: квантиль;
- `interval(0.95)` — доверительный интервал.

Пример: для стандартной нормальной величины:

```python
from scipy.stats import norm

print(norm.cdf(1.96))          # ≈ 0.975
print(norm.ppf(0.975))         # ≈ 1.96
print(norm.interval(0.95))     # (-1.96, 1.96)
```

Биномиальное распределение — число успехов в n испытаниях:

```python
from scipy.stats import binom

# вероятность ровно 3 успеха из 10 при p = 0.5
print(binom.pmf(3, 10, 0.5))
# вероятность хотя бы 8 успехов
print(1 - binom.cdf(7, 10, 0.5))
```

Распределение Пуассона моделирует число событий за фиксированный интервал времени: `poisson.pmf(k, mu)`.

## Центральная предельная теорема

Если брать выборки и усреднять их, средние приближаются к нормальному распределению — каким бы ни было исходное распределение. Проверим:

```python
rng = np.random.default_rng(0)
means = [rng.uniform(0, 1, 30).mean() for _ in range(2000)]
print(np.std(means))   # ≈ σ / √n = (1/√12) / √30 ≈ 0.0527
```

Стандартное отклонение средних падает как 1/√n — это объясняет, почему большие выборки дают более точные оценки.

## Проверка гипотез: t-тест

Гипотеза — это утверждение о параметре распределения, например «среднее равно 0». t-тест сравнивает среднее выборки с гипотетическим значением:

```python
from scipy.stats import ttest_1samp

sample = rng.normal(0.3, 1, 100)
t_stat, p_value = ttest_1samp(sample, 0)
print(t_stat, p_value)   # p < 0.05 — отвергаем «среднее равно 0»
```

p-значение — вероятность получить такую же статистику, если гипотеза верна. Если p < 0.05, гипотезу принято отвергать; если больше — данных недостаточно для вывода.

## Дискретные и непрерывные распределения

Важно различать два семейства. У дискретных распределений (биномиальное, Пуассона) величина принимает отдельные значения, и вероятность каждой точки даёт `pmf` — функция вероятности. У непрерывных (нормальное, равномерное) значение — любое действительное число, вероятность отдельной точки равна нулю, поэтому используют плотность `pdf` и вероятности только через интервалы: `cdf(b) - cdf(a)`. В этом разница между `binom.pmf(3, 10, 0.5)` — «ровно 3 успеха» — и `norm.cdf(1.96)`: «не больше 1.96». Не путай эти методы: взять `pdf` для дискретного распределения — частая ошибка новичков.

Полезно также знать, что у распределений есть числовые характеристики, которые можно получить методами класса: `mean()`, `var()`, `std()`. Для биномиального распределения они совпадают с формулами n·p, n·p·(1−p) и их квадратным корнем. В следующих уроках мы будем использовать эти характеристики для проверки симуляций: если среднее по симулированной выборке сильно расходится с `binom.mean(n, p)`, значит, в генерации данных ошибка.

Всё это — фундамент: дальше мы будем строить на нём симуляции и проверять реальные данные.

### Разбор 1
Решение:

```python
import numpy as np

rng = np.random.default_rng(7)
sample = rng.normal(3, 2, 5000)
print(sample.mean())
print(sample.std())
```

Результат (примерно):

```
2.99
1.99
```

Что здесь происходит? Эмпирические характеристики большой выборки сходятся к параметрам распределения: среднее → 3, стандартное отклонение → 2. Расхождение в сотых долях — нормальная статистическая флуктуация: чем больше выборка, тем она меньше.

### Разбор 2
Решение:

```python
from scipy.stats import norm

print(norm.cdf(0))
print(norm.cdf(1.96))
print(norm.cdf(1.96) - norm.cdf(-1.96))
print(norm.ppf(0.975))
```

Результат:

```
0.5
0.9750021048517795
0.950004209703559
1.959963984540054
```

Что здесь происходит? cdf накапливает вероятность слева от точки: для симметричного распределения P(Z ≤ 0) = 0.5. Значение 1.96 — известный порог: между ±1.96 лежит 95% массы нормального распределения. Квантиль `ppf(0.975)` возвращает ровно то число, левее которого 97.5% вероятности — это и есть 1.96. Обратные функции `ppf` и прямые `cdf` взаимно обратны.

### Разбор 3
Решение:

```python
from scipy.stats import binom

print(binom.pmf(5, 10, 0.5))
print(1 - binom.cdf(7, 10, 0.5))
print(binom.mean(10, 0.5))
```

Результат:

```
0.24609375
0.0546875
5.0
```

Что здесь происходит? pmf(5, 10, 0.5) = C(10,5) / 2¹⁰ = 252 / 1024 ≈ 0.246 — вероятность ровно половины орлов. Вероятность «хотя бы 8» — сумма pmf(8), pmf(9), pmf(10) = (45 + 10 + 1) / 1024 ≈ 0.0547. Математическое ожидание биномиальной величины — n·p = 5. Обрати внимание на разницу между pmf (вероятность конкретной точки) и cdf (вероятность «не больше»).

### Разбор 4
Файл `clt_lab.py`:

```python
import numpy as np

def sample_means_std(n_samples=2000, sample_size=30, seed=0):
    rng = np.random.default_rng(seed)
    means = [rng.uniform(0, 1, sample_size).mean() for _ in range(n_samples)]
    return np.std(means)

print(sample_means_std())
```

Файл `test_clt_lab.py`:

```python
from clt_lab import sample_means_std

def test_clt_std_in_range():
    assert 0.045 < sample_means_std() < 0.06

def test_reproducible():
    assert sample_means_std(seed=7) == sample_means_std(seed=7)
```

Результат: `2 passed`. Что здесь происходит? Средние выборок объёмом 30 из U(0, 1) распределены почти нормально (центральная предельная теорема), а их стандартное отклонение — ошибка среднего σ/√n. У равномерного распределения σ = 1/√12 ≈ 0.2887, значит, теоретическое значение — 0.2887/√30 ≈ 0.0527 — отлично попадает в допуск [0.045, 0.06]. Второй тест проверяет воспроизводимость: сид фиксирует последовательность, поэтому два вызова дают побитово одинаковый результат. Так симуляции становятся проверяемым кодом.

### Разбор 5
Файл `stats_lab.py`:

```python
import numpy as np
from scipy.stats import ttest_1samp

def ttest_shift(mean_shift, seed):
    rng = np.random.default_rng(seed)
    sample = rng.normal(mean_shift, 1, 100)
    t_stat, p_value = ttest_1samp(sample, 0)
    return p_value
```

Файл `test_stats_lab.py`:

```python
from stats_lab import ttest_shift

def test_no_shift_not_significant():
    assert ttest_shift(0, 1) > 0.05

def test_shift_significant():
    assert ttest_shift(0.5, 1) < 0.05
```

Результат: `2 passed`. Что здесь происходит? При истинном среднем 0 нулевая гипотеза верна, и p-значение почти всегда оказывается больше 0.05 — тест не видит эффекта там, где его нет. При среднем 0.5 (сдвиг в полстандартного отклонения) тест уверенно отвергает гипотезу: p < 0.05. Так выглядит честная проверка гипотез: p-значение — не «вероятность, что гипотеза верна», а мера несовместимости данных с ней.
