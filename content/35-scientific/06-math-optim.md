Оптимизация — это наука о выборе лучшего из допустимых решений: меньше затрат, больше прибыли, точнее модель. В Python за неё отвечает `scipy.optimize`. Мы уже видели `minimize` в первом уроке; теперь разберём инструментарий глубже: методы, ограничения, линейное программирование, подгонку кривых и глобальный поиск.

## Безусловная минимизация

Функция `minimize` решает задачу: найти вектор x, минимизирующий f(x). Простейший пример — квадратичная функция:

```python
import numpy as np
from scipy.optimize import minimize

def f(z):
    return (z[0] - 3)**2 + (z[1] + 1)**2

res = minimize(f, [0.0, 0.0])
print(res.x, res.fun)   # [3. -1.] 0.0
```

`res.x` — точка минимума, `res.fun` — значение функции. Метод по умолчанию — BFGS. Для негладких функций используют `method="Nelder-Mead"` — он не требует производных.

## Ограничения: bounds

Часто переменные ограничены, например цена не может быть отрицательной. Параметр `bounds` задаёт прямоугольные ограничения:

```python
res = minimize(lambda z: (z[0] - 1)**2, [5.0],
               bounds=[(0, 10)])
print(res.x)   # [1.]
```

Если минимум лежит вне допустимой области, решение «прилипает» к границе:

```python
res = minimize(lambda z: (z[0] - 20)**2, [5.0],
               bounds=[(0, 10)])
print(res.x)   # [10.]
```

## Ограничения-равенства и неравенства

Более общие ограничения — через параметр `constraints`. Например, задача с ограничением-равенством x + y = 5:

```python
res = minimize(lambda z: z[0]**2 + z[1]**2, [1.0, 1.0],
               constraints={"type": "eq",
                            "fun": lambda z: z[0] + z[1] - 5})
print(res.x)   # [2.5 2.5]
```

Эти задачи решаются методом SLSQP (`method="SLSQP"`).

## Линейное программирование: linprog

Когда и целевая функция, и ограничения линейны, задача решается быстро и гарантированно — это линейное программирование. `linprog` минимизирует cᵀx при неравенствах A_ub x ≤ b_ub и границах:

```python
from scipy.optimize import linprog

c = [-2, -3]                      # максимизируем 2x + 3y
A_ub = [[1, 1], [2, 1]]
b_ub = [4, 5]
bounds = [(0, None), (0, None)]

res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds)
print(res.x, res.fun)   # [0. 4.] -12.0
```

Оптимум — x = 0, y = 4, целевая функция 2·0 + 3·4 = 12 (linprog минимизирует −2x − 3y, поэтому `res.fun` = −12).

## Подгонка кривых: curve_fit

Частая задача — подобрать параметры модели под данные. `curve_fit` минимизирует сумму квадратов отклонений:

```python
from scipy.optimize import curve_fit

rng = np.random.default_rng(1)
t = np.linspace(0, 5, 100)
y_true = 5 * np.exp(-0.5 * t)
y = y_true + rng.normal(0, 0.1, 100)

def model(t, a, k):
    return a * np.exp(-k * t)

popt, pcov = curve_fit(model, t, y, p0=[1, 1])
print(popt)   # ≈ [5. 0.5]
```

`popt` — оптимальные параметры, `pcov` — ковариационная матрица (из неё берутся стандартные ошибки). `p0` — начальное приближение.

## Глобальная оптимизация

Локальные методы могут застрять в местном минимуме. Для многоэкстремальных функций есть глобальные методы — `dual_annealing`, `basinhopping`, `differential_evolution`:

```python
from scipy.optimize import dual_annealing

def bumpy(z):
    return np.sin(3 * z[0]) + (z[0] - 1)**2

res = dual_annealing(bumpy, bounds=[(-5, 5)])
print(res.x, res.fun)
```

`dual_annealing` принимает `bounds` — просто список диапазонов. Он «прочёсывает» всю область, что дороже, но надёжнее.

## Как выбрать инструмент

- гладкая функция, нет ограничений → `minimize` (BFGS);
- негладкая → `Nelder-Mead`;
- прямоугольные ограничения → `bounds`;
- сложные ограничения → `constraints` + SLSQP;
- всё линейно → `linprog`;
- подгонка параметров → `curve_fit` или `least_squares`;
- много локальных минимумов → `dual_annealing`.

## Почему это важно

Оптимизация — сквозной инструмент науки о данных. Обучение моделей — это минимизация функции потерь; подбор гиперпараметров — оптимизация метрики; планирование производства и логистики — линейное программирование; калибровка датчиков — метод наименьших квадратов. Даже нейросети обучаются градиентным спуском — тем же семейством методов, к которому принадлежит BFGS. Понимая ограничения и возможности `scipy.optimize`, ты сможешь правильно выбирать инструмент: например, не пытаться решить невыпуклую задачу локальным методом или не использовать медленный глобальный поиск там, где достаточно быстрого градиентного спуска. Как и в анализе сигналов, половина успеха — в правильной постановке задачи, а не в самом вызове библиотеки.

Это эталон для проверки любого оптимизатора: для выпуклых функций результат практически точный.

import numpy as np
from scipy.optimize import curve_fit

def fit_exponential(t, y):

Дополним `test_optim_lab.py`:

from scipy.optimize import minimize, dual_annealing

def test_minimize_quadratic():
    res = minimize(lambda z: (z[0] - 3)**2 + (z[1] + 1)**2, [0.0, 0.0])
    assert abs(res.x[0] - 3) < 1e-4
