Какой подмодуль SciPy отвечает за оптимизацию?
- scipy.optimize
- scipy.integrate
- scipy.interpolate
- scipy.stats
* Правильный ответ: scipy.optimize
minimize, curve_fit и linprog живут в scipy.optimize.

Что возвращает quad?
- Кортеж (значение интеграла, оценка погрешности)
- Только значение интеграла
- Массив точек
- Подынтегральную функцию
* Правильный ответ: Кортеж (значение интеграла, оценка погрешности)
quad возвращает значение и оценку абсолютной ошибки.

Что означает p-значение меньше 0.05 в регрессии?
- Коэффициент статистически значим
- Модель неверна
- Остатки нормальны
- R² высокий
* Правильный ответ: Коэффициент статистически значим
Малое p-значение свидетельствует против нулевой гипотезы о нулевом коэффициенте.

Для чего нужен sm.add_constant(x)?
- Для добавления перехвата в регрессию
- Для удаления пропусков
- Для нормировки
- Для ускорения
* Правильный ответ: Для добавления перехвата в регрессию
Без столбца единиц модель проходит через начало координат.

Как убывает ошибка оценки Монте-Карло?
- Как 1/√N
- Как 1/N
- Экспоненциально
- Не убывает
* Правильный ответ: Как 1/√N
Для уменьшения ошибки вдвое нужно увеличить N вчетверо.

Зачем фиксировать сид в симуляциях?
- Для воспроизводимости результатов
- Для ускорения
- Для уменьшения ошибки
- Для перехода к другим распределениям
* Правильный ответ: Для воспроизводимости результатов
Одинаковый сид даёт одинаковую последовательность случайных чисел.

Что делает numpy.fft.fft?
- Раскладывает сигнал на частоты
- Усредняет сигнал
- Фильтрует шум
- Находит пики
* Правильный ответ: Раскладывает сигнал на частоты
FFT превращает сигнал в спектр — комплексные амплитуды частот.

Какой фильтр пропускает частоты ниже порога?
- Фильтр нижних частот (lowpass)
- Фильтр верхних частот (highpass)
- Полосовой фильтр
- Режекторный фильтр
* Правильный ответ: Фильтр нижних частот (lowpass)
btype="low" в butter означает фильтр нижних частот.

Что решает scipy.optimize.linprog?
- Линейное программирование
- Нелинейную оптимизацию
- Подгонку кривых
- Глобальную оптимизацию
* Правильный ответ: Линейное программирование
linprog минимизирует линейную функцию при линейных ограничениях.

Что возвращает curve_fit?
- Кортеж (popt, pcov)
- Только popt
- Число итераций
- Список остатков
* Правильный ответ: Кортеж (popt, pcov)
popt — оптимальные параметры модели, pcov — ковариационная матрица.
