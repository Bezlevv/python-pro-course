В прошлом уроке мы научились численно решать математические задачи. Но в данных нас интересует другое: как связаны величины, насколько связь сильна и можно ли ей доверять. Библиотека `statsmodels` — стандарт для статистического моделирования в Python: она строит регрессии, выдаёт p-значения, доверительные интервалы и диагностические тесты. Установка: `pip install statsmodels`.

## Синтетические данные

Чтобы видеть, «правильно» ли работает модель, сгенерируем данные с известной зависимостью: y = 2 + 3x + шум.

```python
import numpy as np

rng = np.random.default_rng(42)
x = rng.uniform(0, 10, 200)
y = 2 + 3 * x + rng.normal(0, 1, 200)
```

Мы знаем истинное решение: перехват 2, наклон 3. Регрессия должна восстановить эти числа приближённо.

## Первая регрессия: statsmodels.api.OLS

Основной интерфейс — `statsmodels.api`. Модель `OLS` (ordinary least squares, обычный метод наименьших квадратов) собирается из матрицы признаков и вектора ответа, а `fit()` обучает её:

```python
import statsmodels.api as sm

X = sm.add_constant(x)      # добавляем столбец единиц — перехват
model = sm.OLS(y, X)
results = model.fit()

print(results.params)        # [перехват, наклон]
print(results.rsquared)      # доля объяснённой дисперсии
```

`add_constant` обязателен, если мы хотим свободный член: без него регрессия пойдёт через начало координат. Поля результата: `params` — коэффициенты, `bse` — их стандартные ошибки, `pvalues` — p-значения, `conf_int()` — доверительные интервалы.

## Отчёт: results.summary()

Красивый текстовый отчёт печатается одним вызовом:

```python
print(results.summary())
```

В таблице — коэффициенты, стандартные ошибки, t-статистики, p-значения, R² и F-тест модели в целом. Умение читать такой отчёт — базовый навык аналитика.

## Формульный интерфейс

Для сложных моделей удобнее формульный синтаксис в стиле R:

```python
import pandas as pd
from statsmodels.formula.api import ols

df = pd.DataFrame({"x": x, "y": y})
model = ols("y ~ x", data=df).fit()
print(model.params)
```

Строка `"y ~ x"` читается как «y объясняется через x». Для нескольких признаков: `"y ~ x1 + x2"`, для взаимодействий: `"y ~ x1 * x2"`. Внутри pandas-фрейма категориальные столбцы автоматически превращаются в фиктивные переменные.

## Статистические тесты: проверка гипотез

statsmodels умеет не только оценивать, но и проверять гипотезы. Ключевой объект — p-значение: вероятность получить такое же или более экстремальное значение статистики, если нулевая гипотеза верна. Обычный порог — 0.05.

Проверим, что остатки регрессии распределены нормально — это предпосылка тестов:

```python
from statsmodels.stats.diagnostic import jarque_bera

jb_stat, jb_pvalue = jarque_bera(results.resid)
print(jb_stat, jb_pvalue)
```

Если p-значение больше 0.05, мы не отвергаем нормальность остатков.

Для сравнения средних двух выборок есть t-тест (его можно взять из `scipy.stats`):

```python
from scipy.stats import ttest_ind

a = rng.normal(0, 1, 100)
b = rng.normal(0.5, 1, 100)
t_stat, p_value = ttest_ind(a, b)
print(t_stat, p_value)   # p_value < 0.05 — средние различаются
```

## Прогнозирование

Обученная модель умеет предсказывать на новых данных:

```python
X_new = sm.add_constant(np.array([1.0, 5.0, 9.0]))
pred = results.predict(X_new)
print(pred)
```

`predict` принимает матрицу с тем же числом столбцов (включая константу). Для результата `ols` проще передать DataFrame с нужными столбцами.

## Диагностика

Хороший анализ не заканчивается коэффициентами. Проверяют:

- значимость коэффициентов: p-значения в `pvalues`;
- качество подгонки: R², скорректированный R² (`rsquared_adj`);
- остатки: графики `results.resid`, тест Жака–Беры на нормальность, тест Бройша–Пагана на гетероскедастичность (`het_breuschpagan`);
- влиятельные наблюдения: `results.get_influence()`.

Это фундамент статистического вывода: модель — не просто числа, а инструмент проверки гипотез о мире.

### Разбор 3
Решение:

```python
import numpy as np
import statsmodels.api as sm
from statsmodels.stats.diagnostic import jarque_bera

rng = np.random.default_rng(7)
x = rng.uniform(0, 10, 200)
y = 2 + 3 * x + rng.normal(0, 1, 200)

results = sm.OLS(y, sm.add_constant(x)).fit()

print(stat, pvalue)
```

Результат (примерно):

```
1.52 0.468
```

Что здесь происходит? Остатки — это отклонения предсказаний модели от реальных y; если модель верна, остатки напоминают шум и распределены нормально. Статистика Жака–Беры проверяет нормальность: при p > 0.05 мы не отвергаем её. Здесь p ≈ 0.47, значит, нормальность остатков не противоречит данным. Это важная предпосылка для доверительных интервалов коэффициентов.

### Разбор 4

import numpy as np

def fit_line(x, y):
    results = sm.OLS(y, sm.add_constant(x)).fit()

import numpy as np
from regression import fit_line

def test_exact_line():
    x = np.arange(5, dtype=float)
    y = 2 * x + 1
    intercept, slope = fit_line(x, y)
    assert abs(intercept - 1) < 1e-6
    assert abs(slope - 2) < 1e-6

Результат: `1 passed`. Что здесь происходит? Если данные лежат точно на прямой, метод наименьших квадратов восстанавливает её с точностью до вычислительной погрешности. Такой тест проверяет реализацию модели без случайных эффектов.

```python
import numpy as np
from regression import fit_line

def test_slope_in_range():
    rng = np.random.default_rng(7)
    x = rng.uniform(0, 10, 200)
    y = 3 + 4 * x + rng.normal(0, 1, 200)
    results, intercept, slope = fit_line(x, y)
    assert 3.5 < slope < 4.5

def test_slope_significant():
    rng = np.random.default_rng(7)
    x = rng.uniform(0, 10, 200)
    y = 3 + 4 * x + rng.normal(0, 1, 200)
    results, intercept, slope = fit_line(x, y)
    assert results.pvalues[1] < 0.05
```

Результат: `2 passed`. Что здесь происходит? Истинный наклон — 4, и оценка по зашумлённой выборке попадает в интервал [3.5, 4.5] с огромным запасом. p-значение 1e-90 говорит: вероятность того, что истинный наклон равен нулю, ничтожна — связь значима. Не забудь обновить тест из задачи 4: теперь `fit_line` возвращает три значения.
