Научные вычисления на Python редко обходятся без библиотеки SciPy. Она построена поверх NumPy и содержит готовые алгоритмы для интегрирования, решения уравнений, интерполяции, оптимизации, обработки сигналов и статистики. В этом уроке мы познакомимся с четырьмя главными подмодулями: `scipy.integrate`, `scipy.interpolate`, `scipy.optimize` и `scipy.signal` (частично). Установить библиотеку можно командой `pip install scipy`.

## Что такое SciPy

SciPy — это не одна вещь, а коллекция подмодулей, каждый из которых решает свой класс задач:

- `scipy.integrate` — численные интегралы и обыкновенные дифференциальные уравнения (ОДУ);
- `scipy.interpolate` — построение функций по табличным данным;
- `scipy.optimize` — поиск минимумов, корней и подгонка параметров;
- `scipy.stats` — распределения и статистические тесты (разберём в следующем уроке);
- `scipy.signal` — фильтры, спектры, свёртки.

Все функции ждут на входе массивы NumPy. Это важно: SciPy не работает со списками Python так же эффективно, поэтому привыкай сразу преобразовывать данные в `np.array`.

## Численное интегрирование: scipy.integrate

Не все интегралы берутся аналитически. Для таких случаев есть численные методы. Функция `quad` вычисляет определённый интеграл методом адаптивной квадратуры:

```python
import numpy as np
from scipy.integrate import quad

f = lambda x: np.exp(-x**2)
value, error = quad(f, 0, 1)
print(value, error)
```

`quad` возвращает кортеж из двух чисел: само значение интеграла и оценку абсолютной погрешности. Здесь мы считаем ∫₀¹ e^{−x²} dx ≈ 0.7468. Заметь: интеграл от гауссовой функции не выражается через элементарные функции — а численно он считается за доли секунды.

Работать `quad` умеет и с бесконечными пределами — это пригодится в задачах:

```python
value, error = quad(f, 0, np.inf)
print(value)  # ≈ 0.8862 = √π / 2
```

А если у тебя не функция, а таблица значений (массив точек), используй `simpson` — интеграл по формуле Симпсона:

```python
from scipy.integrate import simpson

x = np.linspace(0, np.pi, 100)
y = np.sin(x)
print(simpson(y, x))  # ≈ 2.0
```

## Обыкновенные дифференциальные уравнения: solve_ivp

Многие задачи физики и биологии сводятся к ОДУ: «как величина меняется во времени». SciPy решает задачу Коши через `solve_ivp` (initial value problem). Решим уравнение y′ = −y с начальным условием y(0) = 1:

```python
from scipy.integrate import solve_ivp

def rhs(t, y):
    return -y

sol = solve_ivp(rhs, (0, 1), [1.0], t_eval=[0, 1])
print(sol.y[0][-1])  # ≈ 0.3679 = e⁻¹
```

Здесь `(0, 1)` — промежуток времени, `[1.0]` — начальные значения (список, потому что уравнений может быть несколько), а `t_eval` — точки, в которых мы хотим увидеть решение. Аналитическое решение — y(t) = e^{−t}, значит y(1) = e⁻¹ ≈ 0.3679. Метод по умолчанию — RK45 (Рунге–Кутты 4–5 порядка). Массив `sol.y` имеет форму `(число уравнений, число точек)`.

## Интерполяция: scipy.interpolate

У тебя есть экспериментальные точки, а нужна функция, проходящая через них, чтобы вычислять значения между ними. Линейная интерполяция даёт ломаные, а кубические сплайны — гладкие кривые. Класс `CubicSpline` строит кусочный кубический полином, непрерывный вместе со второй производной:

```python
from scipy.interpolate import CubicSpline

x = np.array([0, 1, 2, 3, 4])
y = np.array([0, 1, 4, 9, 16])
cs = CubicSpline(x, y)
print(cs(2.5))  # близко к 6.25
```

Сплайн гарантированно проходит через все узлы: `cs(x[i]) == y[i]`. Это удобно проверять в тестах. Есть и функция `interp1d` с параметром `kind`: `"linear"`, `"cubic"` и другими.

## Оптимизация: scipy.optimize

Поиск минимума функции — одна из самых частых задач: подбор параметров модели, балансировка портфеля, обучение алгоритмов. Универсальная функция `minimize` решает задачу безусловной оптимизации:

```python
from scipy.optimize import minimize

def g(z):
    return (z[0] - 2)**2 + 3

res = minimize(g, [0.0])
print(res.x, res.fun)  # [2.] 3.0
```

`res.x` — точка минимума, `res.fun` — значение функции в ней, `res.success` — флаг успеха. По умолчанию выбирается метод BFGS — квазиньютоновский метод для гладких функций.

Корни уравнений ищутся отдельно — через `root` или `fsolve`:

```python
from scipy.optimize import root

res = root(lambda z: z**3 - 8, [1.0])
print(res.x)  # [2.]
```

## Где это встречается

Интегрирование — в расчётах площадей, вероятностей, физических величин; `solve_ivp` — в моделировании динамики (популяции, радиационный распад, орбиты); интерполяция — при работе с разреженными измерениями сенсоров; оптимизация — везде, от машинного обучения до инженерных конструкций. Это фундамент, на котором стоят более высокоуровневые библиотеки — statsmodels, scikit-learn.

## О границах применимости

Численные методы не панацея — у каждого есть условия корректности. `quad` отлично справляется с гладкими функциями, но не любит сильные особенности (например, разрывы): в таких случаях имеет смысл разбивать интеграл на сегменты. Сплайн `CubicSpline` идеально интерполирует между узлами, однако предсказания **вне** диапазона данных (экстраполяция) часто бессмысленны: сплайн ведёт себя как кубический полином и может резко уйти вверх или вниз. Оптимизатор `minimize` находит локальный минимум — из другой начальной точки он может прийти в другую «яму», поэтому стартовую точку стоит выбирать осмысленно, а для многоэкстремальных функций использовать глобальные методы (мы разберём их в последнем уроке модуля). Понимать ограничения инструмента не менее важно, чем уметь вызывать его API.

### Разбор 4
