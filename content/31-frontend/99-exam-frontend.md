Какой тег должен быть на странице ровно один и содержать основное содержимое?
- main
- header
- section
* Правильный ответ: main
main — основное содержимое страницы, таких тегов должно быть ровно один.

Что делает атрибут aria-label?
- Даёт элементу доступное имя, которое зачитает скринридер
- Добавляет подсказку при наведении
- Меняет цвет элемента
* Правильный ответ: Даёт элементу доступное имя, которое зачитает скринридер
aria-label задаёт имя для технологий доступности, когда видимого текста нет.

Какой атрибут поля ввода включает проверку формата email браузером?
- type="email"
- pattern="email"
- format="email"
* Правильный ответ: type="email"
type="email" заставляет браузер проверять, что введено похожее на email значение.

Почему нужна серверная валидация, если есть клиентская?
- Клиентскую проверку можно обойти, поэтому сервер обязан проверять данные заново
- Чтобы ускорить браузер
- Она не нужна
* Правильный ответ: Клиентскую проверку можно обойти, поэтому сервер обязан проверять данные заново
Браузерную проверку обходят напрямую запросом, поэтому серверная обязательна.

Как объявить CSS-переменную и использовать её?
- :root { --color: #000; } и background: var(--color);
- $color: #000; и background: $color;
- define color #000; и use color
* Правильный ответ: :root { --color: #000; } и background: var(--color);
Переменные объявляются через --имя, используются через var(--имя).

Что делает transition?
- Плавно анимирует изменение свойств между состояниями
- Меняет цвет мгновенно
- Создаёт новую страницу
* Правильный ответ: Плавно анимирует изменение свойств между состояниями
transition задаёт плавный переход при смене значения свойства.

Что делает grid-template-columns: repeat(auto-fit, minmax(220px, 1fr))?
- Создаёт адаптивную сетку: сколько колонок помещается, столько и будет
- Создаёт ровно три колонки
- Запрещает перенос колонок
* Правильный ответ: Создаёт адаптивную сетку: сколько колонок помещается, столько и будет
auto-fit считает колонки по ширине, minmax задаёт минимальный размер каждой.

Какой оператор Jinja2 отвечает за наследование шаблона?
- {% extends %}
- {% include %}
- {% macro %}
* Правильный ответ: {% extends %}
{% extends "base.html" %} подключает родительский шаблон, и он должен быть первой строкой.

Что делает фильтр {{ value|default("нет") }}?
- Возвращает «нет», если value не задано (или пустое)
- Переводит текст в верхний регистр
- Удаляет значение
* Правильный ответ: Возвращает «нет», если value не задано (или пустое)
default подставляет значение по умолчанию, когда переменная отсутствует.

Что делает autoescape=True в Jinja2?
- Включает экранирование вывода: HTML-теги становятся безопасным текстом
- Отключает проверку типов
- Ускоряет рендер
* Правильный ответ: Включает экранирование вывода: HTML-теги становятся безопасным текстом
autoescape нейтрализует XSS, превращая спецсимволы в сущности.
