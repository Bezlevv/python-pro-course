Как расшифровывается метод STAR?
- Situation, Task, Action, Result
- Simple, Technical, Advanced, Review
- Start, Test, Apply, Restart
- Script, Type, Answer, Request
* Правильный ответ: Situation, Task, Action, Result
STAR — схема рассказа о достижении: ситуация, задача, действия, результат.

Какая длина резюме оптимальна для джуна или мидла?
- Одна страница
- Пять страниц
- Только портфолио
- Не имеет значения
* Правильный ответ: Одна страница
Одна страница — стандарт: рекрутер просматривает резюме бегло, лишнее отвлекает.

Что не так с кодом: def add(item, result=[]): result.append(item); return result?
- Дефолтный список создаётся один раз и накапливает данные между вызовами
- Списки нельзя использовать в аргументах
- Такой код не запустится
- Нет ничего плохого
* Правильный ответ: Дефолтный список создаётся один раз и накапливает данные между вызовами
Изменяемый дефолтный аргумент общий для всех вызовов — исправляется через None.

Что делает yield в функции?
- Превращает функцию в генератор
- Завершает программу
- Возвращает значение и завершает функцию
- Объявляет константу
* Правильный ответ: Превращает функцию в генератор
yield приостанавливает выполнение и отдаёт значение по одному, экономя память.

Какова сложность двух вложенных циклов по массиву размера n?
- O(n²)
- O(n)
- O(log n)
- O(1)
* Правильный ответ: O(n²)
Два вложенных цикла дают n × n операций.

Какая структура данных нужна для решения Two Sum за O(n)?
- Словарь (хеш-таблица)
- Кортеж
- Множество в связке с циклом
- Два вложенных цикла
* Правильный ответ: Словарь (хеш-таблица)
Словарь хранит увиденные числа и даёт поиск дополнения за O(1).

Что утверждает CAP-теорема?
- Распределённая система не может одновременно гарантировать согласованность, доступность и устойчивость к разделению сети
- Любая система должна жертвовать доступностью
- Базы данных не бывают распределёнными
- Согласованность всегда важнее
* Правильный ответ: Распределённая система не может одновременно гарантировать согласованность, доступность и устойчивость к разделению сети
CAP описывает компромисс: из трёх свойств одновременно достижимы только два.

Для чего используется Redis в системном дизайне?
- Для кэширования часто читаемых данных в памяти
- Для хранения основного архива документов
- Для замены фронтенда
- Для генерации коротких ссылок
* Правильный ответ: Для кэширования часто читаемых данных в памяти
Redis хранит данные в оперативной памяти, давая ответы за миллисекунды.

Сколько историй стоит подготовить к поведенческому интервью?
- 6–10
- 1–2
- 50+
- Ни одной
* Правильный ответ: 6–10
Карта из 6–10 историй перекрывает основные темы: конфликты, ошибки, дедлайны.

Что важно сделать при получении оффера?
- Попросить время подумать и оценить всю компенсацию
- Немедленно согласиться
- Отказаться без объяснений
- Назвать встречное число мгновенно
* Правильный ответ: Попросить время подумать и оценить всю компенсацию
Оффер — повод спокойно сравнить условия, а не решать в ту же минуту.
