Поиск работы — это процесс, который можно и нужно систематизировать. Если действовать хаотично: «откликнулся пару раз, тишина, значит, я плохой кандидат» — легко разочароваться. Гораздо надёжнее построить воронку: много откликов → несколько собеседований → один-два оффера.

## Где искать вакансии

- **Хедхантер-площадки**: hh.ru, LinkedIn, а также нишевые агрегаторы.
- **Прямые контакты**: писать в компании, которые тебе интересны, напрямую — даже если вакансии нет, можно предложить себя на будущее.
- **Сообщества**: телеграм-чаты, митапы, конференции — многие вакансии закрываются по знакомству.
- **Карьерные ярмарки и стажировки** — быстрый вход для джунов.

## Воронка откликов

Рабочая математика: чтобы получить один оффер, нужно примерно 10–15 собеседований, а для этого — 50–100 откликов. Поэтому нормальная норма — 10–30 откликов в неделю. Не жди ответа на каждый: многие компании молчат, и это нормально.

## Сопроводительное письмо

Короткое письмо на 3 абзаца: кто ты, почему именно эта компания, чем можешь быть полезен. Не дублируй резюме — добавь связку «их задача ↔ твой опыт».

## Этапы найма

Типичная цепочка: HR-скрининг → техническое собеседование (вопросы по языку) → алгоритмическая задача → системный дизайн (для старших позиций) → поведенческое интервью → оффер. Каждый этап — фильтр, и к каждому готовятся отдельно.

## Трекинг заявок

Веди таблицу: компания, дата, этап, следующее действие, ссылка на вакансию. Без этого легко потерять нить в десятке параллельных процессов. Скрипт-трекер ты напишешь в задаче 1.

## Переговоры об оффере

Когда тебе сделали оффер:

1. Поблагодари и попроси время подумать (обычно 2–5 дней).
2. Оцени всю компенсацию: зарплату, бонусы, опционы, обучение, оборудование, удалёнку.
3. Если число ниже ожидаемого — назови свою вилку и аргументируй цифрами рынка.
4. Не играй в «холодную войну» между офферами нагло — но честно скажи, что сравниваешь варианты.
5. Письменно зафиксируй условия до выхода на работу.

## Рост: Junior → Middle → Senior

Уровни отличаются не «количеством знаний», а зоной ответственности:

- **Junior**: делает задачи под присмотром, учится, задаёт вопросы.
- **Middle**: автономно решает задачи среднего размера, участвует в планировании, пишет код, который легко поддерживать.
- **Senior**: проектирует решения, влияет на архитектуру, руководит код-ревью, менторит, думает о бизнес-эффекте.

Как расти: бери задачи чуть сложнее зоны комфорта, проси обратную связь, прокачивай коммуникацию, пиши статьи, выступай, делай пет-проекты. Рост — это не года, а накопленный опыт и меняющаяся ответственность.

## Итог

Системный поиск: 10–30 откликов в неделю, трекинг, подготовка к каждому этапу, грамотные переговоры. А рост — это осознанная работа над ответственностью, а не ожидание «когда-нибудь стану сеньором».

### Разбор 1
Решение:

```python
import json
import sys
from datetime import date

FILENAME = "jobs.json"

def load_jobs():
    try:
        with open(FILENAME, encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return []

def save_jobs(jobs):
    with open(FILENAME, "w", encoding="utf-8") as f:
        json.dump(jobs, f, ensure_ascii=False, indent=2)

def add_job():
    company = input("Компания: ")
    position = input("Позиция: ")
    status = input("Статус (sent/interview/offer/rejected): ")
    jobs = load_jobs()
    jobs.append({"company": company, "position": position,
                 "date": date.today().isoformat(), "status": status})
    save_jobs(jobs)
    print("Заявка добавлена")

def stats():
    jobs = load_jobs()
    counters = {}
    for job in jobs:
        counters[job["status"]] = counters.get(job["status"], 0) + 1
    if not counters:
        print("Пока нет заявок")
    for status, count in counters.items():
        print(f"{status}: {count}")

if __name__ == "__main__":
    if len(sys.argv) > 1 and sys.argv[1] == "add":
        add_job()
    else:
        stats()
```

Запускаем:

```bash
python job_tracker.py add
python job_tracker.py
```

Что здесь происходит? Скрипт хранит заявки в JSON — это удобный человекочитаемый формат. `load_jobs` читает файл, а если его нет — возвращает пустой список. Режим `add` спрашивает данные с клавиатуры и дописывает запись, режим без аргументов печатает статистику по статусам. Такой трекер помогает видеть воронку: сколько откликов отправлено, сколько дошло до интервью, сколько стало офферами.

### Разбор 4
План роста на 6 месяцев:

- **Месяц 1**: цель — закрыть пробелы: Python, алгоритмы, SQL. Инструменты: задачи на LeetCode (2–3 в неделю), курс по SQL, разбор чужих решений. Критерий: решаешь задачи уровня easy-medium без подсказок.
- **Месяц 2**: цель — два пет-проекта на GitHub. Инструменты: FastAPI или Django, PostgreSQL, Docker, README к каждому проекту. Критерий: репозитории открыты, запускаются по инструкции, есть скриншоты.
- **Месяц 3**: цель — задачи сложнее на работе/стажировке. Инструменты: попросить ментора назначить задачи за пределами зоны комфорта. Критерий: закрыл две задачи, которые раньше казались слишком сложными.
- **Месяц 4**: цель — понять архитектуру. Инструменты: книга/курс по системному дизайну, разбор архитектуры своего проекта. Критерий: можешь нарисовать схему сервиса и объяснить выбор технологий.
- **Месяц 5**: цель — дичь. Инструменты: менторство новичка, статья на habr или пост в телеграм. Критерий: кто-то пришёл за советом, статья набрала первые отзывы.
- **Месяц 6**: цель — подтвердить уровень. Инструменты: собеседования в 2–3 компании, сбор обратной связи. Критерий: получаешь оффер на позицию Middle или фидбек «почти Middle, чего не хватает».

Пять признаков Middle: 1) коллеги приходят к тебе за ревью; 2) задачи берутся без подробного ТЗ; 3) ты сам оцениваешь сроки; 4) ты влияешь на выбор технологий; 5) ты менторишь джунов.

Что здесь происходит? План превращает абстрактное «хочу вырасти» в измеримые шаги. У каждого месяца — цель, инструменты и критерий. Признаки Middle — это не «выучил больше», а изменение ответственности: к тебе приходят за решениями.

Что здесь происходит? Критерии и веса отражают твои приоритеты, и честный подсчёт помогает не вестись на эмоции «там платят больше». Ментор в оффере А — долгосрочный актив: быстрее рост, меньше ошибок. А удалёнка экономит время на дорогу. Такой подход делает решение осознанным, а не импульсивным.
