# Формат контента курса «PythonПро»

Все уроки живут в папке `content/`. Платформа читает их при запуске
(`python manage.py load_content`).

## Структура папок

```
content/
├── 01-basics/
│   ├── module.md            ← front-matter модуля
│   ├── 01-python-intro.md   ← урок
│   └── ...
├── 02-advanced/
│   └── ...
```

Имя папки = слаг модуля. Имя файла урока = слаг урока (без `.md`), с числовым префиксом порядка: `01-...`, `02-...`.

## Файл module.md (метаданные модуля)

```
---
title: Основы Python
order: 1
description: Первые шаги: переменные, типы, условия, циклы, функции.
icon: 🚀
---
```

Поля: `title` (обязательно), `order` (число), `description`, `icon` (один эмодзи).

## Файл урока

Урок состоит из front-matter и Markdown-тела с тремя служебными блоками.

### Front-matter

```
---
title: Переменные и типы данных
summary: Что такое переменная, числа, строки, булевы значения.
order: 2
duration: 25 мин
difficulty: beginner
---
```

| Поле | Значения |
|---|---|
| `title` | Название урока (обязательно) |
| `summary` | 1–2 предложения для карточки урока |
| `order` | Порядок внутри модуля (число) |
| `duration` | Примерное время, например `25 мин` |
| `difficulty` | `beginner` / `intermediate` / `advanced` |
| `tags` | Необязательно: теги через запятую, например `ооп, классы, наследование` |
| `exam` | Необязательно: `true`, если это экзамен (только викторина, без теории и задач; порог сдачи — 80%) |

### Тело урока

1. **Теория** — всё, что вне служебных блоков. Markdown: заголовки `##`, списки, таблицы, код в ```python-блоках.
2. **Задачи** — внутри блока `<!--TASK--> ... <!--/TASK-->`. **Минимум 5 задач на урок.** Каждая задача оформляется заголовком `### Задача N` (N — номер).
3. **Подсказки** — внутри `<!--HINT--> ... <!--/HINT-->`, по одной на задачу: `### Подсказка N`.
4. **Разборы** — внутри `<!--SOLUTION--> ... <!--/SOLUTION-->`, по одному на задачу: `### Разбор N`.
5. **Викторина** — внутри `<!--QUIZ--> ... <!--/QUIZ-->`. **Минимум 5 вопросов на урок.**
6. **Ожидаемый вывод** (необязательно) — внутри `<!--EXPECTED_OUTPUT--> ... <!--/EXPECTED_OUTPUT-->`. Если задан, песочница сравнивает вывод кода ученика с этим текстом.
7. **Тест-кейсы** (необязательно) — внутри `<!--TESTS--> ... <!--/TESTS-->` для автопроверки по нескольким входам. Каждый тест — `### Тест N`, внутри два блока кода: вход (после `Ввод:`) и ожидаемый вывод (после `Ожидаемый вывод:`).

```
<!--TESTS-->
### Тест 1
Ввод:
```
5
```
Ожидаемый вывод:
```
25
```
### Тест 2
Ввод:
```
7
```
Ожидаемый вывод:
```
49
```
<!--/TESTS-->
```

Если тест-кейсов нет, используется проверка по `EXPECTED_OUTPUT` (а если нет и его — просто показ вывода).

### Формат викторины

Каждый вопрос отделяется пустой строкой. Первая строка блока — вопрос, далее варианты через `- `, строка `* Правильный ответ: ...` указывает верный вариант, после неё — объяснение.

```
<!--QUIZ-->
Что выведет print(2 ** 3)?
- 6
- 8
- 9
* Правильный ответ: 8
Потому что ** — это возведение в степень.

Какой тип у результата деления 7 / 2?
- int
- float
- complex
* Правильный ответ: float
В Python 3 обычное деление всегда возвращает float.
<!--/QUIZ-->
```

Требования:

- Только русский язык, обращение на «ты».
- Теория: минимум 250 слов плюс рабочие примеры кода. Каждая новая идея — с примером.
- **Норма для уроков (обновлённая): минимум 7 задач, 7 подсказок, 7 разборов и 12 вопросов викторины.**
- **Минимум 1 схема Mermaid в теории** (блок ```mermaid): блок-схема, граф зависимостей, диаграмма последовательности или mindmap. Схема должна быть по теме урока и читаться без пояснений.
- Если в уроке есть блок `<!--TESTS-->` — 5–8 тест-кейсов.
- Номера задач, подсказок и разборов должны совпадать: `### Задача 1` ↔ `### Подсказка 1` ↔ `### Разбор 1`.
- Внутри текста задачи не используй заголовки `###` ни для чего другого.
- Задача: минимум 60 слов; опиши ожидаемый результат (что должно вывестись на экран).
- Подсказка: 25+ слов, направление к решению, но не полное решение.
- Разбор: полное решение + объяснение каждого шага (100+ слов).
- Вопросы викторины: 12 и более на урок (для новых уроков рекомендуется 12–15).
- Код должен быть исполняемым и использовать только реальные API.
- Не используй нестандартную разметку; только чистый Markdown + Mermaid-схемы.
- Не редактируй `module.md` и чужие уроки.
