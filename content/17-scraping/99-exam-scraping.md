Зачем парсеру использовать requests.Session() вместо одиночных requests.get()?
- Чтобы запросы летели быстрее
- Чтобы сохранять куки и другие настройки между запросами
- Чтобы автоматически обходить блокировки
- Чтобы не указывать тайм-ауты
* Правильный ответ: Чтобы сохранять куки и другие настройки между запросами
Сессия — контейнер: куки, заголовки и адаптеры живут в ней между запросами, как в одном «визите».

Почему без заголовка User-Agent парсер может не получить данные?
- Без него сервер не знает, кто запрашивает страницу, и может отдать другой контент или заблокировать запрос
- Потому что без него запрос нельзя отправить
- Потому что он ускоряет сеть
- Он никак не влияет на результат
* Правильный ответ: Без него сервер не знает, кто запрашивает страницу, и может отдать другой контент или заблокировать запрос
User-Agent идентифицирует клиента; пустой или подозрительный заголовок — повод отдать «урезанную» версию или отклонить запрос.

Как в BeautifulSoup выбрать все элементы с классом quote?
- soup.find_all("div", class="quote")
- soup.select("div.quote")
- soup.select_one("div.quote")
- soup.find("div.quote")
* Правильный ответ: soup.select("div.quote")
select() с CSS-селектором возвращает список всех совпадений; .класс соответствует class="quote".

Что вернёт soup.find_all("a"), если на странице нет ни одной ссылки?
- None
- Пустой список
- Пустую строку
- Исключение
* Правильный ответ: Пустой список
find_all() всегда возвращает список — возможно, пустой. Это удобно: можно спокойно итерироваться.

Почему requests не видит контент динамических страниц?
- Потому что такие страницы запрещены для скачивания
- Потому что requests не выполняет JavaScript, а контент создаётся уже в браузере
- Потому что requests работает только с JSON
- Он видит весь контент без исключений
* Правильный ответ: Потому что requests не выполняет JavaScript, а контент создаётся уже в браузере
Для таких страниц нужен настоящий браузер: Selenium или Playwright.

Что делает page.wait_for_selector("div.quote") в Playwright?
- Замедляет загрузку страницы
- Ждёт появления элемента div.quote, максимум заданное время
- Ищет текст внутри div.quote
- Делает скриншот страницы
* Правильный ответ: Ждёт появления элемента div.quote, максимум заданное время
Это явное ожидание: оно экономнее time.sleep() и не «спит в слепую».

Какой признак показывает, что пагинация по номерам страниц закончилась?
- Страница вернула код 200
- Страница вернула пустой список данных
- Параметр page стал больше 50
- Изменился заголовок Content-Type
* Правильный ответ: Страница вернула пустой список данных
Пустая порция — сигнал конца; цикл завершается. Плюс полезен искусственный лимит страниц.

Что такое robots.txt и зачем его проверять?
- Файл с рекламой сайта
- Файл с правилами, какие части сайта можно сканировать
- Файл с паролями администраторов
- Лог запросов сервера
* Правильный ответ: Файл с правилами, какие части сайта можно сканировать
Проверка через urllib.robotparser.RobotFileParser().can_fetch("*", url) — первый шаг вежливого парсера.

Что означает HTTP-код 429 и как правильно реагировать?
- Страница не найдена, перейти дальше
- Слишком много запросов: надо подождать (Retry-After) и использовать экспоненциальную паузу
- Требуется авторизация
- Ошибка на стороне клиента, повторить немедленно
* Правильный ответ: Слишком много запросов: надо подождать (Retry-After) и использовать экспоненциальную паузу
429 — сигнал притормозить. Пауза растёт с каждой попыткой, чтобы не перегружать сервер.

Как в SQLite не дать дубликатам попасть в базу при повторном запуске?
- Использовать csv.DictWriter
- Задать UNIQUE(text, author) и вставлять через INSERT OR IGNORE
- Проверять count перед каждой вставкой
- Использовать только SELECT, без INSERT
* Правильный ответ: Задать UNIQUE(text, author) и вставлять через INSERT OR IGNORE
Ограничение уникальности на уровне таблицы + IGNORE пропускает уже существующие строки.
