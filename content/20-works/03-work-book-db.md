Эта работа — первое настоящее приложение в твоей практике: не скрипт «запустил и посмотрел», а интерактивная программа с меню, которая хранит данные между запусками. Здесь ты применишь объектно-ориентированное программирование (классы, методы, магические методы), сериализацию в JSON и аккуратную обработку пользовательского ввода.

## Постановка задачи

Нужно написать консольное приложение `book_db.py` — «личную библиотеку». В ней хранятся книги с полями: название, автор, год издания, жанр, статус (прочитана или нет) и оценка по 10-балльной шкале (необязательно). Данные сохраняются в JSON-файле и загружаются при следующем запуске. Приложение работает через меню: пользователь вводит номер команды, программа выполняет действие и снова показывает меню.

Чему ты научишься. Во-первых, проектированию классов: класс `Book` описывает одну книгу, класс `Library` — коллекцию книг и операции с ней. Во-вторых, сериализации: превращение объектов в JSON и обратно через словари. В-третьих, построению пользовательского интерфейса: цикл «меню → действие → меню», устойчивость к неверному вводу.

## Требования к программе

- Класс `Book`: поля `title`, `author`, `year`, `genre`, `read` (bool), `rating` (int или None); метод `__str__` для красивого вывода; методы `to_dict()` и `from_dict(data)`.
- Год должен быть разумным числом (например, 1450–2100); при неверном значении — исключение `ValueError`.
- Класс `Library`: методы `add_book(book)`, `remove_book(index)`, `find_title(substr)`, `find_author(substr)`, `stats()`, `__len__`, `__str__`.
- Поиск — по подстроке без учёта регистра; находятся все совпадения.
- Сохранение в `library.json` автоматически после каждого изменения; загрузка при старте; если файла нет — пустая библиотека.
- Меню с командами: 1 — показать все книги, 2 — добавить, 3 — удалить по номеру, 4 — найти по названию, 5 — найти по автору, 6 — статистика, 0 — выход.
- Приложение не должно падать ни на каком вводе: неверный номер команды, пустой ввод, буква вместо числа и т. д.

### Разбор 1

```python
class Book:
    def __init__(self, title, author, year, genre, read=False, rating=None):
        if not (1450 <= year <= 2100):
            raise ValueError(f"Некорректный год: {year}")
        if rating is not None and not (1 <= rating <= 10):
            raise ValueError(f"Оценка должна быть от 1 до 10: {rating}")
        self.title = title
        self.author = author
        self.year = year
        self.genre = genre
        self.read = read
        self.rating = rating

    def __str__(self):
        status = "прочитана" if self.read else "не прочитана"
        rating = f", оценка {self.rating}" if self.rating else ""
        return (f"«{self.title}» — {self.author}, {self.year}, "
                f"{self.genre}, {status}{rating}")
```

Конструктор сразу валидирует данные: неверный год или оценка вызывает `ValueError` — плохие данные не попадут в библиотеку. `__str__` — магический метод: он вызывается автоматически при `print(book)`. Заметь: `if self.rating` работает, потому что `None` — ложное значение, а числа — истинные.

### Разбор 2

```python
class Book:
    def __init__(self, title, author, year=2000, genre="", read=False, rating=None):
        self.title = title
        self.author = author
        self.year = year
        self.genre = genre
        self.read = read
        self.rating = rating

    def to_dict(self):
        return {
            "title": self.title,
            "author": self.author,
            "year": self.year,
            "genre": self.genre,
            "read": self.read,
            "rating": self.rating,
        }

    @classmethod
    def from_dict(cls, data):
        return cls(title=data["title"], author=data["author"], year=data["year"],
                   genre=data["genre"], read=data["read"], rating=data["rating"])

    def __eq__(self, other):
        return (self.title == other.title and self.author == other.author)
```


`to_dict` превращает объект в обычный словарь — именно его можно записать в JSON. `from_dict` — метод класса (`@classmethod`): он создаёт экземпляр из словаря; `cls` здесь — сам класс `Book`. `__eq__` определяет, когда две книги считаются одинаковыми: по названию и автору — это пригодится для проверки дубликатов.

### Разбор 3

```python
class Library:
    def __init__(self):
        self.books = []

    def add_book(self, book):
        for existing in self.books:
            if existing == book:
                print(f"Такая книга уже есть: {book.title}")
                return
        self.books.append(book)

    def remove_book(self, index):
        if 0 <= index < len(self.books):
            removed = self.books.pop(index)
            print(f"Удалено: {removed.title}")
        else:
            print("Неверный номер книги.")

    def __len__(self):
        return len(self.books)

    def find_title(self, substr):
        return [b for b in self.books if substr.lower() in b.title.lower()]

    def find_author(self, substr):
        return [b for b in self.books if substr.lower() in b.author.lower()]
```

`add_book` использует `__eq__` для проверки дубликатов. `remove_book` защищена проверкой границ — неверный индекс даёт сообщение, а не исключение. Поиск работает по подстроке и не чувствителен к регистру: `"СТРУГАЦКИЕ" in "Стругацкие".lower()` — `True`. Список возвращается, даже если совпадений нет, — пустой список.

### Разбор 4

```python
import json


class Library:
    def __init__(self):
        self.books = []

    def save(self, path):
        with open(path, "w", encoding="utf-8") as f:
            json.dump([b.to_dict() for b in self.books], f,
                      ensure_ascii=False, indent=2)

    @classmethod
    def load(cls, path):
        lib = cls()
        try:
            with open(path, encoding="utf-8") as f:
                data = json.load(f)
            for item in data:
                lib.add_book(Book.from_dict(item))
        except (FileNotFoundError, json.JSONDecodeError):
            pass
        return lib
```


`save` записывает список словарей. `ensure_ascii=False` сохраняет русские буквы как есть (иначе JSON был бы полон `\u...`-последовательностей), `indent=2` делает файл читаемым. `load` — метод класса: он создаёт пустую библиотеку и наполняет её из файла. Если файла нет или он повреждён, программа молча начинает с пустой библиотеки — это устойчивое поведение.
