С чего нужно начать написание любого проекта?
- С написания кода
- С формулировки требований и плана
- С настройки сервера
- С выбора цвета интерфейса
* Правильный ответ: С формулировки требований и плана
План и требования определяют объём, структуру и критерии готовности.

Что такое «портфолио-проект»?
- Проект, который можно показать и объяснить на собеседовании
- Любой учебный проект
- Проект с открытым исходным кодом
- Проект, который обязательно нужно монетизировать
* Правильный ответ: Проект, который можно показать и объяснить на собеседовании
Ценно не количество, а качество: читаемый код, тесты, документация, README.

Зачем проекту нужны автоматические тесты?
- Чтобы быстрее писать код
- Чтобы гарантировать, что изменения не ломают существующее поведение
- Чтобы заменить документацию
- Чтобы сократить количество файлов
* Правильный ответ: Чтобы гарантировать, что изменения не ломают существующее поведение
Тесты — страховка при рефакторинге и развитии проекта.

Какой инструмент чаще всего используют для деплоя Python-приложения в Docker?
- Gunicorn + Dockerfile
- Только python runserver
- Excel
- Jupyter Notebook
* Правильный ответ: Gunicorn + Dockerfile
Gunicorn — продакшен-WSGI-сервер; Dockerfile описывает образ приложения.

Что такое «MVP»?
- Минимально жизнеспособный продукт с ядром функциональности
- Максимально всё объёмный продукт
- Продукт для внутреннего использования
- Недоработанный код
* Правильный ответ: Минимально жизнеспособный продукт с ядром функциональности
MVP позволяет быстро проверить гипотезу и получить обратную связь.

Зачем нужен файл README.md в проекте?
- Чтобы описать, как запустить и использовать проект
- Он нужен только для GitHub
- Чтобы хранить секреты
- Он создаётся автоматически и не нужен
* Правильный ответ: Чтобы описать, как запустить и использовать проект
README — точка входа для любого, кто открывает репозиторий.

Что означает «рефакторинг»?
- Изменение внутренней структуры кода без изменения поведения
- Добавление новых функций
- Исправление бага
- Переписывание проекта с нуля
* Правильный ответ: Изменение внутренней структуры кода без изменения поведения
Рефакторинг улучшает читаемость и поддерживаемость, не меняя результаты.

Как правильно хранить секреты (API-ключи, пароли)?
- В переменных окружения или секрет-хранилище
- В коде рядом с логикой
- В README
- В имени переменных
* Правильный ответ: В переменных окружения или секрет-хранилище
Секреты не должны попадать в git — это общепринятая практика безопасности.

Что такое «code review»?
- Проверка кода другим разработчиком перед слиянием
- Автоматическое форматирование кода
- Запуск тестов
- Описание кода в комментариях
* Правильный ответ: Проверка кода другим разработчиком перед слиянием
Ревью выявляет ошибки и улучшает качество кода.

Какой критерий говорит, что проект «готов»?
- Выполнены критерии, заданные в требованиях, и проект проходит проверки
- Код компилируется
- Проект нравится автору
- Проект имеет более 1000 строк
* Правильный ответ: Выполнены критерии, заданные в требованиях, и проект проходит проверки
Готовность определяется заранее определёнными критериями: функциональность, тесты, документация.
