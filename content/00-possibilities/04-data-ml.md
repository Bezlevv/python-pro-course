## Данные — новая нефть, Python — буровая установка

Каждый день человечество создаёт огромные объёмы данных: покупки, посты, датчики, видео, заказы. Но сами по себе данные ничего не стоят — ценность появляется, когда их **анализируют** и превращают в выводы: «кто чаще покупает зимой», «какая тема набирает популярность», «прогноз погоды на завтра». Именно здесь Python — король.

В этом уроке мы пройдём путь от простой статистики до нейросетей и больших языковых моделей (LLM) — тех самых, что лежат в основе ChatGPT и подобных ассистентов.

## Аналитика: Pandas и NumPy

Главные инструменты аналитика на Python:

- **Pandas** — работа с таблицами данных: загрузка, фильтрация, группировка, сводные таблицы. Название произошло от «panel data» — табличных данных.
- **NumPy** — быстрые вычисления с массивами чисел: математика, линейная алгебра, случайные величины.
- **Matplotlib** — графики и визуализация: линии, столбцы, тепловые карты.

Вот как выглядит классическая аналитика на Pandas:

```python
import pandas as pd

# Таблица оценок учеников
data = {
    "Имя": ["Аня", "Боря", "Витя"],
    "Оценка": [5, 4, 3],
}
df = pd.DataFrame(data)

print(df)              # вся таблица
print(df["Оценка"].mean())  # средняя оценка
```

Установи Pandas (`pip install pandas`), и ты получишь мини-аналитический центр. Но даже без Pandas стандартная библиотека Python уже умеет считать статистику — давай проверим.

## Демо: статистика без сторонних библиотек

```python
import statistics

grades = [4, 5, 3, 5, 4, 4, 5, 3]
print("Средняя оценка:", statistics.mean(grades))
print("Медиана:", statistics.median(grades))
print("Самая частая оценка:", statistics.mode(grades))
print("Максимум:", max(grades), "Минимум:", min(grades))
```

`statistics.mean()` — среднее арифметическое, `median()` — медиана (середина ряда), `mode()` — самое частое значение. Этого набора уже хватает, чтобы рассказать о данных главное.

## Машинное обучение: как учат компьютеры

Машинное обучение (ML) — это когда мы не пишем правила вручную, а показываем программе примеры, и она сама находит закономерности. Библиотека **scikit-learn** делает это доступным:

```python
# Пример: предсказание по простому правилу
# (упрощённо — настоящий ML требует данных и модели)
X = [[1], [2], [3], [4]]
y = [2, 4, 6, 8]  # y = 2 * x

from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X, y)
print("Предсказание для x=5:", model.predict([[5]]))
```

Модель сама «догадалась», что зависимость — удвоение. Так работают предсказания цен, спроса и прогнозы.

## Нейросети: PyTorch и TensorFlow

Нейросеть — это программа, вдохновлённая устройством мозга: миллионы «нейронов» учатся распознавать образы. На Python строят нейросети двух главных фреймворков:

- **PyTorch** (разработан компанией Meta) — любимец исследователей ИИ;
- **TensorFlow** (компания Google) — широко используется в промышленности.

Именно на Python тренируются модели, которые распознают лица, переводят речь, пишут код и рисуют картинки. Ты не обязан сразу понимать математику внутри — на старте важно увидеть, что входом в нейросеть служат просто числа (пиксели, слова), а выходом — предсказание.

## LLM: большие языковые модели

LLM (Large Language Model — большая языковая модель) — это нейросеть, обученная на огромных объёмах текста. Она умеет продолжать текст, отвечать на вопросы, писать код и переводить. ChatGPT, Claude, Gemini — все они построены на таких моделях, и Python — главный язык, на котором их создают и используют.

Python позволяет подключаться к LLM через API. Например, через OpenAI API можно отправить промпт и получить ответ:

```python
# Упрощённая схема реального запроса к LLM
import openai

client = openai.OpenAI(api_key="твой_ключ")
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Напиши приветствие на Python"}],
)
print(response.choices[0].message.content)
```

Ключ API — это «пропуск» к сервису. Мы не будем тратить ключи на этом уроке, но важно понять главное: Python — это пульт управления для ИИ. Исследователи и инженеры пишут на нём и сами модели, и приложения вокруг них.

### Разбор 1
Решение:

```python
import statistics

grades = [3, 4, 5, 4, 4, 5, 3, 5, 5, 4]
print("Средняя оценка:", round(statistics.mean(grades), 2))
print("Медиана:", statistics.median(grades))
print("Самая частая оценка:", statistics.mode(grades))
print("Максимум:", max(grades), "Минимум:", min(grades))
```

Результат:

```
Средняя оценка: 4.2
Медиана: 4.0
Самая частая оценка: 4
Максимум: 5 Минимум: 3
```

Что здесь происходит? `statistics.mean(grades)` складывает все оценки и делит на их количество. `round(..., 2)` оставляет два знака после запятой. Медиана `statistics.median()` — это значение «в середине» упорядоченного ряда: половина учеников выше него, половина ниже. Мода `statistics.mode()` — самое встречающееся значение. Такой набор показателей — стандарт любого аналитического отчёта, от школьного журнала до зарплатной статистики целой компании.

### Разбор 2
Решение:

```python
from collections import Counter

text = "python учить интересно python мощный python простой язык"
words = text.split()
frequency = Counter(words)

print("Топ-3 слова:")
for word, count in frequency.most_common(3):
    print(word, ":", count)

print("Всего слов:", len(words))
```

Результат:

```
Топ-3 слова:
python : 3
учить : 1
интересно : 1
Всего слов: 7
```

Что здесь происходит? Строка `text.split()` разбивается по пробелам на список из семи слов. `Counter(words)` сразу строит словарь частот: какое слово сколько раз встречается. `most_common(3)` возвращает три самые частые пары `(слово, количество)`, которые мы и печатаем. Такая частотность слов — основа анализа текстов: от поиска ключевых слов до обучения моделей. Именно с таких простых счётчиков начинается обработка естественного языка.

### Разбор 3
Решение:

```python
grades = {"Аня": 5, "Боря": 3, "Витя": 4, "Гоша": 2, "Даша": 5}

excellent = []
need_work = []

for name, grade in grades.items():
    if grade >= 4:
        excellent.append(name)
    else:
        need_work.append(name)

print("Отличники:", excellent)
print("Нужно подтянуть:", need_work)
```

Результат:

```
Отличники: ['Аня', 'Витя', 'Даша']
Нужно подтянуть: ['Боря', 'Гоша']
```

Что здесь происходит? `grades.items()` возвращает пары «ключ — значение», и мы их «распаковываем» в переменные `name` и `grade`. Условие `if grade >= 4:` (в Python число 5 — это `int`, и сравнение работает напрямую) определяет, в какой список добавить имя. Такая группировка — это, по сути, операция `groupby` из Pandas, только своими руками: мы разбили данные на категории. Именно так аналитики делят клиентов на сегменты, товары — на категории, учеников — на группы.

### Разбор 4

```python
import csv

with open("marks.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["имя", "оценка"])
    writer.writerow(["Аня", 5])
    writer.writerow(["Боря", 4])
    writer.writerow(["Витя", 3])
    writer.writerow(["Гоша", 5])
    writer.writerow(["Даша", 4])

with open("marks.csv", encoding="utf-8") as f:
    rows = list(csv.reader(f))

total = 0
for name, grade in rows[1:]:
    total += int(grade)

average = round(total / len(rows[1:]), 2)
print("Сумма оценок:", total)
print("Средняя оценка:", average)
```

Результат:

```
Сумма оценок: 21
Средняя оценка: 4.2
```

Что здесь происходит? `csv.writer` записывает строки таблицы в файл. `csv.reader` читает их обратно как списки. `rows[1:]` отбрасывает строку-заголовок. Мы проходим по строкам, превращаем строку оценки в число через `int(grade)` и копим сумму. Этот скрипт — прообраз настоящего ETL-процесса: извлечь данные из файла, преобразовать и посчитать. CSV — универсальный формат обмена данными, его понимают Excel, Google Таблицы и все языки программирования.

### Разбор 5
Решение:

```python
from collections import Counter

name = "Александр"
counter = Counter(name)

print("Имя:", name)
print("Длина имени:", len(name))
print("Самая частая буква:", counter.most_common(1)[0][0])
print("Уникальных букв:", len(counter))
```

Результат:

```
Имя: Александр
Длина имени: 9
Самая частая буква: а
Уникальных букв: 8
```

Что здесь происходит? `Counter(name)` принимает строку и считает каждый символ. `most_common(1)` возвращает список из одной пары `(буква, количество)`, поэтому `[0]` берёт пару, а `[0][0]` — букву из пары. `len(counter)` — количество ключей, то есть уникальных букв. Ты только что провёл полноценный мини-эксперимент: собрал данные, посчитал показатели, сделал выводы. Именно так начинается любой исследовательский проект — с любопытства к собственным данным.
