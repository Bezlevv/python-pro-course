Почему Python считают отличным первым языком программирования?
- Его код читается почти как английский текст, и у него огромное сообщество
- Он единственный язык, который работает без компьютера
- Он не требует изучения синтаксиса
* Правильный ответ: Его код читается почти как английский текст, и у него огромное сообщество
Читаемость и поддержка сообщества делают старт лёгким, а перспективы — огромными.

Что делает import this в Python?
- Выводит «Дзен Python» — философию языка
- Обновляет Python до новой версии
- Показывает список установленных библиотек
* Правильный ответ: Выводит «Дзен Python» — философию языка
import this печатает принципы дизайна Python, например «Красивое лучше уродливого».

Какой модуль Python удобнее всего для работы с файлами и папками?
- pathlib
- random
- statistics
* Правильный ответ: pathlib
pathlib представляет пути как объекты с методами mkdir, rename, iterdir.

Что делает цикл while True в сочетании с break?
- Выполняется бесконечно, пока break не выйдет из цикла
- Выполняется ровно один раз
- Выполняется до первого ввода
* Правильный ответ: Выполняется бесконечно, пока break не выйдет из цикла
Это основа ботов: слушать сообщения и выходить по команде.

Какой модуль позволяет делать HTTP-запросы без установки дополнительных библиотек?
- urllib.request
- turtle
- hashlib
* Правильный ответ: urllib.request
urllib.request входит в стандартную библиотеку и умеет обращаться к URL.

Какая библиотека является главным инструментом аналитики табличных данных?
- Pandas
- tkinter
- socket
* Правильный ответ: Pandas
Pandas умеет загружать, фильтровать и группировать данные.

Какая библиотека позволяет создавать десктопные окна без установки?
- tkinter
- pygame
- Kivy
* Правильный ответ: tkinter
tkinter встроен в Python и создаёт окна с кнопками и надписями.

Что делает hashlib.sha256(text.encode()).hexdigest()?
- Возвращает хеш текста строкой
- Шифрует текст, чтобы расшифровать потом
- Сжимает текст
* Правильный ответ: Возвращает хеш текста строкой
Хеш — необратимый «отпечаток» данных; по нему нельзя восстановить текст.

На каком фреймворке Python работает Instagram?
- Django
- Flask
- Kivy
* Правильный ответ: Django
Instagram — один из крупнейших проектов на Django.

Что означает буква M в SMART?
- Measurable — измеримая цель
- More — больше
- Memory — память
* Правильный ответ: Measurable — измеримая цель
У цели должен быть признак успеха, по которому видно, достигнута ли она.
