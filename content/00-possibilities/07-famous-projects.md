## Python уже изменил мир. Ты следующий

Иногда кажется, что программирование — это про экраны и скобки. Но за каждым крупным сервисом, которым ты пользуешься каждый день, стоит код, и в огромном количестве случаев этот код — на Python. Давай прогуляемся по известным проектам и увидим, где именно живёт наш язык. Это не просто интересные факты — это доказательства того, что Python способен на большие дела.

## Веб-гиганты

- **Instagram.** Один из крупнейших проектов на Django — фреймворке Python. Команда Instagram публично рассказывала, что их серверная часть работает на Django и Python, и что это позволяет быстро развивать функции для сотен миллионов пользователей.
- **YouTube.** Видеосервис начинался на Python: ранние версии использовали Python для ключевых частей платформы, и этот код работал в огромных масштабах.
- **Dropbox.** Популярное облачное хранилище: десктопный клиент изначально был написан почти полностью на Python. Основатель Дрю Хьюстон начинал именно с Python.
- **Google.** Python — один из официальных языков Google. Ранний краулер поисковика (программа, обходящая сайты) был написан на Python, и до сих пор Google активно использует его во внутренних инструментах.
- **Spotify, Pinterest, Reddit.** Бэкенд-сервисы этих компаний в значительной степени построены на Python.

## Наука и космос

- **NASA.** Космическое агентство использует Python для обработки изображений со спутников, расчётов орбит и анализа научных данных. Многие инструменты миссий — на Python.
- **CERN.** Европейская лаборатория физики частиц (Большой адронный коллайдер) активно использует Python для анализа данных экспериментов.
- **Научные вычисления.** NumPy, SciPy и Matplotlib — стандарт мировой науки: от биоинформатики до астрофизики.

## Игры и развлечения

- **Civilization IV.** Культовая пошаговая стратегия позволяла модифицировать игру именно на Python — игровое сообщество создало тысячи модов.
- **EVE Online.** Космическая MMO-игра использует Python (версию Stackless Python) для логики игрового мира, обслуживая десятки тысяч одновременных игроков.
- **Blender.** Профессиональный 3D-редактор: его скриптовый язык — Python, и вся автоматизация анимаций и эффектов пишется на нём.

## Искусственный интеллект

- **PyTorch.** Фреймворк для нейросетей, созданный в Meta, сделал Python стандартом ИИ-исследований.
- **OpenAI и ChatGPT.** Модели GPT обучались и обслуживаются на Python-экосистеме: PyTorch, а также внутренние инструменты на Python.
- **Все главные LLM.** Практически все большие языковые модели — Gemini, Llama, Claude — так или иначе живут в Python-мире: обучение, обработка данных, API.

## Финансы

Банки, биржи и финтех-компании используют Python для анализа рисков, торговых алгоритмов и прогнозов. Простота и математические библиотеки сделали Python фактическим стандартом количественных финансов.

## Что это значит для тебя

Все эти проекты когда-то начинались с простых скриптов — таких же, какие ты уже писал на прошлых уроках. Никто не «родился» с умением писать Instagram или игру: сначала были сотни маленьких программ, ошибки, любопытство. Python не делает тебя гением автоматически, но он убирает барьер между мыслью и работающим кодом — и это самое важное.

Давай завершим урок мини-демо, которое напомнит: даже из простых кирпичиков строятся большие системы.

```python
import random

facts = [
    "Instagram работает на Django — фреймворке Python.",
    "Клиент Dropbox исторически написан на Python.",
    "Ранний краулер Google был написан на Python.",
    "NASA использует Python для обработки космических данных.",
    "EVE Online использует Python для логики игрового мира.",
]
print(random.choice(facts))
```

### Разбор 1
Решение:

```python
import random

facts = [
    "Instagram работает на Django — фреймворке Python.",
    "Клиент Dropbox исторически написан на Python.",
    "Ранний краулер Google был написан на Python.",
    "NASA использует Python для обработки космических данных.",
    "EVE Online использует Python для логики игрового мира.",
]

print(random.choice(facts))
print("Факт дня готов!")
```

Что здесь происходит? Список `facts` содержит пять строк. `random.choice(facts)` выбирает одну случайную строку из списка — при каждом запуске результат может быть разным. Так работают «факт дня» на сайтах, случайные мудрости в приложениях и даже сервера, которые перемешивают словари для квизов. Случайность — важный инструмент: она делает программы живыми и непредсказуемыми в хорошем смысле.

### Разбор 2
Решение:

```python
from collections import Counter

purchases = ["книга", "кофе", "книга", "плед", "кофе", "книга"]
counter = Counter(purchases)

top_product, top_count = counter.most_common(1)[0]
rare_product, rare_count = counter.most_common()[-1]

print(f"Рекомендуем купить: {top_product} ({top_count} покупки)")
print(f"Самая редкая покупка: {rare_product} ({rare_count} покупка)")
```

Результат:

```
Рекомендуем купить: книга (3 покупки)
Самая редкая покупка: плед (1 покупка)
```

Что здесь происходит? `Counter` считает частоты покупок. `most_common(1)[0]` возвращает первую (самую частую) пару, `most_common()[-1]` — последнюю (самую редкую). Мы распаковываем пары в переменные `top_product, top_count`. Это прообраз рекомендательных систем: Netflix рекомендует то, что вы смотрели чаще, магазины подсказывают «часто покупают вместе». Вся магия — в подсчёте частот, а это ровно то, что мы умеем.

### Разбор 3
Решение:

```python
pages = {
    "python.org": "Python — отличный язык",
    "github.com": "Хостинг кода",
    "wikipedia.org": "Свободная энциклопедия",
}

query = input("Поиск: ").lower()
found = []

for page, text in pages.items():
    if query in text.lower():
        found.append(page)

if found:
    print("Найдено на страницах:", found)
else:
    print("Ничего не найдено")
```

Пример работы:

```
Поиск: язык
Найдено на страницах: ['python.org']
```

Что здесь происходит? `pages.items()` перебирает пары «адрес — текст страницы». Оператор `query in text.lower()` проверяет, встречается ли запрос в тексте; `lower()` приводит всё к нижнему регистру, чтобы «Язык» и «язык» считались одинаковыми. Найденные страницы собираются в список `found`. Это упрощённый, но настоящий поиск по тексту — тот самый принцип, по которому работают поисковые системы, только в масштабе миллиардов страниц.

### Разбор 4
Решение:

```python
events = {
    "Python создан": 1991,
    "Google начал использовать Python": 1996,
    "YouTube запущен": 2005,
    "Instagram запущен": 2010,
    "PyTorch создан": 2016,
    "ChatGPT запущен": 2022,
}

sorted_events = sorted(events.items(), key=lambda item: item[1])

for event, year in sorted_events:
    print(f"{year}: {event}")

earliest = sorted_events[0]
print("Самое раннее событие:", earliest[0], earliest[1])
```

Результат:

```
1991: Python создан
1996: Google начал использовать Python
2005: YouTube запущен
2010: Instagram запущен
2016: PyTorch создан
2022: ChatGPT запущен
Самое раннее событие: Python создан 1991
```

Что здесь происходит? `sorted(events.items(), key=lambda item: item[1])` сортирует пары по второму элементу (году). `lambda item: item[1]` — анонимная функция, которая говорит: «извлекай для сравнения элемент с индексом 1». Получается хронология. Так в аналитике строят таймлайны событий — от истории проекта до графиков продаж. `sorted()` — один из самых полезных инструментов Python, ты будешь встречать его постоянно.

### Разбор 5
Решение:

```python
from collections import Counter

word = "python"
counter = Counter(word)

print("Частота букв:")
for letter, count in counter.most_common():
    print(letter, "-", count)

print("Уникальных букв:", len(counter))
```

Результат:

```
Частота букв:
p - 1
y - 1
t - 1
h - 1
o - 1
n - 1
Уникальных букв: 6
```

Что здесь происходит? `Counter("python")` считает каждый символ. `most_common()` возвращает все пары в порядке убывания частоты — здесь все буквы встретились по одному разу, но если взять слово с повторяющимися буквами, порядок станет наглядным. `len(counter)` — количество уникальных букв. Это крошечное, но настоящее исследование данных: ты собрал статистику по тексту. Именно такие простые эксперименты вырабатывают аналитическое мышление — главный навык для работы с данными.
