## Программы, которые можно потрогать

До сих пор наши программы жили в терминале — выводили текст и ждали ввода. Но Python умеет создавать и то, что видно на экране и с чем можно взаимодействовать мышкой: окна приложений, игры, интерфейсы. Это отдельная магия — когда твой код превращается в кнопки, поля и анимации.

Сегодня мы сделаем первые шаги сразу в трёх направлениях: десктопные приложения, игры и мобильная разработка.

## Десктоп: Tkinter и PyQt

Десктопные приложения — это программы, которые работают на компьютере в собственном окне: редакторы, плееры, календари, утилиты.

- **Tkinter** — встроенная в Python библиотека графического интерфейса. Её не нужно устанавливать: она уже есть вместе с Python. Отлично подходит для старта: окна, кнопки, поля ввода, списки.
- **PyQt / PySide** — более мощные фреймворки на основе Qt. Профессиональный инструмент для серьёзных приложений с современным дизайном.

Вот минимальная программа на Tkinter — окно с надписью:

```python
import tkinter as tk

# Создаём главное окно
window = tk.Tk()
window.title("Моё первое окно")
window.geometry("300x200")

# Добавляем надпись
label = tk.Label(window, text="Привет, мир!", font=("Arial", 16))
label.pack()

# Запускаем событийный цикл — окно остаётся открытым
window.mainloop()
```

Запусти — появится настоящее окно с текстом. `tk.Tk()` создаёт окно, `tk.Label()` — надпись, `pack()` размещает её, а `mainloop()` запускает «событийный цикл»: программа ждёт действий пользователя (клики, нажатия клавиш) и реагирует на них.

## Игры: pygame и turtle

Python часто недооценивают как игровой язык, а зря. Конечно, для AAA-игр используют C++ и специализированные движки, но для инди-игр, прототипов и обучения Python — отличный выбор.

- **pygame** — библиотека для создания игр: спрайты, звук, обработка нажатий, игровой цикл. Тысячи учебных игр — от «Змейки» до платформеров — написаны на pygame.
- **turtle** — встроенный учебный модуль, где «черепашка» рисует линии и фигуры по твоим командам. Это идеальный способ понять графику без сложной теории.

Пример «Змейки» на pygame занимает около сотни строк — это реальный объём для начинающего. А вот как выглядит быстрый старт:

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((400, 300))
pygame.display.set_caption("Моя игра")

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    screen.fill((30, 30, 60))   # тёмно-синий фон
    pygame.display.flip()

pygame.quit()
```

Здесь видна структура любой игры: цикл `while`, обработка событий (закрытие окна), отрисовка кадра. Добавишь спрайты и логику — и получится игра.

## Мобильные приложения: Kivy

Хочешь, чтобы твоя программа работала на телефоне? Python и тут приходит на помощь:

- **Kivy** — фреймворк для мультитач-приложений: один и тот же код работает на Android, iOS, Windows и macOS.
- **BeeWare** — позволяет собирать приложения с нативным интерфейсом и публиковать их в магазинах.

Мобильная разработка на Python — ниша поскромнее, чем JS/Flutter, но она существует и развивается, особенно для внутренних инструментов, прототипов и учебных приложений.

## Строим первое окно и первую игру

Мы уже видели окно Tkinter. Давай ещё добавим кнопку, которая меняет текст, — так ты почувствуешь, что программа слушает тебя:

```python
import tkinter as tk

def change_text():
    label.config(text="Ты нажал кнопку!")

window = tk.Tk()
label = tk.Label(window, text="Привет!")
label.pack()
button = tk.Button(window, text="Нажми меня", command=change_text)
button.pack()
window.mainloop()
```

Функция `change_text` вызывается при каждом клике по кнопке (это и есть «событие»). `label.config(text=...)` меняет текст надписи. Так работает почти любой интерфейс: кнопка → событие → функция.

### Разбор 1
Решение:

```python
import tkinter as tk

window = tk.Tk()
window.title("Моё приложение")
window.geometry("400x300")

label1 = tk.Label(window, text="Привет, мир!", font=("Arial", 18))
label1.pack()

label2 = tk.Label(window, text="Python открывает окна", font=("Arial", 12))
label2.pack()

window.mainloop()
```

Что здесь происходит? `tk.Tk()` создаёт главное окно. `geometry("400x300")` задаёт размер, `title()` — заголовок. `tk.Label()` создаёт надпись: первым аргументом — родительское окно, затем текст и шрифт. `pack()` размещает надпись в окне и следит за компоновкой. `mainloop()` запускает событийный цикл: окно живёт, пока его не закроют. Это и есть минимальная «программа с лицом» — графический интерфейс, который можно показывать друзьям.

### Разбор 2
Решение:

```python
import tkinter as tk

colors = ["black", "blue", "red"]
index = 0

def change():
    global index
    label.config(fg=colors[index])
    index = (index + 1) % len(colors)

window = tk.Tk()
label = tk.Label(window, text="Я ещё не нажата")
label.pack()
button = tk.Button(window, text="Нажми меня", command=change)
button.pack()
window.mainloop()
```

Что здесь происходит? `command=change` означает: «при клике вызови функцию change». Внутри функции `global index` разрешает менять глобальную переменную. `label.config(fg=colors[index])` меняет цвет текста (fg — foreground, цвет текста). Выражение `(index + 1) % len(colors)` возвращает остаток от деления: 0 → 1 → 2 → 0 → … — поэтому цвета перебираются по кругу. Это классический паттерн интерфейсов: состояние (текущий цвет) + событие (клик) → реакция.

### Разбор 3
Решение:

```python
import tkinter as tk

def greet():
    name = entry.get()
    if name == "":
        label.config(text="Введи имя!")
    else:
        label.config(text=f"Привет, {name}!")

window = tk.Tk()
entry = tk.Entry(window)
entry.pack()
button = tk.Button(window, text="Поздороваться", command=greet)
button.pack()
label = tk.Label(window, text="")
label.pack()
window.mainloop()
```

Что здесь происходит? `tk.Entry` — поле ввода, в котором пользователь печатает текст. `entry.get()` возвращает введённую строку. Если она пустая — просим ввести имя, иначе подставляем его в f-строку `f"Привет, {name}!"` и обновляем надпись. Это уже полноценная интерактивная программа: ввод → обработка → вывод. Именно так устроены формы, поисковые строки и чаты. Добавь этот паттерн в свою копилку — он понадобится в сотне проектов.

### Разбор 4
Решение:

```python
import turtle

t = turtle.Turtle()
for i in range(4):
    t.forward(100)
    t.left(90)

turtle.done()
```

Что здесь происходит? `turtle.Turtle()` создаёт «черепашку» — курсор, который оставляет след. `t.forward(100)` двигает её вперёд на 100 пикселей, `t.left(90)` поворачивает на 90 градусов влево. Четыре повторения цикла дают замкнутый квадрат. `turtle.done()` оставляет окно открытым, чтобы ты успел полюбоваться рисунком. Turtle — это ворота в компьютерную графику: та же идея «двигайся и рисуй» лежит в основе векторной графики и игровых движков.

### Разбор 5
Решение:

```python
import random

secret = random.randint(1, 10)
attempts = 0
print("Я загадал число от 1 до 10.")

while True:
    guess = int(input("Твоё число: "))
    attempts += 1
    if guess < secret:
        print("Больше!")
    elif guess > secret:
        print("Меньше!")
    else:
        print("Верно! Число:", secret)
        print("Попыток:", attempts)
        break
```

Пример игры:

```
Я загадал число от 1 до 10.
Твоё число: 5
Больше!
Твоё число: 8
Меньше!
Твоё число: 7
Верно! Число: 7
Попыток: 3
```

Что здесь происходит? `random.randint(1, 10)` загадывает случайное число. Цикл `while True` даёт игроку бесконечные попытки, `int(input(...))` читает и превращает ввод в число. Условия «меньше/больше» дают обратную связь — это «умная» игра, которая помогает игроку. При угадывании `break` завершает цикл. Механика «загадай → сравняй → дай подсказку» — это скелет почти любой игры, от «Морского боя» до квестов.
