## Веб — это три суперсилы

Интернет — самое большое место, где работает Python. И в нём три главных направления:

1. **Создание сайтов** — от блога до маркетплейса, похожего на Amazon.
2. **API** — «язык общения» между программами: твой код просит данные у сервиса, сервис отвечает.
3. **Парсеры** — программы, которые собирают данные с веб-страниц (цены, новости, объявления).

Сегодня мы откроем все три двери — и даже напишем код, который свяжется с настоящим сервером в интернете.

## Сайты: Django, Flask и FastAPI

Чтобы сделать сайт, не нужно вручную писать сервер на низком уровне. Python даёт готовые каркасы — фреймворки:

- **Django** — «тяжёлая артиллерия»: всё включено, админка, база данных, безопасность. Именно на Django работает Instagram (крупнейший проект на этом фреймворке).
- **Flask** — лёгкий и минималистичный: стартует за пять минут, идеален для небольших сервисов и учебных проектов.
- **FastAPI** — современный и быстрый: автоматическая документация, отличная работа с API.

Пример минимального сайта на Flask выглядит так:

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Привет, мир! Это мой сайт на Flask."

if __name__ == "__main__":
    app.run()
```

Установи Flask (`pip install flask`), запусти — и открой `http://127.0.0.1:5000` в браузере. Ты только что создал настоящий веб-сайт.

## API: программы разговаривают друг с другом

API (Application Programming Interface) — это набор правил, по которым программы обмениваются данными. Когда ты открываешь приложение погоды, оно просит данные у API погодного сервиса. Когда ты платишь картой — платёжный сервис обращается к API банка.

Данные обычно передаются в формате **JSON** — удобном текстовом формате, который выглядит как словари Python:

```json
{"userId": 1, "id": 1, "title": "Помыть посуду", "completed": false}
```

## Демо: живой запрос к настоящему API

Давай напишем программу, которая спросит данные у настоящего публичного API — JSONPlaceholder (тестовый сервис для обучения). Для этого в Python есть встроенный модуль `urllib.request` — он умеет ходить в интернет без установки чего-либо:

```python
import json
import urllib.request

url = "https://jsonplaceholder.typicode.com/todos/1"
with urllib.request.urlopen(url) as response:
    data = json.loads(response.read())

print("Задача:", data["title"])
print("Выполнено:", data["completed"])
```

Что здесь происходит? `urlopen(url)` открывает соединение с сервером и получает ответ. `response.read()` читает тело ответа (текст в формате JSON), а `json.loads()` превращает его в словарь Python. Дальше мы обращаемся к данным по ключам, как к обычному словарю: `data["title"]`. Если интернет доступен, ты увидишь первую задачу из списка дел. Если сети нет — программа честно сообщит об ошибке, но сам код от этого не перестаёт быть настоящим клиентом API.

## Парсеры: собираем данные с сайтов

Парсер — это программа, которая заходит на страницы, достаёт нужные данные и складывает их в удобный вид. Парсеры используют для мониторинга цен, сбора новостей, анализа объявлений.

По сути парсер делает то же, что и наш запрос к API: получает страницу, но дальше не просто выводит JSON, а ищет в тексте нужные фрагменты. Для сложных страниц используют библиотеку `BeautifulSoup` — она умеет разбирать HTML и доставать из него элементы. Работает это примерно так:

```python
# Упрощённая схема: получили HTML страницы
html = "<h1>Привет</h1><p>Цена: 999 руб.</p>"

# Это можно сделать через BeautifulSoup, а мы просто поищем текст
if "999 руб." in html:
    print("Нашли цену: 999 руб.")
```

## Этикет парсинга

Прежде чем писать парсер, запомни три правила:

- **Читай правила сайта.** Не собирай данные, которые сайт запрещает собирать.
- **Не перегружай сервер.** Делай паузы между запросами, не «долби» сайт тысячами запросов в секунду.
- **Используй API, если есть.** Если у сайта есть публичный API — это всегда лучше и легальнее, чем парсинг.

### Разбор 1

```python
import json
import urllib.request

url = "https://jsonplaceholder.typicode.com/posts/1"
with urllib.request.urlopen(url) as response:
    data = json.loads(response.read())

print("Заголовок:", data["title"])
print("Текст:", data["body"])
```

Результат (сокращённо):

```
Заголовок: sunt aut facere repellat provident occaecati excepturi optio reprehenderit
Текст: quia et suscipit ...
```

Что здесь происходит? `urllib.request.urlopen(url)` открывает соединение с сервером. Оператор `with` гарантирует, что соединение будет закрыто, даже если случится ошибка. `response.read()` возвращает байты ответа — в нашем случае это JSON-текст. `json.loads()` превращает его в словарь Python. Дальше `data["title"]` и `data["body"]` — обычное обращение к словарю. Поздравляю: ты написал полноценного клиента API — такую же программу, какую используют приложения, когда показывают тебе новости или погоду.

### Разбор 2
Решение:

```python
import json
import urllib.request

done = 0
for i in range(1, 6):
    url = f"https://jsonplaceholder.typicode.com/todos/{i}"
    with urllib.request.urlopen(url) as response:
        data = json.loads(response.read())
    mark = "[x]" if data["completed"] else "[ ]"
    print(mark, data["title"])
    if data["completed"]:
        done += 1

print("Выполнено:", done, "из 5")
```

Результат:

```
[ ]  delectus aut autem
[x]  quis ut nam facilis et officia qui
[ ]  fugiat veniam minus
[ ]  et porro tempora
[x]  laboriosam mollitia et enim quasi adipisci quia provident illum
Выполнено: 2 из 5
```

Что здесь происходит? f-строка `f"...todos/{i}"` подставляет номер задачи в URL. Тернарный оператор `"[x]" if data["completed"] else "[ ]"` — это короткое условие: если `completed` истинно, берём `[x]`, иначе `[ ]`. Счётчик `done` увеличивается только для выполненных задач. Так мы автоматически собрали и обработали данные о пяти задачах — тот же принцип лежит в основе приборных панелей и отчётов, которые собирают статистику из разных источников.

### Разбор 3
Решение:

```python
import json
import urllib.request

url = "https://jsonplaceholder.typicode.com/posts?userId=1"
with urllib.request.urlopen(url) as response:
    posts = json.loads(response.read())

print("Всего постов:", len(posts))
for post in posts:
    print("-", post["title"])
```

Результат (фрагмент):

```
Всего постов: 10
- sunt aut facere repellat ...
- qui est esse
- ea molestias quasi exercitationem repellat qui ipsa sit aut
...
```

Что здесь происходит? Знак `?` в URL начинает параметры запроса: `userId=1` говорит серверу «верни посты только пользователя 1». Сервер возвращает не один объект, а **список** объектов. `len(posts)` считает количество, а цикл `for post in posts:` перебирает каждый пост и печатает заголовок. Заметь: API часто возвращают именно списки, и умение работать с ними — ключевое для любого веб-разработчика. Параметры запроса — это то, как приложения передают серверам условия фильтрации.

Обрати внимание на `true` в JSON: он автоматически становится булевым `True` в Python. Условие `if data["popular"]:` работает напрямую с этим значением. ### Разбор 5
Решение:

```python
from datetime import datetime

def my_api(request):
    if request["action"] == "hello":
        return {"message": "Привет, мир!"}
    elif request["action"] == "time":
        now = datetime.now().strftime("%H:%M")
        return {"time": now}
    else:
        return {"error": "Неизвестное действие"}

print(my_api({"action": "hello"}))
print(my_api({"action": "time"}))
print(my_api({"action": "magic"}))
```

Результат:

```
{'message': 'Привет, мир!'}
{'time': '14:35'}
{'error': 'Неизвестное действие'}
```

Что здесь происходит? Функция `my_api` — это модель настоящего API: она принимает запрос (словарь) и возвращает ответ (тоже словарь). Внутри — маршрутизация: в зависимости от `action` мы выбираем, что ответить. Так устроены сотни реальных сервисов: пришёл запрос — мы его разобрали — отдали ответ в JSON. Постепенно ты заменишь `my_api` на Flask или FastAPI, и твоя функция станет настоящим веб-сервисом, доступным по адресу в интернете.
