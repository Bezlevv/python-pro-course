## Рутину можно делегировать

Вспомни, сколько раз ты делал одно и то же руками: переименовывал сотню файлов, рассортировывал фотографии по папкам, вручную заполнял таблицы, отвечал на одинаковые сообщения. Это и есть рутина — самая скучная часть любой работы. И вот главная новость этого урока: **Python отлично умеет делать это за тебя**.

Автоматизация — это превращение повторяющихся действий в программу, которая выполнит их сама, быстро и без ошибок. Разработчики называют такие программы скриптами. Это «маленькие роботы»: запустил — и они сделали свою работу.

## Скрипт: программа-робот

Скрипт — это обычный файл `.py`, но с фокусом на конкретную задачу: обработать файлы, собрать данные, разослать письма, следить за системой. Пишутся они на удивление быстро.

Начнём с работы с файлами. В Python есть отличный инструмент — модуль `pathlib`, который делает работу с папками и файлами простой, как в проводнике:

```python
from pathlib import Path

# Создаём папку и файл внутри неё
folder = Path("мой_проект")
folder.mkdir(exist_ok=True)

# Записываем текст в файл
(folder / "привет.txt").write_text("Привет из скрипта!", encoding="utf-8")

# Читаем его обратно
text = (folder / "привет.txt").read_text(encoding="utf-8")
print(text)
```

Обрати внимание: `Path("мой_проект")` — это «путь» к папке. `mkdir(exist_ok=True)` создаёт папку, если её ещё нет. Оператор `/` соединяет путь с именем файла. `write_text()` и `read_text()` — запись и чтение текста. Всего пять строчек — и у тебя уже есть утилита для работы с файлами.

## Демо: массовое переименование

Представь, что у тебя есть папка с файлами, в названия которых нужно добавить дату. Вручную это муторно, а вот скрипт справится за секунду:

```python
from pathlib import Path
from datetime import datetime

folder = Path("фотографии")
folder.mkdir(exist_ok=True)

# Создадим пару файлов для примера
for i in range(1, 4):
    (folder / f"image{i}.jpg").write_text("данные", encoding="utf-8")

date = datetime.now().strftime("%Y-%m-%d")
for file in folder.iterdir():
    new_name = folder / f"{date}_{file.name}"
    file.rename(new_name)
    print("Переименовано:", file.name, "->", new_name.name)
```

Здесь мы познакомились с циклом `for ... in ...`, который перебирает элементы, и с f-строками — строками, куда можно подставлять значения через фигурные скобки: `f"image{i}.jpg"`. `iterdir()` перечисляет все файлы в папке, а `rename()` переименовывает. Запусти — и увидишь, как три файла получили новый префикс.

## Боты: программа, которая разговаривает

Бот — это программа, которая ждёт сообщений и реагирует на них. Самый простой бот живёт прямо в терминале: он спрашивает, слушает и отвечает. В основе любого бота лежит цикл «слушай → отвечай»:

```python
print("Привет! Я бот-эхо. Напиши что-нибудь.")
while True:
    message = input("Ты: ")
    if message.lower() == "пока":
        print("Бот: Пока-пока! Возвращайся.")
        break
    print("Бот: Ты написал:", message)
```

`input()` ждёт, пока пользователь что-то введёт, а `while True` — бесконечный цикл, то есть бот будет слушать, пока не услышит «пока» (`break` — выход из цикла). Именно так устроены настоящие боты в Telegram и других мессенджерах, только вместо терминала они слушают сообщения из сети.

## Расписания и таймеры

Иногда нужно, чтобы скрипт выполнялся не сразу, а по расписанию — например, раз в час. Самый простой способ — заставить программу подождать:

```python
import time

for i in range(3):
    print("Тик", i + 1)
    time.sleep(2)  # пауза 2 секунды
```

`time.sleep(2)` ставит программу на паузу на 2 секунды. Для настоящих расписаний существуют библиотеки вроде `schedule`, а для запуска скриптов по времени — средства операционной системы (планировщик задач в Windows или cron в Linux).

## Правила безопасности автоматизации

Автоматизация — сила, но с ней нужно обращаться аккуратно:

- **Не удаляй файлы вслепую.** Программа, которая что-то удаляет, должна сначала показать список того, что собирается удалить, и спросить подтверждения.
- **Сначала проверий, потом меняй.** Переименовывай файлы только после того, как убедился, что список имён правильный.
- **Работай в копии.** Для экспериментов создавай отдельные папки, чтобы случайно не испортить настоящие данные.

### Разбор 4
Решение:

```python
from pathlib import Path

base = Path("demo_auto")
base.mkdir(exist_ok=True)

(base / "a.txt").write_text("текст", encoding="utf-8")
(base / "b.txt").write_text("текст", encoding="utf-8")
(base / "readme.md").write_text("# Заголовок", encoding="utf-8")

Path("txt_files").mkdir(exist_ok=True)
Path("md_files").mkdir(exist_ok=True)

for file in base.iterdir():
    if file.suffix == ".txt":
        file.rename(Path("txt_files") / file.name)
    elif file.suffix == ".md":
        file.rename(Path("md_files") / file.name)

print("txt_files:", [p.name for p in Path("txt_files").iterdir()])
print("md_files:", [p.name for p in Path("md_files").iterdir()])
```

Результат:

```
txt_files: ['a.txt', 'b.txt']
md_files: ['readme.md']
```

Что здесь происходит? Мы создаём файлы разных типов, затем две папки-приёмника. Цикл проверяет расширение каждого файла и «переезжает» его в нужную папку через `rename()`. Обрати внимание: `file.rename(Path("txt_files") / file.name)` не меняет имя файла, а меняет только папку. Такие «организаторы» реально используются для сортировки загрузок: музыка — в одну папку, картинки — в другую, документы — в третью.
