## Как OpenCV хранит изображения

Функция `cv2.imread(path)` читает файл и возвращает **numpy-массив**. Цветное изображение — это трёхмерный массив: `(высота, ширина, каналы)`. Каждый пиксель хранит три числа от 0 до 255 (тип `uint8`).

```python
img = cv2.imread("photo.jpg")
print(img.shape)      # (1080, 1920, 3) — высота, ширина, каналы
print(img.dtype)      # uint8
print(img[0, 0])      # BGR-значения левого верхнего пикселя
```

Критически важная деталь: **OpenCV хранит цвет в порядке BGR** (синий, зелёный, красный), а не RGB. Большинство остальных инструментов — matplotlib, PIL — ожидают RGB. Если просто передать массив из OpenCV в `plt.imshow()`, красный и синий каналы поменяются местами, и изображение будет выглядеть «неправильно». Посмотрим это в действии:

```python
# Создадим "красное" изображение 100x100
red_bgr = np.zeros((100, 100, 3), dtype=np.uint8)
red_bgr[:] = (0, 0, 255)   # BGR: синий=0, зелёный=0, красный=255

plt.subplot(1, 2, 1)
plt.imshow(red_bgr)              # matplotlib думает, что это RGB — будет синий!
plt.title("Без конвертации")
plt.axis("off")

# Правильно: сначала превратим BGR в RGB
red_rgb = cv2.cvtColor(red_bgr, cv2.COLOR_BGR2RGB)
plt.subplot(1, 2, 2)
plt.imshow(red_rgb)              # теперь честный красный
plt.title("После cvtColor")
plt.axis("off")
plt.show()
```

Запомни правило: `cv2.imread` → BGR, `plt.imshow` → RGB. Между ними всегда делай `cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`.

## Доступ к пикселям и срезы

Раз изображение — это numpy-массив, с ним работают обычные механизмы индексации. Обрати внимание: первая координата — строка (y), вторая — столбец (x).

```python
pixel = img[100, 200]          # пиксель на строке 100, столбце 200
img[100, 200] = (255, 0, 0)    # перекрасить в синий (BGR!)
channel_blue = img[:, :, 0]    # отдельный канал
region = img[50:150, 200:400]  # прямоугольная область (срез)
```

Срез — это не копия, а «окно» на те же данные. Если изменить `region`, изменится и оригинал. Чтобы получить независимую копию, используй `.copy()`.

## Изменение размера и кадрирование

`cv2.resize` меняет размер. Размер задаётся либо явно, либо коэффициентами:

```python
small = cv2.resize(img, (640, 360))        # точные ширина и высота
half = cv2.resize(img, None, fx=0.5, fy=0.5)  # уменьшить вдвое
```

Кадрирование — это просто срез:

```python
crop = img[100:400, 200:600]
```

## Запись и отображение

Запись на диск — `cv2.imwrite`, возвращает `True` при успехе:

```python
ok = cv2.imwrite("out.png", crop)
print(ok)  # True
```

Для показа на экране в учебной среде лучше не использовать `cv2.imshow` (ему нужен графический интерфейс), а сохранять файлы и открывать их через matplotlib:

```python
rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
plt.imshow(rgb)
plt.axis("off")
plt.show()
```

## Создаём изображения с нуля

blank = np.zeros((300, 400, 3), dtype=np.uint8)   # чёрное
blank[:] = (255, 255, 255)                        # залить белым
blank[50:150, 100:250] = (0, 0, 255)              # красный прямоугольник

def generate_grid():

Решение:

```python
import cv2

def flip_horizontal(img):
    return img[:, ::-1]

img = cv2.imread("photo.jpg")
cv2.imwrite("original.png", img)
cv2.imwrite("flipped.png", flip_horizontal(img))

Это чистый numpy без `cv2.flip`: функция возвращает массив той же формы, но с зеркально расположенными пикселями. ### Разбор 4
Решение:

```python
import cv2
import numpy as np

def crop_center(img, width, height):
    h, w = img.shape[:2]
    if width > w or height > h:
        return img
    x1 = (w - width) // 2
    y1 = (h - height) // 2
    return img[y1:y1 + height, x1:x1 + width]
```

Тесты:

```python
def test_crop_center_shape():
    img = np.zeros((100, 200, 3), dtype=np.uint8)
    out = crop_center(img, 50, 40)
    assert out.shape == (40, 50, 3)

def test_crop_center_odd():
    img = np.zeros((101, 201, 3), dtype=np.uint8)
    out = crop_center(img, 51, 41)
    assert out.shape == (41, 51, 3)

def test_crop_center_too_large():
    img = np.zeros((10, 10, 3), dtype=np.uint8)
    out = crop_center(img, 50, 50)
    assert out.shape == (10, 10, 3)

def test_crop_center_center_pixel():
    img = np.zeros((100, 100, 3), dtype=np.uint8)
    img[50, 50] = (255, 0, 0)
    out = crop_center(img, 10, 10)
    assert out[5, 5].tolist() == [255, 0, 0]
```

Что здесь происходит? Функция считает координаты левого верхнего угла центрального прямоугольника как `(w - width) // 2` и `(h - height) // 2` — целочисленное деление гарантирует, что при нечётных размерах мы не выйдем за границы. Проверка `width > w or height > h` защищает от срезов больше исходного изображения. Четвёртый тест подтверждает, что срез берётся именно из центра: пиксель `(50, 50)` — центр изображения 100×100, и в результате 10×10 он должен оказаться в точке `(5, 5)`.

### Разбор 5
Решение:

```python
import cv2

def to_gray_and_resize(img, scale):
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    return cv2.resize(gray, None, fx=scale, fy=scale)
```

Тесты:

```python

def test_gray_is_2d():
    img = np.random.randint(0, 256, (80, 120, 3), dtype=np.uint8)
    out = to_gray_and_resize(img, 0.5)
    assert len(out.shape) == 2

def test_gray_dtype():
    img = np.random.randint(0, 256, (80, 120, 3), dtype=np.uint8)
    out = to_gray_and_resize(img, 0.5)
    assert out.dtype == np.uint8

def test_gray_resize_shape():
    img = np.random.randint(0, 256, (80, 120, 3), dtype=np.uint8)
    out = to_gray_and_resize(img, 0.5)
    assert out.shape == (40, 60)

def test_gray_resize_custom_scale():
    img = np.random.randint(0, 256, (100, 200, 3), dtype=np.uint8)
    out = to_gray_and_resize(img, 0.25)

```

Что здесь происходит? `cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)` превращает трёхканальный массив в двумерный — каждый пиксель становится одним числом яркости. `cv2.resize(gray, None, fx=scale, fy=scale)` уменьшает изображение в `scale` раз по обеим осям: при `scale=0.5` высота 80 станет 40. `np.random.randint` в тестах генерирует случайное изображение, чтобы не зависеть от конкретного файла. Тесты проверяют главные контракты функции: двумерность, тип и точную геометрию результата.
