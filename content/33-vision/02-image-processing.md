На прошлом уроке мы научились читать изображения и работать с пикселями. Но настоящие задачи (поиск объектов, распознавание, сегментация) требуют подготовки изображения: убрать шум, превратить картинку в чёрно-белую и найти границы объектов. Этим мы и займёмся.

## Шум и фильтрация

Любое изображение с камеры содержит шум — случайные яркие или тёмные точки. Фильтры усредняют соседние пиксели и сглаживают картинку.

```python
import cv2

img = cv2.imread("photo.jpg")

# Простое среднее по окну 5x5
blurred = cv2.blur(img, (5, 5))

# Гауссово размытие — взвешенное среднее, мягче сохраняет края
gauss = cv2.GaussianBlur(img, (5, 5), 0)

# Медианный фильтр — отлично убивает «соль и перец»
median = cv2.medianBlur(img, 5)
```

Размер окна — нечётное число (3, 5, 7...). Чем больше окно, тем сильнее размытие.

## Пороговая бинаризация

После размытия полезно превратить изображение в бинарное: каждый пиксель — либо 0 (чёрный), либо 255 (белый). Делается это функцией `cv2.threshold`:

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
```

Здесь порог 127: пиксели светлее — белые, темнее — чёрные. Порог часто трудно подобрать вручную. Помогает метод Оцу — он сам находит оптимальный порог:

```python
_, binary_otsu = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
```

Для сцен с неравномерным освещением лучше `cv2.adaptiveThreshold` — он считает порог отдельно для каждой маленькой области:

```python
adaptive = cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                 cv2.THRESH_BINARY, 11, 2)
```

## Морфология

Бинарное изображение часто содержит «дырки» внутри объектов и случайные шумовые пятна. Морфологические операции исправляют это, прокатывая по изображению структурный элемент (обычно ядро из единиц).

```python
import numpy as np

kernel = np.ones((5, 5), np.uint8)

# Эрозия: уменьшает белые области, убирает мелкие пятна
eroded = cv2.erode(binary, kernel, iterations=1)

# Дилатация: увеличивает белые области, заполняет дырки
dilated = cv2.dilate(binary, kernel, iterations=1)

# Открытие = эрозия + дилатация: чистит фон от белого шума
opened = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)

# Закрытие = дилатация + эрозия: заполняет дырки внутри объектов
closed = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
```

## Контуры

Контуры — это границы белых областей на бинарном изображении. `cv2.findContours` возвращает список контуров (и иерархию — в OpenCV 4 функция возвращает ровно два значения):

```python
contours, hierarchy = cv2.findContours(closed, cv2.RETR_EXTERNAL,
                                       cv2.CHAIN_APPROX_SIMPLE)
```

- `cv2.RETR_EXTERNAL` — только внешние контуры, без вложенных дырок;
- `cv2.CHAIN_APPROX_SIMPLE` — сжимает контур, оставляя только углы.

Каждый контур — это массив точек. Нарисуем их на копии оригинала:

```python
out = img.copy()
cv2.drawContours(out, contours, -1, (0, 255, 0), 3)
```

Для каждого контура можно получить ограничивающий прямоугольник и площадь:

```python
for c in contours:
    x, y, w, h = cv2.boundingRect(c)   # координаты и размеры прямоугольника
    area = cv2.contourArea(c)          # площадь контура в пикселях
```

Именно эти данные нужны, чтобы посчитать объекты, отсеять мелкий мусор по площади и нарисовать рамки вокруг найденных предметов.

### Разбор 1
Решение:

```python
import cv2

def denoise(path, ksize=5):
    img = cv2.imread(path)
    blurred = cv2.GaussianBlur(img, (ksize, ksize), 0)
    cv2.imwrite("denoised.png", blurred)
    print(img.shape, blurred.shape)

denoise("photo.jpg")
```

Результат:

```
(1080, 1920, 3) (1080, 1920, 3)
```

Что здесь происходит? `cv2.GaussianBlur` размывает изображение, используя гауссово ядро размера `(ksize, ksize)` — третий аргумент (стандартное отклонение) мы передаём как 0, и OpenCV сам вычисляет его из размера окна. Размер окна обязан быть нечётным, иначе OpenCV бросит исключение. Форма массива при этом не меняется: фильтр работает с каждым пикселем, пересчитывая его по соседям, но геометрия остаётся прежней.

### Разбор 2
Решение:

```python
import cv2
import numpy as np

def binarize(path):
    img = cv2.imread(path)
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    _, binary = cv2.threshold(gray, 0, 255,
                              cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    cv2.imwrite("binary.png", binary)
    white = np.count_nonzero(binary) / binary.size * 100
    print(f"Белых пикселей: {white:.1f}%")

binarize("photo.jpg")
```

Что здесь происходит? Метод Оцу работает так: OpenCV перебирает все возможные пороги и выбирает тот, при котором дисперсия между чёрным и белым классами максимальна. Поэтому числовое значение порога (первый возвращаемый параметр) нам не нужно — мы игнорируем его через `_`. Процент белых пикселей считается через `np.count_nonzero` — он возвращает количество ненулевых элементов (а белый — это 255). Результат удобно вывести с одной десятой через f-строку.

### Разбор 3
Решение:

```python
import cv2
import numpy as np

def morph_clean(binary):
    kernel = np.ones((5, 5), np.uint8)
    opened = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
    cleaned = cv2.morphologyEx(opened, cv2.MORPH_CLOSE, kernel)
    cv2.imwrite("cleaned.png", cleaned)
    before = np.count_nonzero(binary)
    after = np.count_nonzero(cleaned)
    print(f"Было: {before}, стало: {after}")
    return cleaned
```

Что здесь происходит? Открытие (эрозия, затем дилатация) стирает маленькие белые пятна с фона, а закрытие (дилатация, затем эрозия) заполняет тёмные дырки внутри объектов. Обе операции используют одинаковое ядро. Количество белых пикселей обычно уменьшается, потому что открытие убирает мусор; если объекты содержали много дырок, закрытие может их компенсировать — поэтому в задаче и сказано «либо меньше, либо примерно столько же». Такой очищенный бинарный слой идеально подходит для поиска контуров.

### Разбор 4
Решение:

```python
import cv2
import numpy as np

def preprocess_bin(img, kernel_size=5):
    blur = cv2.GaussianBlur(img, (kernel_size, kernel_size), 0)
    gray = cv2.cvtColor(blur, cv2.COLOR_BGR2GRAY)
    _, th = cv2.threshold(gray, 0, 255,
                          cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    kernel = np.ones((kernel_size, kernel_size), np.uint8)
    opened = cv2.morphologyEx(th, cv2.MORPH_OPEN, kernel)
    return cv2.morphologyEx(opened, cv2.MORPH_CLOSE, kernel)
```

Тесты:

```python
def test_preprocess_shape():
    img = np.zeros((60, 80, 3), dtype=np.uint8)
    out = preprocess_bin(img)
    assert len(out.shape) == 2
    assert out.shape == (60, 80)

def test_preprocess_dtype():
    img = np.zeros((60, 80, 3), dtype=np.uint8)
    out = preprocess_bin(img)
    assert out.dtype == np.uint8

def test_preprocess_binary_values():
    img = np.random.randint(0, 256, (60, 80, 3), dtype=np.uint8)
    out = preprocess_bin(img)
    assert set(np.unique(out)).issubset({0, 255})

def test_preprocess_black_image():
    img = np.zeros((60, 80, 3), dtype=np.uint8)
    out = preprocess_bin(img)
    assert not np.any(out)
```

Что здесь происходит? Функция собирает полный пайплайн: размытие убирает шум до бинаризации, порог Оцу сам находит границу, морфология чистит результат. Для чёрного изображения Оцу увидит только один класс яркости, поэтому результат будет целиком чёрным — это и проверяет четвёртый тест. Важно, что `kernel_size` используется и для окна размытия, и для ядра — это делает функцию согласованной.

### Разбор 5
Решение:

```python
import cv2
import numpy as np

def largest_contour_bbox(binary):
    contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL,
                                   cv2.CHAIN_APPROX_SIMPLE)
    if not contours:
        return None
    best = max(contours, key=cv2.contourArea)
    return cv2.boundingRect(best)
```

Тесты:

```python
def test_largest_bbox_square():
    binary = np.zeros((100, 200), dtype=np.uint8)
    binary[10:90, 10:90] = 255
    assert largest_contour_bbox(binary) == (10, 10, 80, 80)

def test_largest_bbox_empty():
    binary = np.zeros((100, 200), dtype=np.uint8)
    assert largest_contour_bbox(binary) is None

def test_largest_bbox_picks_biggest():
    binary = np.zeros((100, 200), dtype=np.uint8)
    binary[10:30, 10:30] = 255     # маленький квадрат
    binary[50:90, 120:180] = 255   # большой квадрат
    x, y, w, h = largest_contour_bbox(binary)
    assert (x, y, w, h) == (120, 50, 60, 40)
```

Что здесь происходит? `cv2.findContours` в OpenCV 4 возвращает кортеж из двух элементов — контуры и иерархию, поэтому мы распаковываем `contours, _`. `max(contours, key=cv2.contourArea)` находит контур с максимальной площадью. `cv2.boundingRect` возвращает кортеж `(x, y, w, h)` — координаты верхнего левого угла и размеры прямоугольника. Третий тест показывает, что функция выбирает именно самый большой контур, а не первый попавшийся: маленький квадрат 20×20 слева игнорируется в пользу большого 60×40 справа.
