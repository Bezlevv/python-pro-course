Твоя папка «Загрузки» наверняка похожа на беспорядок: здесь PDF-ки, там картинки, где-то установщики. Разбирать это руками — скучно и долго. Хорошая новость: Python делает это за пару секунд, а мы за один урок напишем собственный сортировщик файлов.

## Знакомимся с pathlib

В современном Python путь к файлу — это не просто строка, а объект класса `Path` из модуля `pathlib`. У него много удобных методов. Чтобы получить объект пути к папке, пишем:

```python
from pathlib import Path

downloads = Path.home() / "Downloads"
print(downloads)
```

Оператор `/` склеивает части пути — это читается куда лучше, чем `os.path.join()`. Вот что умеет `Path`:

- `p.mkdir(parents=True, exist_ok=True)` — создать папку вместе со всеми родительскими, не выдавая ошибку, если она уже есть;
- `p.exists()` — проверить, существует ли путь;
- `p.is_file()` и `p.is_dir()` — это файл или папка;
- `p.name` — имя файла с расширением;
- `p.suffix` — расширение, например `".pdf"`;
- `p.stem` — имя без расширения.

Например, вывести все файлы папки с их расширениями:

```python
for f in downloads.iterdir():
    if f.is_file():
        print(f.name, "→", f.suffix)
```

Метод `iterdir()` перечисляет всё содержимое папки, а мы фильтруем по `is_file()`, чтобы не трогать подпапки.

## Перемещаем файлы: shutil

Для перемещения файлов стандартная библиотека даёт `shutil.move(источник, назначение)`:

```python
import shutil

source = downloads / "photo.jpg"
target_folder = downloads / "images"
target_folder.mkdir(parents=True, exist_ok=True)
shutil.move(str(source), str(target_folder))
```

`shutil.move` умеет перемещать и файлы, и папки. Если второй аргумент — существующая папка, файл окажется внутри неё с прежним именем.

## Идея сортировщика

Мы хотим получить словарь «расширение → категория»:

```python
CATEGORIES = {
    ".jpg": "images", ".png": "images", ".gif": "images",
    ".pdf": "documents", ".docx": "documents", ".txt": "documents",
    ".mp3": "audio", ".mp4": "video",
}
```

А дальше для каждого файла: определить расширение, найти категорию, создать папку (если надо) и переместить файл. Если расширение незнакомое — кладём в `"others"`. Это и есть твой будущий мини-проект, задачи ниже проведут его по шагам.

Ещё пара нюансов. Во-первых, перемещать нужно не вслепую: если в целевой папке уже лежит файл с тем же именем, `shutil.move` просто заменит его. Для сортировщика это опасно — можно потерять данные, поэтому в задачах мы добавим проверку и «умное» имя с номером. Во-вторых, для первой тренировки создай тестовую папку с копиями файлов, а не запускай скрипт сразу на настоящих «Загрузках».

### Разбор 1
Решение:

```python
from pathlib import Path

folder = Path("test_data")

for f in folder.iterdir():
    if f.is_file():
        ext = f.suffix or "(нет расширения)"
        print(f"{f.name} → {ext}")
```

Результат:

```
photo.jpg → .jpg
report.pdf → .pdf
notes.txt → .txt
music.mp3 → .mp3
README → (нет расширения)
```

Что здесь происходит? `iterdir()` возвращает итератор по всем элементам папки: файлам и подпапкам. Проверка `f.is_file()` оставляет только файлы. Далее `f.suffix` даёт расширение с точкой, а конструкция `f.suffix or "(нет расширения)"` — классический трюк: пустая строка (файл без расширения) считается ложью, поэтому подставляется поясняющий текст. Наконец, f-строка удобно собирает вывод. Обрати внимание, что порядок строк в отчёте определяется порядком элементов в папке — это нормально.

### Разбор 2
Решение:

```python
import shutil
from pathlib import Path

CATEGORIES = {
    ".jpg": "images", ".png": "images", ".gif": "images",
    ".pdf": "documents", ".docx": "documents", ".txt": "documents",
    ".mp3": "audio", ".mp4": "video",
}

folder = Path("test_data")

for f in folder.iterdir():
    if not f.is_file():
        continue
    cat = CATEGORIES.get(f.suffix.lower(), "others")
    target = folder / cat
    target.mkdir(parents=True, exist_ok=True)
    shutil.move(str(f), str(target))

print("Готово!")
```

Что здесь происходит? `continue` пропускает подпапки, не трогая их. `CATEGORIES.get(f.suffix.lower(), "others")` ищет категорию по расширению; приведение к нижнему регистру защищает от файлов вроде `PHOTO.JPG`. `target.mkdir(parents=True, exist_ok=True)` создаёт папку один раз, а при повторных запусках не падает. `shutil.move(str(f), str(target))` переносит файл в папку-категорию. Обрати внимание: `shutil.move` принимает строки или объекты `Path`, поэтому `str()` необязателен, но делает поведение явным.

### Разбор 4
Решение:

```python
import shutil
from pathlib import Path

def safe_move(f: Path, target: Path) -> None:
    dest = target / f.name
    if not dest.exists():
        shutil.move(str(f), str(dest))
        return
    n = 1
    while True:
        dest = target / f"{f.stem}_{n}{f.suffix}"
        if not dest.exists():
            shutil.move(str(f), str(dest))
            return
        n += 1
```

Что здесь происходит? Сначала проверяем простейший случай: если файла с таким именем в целевой папке нет, перемещаем как обычно. Если есть — запускаем цикл: пробуем `photo_1.jpg`, затем `photo_2.jpg` и так далее, пока не найдём свободное имя. `f.stem` даёт имя без расширения, `f.suffix` — расширение, поэтому склейка `f"{f.stem}_{n}{f.suffix}"` всегда корректна даже для файлов с несколькими точками, например `archive.backup.zip`. Такой подход исключает потерю данных при повторных запусках: файлы не заменяются, а получают уникальные имена.

### Разбор 5
Решение:

```python
import shutil
from collections import Counter
from pathlib import Path

CATEGORIES = {
    ".jpg": "images", ".png": "images", ".gif": "images",
    ".pdf": "documents", ".docx": "documents", ".txt": "documents",
    ".mp3": "audio", ".mp4": "video",
}

def safe_move(f: Path, target: Path) -> None:
    dest = target / f.name
    if not dest.exists():
        shutil.move(str(f), str(dest))
        return
    n = 1
    while True:
        dest = target / f"{f.stem}_{n}{f.suffix}"
        if not dest.exists():
            shutil.move(str(f), str(dest))
            return
        n += 1

def organize(folder: str) -> Counter:
    folder = Path(folder)
    moved = Counter()
    for f in folder.iterdir():
        if not f.is_file():
            continue
        cat = CATEGORIES.get(f.suffix.lower(), "others")
        target = folder / cat
        target.mkdir(parents=True, exist_ok=True)
        safe_move(f, target)
        moved[cat] += 1
    return moved

report = organize("test_data")
for cat, count in sorted(report.items()):
    print(f"{cat}: {count}")
```

Результат (пример):

```
audio: 1
documents: 2
images: 1
others: 1
```

Что здесь происходит? Функция `organize` принимает путь строкой, превращает его в `Path`, создаёт счётчик `Counter`, прогоняет цикл перемещения и возвращает статистику. В конце программы `sorted(report.items())` сортирует категории по алфавиту, и отчёт выводится аккуратно. Такую функцию легко переиспользовать: вызови `organize(str(Path.home() / "Downloads"))` — и настоящие «Загрузки» будут приведены в порядок. Поздравляю, это твой первый полноценный инструмент автоматизации!
