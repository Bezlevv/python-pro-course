Микроконтроллеры окружают нас повсюду: они внутри стиральной машины, умных лампочек, фитнес-браслетов и даже твоего холодильника. Это крошечные компьютеры с процессором и памятью, но без монитора, клавиатуры и операционной системы. Программировать их можно на низкоуровневых языках вроде C, но это долго и сложно. А можно использовать MicroPython — более простую версию Python, специально созданную для таких устройств.

## Что такое MicroPython

MicroPython — это реализация языка Python, которая работает прямо на микроконтроллере. Её создал инженер Дэмиан Джордж в 2014 году. Ядро языка осталось тем же: циклы, функции, списки, словари, классы — всё знакомое тебе по курсу работает и здесь. Но есть и важные отличия.

Во-первых, интерпретатор MicroPython занимает всего несколько сотен килобайт flash-памяти и может работать с ОЗУ объёмом 20–500 КБ. Для сравнения: обычный CPython для той же задачи потребовал бы десятки мегабайт. Во-вторых, MicroPython не полагается на операционную систему: он сам управляет железом. В-третьих, он использует другой набор модулей: вместо раздутой стандартной библиотеки — компактные модули `machine`, `network`, `ujson`, `urequests`, `time`.

Код на MicroPython пишется так же, как обычный Python, поэтому почти всё, что ты уже знаешь, пригодится.

## REPL — живой диалог с платой

REPL — это интерактивный режим, где команды выполняются сразу. Если подключить плату к компьютеру через USB и открыть терминал (например, в программе Thonny), появится приглашение `>>>`:

```python
>>> print("Привет, MicroPython!")
Привет, MicroPython!
>>> 2 ** 10
1024
>>> 17 * 3
51
```

Каждая строка выполняется мгновенно — плата отвечает сразу. Это лучший способ экспериментировать.

## Как узнать свою плату

Ты можешь спросить у MicroPython, на чём он запущен:

```python
import os
print(os.uname())
```

В ответ придёт что-то вроде:

```
(sysname='esp32', nodename='esp32', release='1.24.0', version='v1.24.0 on 2024-09-02', machine='ESP32 module with ESP32')
```

Полезны и встроенные переменные:

```python
import sys
print(sys.platform)
print(sys.version)
```

## Модуль machine — ключ к железу

Все операции с пинами, таймерами, ШИМ и другими устройствами живут в модуле `machine`. Посмотри, что в нём есть:

```python
import machine
print(dir(machine))
```

Ты увидишь `Pin`, `PWM`, `ADC`, `I2C`, `Timer`, `WDT` и многое другое. Это «органы управления» платой. Например, вот так включается светодиод, подключённый к пину 2:

```python
from machine import Pin
led = Pin(2, Pin.OUT)  # пин 2 — на вывод
led.value(1)            # подать высокий уровень — LED горит
```

Никакой магии: мы просто управляем физическим выводом микроконтроллера. Следующие уроки будут целиком посвящены этому.

## Как установить MicroPython

Чтобы получить эту среду, нужно «прошить» плату: записать в её память файл прошивки (`.bin`). Проще всего сделать это через программу Thonny, которая умеет и прошивать, и редактировать код, и показывать REPL. Выбираешь свою плату (ESP32, Raspberry Pi Pico и другие), скачиваешь официальную прошивку с сайта micropython.org и запускаешь установку. После этого плата готова к исполнению.

### Подсказка 1
В REPL просто вводи выражения и жми Enter. Числа можно вводить как есть, без print(): `>>> 17 * 3` тоже сработает, но лучше привыкать к `print()` — так вывод будет понятнее и одинаковым на любой плате.

### Подсказка 2
Файл в Thonny — это обычный текстовый файл с расширением `.py`. Команды выполняются сверху вниз. Будь внимателен: вывод REPL появляется сразу после каждой строки, а вывод файла печатается весь разом после запуска.

### Подсказка 3
`os.uname()` возвращает объект, похожий на словарь, с полями `sysname`, `nodename`, `release`, `version`, `machine`. Выведь его целиком через `print()` — и просто найди в тексте строку `sysname=...`.

### Подсказка 4

### Подсказка 5

### Разбор 1
В REPL печатаем:

```python
>>> print("Привет, MicroPython!")
```

Результат: `Привет, MicroPython!`. Затем:

```python
>>> 17 * 3
51
>>> 2 ** 10
1024
```

Что здесь происходит? REPL выполняет каждую введённую строку сразу после нажатия Enter. Выражения вроде `17 * 3` вычисляются, и результат печатается автоматически. Выполнение занимает доли секунды — микроконтроллер работает на частоте 80–240 МГц, и способ простые вычисления очень быстро. Обрати внимание: приглашение `>>>` возвращается после каждой команды — это значит, что плата готова к следующему вводу.

### Разбор 2
Файл `hello.py`:

```python
print("Привет, MicroPython!")
import sys
print(sys.version)
```

После запуска через кнопку Run в Thonny увидишь:

```
Привет, MicroPython!
3.4.0
```

Что здесь происходит? Скрипт выполняется как единый «запуск»: строки идут сверху вниз, и весь вывод печатается вместе. В REPL же каждая строка выполняется по отдельности и результат виден сразу — поэтому в REPL удобно пробовать, а в файле писать настоящие программы. `sys.version` показывает версию MicroPython (например, `3.4.0` — это ядро Python 3.4 с добавками). Это короткий способ убедиться, что прошивка установлена корректно.

### Разбор 3
Программа:

```python
import os
print(os.uname())
```

Типичный вывод для ESP32:

```
(sysname='esp32', nodename='esp32', release='1.24.0', version='v1.24.0 on 2024-09-02', machine='ESP32 module with ESP32')
```

А для Raspberry Pi Pico:

```
(sysname='rp2', nodename='rp2', release='1.24.0', version='v1.24.0 on 2024-09-02', machine='Raspberry Pi Pico with RP2040')
```

Что здесь происходит? `os.uname()` возвращает объект с полями: `sysname` — имя платформы, `release` — версия прошивки, `machine` — описание железа. Это удобно, когда нужно написать программу, которая ведёт себя по-разному на разных платах. Например, можно сравнить `sysname` с `"esp32"` и выбрать другие номера пинов.

### Разбор 4
`dir(machine)` вернёт список вроде:

```
['ADC', 'DAC', 'I2C', 'Pin', 'PWM', 'RTC', 'SoftI2C', 'SoftSPI', 'SPI', 'Timer', 'UART', 'WDT', ...]
```

Три осмысленных имени и их назначение:

- `Pin` — управление цифровыми пинами: включить/выключить вывод, прочитать уровень на входе. Это база всей работы с железом.
- `ADC` — аналогово-цифровой преобразователь: превращает напряжение (например, с потенциометра) в число от 0 до 65535.
- `I2C` — шина для общения с внешними чипами: дисплеями, датчиками, памятью.

Что здесь происходит? `dir()` показывает все имена, которые доступны в модуле. Читая имена, ты можешь догадаться о возможностях: заглавные буквы указывают на классы. Это универсальный приём — так можно исследовать любой модуль, даже без документации.

### Разбор 5
Программа:

```python
import time
print("Начинаю работу")
time.sleep(2)
print("Готово")
```

Результат: сначала печатается `Начинаю работу`, затем плата «замирает» на две секунды, и только потом появляется `Готово`. С `time.sleep(5)` пауза станет ещё заметнее. Что здесь происходит? `time.sleep(2)` останавливает выполнение программы на 2 секунды (время действительно в секундах). Это базовая функция для всех временных задержек: пауза между миганиями светодиода, ожидание ответа датчика, антидребезг кнопки. В MicroPython есть и `time.sleep_ms()` — для миллисекунд, она удобнее, когда нужна точность.
