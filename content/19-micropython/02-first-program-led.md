Классическая «первая программа» для микроконтроллера — мигание светодиодом. Это аналог `print("Привет, мир!")`, но для железа: ты убеждаешься, что плата работает, ты правильно собрал схему и научился управлять пинами. Попутно ты освоишь два самых важных инструмента: `machine.Pin` и `time.sleep`.

## Что нужно собрать

Возьми светодиод и резистор на 220–330 Ом. Соедини их последовательно: ножка анода (длинная, через резистор) — к пину 2 платы, ножка катода (короткая) — к земле (GND). Резистор обязателен: он ограничивает ток и защищает и светодиод, и пин платы от перегорания. На многих платах есть и встроенный светодиод: у Raspberry Pi Pico это пин 25 (GP25), у многих ESP32-плат — пин 2. Тогда паять ничего не нужно — можно сразу писать код и смотреть на встроенный светодиод.

## Пины: вывод и ввод

Любой пин микроконтроллера можно настроить как выход (OUT) — подавать на него напряжение, или как вход (IN) — считывать уровень сигнала извне. Для этого создаётся объект `Pin`:

```python
from machine import Pin

led = Pin(2, Pin.OUT)  # пин 2 работает как выход
```

Теперь объектом `led` можно управлять:

```python
led.value(1)   # высокий уровень (3.3 В) — светодиод горит
led.value(0)   # низкий уровень (0 В) — светодиод погас
```

Есть и короткая форма — `led.on()` и `led.off()`, а также `led.toggle()`, которая переключает состояние на противоположное:

```python
led.toggle()  # если горел — погаснет, и наоборот
```

## Первое мигание

Соберём всё вместе. Чтобы светодиод мигал, нужно чередовать включение и выключение с паузами:

```python
from machine import Pin
import time

led = Pin(2, Pin.OUT)

while True:
    led.value(1)
    time.sleep(0.5)   # полсекунды горит
    led.value(0)
    time.sleep(0.5)   # полсекунды погашен
```

Цикл `while True:` выполняется бесконечно, поэтому светодиод будет мигать, пока плата включена. Чтобы остановить программу — нажми Ctrl+C в Thonny (или Reset на плате).

А если нужно мигнуть ровно N раз — используй `range`:

```python
for _ in range(5):
    led.on()
    time.sleep(1)
    led.off()
    time.sleep(1)
```

Скорость мигания задаётся паузами: чем меньше `time.sleep(0.5)`, тем быстрее.

## Что происходит внутри

`led.value(1)` — это не абстракция: микроконтроллер выставляет на пине напряжение 3.3 В, через резистор течёт ток, и светодиод загорается. `led.value(0)` — напряжение падает до нуля, ток исчезает, светодиод гаснет. Ты буквально управляешь электричеством с помощью нескольких строк Python. Через несколько уроков ты поймёшь, что за этим же принципом стоят и более сложные вещи — ШИМ, датчики и даже Wi-Fi.

### Разбор 1
Программа:

```python
from machine import Pin
import time

led = Pin(2, Pin.OUT)

for _ in range(5):
    led.value(1)
    time.sleep(1)
    led.value(0)
    time.sleep(1)
```

Что здесь происходит? `for _ in range(5)` повторяет тело цикла ровно 5 раз. В каждой итерации светодиод загорается (`value(1)`), ждёт секунду, гаснет (`value(0)`) и снова ждёт секунду. После пятого повтора цикл завершается, программа доходит до конца файла и останавливается — светодиод остаётся погашенным. Переменная `_` — это принятое в Python имя для «неиспользуемой» переменной цикла: само значение нам не нужно, важно только количество повторов.

### Разбор 2
Вариант (а):

```python
from machine import Pin
import time

led = Pin(2, Pin.OUT)

for _ in range(5):
    led.on()
    time.sleep(1)
    led.off()
    time.sleep(1)
```

Вариант (б):

```python
from machine import Pin
import time

led = Pin(2, Pin.OUT)

for _ in range(10):
    led.toggle()
    time.sleep(0.5)
```

Что здесь происходит? `on()`/`off()` — это просто более читаемые синонимы `value(1)`/`value(0)`. А `toggle()` меняет состояние на противоположное: если светодиод горел — гаснет, если гас — загорается. Поэтому в варианте (б) достаточно одного вызова на итерацию: каждый вызов переключает состояние, а пауза 0.5 с делает мигание. Обрати внимание: оба варианта дают одинаковый «рисунок» мигания, но отличаются стилем и количеством кода.

### Разбор 3
Программа:

```python
from machine import Pin
import time

led = Pin(2, Pin.OUT)

def blink(duration):
    led.on()
    time.sleep(duration)
    led.off()
    time.sleep(0.3)

while True:
    for _ in range(3):      # три коротких
        blink(0.3)
    time.sleep(0.3)
    for _ in range(3):      # три длинных
        blink(1)
    time.sleep(0.3)
    for _ in range(3):      # три коротких
        blink(0.3)
    time.sleep(2)           # пауза между сигналами
```

Что здесь происходит? Функция `blink(duration)` выносит повторяющуюся последовательность «включить — подождать — выключить — подождать». Короткий сигнал — `blink(0.3)`, длинный — `blink(1)`. Тройки повторяются циклами `for`. Группировка кода в функции делает программу читаемой и позволяет менять длительности в одном месте. Пауза 2 секунды в конце внешнего цикла отделяет один сигнал SOS от следующего.

### Разбор 4
Программа:

```python
from machine import Pin
import time

red = Pin(2, Pin.OUT)
green = Pin(4, Pin.OUT)

while True:
    red.on()
    time.sleep(2)
    red.off()
    time.sleep(0.5)

    green.on()
    time.sleep(2)
    green.off()
    time.sleep(0.5)
```

Что здесь происходит? У нас два независимых объекта `Pin`, каждый управляет своим светодиодом. Сначала горит красный 2 секунды, гаснет, и после короткой паузы 0.5 с загорается зелёный. Пауза между переключениями нужна, чтобы было видно границу состояний — без неё переключение выглядело бы «слипшимся». Цикл `while True` повторяет эту последовательность бесконечно — это классическая структура для состояния «светофор»: состояния чередуются по таймингу.

### Разбор 5
Программа:

```python
from machine import Pin
import time

led = Pin(2, Pin.OUT)

delay = 1.0
for _ in range(10):
    led.on()
    time.sleep(delay)
    led.off()
    time.sleep(delay)
    delay *= 0.8

print("Готово, скорость:", round(delay, 2), "с")
```

Что здесь происходит? Переменная `delay` хранит текущую паузу. Каждое мигание использует её, а затем строка `delay *= 0.8` уменьшает паузу на 20%: 1.0 → 0.8 → 0.64 → 0.512 и так далее. После 10 итераций `delay` примерно равна 0.13 — это и печатает `print()` с округлением через `round(delay, 2)`. Так мы видим, как переменная «живёт» внутри цикла и как простая арифметика превращается в управление скоростью физического процесса.
