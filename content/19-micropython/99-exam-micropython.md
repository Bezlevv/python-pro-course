Что такое MicroPython?
- Расширение Python для создания сайтов
- Компактная реализация Python для микроконтроллеров
- Версия Python для суперкомпьютеров
- Библиотека для работы с Excel
* Правильный ответ: Компактная реализация Python для микроконтроллеров
MicroPython работает прямо на микроконтроллере без операционной системы и занимает всего несколько сотен килобайт.

Какой модуль в MicroPython управляет пинами ввода-вывода?
- os
- machine
- sys
- math
* Правильный ответ: machine
В модуле machine есть классы Pin, PWM, ADC, I2C, Timer и другие для работы с аппаратурой.

Что делает led.toggle()?
- Включает светодиод навсегда
- Переключает состояние на противоположное
- Проверяет, горит ли светодиод
- Выключает питание платы
* Правильный ответ: Переключает состояние на противоположное
Если светодиод горит — toggle() погасит его, если погашен — зажжёт.

Какое значение вернёт button.value() при нажатой кнопке с подтяжкой Pin.PULL_UP?
- 1
- 0
- 65535
- Ошибку
* Правильный ответ: 0
Нажатие замыкает пин на землю, и уровень падает до 0 — поэтому для PULL_UP логика «перевёрнутая».

Какой диапазон значений у pwm.duty_u16()?
- 0–1
- 0–255
- 0–65535
- -100–100
* Правильный ответ: 0–65535
duty_u16 принимает заполнение от 0 (выключено) до 65535 (полная мощность).

Какая частота PWM нужна сервоприводу?
- 1000 Гц
- 50 Гц
- 1 Гц
- Любая, от 1 до 50 000 Гц
* Правильный ответ: 50 Гц
Серво считывает ширину импульса с частотой 50 Гц (период 20 мс).

Что делает oled.show() после oled.text(...)?
- Ничего, текст появляется сразу
- Отправляет буфер на экран — без этого картинка не появится
- Очищает экран
- Увеличивает яркость
* Правильный ответ: Отправляет буфер на экран — без этого картинка не появится
Рисование идёт в буфер в памяти платы, а oled.show() передаёт его в контроллер экрана.

Как подключить плату к Wi-Fi в режиме клиента?
- network.WLAN(network.AP_IF)
- network.WLAN(network.STA_IF).active(True); wlan.connect(...)
- network.connect("Wi-Fi")
- socket.WLAN()
* Правильный ответ: network.WLAN(network.STA_IF).active(True); wlan.connect(...)
STA_IF — режим клиента: включаем интерфейс и подключаемся к точке доступа.

Что делает s.accept() на сервере?
- Отправляет ответ клиенту
- Блокирует выполнение и ждёт подключения клиента, затем возвращает соединение и адрес
- Закрывает соединение
- Проверяет доступность интернета
* Правильный ответ: Блокирует выполнение и ждёт подключения клиента, затем возвращает соединение и адрес
accept() «засыпает» до прихода клиента и возвращает кортеж (conn, addr).

Почему важно вызывать r.close() после urequests.get()?
- Чтобы вывести ответ на экран
- Чтобы закрыть соединение и не тратить память платы
- Чтобы перезагрузить плату
- Чтобы очистить мусор
* Правильный ответ: Чтобы закрыть соединение и не тратить память платы
Каждое открытое соединение занимает память и ресурсы, которых на плате очень мало.

Чем плоха конкатенация строк в цикле?
- Строки нельзя складывать в MicroPython
- Каждая итерация создаёт новую строку, выбрасывая старую — медленно и затратно
- Это вызывает зависание таймера
- Это запрещено стандартом языка
* Правильный ответ: Каждая итерация создаёт новую строку, выбрасывая старую — медленно и затратно
Лучше собрать части в список и склеить через "".join(...) за один проход.

Для чего нужен machine.Timer?
- Чтобы перезагрузить плату через заданный период
- Чтобы вызывать функцию периодически, не блокируя главный цикл
- Чтобы измерять температуру
- Чтобы ускорять код
* Правильный ответ: Чтобы вызывать функцию периодически, не блокируя главный цикл
Таймер вызывает callback через заданный период независимо от того, что делает главная программа.
