Какой принцип SOLID требует, чтобы у класса была одна причина для изменения?
- SRP
- OCP
- LSP
- DIP
* Правильный ответ: SRP
Single Responsibility — у класса одна ответственность и одна причина для изменения.

Что означает «открытость для расширения, закрытость для изменения»?
- Новое поведение добавляется новым кодом, а не правкой существующего
- Класс нельзя наследовать
- Все методы должны быть публичными
- Изменения запрещены
* Правильный ответ: Новое поведение добавляется новым кодом, а не правкой существующего
Это принцип OCP: полиморфизм вместо цепочек if/elif.

Куда направлены зависимости в чистой архитектуре?
- От внешних слоёв к внутренним
- От внутренних к внешним
- Внутренние слои зависят от базы данных
- Зависимости отсутствуют
* Правильный ответ: От внешних слоёв к внутренним
Домен не знает о фреймворках и базах; внешние слои зависят от абстракций домена.

Что такое порт в чистой архитектуре?
- Сетевой порт
- Абстракция (протокол), которую реализуют адаптеры
- Конфигурационный файл
- Контроллер FastAPI
* Правильный ответ: Абстракция (протокол), которую реализуют адаптеры
Порт описывает потребность домена, адаптер — реализацию конкретной технологией.

Какой статус-код уместен при удалении ресурса без тела ответа?
- 200
- 201
- 204
- 400
* Правильный ответ: 204
204 No Content — успешное удаление без тела ответа.

В чём главный плюс GraphQL перед REST?
- Клиент сам выбирает нужные поля одним запросом
- Нет схемы
- Работает только с XML
- Не требуется сервер
* Правильный ответ: Клиент сам выбирает нужные поля одним запросом
Схема и один endpoint, клиент запрашивает ровно нужные поля.

Какая основная проблема микросервисов по сравнению с монолитом?
- ACID-транзакции между сервисами не работают
- Сервисы нельзя деплоить
- Нет общих библиотек
- У них нет баз данных
* Правильный ответ: ACID-транзакции между сервисами не работают
Нужны саги и компенсации, а также контроль сетевых сбоев.

Что делает паттерн «удушающий фикус»?
- Постепенно заменяет куски монолита микросервисами через фасад
- Удаляет все сервисы
- Отключает логирование
- Удваивает нагрузку
* Правильный ответ: Постепенно заменяет куски монолита микросервисами через фасад
Фасад прячет переход от клиента, миграция идёт шагами.

Какой режим доставки сообщений требует идемпотентного обработчика?
- At-most-once
- At-least-once
- Exactly-once
- Никакой
* Правильный ответ: At-least-once
Сообщение может прийти несколько раз, и повторная обработка должна быть безвредной.

Что такое ключ идемпотентности?
- Уникальный идентификатор запроса, по которому сервер возвращает сохранённый результат при повторе
- Пароль пользователя
- Ключ шифрования
- Индекс базы данных
* Правильный ответ: Уникальный идентификатор запроса, по которому сервер возвращает сохранённый результат при повторе
Это защищает от двойной оплаты и прочих дубликатов.
