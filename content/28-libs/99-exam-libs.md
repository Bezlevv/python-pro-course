Что возвращает img.thumbnail((100, 100))?
- Новый объект Image
- None — изображение изменяется на месте
- Кортеж (100, 100)
- Ошибку
* Правильный ответ: None — изображение изменяется на месте
thumbnail() модифицирует объект и возвращает None, пропорции сохраняются.

Почему перед сохранением в JPEG нужно конвертировать RGBA в RGB?
- JPEG не поддерживает альфа-канал
- Это ускоряет сохранение
- Без этого файл не откроется
- Это требование только для WebP
* Правильный ответ: JPEG не поддерживает альфа-канал
JPEG не хранит прозрачность, поэтому лишний канал убирают.

Что делает HTTPAdapter(max_retries=Retry(...)) в requests?
- Включает автоматические повторы и пул соединений
- Ускоряет DNS-запросы
- Шифрует трафик
- Меняет протокол на HTTP/2
* Правильный ответ: Включает автоматические повторы и пул соединений
HTTPAdapter отвечает за пул соединений и применяет политику повторов.

Что делает r.raise_for_status()?
- Возвращает код статуса
- Бросает HTTPError при 4xx/5xx
- Игнорирует ошибки
- Устанавливает таймаут
* Правильный ответ: Бросает HTTPError при 4xx/5xx
raise_for_status() превращает ошибки HTTP в исключения.

Зачем rich отключает ANSI-коды при выводе в StringIO?
- Потому что цвета поддерживаются только в терминалах
- Чтобы ускорить вывод
- Это случайный баг
- Для совместимости с Windows XP
* Правильный ответ: Потому что цвета поддерживаются только в терминалах
В не-терминал rich пишет чистый текст без управляющих кодов.

Как в rich построить таблицу?
- Создать Table, добавить колонки и строки, передать в console.print()
- Вызвать console.table_data()
- Использовать класс Grid
- Написать Markdown
* Правильный ответ: Создать Table, добавить колонки и строки, передать в console.print()
Table собирает данные, console.print рендерит её.

Как объявить команду в typer?
- @app.command() над функцией
- app.add_command()
- typer.run_command()
- class Command(app)
* Правильный ответ: @app.command() над функцией
Декоратор регистрирует функцию как команду CLI.

Через что тестируют команды typer?
- CliRunner из typer.testing
- requests
- unittest.mock.patch
- Только запуском отдельного процесса
* Правильный ответ: CliRunner из typer.testing
runner.invoke(app, args) запускает команду in-process и возвращает Result.

Как записать формулу в ячейку openpyxl?
- ws["B8"] = "=SUM(B2:B7)"
- ws["B8"] = SUM(B2:B7)
- ws.formula(B8, "SUM")
- Это невозможно
* Правильный ответ: ws["B8"] = "=SUM(B2:B7)"
Формула хранится как строка; значение вычислит Excel.

Когда ThreadPoolExecutor ускоряет выполнение?
- На IO-задачах (сеть, файлы)
- Только на простых вычислениях
- Никогда
- Всегда, даже на CPU-задачах
* Правильный ответ: На IO-задачах (сеть, файлы)
Потоки эффективны, когда задача ждёт ввода-вывода.
