Привет! Графы — это универсальный способ описывать связи между объектами: дороги между городами, дружбу в соцсети, зависимости между задачами. В этом уроке ты научишься хранить графы в Python и обходить их двумя классическими способами — в глубину (DFS) и в ширину (BFS).

## Основные понятия

Граф состоит из **вершин** (nodes) и **рёбер** (edges), которые их соединяют. Если ребро можно пройти в обе стороны, граф называется **неориентированным**: ребро `1 – 2` означает, что из 1 можно попасть в 2 и обратно. Если у ребра есть направление, граф — **ориентированный**, и ребро `1 → 2` работает только в одну сторону. Если каждое ребро несёт число (вес), граф — **взвешенный**.

## Представление графа

Самые популярные способы — матрица смежности и список смежности.

**Матрица смежности** — это таблица `n × n`, где ячейка `[i][j]` равна 1 (или весу), если есть ребро из i в j. Она проста, но занимает O(n²) памяти и медленно обходится.

**Список смежности** — для каждой вершины хранится список её соседей. Это самый ходовой способ: память O(V + E), а обход посещает только реально существующие рёбра.

```python
n, m = 5, 4
edges = [(1, 2), (1, 3), (2, 4), (4, 5)]

graph = [[] for _ in range(n + 1)]  # индексы 1..n
for a, b in edges:
    graph[a].append(b)
    graph[b].append(a)  # неориентированный граф
```

Теперь `graph[1]` — это `[2, 3]`, то есть соседи вершины 1. Индекс 0 мы не используем, чтобы вершины нумеровались с единицы (так удобнее в задачах).

## Обход в глубину: DFS

DFS идёт «вглубь»: уходит в первого соседа, потом в его соседа и так далее, пока не упрётся, затем возвращается назад. Рекурсивно это выглядит так:

```python
visited = [False] * (n + 1)

def dfs(v):
    visited[v] = True
    print(v, end=" ")
    for to in graph[v]:
        if not visited[to]:
            dfs(to)

dfs(1)
```

Можно написать DFS и без рекурсии — через явный стек:

```python
visited = [False] * (n + 1)
stack = [1]
while stack:
    v = stack.pop()
    if visited[v]:
        continue
    visited[v] = True
    print(v, end=" ")
    for to in graph[v]:
        if not visited[to]:
            stack.append(to)
```

Обрати внимание: порядок посещения у итеративной версии может отличаться от рекурсивной, потому что стек работает по принципу LIFO. В задачах мы будем сортировать соседей, чтобы порядок был однозначным.

## Обход в ширину: BFS

BFS обходит граф «слоями»: сначала старт, потом все его соседи, потом соседи соседей. Для этого нужна очередь `collections.deque`. Ключевой бонус: BFS находит **кратчайшие пути** в невзвешенном графе.

```python
from collections import deque

def bfs(start):
    dist = [-1] * (n + 1)   # -1 = вершина ещё не посещена
    dist[start] = 0
    q = deque([start])
    while q:
        v = q.popleft()
        for to in graph[v]:
            if dist[to] == -1:
                dist[to] = dist[v] + 1
                q.append(to)
    return dist
```

Здесь `dist[v]` — минимальное число рёбер от старта до v. Проверка `dist[to] == -1` заменяет массив `visited`: если расстояние ещё не установлено, значит, вершина не посещалась.

## Сложность

Оба обхода проходят каждую вершину и каждое ребро ровно один раз, поэтому работают за O(V + E). Это лучшее, чего можно ожидать для обхода графа. Разница: DFS удобен для поиска путей, циклов и компонент связности, а BFS — для кратчайших расстояний в невзвешенном графе и для «распространения волны» (например, от точки старта в лабиринте).

## Итог

Список смежности — стандартный способ хранения графов. DFS и BFS — две базовые «моторные» техники, на которых строятся почти все графовые алгоритмы. В задачах ниже ты применишь их для обхода, поиска пути и подсчёта компонент связности.

### Разбор 1
Решение:

```python
import sys

def main():
    data = sys.stdin.read().strip().splitlines()
    n, m = map(int, data[0].split())
    graph = [[] for _ in range(n + 1)]
    for i in range(1, m + 1):
        a, b = map(int, data[i].split())
        graph[a].append(b)
        graph[b].append(a)

    for v in range(1, n + 1):
        print(f"{v}: {' '.join(map(str, sorted(graph[v])))}")

if __name__ == "__main__":
    main()
```

Сначала создаём `n + 1` пустых списков — индекс 0 остаётся неиспользованным, а вершины 1..n получают свои списки. Для каждого ребра добавляем обе вершины друг другу, ведь граф неориентированный. При выводе сортируем соседей: `sorted(graph[v])` возвращает новый отсортированный список, а `' '.join(map(str, ...))` склеивает числа через пробел. Для входа:

```
4 4
1 2
1 3
2 4
3 4
```

получим:

```
1: 2 3
2: 1 4
3: 1 4
4: 2 3
```

Обрати внимание на пустую вершину: если у вершины нет соседей, `join` от пустого списка даст пустую строку — на экране будет `v:`.

### Разбор 2
Решение:

```python
import sys

def main():
    data = sys.stdin.read().strip().splitlines()
    n, m = map(int, data[0].split())
    graph = [[] for _ in range(n + 1)]
    for i in range(1, m + 1):
        a, b = map(int, data[i].split())
        graph[a].append(b)
        graph[b].append(a)
    for v in range(1, n + 1):
        graph[v].sort()

    visited = [False] * (n + 1)
    order = []

    def dfs(v):
        visited[v] = True
        order.append(v)
        for to in graph[v]:
            if not visited[to]:
                dfs(to)

    dfs(1)
    print(*order)

if __name__ == "__main__":
    main()
```

Мы сортируем соседей каждой вершины, чтобы обход шёл по возрастанию номеров — тогда результат однозначен. Рекурсивная `dfs` помечает вершину, добавляет её в `order` и уходит в каждого непосещённого соседа. Когда ветка заканчивается, рекурсия автоматически возвращается назад (это и есть «возврат» — backtracking). Для входа:

```
4 4
1 2
1 3
2 4
3 4
```

порядок будет: 1 → 2 (младший сосед) → 4 → 3, то есть вывод `1 2 4 3`. Сложность — O(V + E): каждая вершина посещается один раз, каждое ребро просматривается дважды (по разу из каждого конца).

### Разбор 3
Решение:

```python
import sys
from collections import deque

def main():
    data = sys.stdin.read().strip().splitlines()
    n, m = map(int, data[0].split())
    graph = [[] for _ in range(n + 1)]
    for i in range(1, m + 1):
        a, b = map(int, data[i].split())
        graph[a].append(b)
        graph[b].append(a)

    dist = [-1] * (n + 1)
    dist[1] = 0
    q = deque([1])
    while q:
        v = q.popleft()
        for to in graph[v]:
            if dist[to] == -1:
                dist[to] = dist[v] + 1
                q.append(to)

    print(*dist[1:])

if __name__ == "__main__":
    main()
```

BFS раскрашивает граф «слоями»: сначала старт (расстояние 0), затем все его соседи (расстояние 1), затем их соседи (2) и так далее. Из-за этого первый раз, когда мы добираемся до вершины, расстояние оказывается минимально возможным. Массив `dist` со значением `-1` совмещает роли «посещённости» и «расстояния». Для входа:

```
4 3
1 2
2 3
3 4
```

расстояния будут `0 1 2 3`. Если какая-то вершина недостижима, она останется `-1`. Сложность — O(V + E), а очередь `deque` даёт удаление из начала за O(1).

### Разбор 4
Решение:

```python
import sys

def main():
    data = sys.stdin.read().strip().splitlines()
    n, m = map(int, data[0].split())
    graph = [[] for _ in range(n + 1)]
    for i in range(1, m + 1):
        a, b = map(int, data[i].split())
        graph[a].append(b)
        graph[b].append(a)

    visited = [False] * (n + 1)
    components = 0
    for start in range(1, n + 1):
        if not visited[start]:
            components += 1
            stack = [start]
            visited[start] = True
            while stack:
                v = stack.pop()
                for to in graph[v]:
                    if not visited[to]:
                        visited[to] = True
                        stack.append(to)

    print(components)

if __name__ == "__main__":
    main()
```

Идея: если вершина ещё не посещена, значит, она принадлежит новой компоненте, которую мы ещё не видели. Запускаем из неё обход (здесь — итеративный DFS на явном стеке), который пометит ровно её компоненту, и увеличиваем счётчик. Одиночная вершина без рёбер — тоже компонента: цикл `for start` заметит, что она не посещена, и посчитает её. Для входа:

```
6 3
1 2
2 3
4 5
```

компоненты: {1, 2, 3}, {4, 5} и {6} — вывод `3`. Обрати внимание на отличие от рекурсивного DFS: здесь мы сами управляем стеком и не рискуем упереться в лимит глубины рекурсии на большом графе.

### Разбор 5
Решение:

```python
import sys
from collections import deque

def main():
    data = sys.stdin.read().strip().splitlines()
    n, m = map(int, data[0].split())
    graph = [[] for _ in range(n + 1)]
    for i in range(1, m + 1):
        a, b = map(int, data[i].split())
        graph[a].append(b)
        graph[b].append(a)

    a, b = map(int, data[m + 1].split())

    visited = [False] * (n + 1)
    q = deque([a])
    visited[a] = True
    while q:
        v = q.popleft()
        for to in graph[v]:
            if not visited[to]:
                visited[to] = True
                q.append(to)

    print("YES" if visited[b] else "NO")

if __name__ == "__main__":
    main()
```

Мы запускаем BFS из вершины `a` и собираем все достижимые из неё вершины. Если `b` попала в `visited`, путь существует; иначе — нет. Важный момент: старт мы помечаем сразу, поэтому при `a == b` ответ автоматически `YES`. Для входа:

```
4 2
1 2
3 4
1 3
```

вершины 1 и 2 образуют одну компоненту, 3 и 4 — другую, поэтому из 1 до 3 не добраться — вывод `NO`. Тот же приём работает и для ориентированных графов: достаточно убрать строку добавления обратного ребра при построении списка смежности.

- Матрица смежности

* Правильный ответ: Помечает вершину как посещённую, чтобы не зацикливаться
