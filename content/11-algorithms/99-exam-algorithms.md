Что означает запись O(n log n)?
- Алгоритм делает ровно n log n операций
- Время роста ограничено сверху функцией n log n
- Алгоритм всегда требует n log n памяти
- n log n — это количество строк в коде
* Правильный ответ: Время роста ограничено сверху функцией n log n
О-большое описывает верхнюю границу роста времени/памяти, а не точное число операций.

Какова сложность бинарного поиска в отсортированном массиве?
- O(1)
- O(n)
- O(log n)
- O(n log n)
* Правильный ответ: O(log n)
Каждое сравнение отбрасывает половину элементов, поэтому шагов ~log2(n).

Что делает heapq.heappop(heap)?
- Возвращает максимальный элемент
- Удаляет и возвращает минимальный элемент кучи
- Сортирует кучу
- Добавляет элемент в кучу
* Правильный ответ: Удаляет и возвращает минимальный элемент кучи
heapq реализует min-кучу: heappop извлекает наименьший элемент.

Какая структура данных используется для реализации DFS?
- Очередь
- Стек
- Куча
- Словарь
* Правильный ответ: Стек
DFS идёт вглубь — это соответствует LIFO-порядку стека (в рекурсии стек неявный).

Что такое «мемоизация»?
- Хранение результатов подзадач для повторного использования
- Запись алгоритма в одну строку
- Оптимизация ввода-вывода
- Способ обхода графа
* Правильный ответ: Хранение результатов подзадач для повторного использования
Это ключевой приём динамического программирования: не пересчитывать одно и то же.

Какова сложность быстрой сортировки в среднем случае?
- O(n)
- O(log n)
- O(n log n)
- O(n²)
* Правильный ответ: O(n log n)
В среднем qsort делит массив пополам и рекурсивно сортирует — O(n log n); в худшем случае O(n²).

Какой алгоритм сортировки устойчив и работает за O(n log n) в худшем случае?
- Пузырьком
- Сортировка слиянием
- Быстрая
- Шейкерная
* Правильный ответ: Сортировка слиянием
Merge sort гарантирует O(n log n) и не меняет порядок равных элементов.

Что такое «скользящее окно»?
- Приём, при котором за один проход обрабатывается подмассив фиксированной длины
- Окно в графическом интерфейсе
- Способ визуализации кучи
- Особый тип очереди
* Правильный ответ: Приём, при котором за один проход обрабатывается подмассив фиксированной длины
Окно «скользит» по массиву, снижая сложность перебора подмассивов.

Для чего используется объект deque из collections?
- Для быстрых добавлений/удалений с обоих концов
- Только как очередь FIFO
- Только как стек
- Для хранения уникальных значений
* Правильный ответ: Для быстрых добавлений/удалений с обоих концов
deque — двусторонняя очередь с O(1) на концах.

В графе из 100 вершин, представленном списками смежности, сколько памяти нужно в худшем случае?
- O(100)
- O(100²)
- O(100 × средняя степень)
- O(1)
* Правильный ответ: O(100 × средняя степень)
Списки смежности хранят рёбра — память пропорциональна числу рёбер, а не квадрату вершин.
