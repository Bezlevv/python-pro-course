Какой HTTP-метод и эндпоинт используются для отправки чат-запроса к LLM API?
- GET /v1/models
- POST /v1/chat/completions
- PUT /v1/completions
* Правильный ответ: POST /v1/chat/completions
Chat completions создают генерацию, поэтому используется POST.

Какая роль сообщения задаёт поведение модели (тон и правила)?
- user
- system
- assistant
* Правильный ответ: system
Системное сообщение описывает рамки и стиль ответов.

Что произойдёт, если выставить temperature = 0?
- Ответы станут почти детерминированными
- Модель начнёт отвечать быстрее
- Ответы станут случайнее
* Правильный ответ: Ответы станут почти детерминированными
Нулевая температура означает выбор наиболее вероятного токена.

Что такое few-shot промпт?
- Промпт с примерами вход-выход
- Промпт без системного сообщения
- Промпт с максимальной температурой
* Правильный ответ: Промпт с примерами вход-выход
Примеры задают паттерн, которому модель следует.

Чем измеряют семантическую близость эмбеддингов?
- Длиной текста
- Косинусной близостью
- Количеством токенов
* Правильный ответ: Косинусной близостью
Косинус угла между векторами отражает близость смыслов.

Для чего нужны эмбеддинги в пайплайне RAG?
- Для поиска релевантных фрагментов документов
- Для шифрования текста
- Для сокращения стоимости API
* Правильный ответ: Для поиска релевантных фрагментов документов
По векторам находят чанки, близкие по смыслу к запросу.

Что такое чанкинг?
- Разбиение документа на фрагменты для индексации
- Шифрование документа
- Обучение модели на документе
* Правильный ответ: Разбиение документа на фрагменты для индексации
Чанки — единицы поиска и контекста в RAG.

Что делает оператор | в LCEL (LangChain)?
- Соединяет компоненты в цепь
- Извлекает JSON из ответа
- Задаёт температуру модели
* Правильный ответ: Соединяет компоненты в цепь
prompt | llm | parser — конвейер обработки.

Зачем в LangChain используют with_structured_output(Pydantic-модель)?
- Чтобы получить валидированный структурированный объект
- Чтобы ускорить запрос
- Чтобы добавить инструменты
* Правильный ответ: Чтобы получить валидированный структурированный объект
Модель отвечает JSON, который валидируется по схеме.

Что происходит в цикле агента после получения tool_calls?
- Код исполняет вызовы и возвращает результаты модели
- Модель сразу печатает ответ
- Пользователь вводит данные заново
* Правильный ответ: Код исполняет вызовы и возвращает результаты модели
Результаты добавляются как tool-сообщения, и цикл продолжается.
