Что обязательно нужно создать перед любыми виджетами в PyQt6?
- QMainWindow
- QApplication
- QLabel
* Правильный ответ: QApplication
QApplication управляет приложением; виджеты создаются после него.

Что делает метод app.exec()?
- Показывает все окна
- Запускает цикл событий и возвращает управление только при выходе
- Завершает программу мгновенно
* Правильный ответ: Запускает цикл событий и возвращает управление только при выходе
exec() обрабатывает события до закрытия приложения.

Как правильно подключить функцию handle_click к нажатию кнопки?
- button.clicked.connect(handle_click())
- button.clicked.connect(handle_click)
- button.clicked = handle_click
* Правильный ответ: button.clicked.connect(handle_click)
Функция передаётся без скобок — иначе она выполнится сразу.

Как объявить собственный сигнал, передающий строку, в PyQt6?
- signal = Signal(str)
- greeted = pyqtSignal(str)
- self.signal = str()
* Правильный ответ: greeted = pyqtSignal(str)
В PyQt6 сигналы объявляются атрибутом класса через pyqtSignal; в PySide6 — через Signal.

Какой layout лучше всего подходит для формы «подпись → поле»?
- QVBoxLayout
- QFormLayout
- QGridLayout
* Правильный ответ: QFormLayout
QFormLayout сам выравнивает подписи и поля по колонкам.

Что возвращает QInputDialog.getText?
- Только строку
- Кортеж (текст, ok)
- Список вариантов
* Правильный ответ: Кортеж (текст, ok)
Второй элемент — подтвердил ли пользователь ввод.

Какой сигнал испускает QAction при активации?
- clicked
- triggered
- activated
* Правильный ответ: triggered
triggered срабатывает при выборе действия из меню, тулбара или по клавише.

Что хранит модель в архитектуре Модель-представление?
- Внешний вид
- Данные и правила доступа
- Позицию окна
* Правильный ответ: Данные и правила доступа
Модель отвечает за данные, представление — за их отображение.

Зачем нужен QSortFilterProxyModel?
- Для ускорения отрисовки
- Для фильтрации и сортировки без изменения исходной модели
- Для создания новых окон
* Правильный ответ: Для фильтрации и сортировки без изменения исходной модели
Прокси встаёт между моделью и представлением.

Как в QSS обратиться к виджету с objectName="okButton"?
- QPushButton.okButton
- #okButton
- .okButton
* Правильный ответ: #okButton
Селектор с решёткой # выбирает виджет по objectName.
