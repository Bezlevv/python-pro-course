Почти любая программа работает с датами или обменивается структурированными данными. Модули `datetime` и `json` покрывают обе задачи.

## Модуль datetime

Основные типы: `date` (дата), `time` (время), `datetime` (и то и другое), `timedelta` (разница). Получить текущий момент:

```python
from datetime import datetime

now = datetime.now()
print(now)            # 2026-11-01 14:20:00.123456
print(now.year)       # 2026
print(now.month)      # 11
print(now.day)        # 1
```

## Форматирование и разбор строк

`strftime` превращает дату в строку по формату, `strptime` — наоборот:

```python
formatted = now.strftime("%d.%m.%Y %H:%M")
print(formatted)  # 01.11.2026 14:20

parsed = datetime.strptime("15.07.2025", "%d.%m.%Y")
print(parsed)  # 2025-07-15 00:00:00
```

Популярные директивы: `%Y` — год, `%m` — месяц, `%d` — день, `%H` — часы, `%M` — минуты.

## Арифметика: timedelta

Из дат можно вычитать и к ним прибавлять интервалы:

```python
from datetime import timedelta

tomorrow = now + timedelta(days=1)
delta = tomorrow - now
print(delta.total_seconds())  # 86400.0
```

## JSON: dumps и loads

JSON — текстовый формат обмена данными, понятный почти всем языкам. Python-объекты превращаются в JSON-строку через `dumps`, а обратно — через `loads`:

```python
import json

data = {"name": "Аня", "age": 25, "tags": ["python", "курс"]}
s = json.dumps(data, ensure_ascii=False, indent=2)
print(s)
```

`ensure_ascii=False` оставляет русские буквы как есть, `indent=2` придаёт читабельный вид.

## Файлы: dump и load

Для работы с файлами используются `dump` и `load`:

```python
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

with open("data.json", encoding="utf-8") as f:
    restored = json.load(f)

print(restored["name"])  # Аня
```

## Нестандартные объекты

`datetime` не сериализуется в JSON напрямую — будет ошибка. Решение: переводить в ISO-строку `isoformat()` или передать `default=str` в `dumps`.

### Разбор 1
Решение:

```python
from datetime import date
import json

events = [
    {"name": "Новый год", "date": "2026-12-31"},
    {"name": "День рождения", "date": "2026-11-15"},
    {"name": "Релиз проекта", "date": "2027-03-01"},
]

with open("events.json", "w", encoding="utf-8") as f:
    json.dump(events, f, ensure_ascii=False, indent=2)

with open("events.json", encoding="utf-8") as f:
    loaded = json.load(f)

today = date.today()
for event in loaded:
    when = date.fromisoformat(event["date"])
    left = (when - today).days
    print(f"{event['name']}: осталось {left} дн.")
```

Что здесь происходит? Сначала `json.dump` сохраняет список словарей в файл: `ensure_ascii=False` сохраняет кириллицу, `indent=2` — красивое оформление. Затем `json.load` восстанавливает ровно тот же список. `date.fromisoformat` принимает строку вида `"2026-12-31"` и превращает её в объект `date`. Разность двух дат даёт `timedelta`, а свойство `.days` — целое число дней. Осталось подставить его в f-строку.

Пример вывода (при запуске 1 ноября 2026 года):

```
Новый год: осталось 60 дн.
День рождения: осталось 14 дн.
Релиз проекта: осталось 120 дн.
```

Такой пары «JSON для хранения + datetime для вычислений» хватает для множества реальных задач: напоминания, планы, ленты событий.

### Разбор 2
Решение:

```python
from datetime import date

birth_str = "2000-05-15"
birth = date.fromisoformat(birth_str)
today = date.today()

# Возраст: разница лет минус поправка, если день рождения ещё не наступил
age = today.year - birth.year - ((today.month, today.day) < (birth.month, birth.day))

# Следующий день рождения: в этом году, а если уже прошёл — в следующем
next_birthday = date(today.year, birth.month, birth.day)
if next_birthday < today:
    next_birthday = date(today.year + 1, birth.month, birth.day)

days_left = (next_birthday - today).days
print(f"Возраст: {age} лет, до дня рождения: {days_left} дн.")
```

Как считаем возраст? Базовая формула `today.year - birth.year` даёт 26. Но если день рождения в этом году ещё не наступил, реальный возраст на единицу меньше. Булево сравнение кортежей `(today.month, today.day) < (birth.month, birth.day)` — `True` (равно 1), когда сегодняшний месяц-день раньше даты рождения; вычитаем его из разницы лет. Следующий день рождения: пробуем `date(today.year, birth.month, birth.day)`, а если он уже прошёл (раньше сегодня), берём тот же месяц-день следующего года. Разность в днях берём через `.days`.

Вывод (при запуске 1 ноября 2026 года):

```
Возраст: 26 лет, до дня рождения: 195 дн.
```

### Разбор 3
Решение:

```python
from datetime import datetime

start = datetime.strptime("09:30", "%H:%M")
end = datetime.strptime("17:45", "%H:%M")

delta = end - start
minutes = int(delta.total_seconds() // 60)
print(f"Продолжительность: {minutes} минут")
```

`datetime.strptime("09:30", "%H:%M")` создаёт объект `datetime` с датой 1900-01-01 и заданным временем — дата не важна, потому что обе строки разбираются одинаково, и разность зависит только от времени. `end - start` даёт `timedelta`, равный 8 часам 15 минутам. `.total_seconds()` переводит его в секунды (29700), `// 60` — в целые минуты (495), а `int(...)` снимает тип float. 8 часов 15 минут = 495 минут.

Вывод:

```
Продолжительность: 495 минут
```

Этот приём работает и с датами: если разбирать полные строки вида `"2026-11-01 09:30"`, разность учтёт и дни.

### Разбор 4
Решение:

```python
from datetime import datetime
import json

data = {"event": "старт", "created": datetime(2026, 11, 1, 10, 30)}

s = json.dumps(data, ensure_ascii=False, default=str)
restored = json.loads(s)

print(restored["created"])
print(type(restored["created"]).__name__)
```

Стандартный JSON не знает тип `datetime`: если вызвать `json.dumps(data)` без `default`, Python выбросит `TypeError`. Параметр `default=str` говорит: «для всего, что не умеет сериализовать, вызови `str()`». Для `datetime` это даёт строку `"2026-11-01 10:30:00"`. При обратном разборе `json.loads` видит обычную строку и не пытается «угадать» в ней дату, поэтому в восстановленном словаре `created` — строка. Мы это проверяем и печатаем её тип.

Вывод:

```
2026-11-01 10:30:00
str
```

Если нужно сохранить именно дату, а не строку — пиши свой конвертер или переводи в ISO-формат вручную.

### Разбор 5
Решение:

```python
from datetime import date, timedelta

today = date.today()

in_month = today + timedelta(days=30)
year_end = date(today.year, 12, 31)
left = (year_end - today).days

print("Через 30 дней:", in_month.strftime("%d.%m.%Y"))
print("До конца года:", left, "дн.")
```

`today + timedelta(days=30)` прибавляет к сегодняшней дате ровно 30 дней: арифметика сама разберётся с переходом через месяц. `.strftime("%d.%m.%Y")` форматирует результат: день, месяц и год с нулями (`01.12.2026`). Конец года строится явно: `date(today.year, 12, 31)`. Разность `year_end - today` даёт `timedelta`, а `.days` — целое число дней до Нового года.

Вывод (при запуске 1 ноября 2026 года):

```
Через 30 дней: 01.12.2026
До конца года: 60 дн.
```

Комбинация `timedelta` и `strftime` покрывает большинство бытовых задач с датами: дедлайны, напоминания, отчёты.
