Какой метод вызывается автоматически при создании объекта класса?
- __init__
- __new__
- __main__
- __start__
* Правильный ответ: __init__
Метод __init__ — конструктор, он инициализирует новый объект.

Зачем в наследнике вызывают super().__init__()?
- Чтобы переопределить класс
- Чтобы вызвать метод родительского класса
- Чтобы создать новый объект
- Чтобы завершить программу
* Правильный ответ: Чтобы вызвать метод родительского класса
super() обращается к методам базового класса, сохраняя инициализацию родителя.

Что делает декоратор над функцией?
- Удаляет функцию
- Ускоряет выполнение кода
- Оборачивает функцию, расширяя её поведение
- Меняет имя функции
* Правильный ответ: Оборачивает функцию, расширяя её поведение
Декоратор — это функция, которая принимает функцию и возвращает новую версию с дополнительным поведением.

Чем генератор отличается от обычной функции?
- Возвращает список сразу
- Использует yield и вычисляет значения лениво
- Не может принимать аргументы
- Всегда возвращает None
* Правильный ответ: Использует yield и вычисляет значения лениво
Генератор отдаёт значения по одному через yield и не хранит их все в памяти сразу.

Какие методы реализует контекстный менеджер?
- __open__ / __close__
- __enter__ / __exit__
- __start__ / __stop__
- __begin__ / __end__
* Правильный ответ: __enter__ / __exit__
Блок with выполняет __enter__ при входе и __exit__ при выходе, даже если произошла ошибка.

Что такое lambda?
- Тип данных
- Анонимная функция
- Модуль
- Декоратор
* Правильный ответ: Анонимная функция
lambda x: x * 2 создаёт небольшую функцию без имени в одном выражении.

Какой декоратор упрощает создание классов-хранилищ данных?
- @classmethod
- @dataclass
- @property
- @staticmethod
* Правильный ответ: @dataclass
@dataclass автоматически генерирует __init__, __repr__ и сравнение для полей класса.

Как объявить асинхронную функцию?
- async def fetch_data(): ...
- await def fetch_data(): ...
- async function fetch_data(): ...
- def fetch_data() async: ...
* Правильный ответ: async def fetch_data(): ...
Асинхронные функции объявляются через async def, а ожидание результата — через await.

Что вернёт re.findall(r"\d+", "цена: 100 руб.")?
- ["100"]
- ["цена", "100"]
- [100]
- ["цена:"]
* Правильный ответ: ["100"]
re.findall возвращает список всех совпадений шаблона; \d+ находит последовательности цифр.

Как создать изолированное окружение для проекта?
- pip freeze
- python -m venv env
- python install env
- pip install venv
* Правильный ответ: python -m venv env
Команда python -m venv создаёт виртуальное окружение с собственными пакетами.
