Python силён не только сам по себе, но и всем, что построено вокруг него: библиотеками, инструментами и людьми. Сегодня мы заглянем в этот мир и научимся в нём ориентироваться.

## PyPI: золотая жила

Главный склад пакетов Python называется PyPI (Python Package Index) — это сайт `pypi.org`, где лежат сотни тысяч библиотек. Если тебе нужна функция — с вероятностью 99% кто-то уже написал библиотеку для неё. Рисовать графики, парсить сайты, делать игры, работать с таблицами, телеграм-ботами, нейросетями — для всего есть готовые решения.

## pip: волшебный курьер

Библиотеки устанавливаются командой `pip` прямо из терминала:

```bash
pip install requests
```

Эта команда скачает пакет с PyPI и поставит его в твоё окружение. Затем можно просто импортировать:

```python
import requests
```

Пакетов много, поэтому принято вести их список в файле `requirements.txt` — тогда любой человек может воспроизвести твоё окружение одной командой `pip install -r requirements.txt`.

## Известные библиотеки

Вот несколько имён, которые ты будешь встречать постоянно:

- `requests` — запросы к сайтам (HTTP);
- `beautifulsoup4` — разбор HTML-страниц;
- `numpy` — математика и массивы;
- `pandas` — таблицы и анализ данных;
- `matplotlib` — графики и визуализация;
- `django` и `flask` — веб-сайты;
- `pygame` — игры;
- `pillow` — работа с изображениями;
- `pytest` — тестирование.

Что важно: **бесплатность и открытость**. Почти все библиотеки — open source: исходный код открыт, его можно читать, изучать и улучшать. Это лучший учебник, который только можно придумать.

## Окружения и чистота

Разные проекты требуют разных версий библиотек. Чтобы они не мешали друг другу, используют виртуальные окружения:

```bash
python -m venv .venv
```

В Windows активируется так: `.venv\Scripts\activate`, в macOS/Linux: `source .venv/bin/activate`. После этого `pip` ставит пакеты в изолированное окружение.

## Сообщество: люди, которые любят Python

За языком стоят люди. Ежегодно проходят конференции PyCon в десятках стран, включая PyCon Russia. Проект PEP (Python Enhancement Proposal) — это документы, предлагающие улучшения языка: любой может предложить свою идею. А Python Software Foundation (PSF) — некоммерческая организация, которая управляет развитием языка.

Помочь сообществу можно даже новичку: ответить на вопрос на форуме, перевести документацию, сообщить об ошибке в библиотеке, написать пост о том, чему научился. Именно так всё и растёт: люди делятся, и язык становится лучше. Дзен Python говорит: «Сейчас лучше, чем никогда» — так что начни участвовать сегодня.

### Разбор 1
Решение:

```python
library_guide = {
    "requests": "запросы к сайтам",
    "pandas": "таблицы и анализ данных",
    "matplotlib": "графики и визуализация",
    "django": "веб-сайты",
    "pygame": "игры",
}

for name, description in library_guide.items():
    print(f"{name} — {description}")
```

Результат:

```
requests — запросы к сайтам
pandas — таблицы и анализ данных
matplotlib — графики и визуализация
django — веб-сайты
pygame — игры
```

Что здесь происходит? Мы храним данные в словаре, где ключ — имя библиотеки, а значение — описание. Цикл `for name, description in library_guide.items()` распаковывает каждую пару. f-string собирает строку вывода. Такой подход удобен: чтобы добавить библиотеку, достаточно дописать одну строку в словарь — цикл сам выведет её. Данные отделены от логики вывода, это хороший стиль.

### Разбор 2
Решение:

```python
guide = {
    "сайт": "django",
    "график": "matplotlib",
    "таблица": "pandas",
    "игра": "pygame",
    "запросы": "requests",
}

def recommend(task):
    return guide.get(task, "Не знаю, поищи на PyPI!")

for task in ["сайт", "график", "таблица", "игра", "запросы", "бот"]:
    print(task, "→", recommend(task))
```

Результат:

```
сайт → django
график → matplotlib
таблица → pandas
игра → pygame
запросы → requests
бот → Не знаю, поищи на PyPI!
```

Что здесь происходит? Метод `dict.get(task, default)` — безопасный способ достать значение: если ключа нет, возвращается значение по умолчанию. Так функция `recommend` делает всё за одну строку: без `if` и явного `return`, для отсутствующего ключа. Это идиоматичный Python: коротко, ясно и без ветвлений. Проверка на пяти известных задачах и одном неизвестном слове показывает оба пути.

### Разбор 3
Решение:

```python
import importlib

packages = ["requests", "pandas", "flask", "pygame"]

for name in packages:
    try:
        importlib.import_module(name)
        print(f"{name} — установлен")
    except ImportError:
        print(f"{name} — не установлен")
```

Результат (пример):

```
requests — установлен
pandas — установлен
flask — не установлен
pygame — не установлен
```

Что здесь происходит? `importlib.import_module(name)` пытается импортировать модуль по имени — так же, как `import requests`, но с именем из переменной. Если модуль установлен, импорт проходит успешно и печатается «установлен». Если нет — поднимается `ImportError`, который мы ловим и печатаем «не установлен». Эта техника полезна, когда надо проверить наличие десятков пакетов, не зная заранее, какие из них есть. Результат на твоём компьютере может отличаться — это нормально.

### Разбор 4
Решение:

```python
def print_requirements(packages):
    print("Мой requirements.txt:")
    print("\n".join(packages))

print_requirements(["requests", "pandas", "matplotlib"])
```

Результат:

```
Мой requirements.txt:
requests
pandas
matplotlib
```

Что здесь происходит? `"\n".join(packages)` склеивает элементы списка символом перевода строки — получается многострочный текст. Так выглядит настоящий файл `requirements.txt`: по одному названию пакета на строку. Этот файл — стандарт индустрии: его можно приложить к проекту, и любой человек воспроизведёт окружение командой `pip install -r requirements.txt`. Мы не печатаем кавычки, поэтому вывод точно соответствует реальному формату файла.

### Разбор 5
Решение:

```python
import random

ideas = [
    "почитать документацию по pandas",
    "написать пост о том, что выучил",
    "ответить на вопрос новичка",
    "изучить исходный код любимой библиотеки",
    "поучаствовать в PyCon",
]

idea = random.choice(ideas)
print(f"Сегодня я: {idea}!")
```

Результат (один из вариантов):

```
Сегодня я: изучить исходный код любимой библиотеки!
```

Что здесь происходит? `random.choice(ideas)` выбирает один случайный элемент из списка. При каждом запуске программа предложит разную идею — это маленький «оракул сообщества». f-string подставляет выбранную идею в фразу. Хотя результат случаен, программа всегда выведет ровно одну строку. Такой генератор случайности — простой способ добавить жизни и неожиданности любой программе.
