Ты уже знаешь достаточно, чтобы начать создавать своё. Проекты для души — это не «обязаловка», а то, что делает навык живым: ты выбираешь тему, которая согревает, и превращаешь её в код. Сегодня я покажу пять каркасов — надёжных отправных точек, а дальше полёт фантазии твой.

## Почему это важно

Учебные задачки учат синтаксису, а проекты учат творить: проектировать, разбивать на функции, доводить до конца. Вдобавок готовый проект — лучший портфолио: он говорит о тебе больше, чем любой сертификат.

## Идея 1: CLI-список дел

Управление задачами из терминала. Каркас: словарь `{название: статус}` плюс функции `add`, `list_tasks`, `done`:

```python
tasks = {}

def add(name):
    tasks[name] = False

def list_tasks():
    for name, completed in tasks.items():
        mark = "✓" if completed else "○"
        print(f"{mark} {name}")

add("Сделать уроки")
list_tasks()
```

## Идея 2: Текстовая игра

Бродилка по комнатам: комната — это словарь с описанием и выходами:

```python
rooms = {
    "кухня": {"описание": "Пахнет пирогами.", "выходы": {"север": "гостиная"}},
    "гостиная": {"описание": "Большой диван.", "выходы": {"юг": "кухня"}},
}
```

## Идея 3: Трекер привычек

Отмечай дни, когда выполнил привычку, и считай непрерывную серию:

```python
week = [False, True, True, True]

def streak(days):
    count = 0
    for day in reversed(days):
        if not day:
            break
        count += 1
    return count

print(streak(week))  # 3: три последних дня подряд True
```

## Идея 4: Генератор мотивации

Вдохновляющие фразы + случайность + персональное имя:

```python
import random

phrases = ["Ты справишься!", "Каждый день — шаг вперёд!"]
print(random.choice(phrases))
```

## Идея 5: Анализатор текста

Считай слова, находи частые, находи палиндромы:

```python
from collections import Counter

text = "питон змея питон"
words = text.split()
print(Counter(words))  # Counter({'питон': 2, 'змея': 1})
```

`collections.Counter` — готовый счётчик, маленькая, но могучая фишка.

## Главное правило проекта

Дели проект на функции, каждая — маленькая и понятная. Начинай с самого простого варианта, который работает, а потом усложняй. Ни один великий проект не был написан за вечер — зато каждый начинался с первой рабочей версии. «Сейчас лучше, чем никогда» — помнишь?

### Разбор 1
Решение:

```python
tasks = {}

def add(task):
    tasks[task] = False

def list_tasks():
    for task, done in tasks.items():
        mark = "✓" if done else "○"
        print(f"{mark} {task}")

def mark_done(task):
    tasks[task] = True

add("Выучить урок")
add("Прочитать главу")
add("Сделать зарядку")
mark_done("Выучить урок")

list_tasks()
```

Результат:

```
✓ Выучить урок
○ Прочитать главу
○ Сделать зарядку
```

Что здесь происходит? Словарь `tasks` хранит задачи: ключ — название, значение — статус. Функция `add` добавляет задачу с пометкой «не выполнена» (`False`). `list_tasks` идёт по всем задачам и выбирает символ через тернарное выражение `"✓" if done else "○"`. `mark_done` меняет статус. Программа — цельный мини-проект: его легко расширить (удаление, сохранение в файл, приоритеты), но и в таком виде он уже работает.

### Разбор 2
Решение:

```python
rooms = {
    "кухня": {"описание": "Пахнет пирогами.", "выходы": {"север": "гостиная"}},
    "гостиная": {"описание": "Большой диван.", "выходы": {"юг": "кухня", "восток": "сад"}},
    "сад": {"описание": "Цветут розы.", "выходы": {"запад": "гостиная"}},
}

def go(room, direction):
    if direction in rooms[room]["выходы"]:
        return rooms[room]["выходы"][direction]
    return "Туда нельзя!"

next_room = go("кухня", "север")
print(next_room, "—", rooms[next_room]["описание"])
next_room = go("гостиная", "восток")
print(next_room, "—", rooms[next_room]["описание"])
next_room = go("сад", "запад")
print(next_room, "—", rooms[next_room]["описание"])
print(go("кухня", "юг"))
```

Результат:

```
гостиная — Большой диван.
сад — Цветут розы.
гостиная — Большой диван.
Туда нельзя!
```

Что здесь происходит? Каждая комната — словарь с описанием и выходами. Функция `go` проверяет, есть ли направление в словаре выходов: если есть — возвращает имя новой комнаты, если нет — сообщение «Туда нельзя!». Это ядро любой текстовой игры. Дальше игру легко развивать: добавить предметы, инвентарь, условия победы — структура данных уже готова.

### Разбор 3
Решение:

```python
def streak(days):
    count = 0
    for day in reversed(days):
        if not day:
            break
        count += 1
    return count

print(streak([True, True, False, True, True]))
print(streak([True, True, True]))
print(streak([False, True, False]))
```

Результат:

```
2
3
0
```

Что здесь происходит? `reversed(days)` обходит список с конца — от последнего дня к первому. Пока день — `True`, мы увеличиваем счётчик. Как только встречается `False`, цикл прерывается `break`. В первом примере последние два дня — True, серия равна 2. Во втором все три дня — True, серия 3. В третьем последний день — False, поэтому счётчик остаётся 0. Так работает «серия» (streak) в трекерах привычек — та самая механика, что поддерживает людей в ежедневных занятиях.

### Разбор 4
Решение:

```python
import random

phrases = [
    "каждый день — шаг вперёд!",
    "ты справишься с любой задачей!",
    "код не кусается, пробуй!",

]

```

Результат (пример):

```
Как тебя зовут? Аня
Аня, каждый день — шаг вперёд!
```

Что здесь происходит? `input` спрашивает имя, `random.choice` выбирает случайную фразу из списка, f-string собирает итоговое приветствие. При каждом запуске программа может выдать разную фразу — это делает её «живой». Такой генератор мотивации — отличный подарок другу или просто весёлый скрипт на рабочий стол. Проект легко расширить: добавить время суток, список достижений, случайные эмодзи.

### Разбор 5
Решение:

```python
from collections import Counter

text = "солнце светит ярко солнце греет землю"
words = text.split()
counts = Counter(words)

for word, count in counts.most_common(3):
    print(f"{word}: {count}")
```

Результат:

```
солнце: 2
светит: 1
ярко: 1
```

Что здесь происходит? `text.split()` разбивает строку на слова по пробелам. `Counter(words)` подсчитывает, сколько раз встретилось каждое слово, — возвращает словарь счётчиков. `most_common(3)` отдаёт три самых частых пары `(слово, количество)` в порядке убывания частоты. Цикл распаковывает пары и печатает их. Это база для анализа текстов: от стихов до новостей. Можешь заменить текст на свой — и увидеть, какие слова ты используешь чаще всего. Подобные анализаторы — отличный способ «увидеть» свой текст по-новому.
