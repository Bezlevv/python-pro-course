Какой слайс вернёт строку "питон" в обратном порядке?
- "питон"[::-1]
- "питон"[::1]
- "питон"[-1:]
* Правильный ответ: "питон"[::-1]
Отрицательный шаг -1 обходит последовательность с конца.

Что делает строка a, b = b, a?
- Меняет местами значения a и b без третьей переменной
- Копирует a в b
- Присваивает a значение b, а b остаётся прежним
* Правильный ответ: Меняет местами значения a и b без третьей переменной
Правая часть собирает кортеж, который распаковывается в переменные слева.

Что вернёт zip([1, 2], ["a", "b"]), обёрнутый в list()?
- [(1, "a"), (2, "b")]
- [1, 2, "a", "b"]
- [(1, 2), ("a", "b")]
* Правильный ответ: [(1, "a"), (2, "b")]
zip склеивает элементы с одинаковыми индексами в кортежи.

Что делает key-слово yield в функции?
- Превращает функцию в генератор
- Возвращает функцию
- Завершает программу
* Правильный ответ: Превращает функцию в генератор
yield временно приостанавливает выполнение и отдаёт значение.

Сколько раз можно перебрать генератор?
- Один раз, после чего он исчерпан
- Бесконечное число раз
- Два раза
* Правильный ответ: Один раз, после чего он исчерпан
Генератор ленив и после полного прохода не повторяет значения.

Что делает @functools.cache?
- Кэширует результаты вызовов функции
- Ускоряет интернет
- Запоминает имя функции
* Правильный ответ: Кэширует результаты вызовов функции
cache сохраняет результат для каждого аргумента и переиспользует его.

Какой блок перехватит ошибку при делении на ноль?
- except ZeroDivisionError
- except TypeError
- except ValueError
* Правильный ответ: except ZeroDivisionError
ZeroDivisionError возникает именно при делении на ноль.

Что делает из.cycle(["a", "b"])?
- Бесконечно повторяет элементы
- Возвращает список
- Сортирует список
* Правильный ответ: Бесконечно повторяет элементы
cycle зацикливает последовательность: a, b, a, b, ...

Зачем нужен field(default_factory=list) в dataclass?
- Чтобы каждый объект получил отдельный список
- Чтобы список был общим
- Чтобы поле было обязательным
* Правильный ответ: Чтобы каждый объект получил отдельный список
default_factory создаёт новый список для каждого экземпляра.

Что такое PyPI?
- Склад пакетов Python
- Язык программирования
- Команда установки
* Правильный ответ: Склад пакетов Python
PyPI — репозиторий библиотек, откуда pip устанавливает пакеты.
