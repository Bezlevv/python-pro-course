Настало время тех фишек, ради которых стоит любить Python: маленьких, но мощных инструментов из стандартной библиотеки. Они превращают нудный код в короткий и выразительный.

## Декораторы: функции, украшающие функции

Декоратор — функция, которая принимает функцию и возвращает новую, расширенную версию. Классика — замер времени:

```python
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f"{func.__name__} заняла {elapsed:.6f} сек")
        return result
    return wrapper

@timer
def slow_square(x):
    time.sleep(0.1)
    return x * x

print(slow_square(5))  # выведет время и 25
```

Запись `@timer` — это просто сахар для `slow_square = timer(slow_square)`. Функция `wrapper` принимает любые аргументы (`*args, **kwargs`) и передаёт их дальше — так декоратор подходит любой функции.

## functools.cache: мгновенный кэш

Декоратор `@functools.cache` запоминает результаты вызовов. Вернуть Fibonacci без экспоненциальной сложности — одна строка:

```python
from functools import cache

@cache
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(50))  # 12586269025, мгновенно
```

Без `@cache` такой вызов считался бы миллиарды лет. Кэш — это и есть «помнить о прошлом».

## contextlib: менеджеры контекста без классов

Оператор `with` гарантирует, что ресурс будет закрыт, даже если случится ошибка:

```python
with open("notes.txt", "w") as f:
    f.write("Привет!")
```

А `@contextlib.contextmanager` позволяет сделать свой менеджер контекста простой функцией:

```python
from contextlib import contextmanager

@contextmanager
def temporary_message():
    print("Входим в блок")
    yield
    print("Выходим из блока")

with temporary_message():
    print("Внутри блока")
```

## itertools: фабрика итераторов

Модуль `itertools` — кладезь маленьких генераторов:

```python
from itertools import count, cycle, chain

# бесконечный счётчик
evens = count(0, 2)          # 0, 2, 4, ...
print(next(evens), next(evens))  # 0 2

# цикл по списку
turns = cycle(["камень", "ножницы", "бумага"])
print(next(turns), next(turns), next(turns))  # камень ножницы бумага

# склейка последовательностей
combined = chain([1, 2], [3, 4])
print(list(combined))  # [1, 2, 3, 4]
```

## dataclasses: классы для данных без рутины

Обычный класс-«мешок данных» требует писать `__init__`, `__repr__`, сравнения... `@dataclass` делает это автоматически:

```python
from dataclasses import dataclass

@dataclass
class Book:
    title: str
    author: str
    pages: int

book = Book("Война и мир", "Толстой", 1274)
print(book)          # Book(title='Война и мир', author='Толстой', pages=1274)
print(book.pages)    # 1274
```

Одна строка декоратора — и класс получил конструктор, красивое представление и сравнение между экземплярами.

## Зачем это всё?

Эти инструменты не просто сокращают код — они убирают целые классы ошибок: декораторы избавляют от копирования таймеров, кэш — от ручных словарей-кэшей, контекст-менеджеры — от забытых закрытий файлов, dataclasses — от опечаток в `__init__`. Это фишки, которые делают программиста быстрее и код — надёжнее. Давай попробуем их в деле.

### Разбор 1
Решение:

```python
def logger(func):
    def wrapper(*args, **kwargs):
        print(f"Вызываем {func.__name__}")
        result = func(*args, **kwargs)
        print("Готово!")
        return result
    return wrapper

@logger
def add(a, b):
    return a + b

print(add(3, 4))
```

Результат:

```
Вызываем add
Готово!
7
```

Что здесь происходит? Декоратор `logger` — функция, которая принимает `func` и возвращает `wrapper`. Когда мы пишем `@logger` над `add`, Python делает `add = logger(add)`, и теперь `add` — это `wrapper`. При вызове `add(3, 4)` выполняется `wrapper`: печатает имя функции, вызывает настоящий `add` с теми же аргументами (`*args, **kwargs` передают их без изменений), печатает «Готово!» и возвращает результат. Благодаря `*args, **kwargs` декоратор можно вешать на любые функции.

### Разбор 2
Решение:

```python
from functools import cache

calls = 0

@cache
def fib(n):
    global calls
    calls += 1
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(30))
print("Вызовов с кэшем:", calls)
```

Результат:

```
832040
Вызовов с кэшем: 31
```

Что здесь происходит? `@cache` запоминает результат для каждого аргумента. Поэтому каждый `n` от 0 до 30 вычисляется ровно один раз: всего 31 вызов вместо миллионов. Без декоратора `fib(30)` рекурсивно вызвала бы себя около 2,7 миллиона раз — и числа росли бы экспоненциально. Кэш — элегантное решение классической проблемы: мы добавляем один декоратор и получаем ускорение в сотни тысяч раз. При этом код остаётся чистым и читаемым.

### Разбор 3
Решение:

```python
from contextlib import contextmanager

@contextmanager
def indent():
    def print_line(line):
        print(">>>", line)
    yield print_line
    print("<<<")

with indent() as print_indented:
    print_indented("строка 1")
    print_indented("строка 2")
```

Результат:

```
>>> строка 1
>>> строка 2
<<<
```

Что здесь происходит? Код до `yield` выполняется при входе в `with` — здесь мы создаём функцию `print_line` и отдаём её через `yield`. Переменная `print_indented` в `with` получает именно её. Внутри блока мы вызываем `print_indented`, и она печатает строки с префиксом `>>>`. Когда блок заканчивается, выполняется код после `yield` — `print("<<<")`. Эта конструкция — компактный способ сделать менеджер контекста без класса с методами `__enter__` и `__exit__`.

### Разбор 4
Решение:

```python
from itertools import count, cycle, islice

print(list(islice(count(0, 2), 5)))
print(list(islice(cycle(["🐍", "❤️"]), 6)))
```

Результат:

```
[0, 2, 4, 6, 8]
['🐍', '❤️', '🐍', '❤️', '🐍', '❤️']
```

Что здесь происходит? `count(0, 2)` — бесконечный счётчик чётных чисел. Сам по себе он бесконечен, поэтому мы ограничиваем его через `islice(..., 5)`, который берёт первые 5 элементов. `cycle(["🐍", "❤️"])` бесконечно повторяет список, и `islice` берёт первые 6 элементов. Обрати внимание: весь модуль `itertools` построен на ленивых генераторах — бесконечные последовательности не занимают память, они вычисляются по требованию.

### Разбор 5
Решение:

```python
from dataclasses import dataclass, field

@dataclass
class Student:
    name: str
    group: str = "PY-31"
    scores: list = field(default_factory=list)

    def average(self):
        if self.scores:
            return sum(self.scores) / len(self.scores)
        return 0.0

anna = Student("Аня", scores=[5, 4, 5, 4])
borya = Student("Боря")

print(anna)
print(anna.average())
print(borya)
print(borya.average())
```

Результат:

```
Student(name='Аня', group='PY-31', scores=[5, 4, 5, 4])
4.5
Student(name='Боря', group='PY-31', scores=[])
0.0
```

Что здесь происходит? `@dataclass` автоматически генерирует конструктор, `__repr__` (красивое представление для `print`) и сравнение объектов. `field(default_factory=list)` — обязательный приём для изменяемых значений по умолчанию: без него все студенты делили бы один общий список. Метод `average()` использует тернарное выражение: если оценки есть — считает среднее, иначе — `0.0`. Класс получился коротким, но полноценным — без рутины ручного `__init__`.
