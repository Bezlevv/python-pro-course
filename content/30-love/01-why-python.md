Есть языки, которые уважают. Есть языки, которым подчиняются. А есть язык, который любят, — и это Python. В этом уроке мы начнём разговор о том, почему миллионы людей по всему миру называют его своим любимым. Это не маркетинг и не хайп: почти у каждого Python-разработчика есть своя история первой встречи — момент, когда код вдруг начал читаться как английский текст, а не как шифр.

## Главное: Python читается

Начнём с главного. Вот программа:

```python
name = "Аня"
age = 25
print("Привет, меня зовут", name, "и мне", age)
```

Даже человек, который никогда в жизни не программировал, примерно понимает, что здесь происходит. Эта читаемость — не мелочь. Настоящие программы живут годами, их читают десятки разных людей, и времени на чтение кода тратится в разы больше, чем на его написание. Python делает этот процесс почти удовольствием: код похож на инструкцию на английском языке с минимальным синтаксисом.

## Простота входа

Второе, за что Python любят, — простота первого шага. Чтобы начать, не нужно разбираться в указателях, сборке мусора, перегрузке операторов и архитектуре компилятора. Ты можешь написать первую полезную программу в первый же вечер. Сравни: на C тот же «Привет, мир» занимает четыре строки с угловыми скобками, а здесь — одна строка. А если что-то не так, сообщения об ошибках у Python понятные и добрые: они пишут, что именно не так и где.

```python
print("Привет, мир!")
```

## «Батарейки в комплекте»

Третье — принцип batteries included («батарейки в комплекте»). Стандартная библиотека Python умеет работать с файлами, архивами, датами, интернетом, математикой, тестированием и даже с почтой. Всё это есть сразу, без установки чего-либо дополнительно. Для многих задач вообще не нужно ставить ни одной сторонней библиотеки — просто открой документацию стандартной библиотеки.

## Универсальность и один язык на всё

Четвёртое — универсальность. Один и тот же язык используется для автоматизации рутины, создания сайтов, анализа данных, искусственного интеллекта, игр, научных расчётов и робототехники. Можно менять направление карьеры или хобби, не меняя язык. Это редкий дар: вложенное время в Python никогда не пропадает.

```python
# Одна и та же функция print пригодится везде
print("Автоматизация, аналитика, веб, ИИ — всё это Python")
```

## Люди

И наконец — люди. У Python одно из самых дружелюбных сообществ в мире. Новичкам помогают, над «глупыми» вопросами не смеются, а документация и уроки есть на всех языках, включая русский. Это сообщество каждый год проводит конференции PyCon в десятках стран, а в интернете полно чатов, где тебе ответят даже в три часа ночи.

Мы не будем торопиться. Этот модуль — про душу языка. Впереди: почему элегантный код — это навык, а не роскошь; Дзен Python; удивительные фишки, ради которых стоит открывать документацию; и проекты для души, которые хочется показывать друзьям.

А чтобы ты почувствовал тепло прямо сейчас, выполни вот это в своей среде:

```python
# Первая программа модуля «Душа Python»
print("Я начинаю понимать, почему Python любят")
```

Если ты видишь эту строку на экране — поздравляю, ты официально принят в ряды любителей Python. 💛 Теперь закрепим любовь практикой.

### Подсказка 1
Переменной присваивается значение через `=`: `name = "Аня"`. Чтобы использовать её в `print()`, передай имя переменной без кавычек: `print("Меня зовут", name)`. Если поставить кавычки вокруг `name`, напечатается слово name, а не её значение.
### Подсказка 2
`input("Вопрос: ")` приостанавливает программу, ждёт, пока пользователь напечатает текст и нажмёт Enter, а затем возвращает введённую строку. Сохрани результат: `name = input("Как тебя зовут? ")`. Дальше используй `name` в `print()` как обычную переменную.
### Подсказка 3
Внутри `print()` можно сразу писать выражения: `print("В неделе", 7 * 24, "часов")`. Python сначала вычислит `7 * 24`, а потом напечатает всё через пробел. Напиши четыре факта четырьмя вызовами `print()`.
### Подсказка 4
Внимательно посмотри на каждую строку: в первой не хватает закрывающей кавычки, во второй — знака `+` между строкой и переменной, а в третьей использовано русское слово `печать` вместо `print`. Исправь эти три момента и добавь комментарий с пояснением.
### Подсказка 5
Запятая в `print()` расставляет пробелы сама, а знак `+` — только там, где ты сам их написал. Комментарий начинается с `#` и идёт до конца строки. Пример: `# Это строка о любви к Python` над вызовом `print()`.

### Разбор 1
Одно из возможных решений:

```python
name = "Аня"
favorite_thing = "читать книги"
dream = "написать свою программу"

print("Меня зовут", name)
print("Я люблю", favorite_thing)
print("Моя мечта —", dream)
```

Результат:

```
Меня зовут Аня
Я люблю читать книги
Моя мечта — написать свою программу
```

Что здесь происходит? Мы создали три переменные и записали в них строки. Затем передали переменные в `print()` через запятую: Python подставил их значения вместо имён. Обрати внимание: переменные передаются без кавычек, иначе напечаталось бы слово `name`, а не `Аня`. Такой приём — переменные вместо повторения текста — основа любой программы: информация хранится в одном месте, а используется во многих строках.

### Разбор 2
Решение:

```python
name = input("Как тебя зовут? ")
print("Привет,", name, "! Добро пожаловать в мир Python!")

activity = input("Что ты любишь делать? ")
print("Круто, что ты любишь", activity, "!")
```

Результат (если пользователь ввёл `Аня` и `рисовать`):

```
Как тебя зовут? Аня
Привет, Аня ! Добро пожаловать в мир Python!
Что ты любишь делать? рисовать
Круто, что ты любишь рисовать !
```

Что здесь происходит? `input()` ждёт ввода с клавиатуры и возвращает строку. Мы сохраняем её в переменную `name`, а затем используем в `print()`. Обрати внимание на пробелы: в `print("Привет,", name, "! ...")` между запятой и `name` появится лишний пробел перед `!` — это нормально для первого раза, а в следующем уроке ты узнаешь, как склеивать строки красивее. Главное здесь — диалог с пользователем: программа становится интерактивной.

### Разбор 3
Решение:

```python
print("В неделе", 7 * 24, "часов")
print("В сутках", 24 * 60, "минут")
print("В часе", 60 * 60, "секунд")
print("В обычном году", 365, "дней")
```

Результат:

```
В неделе 168 часов
В сутках 1440 минут
В часе 3600 секунд
В обычном году 365 дней
```

Что здесь происходит? Внутри `print()` мы пишем арифметические выражения прямо в аргументах. Python сначала вычисляет `7 * 24`, получает `168` и лишь затем печатает все значения через пробел. То, что вычисления можно делать прямо в `print()`, — удобно для коротких программ, но в больших проектах результат обычно сохраняют в переменные, чтобы использовать его несколько раз.

### Разбор 4
Исправленный код:

```python
print("Привет, мир!")
print("Меня зовут", "Аня")
print("Это не C — это Python!")
```

Результат:

```
Привет, мир!
Меня зовут Аня
Это не C — это Python!
```

Что здесь происходит? В исходном коде было три ошибки. Первая строка не имела закрывающей кавычки — Python выдал `SyntaxError: unterminated string literal`, потому что не понял, где заканчивается текст. Во второй строке не хватало запятой или знака `+` между строкой и значением — Python ждал продолжения выражения. В третьей строке было использовано русское слово `печать` вместо `print` — Python не нашёл такой функции и выдал `NameError: name 'печать' is not defined`. Все три ошибки — из самых частых у новичков, и теперь ты умеешь их читать и исправлять. Запомни: текст ошибки почти всегда подсказывает, что именно не так.

### Разбор 5
Решение:

```python
# Строка из нескольких значений через запятую
print("Я люблю Python за", "читаемость", "и", "простоту")

# Строка, собранная из частей через +
print("Python — это " + "язык для души")

# Строка с числами и переменными
year = 1991
print("Python появился в", year, "году")
```

Результат:

```
Я люблю Python за читаемость и простоту
Python — это язык для души
Python появился в 1991 году
```

Что здесь происходит? В первом вызове запятые заставляют `print()` вставлять пробелы между значениями автоматически. Во втором — знак `+` склеивает две строки в одну, и пробел сохраняется только потому, что мы сами написали его в конце первой части. В третьем — мы используем переменную `year` с числом. Комментарии `#` Python полностью игнорирует: они нужны только людям, которые читают код. Такой «плакат» — отличный способ запомнить, что утверждения о программе лучше хранить в переменных, а текст — собирать из понятных частей.
