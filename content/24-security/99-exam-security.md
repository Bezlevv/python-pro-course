Что такое OWASP Top 10?
- Список десяти самых распространённых классов рисков веб-приложений
- Десять обязательных библиотек Python
- Топ-10 языков для веб-разработки
* Правильный ответ: Список десяти самых распространённых классов рисков веб-приложений
OWASP Top 10 — категории рисков из данных реальных атак.

Какой класс рисков описывает IDOR — обращение к чужим объектам через подменённый id?
- A01 — Сломанный контроль доступа
- A03 — Инъекции
- A10 — SSRF
* Правильный ответ: A01 — Сломанный контроль доступа
Права должны определяться по проверенным данным пользователя, а не по id из запроса.

Как правильно читать секрет из окружения?
- os.environ.get(name) с проверкой на None и ошибкой
- Хранить значение прямо в коде
- Записывать в requirements.txt
* Правильный ответ: os.environ.get(name) с проверкой на None и ошибкой
Секреты приходят из окружения; отсутствие секрета — повод упасть.

Какой инструмент проверяет зависимости на известные CVE?
- pip-audit
- git commit
- black
* Правильный ответ: pip-audit
pip-audit сверяет пакеты с базой OSV; safety — аналогичный инструмент.

Что такое SSRF?
- Сервер по указанию злоумышленника обращается к внутренним адресам
- Кража cookie сессии
- Переполнение буфера
* Правильный ответ: Сервер по указанию злоумышленника обращается к внутренним адресам
Защита — блокировка приватных, loopback и link-local адресов.

Какая строка — пример SQL-инъекции?
- ' OR '1'='1
- SELECT * FROM users
- admin123
* Правильный ответ: ' OR '1'='1
Без параметризации она вернёт все строки таблицы.

Почему pickle опасен?
- Он может выполнить произвольный код при распаковке
- Он слишком медленный
- Он не поддерживает словари
* Правильный ответ: Он может выполнить произвольный код при распаковке
Метод __reduce__ кодирует вызов любой функции.

Чем хеширование отличается от шифрования?
- Хеширование одностороннее, шифрование обратимо
- Это одно и то же
- Шифрование медленнее
* Правильный ответ: Хеширование одностороннее, шифрование обратимо
Из хеша нельзя восстановить исходные данные, а зашифрованные — можно.

Зачем нужна соль при хешировании паролей?
- Чтобы одинаковые пароли давали разные хеши
- Чтобы ускорить проверку
- Чтобы сократить хеш
* Правильный ответ: Чтобы одинаковые пароли давали разные хеши
Соль разрушает таблицы радужных хешей.

Что делает RotatingFileHandler?
- Обрезает лог-файл при достижении размера и хранит резервные копии
- Удаляет все логи
- Шифрует логи
* Правильный ответ: Обрезает лог-файл при достижении размера и хранит резервные копии
maxBytes и backupCount ограничивают объём логов.
