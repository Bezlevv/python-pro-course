Какой JOIN вернёт пользователя без заказов, если он стоит слева, а заказы — справа?
- INNER JOIN
- LEFT JOIN
- CROSS JOIN
- Никакой
* Правильный ответ: LEFT JOIN
LEFT JOIN сохраняет все строки левой таблицы, подставляя NULL там, где нет совпадений справа.

Чем HAVING отличается от WHERE?
- HAVING фильтрует строки до группировки, WHERE — после
- HAVING фильтрует группы после агрегации, WHERE — строки до неё
- Это полные синонимы
- HAVING работает только с JOIN
* Правильный ответ: HAVING фильтрует группы после агрегации, WHERE — строки до неё
WHERE не видит результатов агрегатных функций; для этого нужен HAVING.

Какое нарушение устраняет 3НФ?
- Частичную зависимость от составного ключа
- Транзитивную зависимость колонок друг от друга
- Отсутствие первичного ключа
- Хранение неатомарных значений
* Правильный ответ: Транзитивную зависимость колонок друг от друга
3НФ требует 2НФ и отсутствия зависимостей вида «колонка зависит от другой непервичной колонки».

Что ускоряет индекс в базе данных?
- Запись данных
- Поиск строк по колонке без полного сканирования
- Создание таблиц
- Резервное копирование
* Правильный ответ: Поиск строк по колонке без полного сканирования
Индекс (обычно B-дерево) сокращает путь к нужным строкам; запись при этом замедляется.

Какая буква ACID отвечает за то, что транзакция либо применяется целиком, либо откатывается?
- A (Atomicity)
- C (Consistency)
- I (Isolation)
- D (Durability)
* Правильный ответ: A (Atomicity)
Атомарность: «всё или ничего» — частичный успех невозможен.

Какой уровень изоляции полностью исключает грязное чтение, неповторяемое чтение и фантомы?
- READ UNCOMMITTED
- READ COMMITTED
- REPEATABLE READ
- SERIALIZABLE
* Правильный ответ: SERIALIZABLE
SERIALIZABLE — самый строгий: транзакции выполняются так, будто они идут одна за одной.

Что делает ROLLBACK TO sp1 внутри транзакции?
- Откатывает всю транзакцию
- Откатывает изменения, сделанные после savepoint sp1
- Удаляет все таблицы
- Завершает соединение
* Правильный ответ: Откатывает изменения, сделанные после savepoint sp1
Savepoint — точка отката; ROLLBACK TO возвращает базу к ней, не завершая транзакцию.

В чём причина проблемы N+1 в ORM?
- База дублирует данные
- Сначала грузится N объектов, затем для каждого выполняется ещё один запрос к связанным данным
- Индексы не используются
- Запросы выполняются параллельно
* Правильный ответ: Сначала грузится N объектов, затем для каждого выполняется ещё один запрос к связанным данным
Ленивая загрузка связей порождает 1 + N запросов; решается жадной загрузкой (selectinload, select_related).

Какая защита от SQL-инъекций является главной?
- Удаление лишних пробелов
- Параметризованные запросы (плейсхолдеры)
- Чёрный список SQL-слов
- Шифрование базы
* Правильный ответ: Параметризованные запросы (плейсхолдеры)
Значения отправляются отдельно от текста запроса и никогда не становятся кодом.

Что делает команда SETEX key 300 value в Redis?
- Читает значение ключа
- Записывает значение с временем жизни 300 секунд
- Увеличивает значение на 300
- Создаёт список из 300 элементов
* Правильный ответ: Записывает значение с временем жизни 300 секунд
SETEX — атомарная комбинация SET и EXPIRE, стандартный способ положить данные в кэш с TTL.
