UV is a fast, modern package manager built for Python: one tool for environments, dependencies and running scripts.

## Install

```bash
pip install uv
```

## Start a project

```bash
uv init myproj
cd myproj
```

Creates pyproject.toml and an example script.

## Add dependencies

```bash
uv add requests
uv add --dev pytest
```

## Run

```bash
uv run python script.py
uv run pytest
```

## Virtual env

```bash
uv venv
uv sync
```

## Tool

```bash
uv tool install ruff
```

## Lesson summary

UV combines pip, venv and more: fast, reproducible, simple.
