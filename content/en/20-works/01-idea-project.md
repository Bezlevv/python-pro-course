Projects turn ideas into working software.

## Choose

- Solves a real problem;
- Within your skills;
- Small enough to finish.

## Plan

Features, milestones, deadlines.

## Scope

Minimal core first; add later.

## Lesson summary

Start small, define success, build.

<!--TASK-->
### Task 1 — Idea
Write three project ideas.

### Task 2 — Choose
Pick one and justify.

### Task 3 — Features
List 5 features.

### Task 4 — MVP
Define the minimal version.

### Task 5 — Milestones
Split into 3 steps.

### Task 6 — Risks
Name two risks.

### Task 7 — Success
Define "done".
