What does the STAR method stand for?
- Situation, Task, Action, Result
- Simple, Technical, Advanced, Review
- Start, Test, Apply, Restart
- Script, Type, Answer, Request
* Correct answer: Situation, Task, Action, Result
STAR is a framework for telling an achievement story: situation, task, actions, result.

What resume length is optimal for a junior or mid-level developer?
- One page
- Five pages
- Only a portfolio
- It doesn't matter
* Correct answer: One page
One page is the standard: recruiters skim resumes, extra content distracts.

What's wrong with this code: def add(item, result=[]): result.append(item); return result?
- The default list is created once and accumulates data between calls
- Lists can't be used in arguments
- Such code won't run
- Nothing is wrong
* Correct answer: The default list is created once and accumulates data between calls
A mutable default argument is shared across all calls — fixed with None.

What does yield do in a function?
- Turns the function into a generator
- Terminates the program
- Returns a value and ends the function
- Declares a constant
* Correct answer: Turns the function into a generator
yield pauses execution and yields one value at a time, saving memory.

What is the complexity of two nested loops over an array of size n?
- O(n²)
- O(n)
- O(log n)
- O(1)
* Correct answer: O(n²)
Two nested loops perform n × n operations.

What data structure is needed to solve Two Sum in O(n)?
- A dictionary (hash table)
- A tuple
- A set combined with a loop
- Two nested loops
* Correct answer: A dictionary (hash table)
A dict stores seen numbers and gives O(1) complement lookup.

What does the CAP theorem state?
- A distributed system cannot simultaneously guarantee consistency, availability, and partition tolerance
- Every system must sacrifice availability
- Databases cannot be distributed
- Consistency always matters more
* Correct answer: A distributed system cannot simultaneously guarantee consistency, availability, and partition tolerance
CAP describes a trade-off: only two of the three properties are achievable at once.

What is Redis used for in system design?
- Caching frequently read data in memory
- Storing the main document archive
- Replacing the frontend
- Generating short links
* Correct answer: Caching frequently read data in memory
Redis keeps data in RAM, giving millisecond responses.

How many stories should you prepare for a behavioral interview?
- 6–10
- 1–2
- 50+
- None
* Correct answer: 6–10
A map of 6–10 stories covers the main themes: conflicts, mistakes, deadlines.

What's important to do when you receive an offer?
- Ask for time to think and evaluate the whole compensation
- Agree immediately
- Decline without explanation
- State a counter number instantly
* Correct answer: Ask for time to think and evaluate the whole compensation
An offer is a reason to calmly compare conditions, not decide on the spot.
