Why is Python considered an excellent first programming language?
- Its code reads almost like English text, and it has a huge community
- It's the only language that works without a computer
- It doesn't require learning syntax
* Correct answer: Its code reads almost like English text, and it has a huge community
Readability and community support make the start easy, and the prospects huge.

What does import this do in Python?
- Prints the "Zen of Python" — the language's philosophy
- Updates Python to a new version
- Shows the list of installed libraries
* Correct answer: Prints the "Zen of Python" — the language's philosophy
import this prints Python's design principles, e.g., "Beautiful is better than ugly".

Which Python module is most convenient for working with files and folders?
- pathlib
- random
- statistics
* Correct answer: pathlib
pathlib represents paths as objects with methods mkdir, rename, iterdir.

What does the while True loop combined with break do?
- Runs forever until break exits the loop
- Runs exactly once
- Runs until the first input
* Correct answer: Runs forever until break exits the loop
This is the basis of bots: listen to messages and exit on command.

Which module allows HTTP requests without installing extra libraries?
- urllib.request
- turtle
- hashlib
* Correct answer: urllib.request
urllib.request is part of the standard library and can access URLs.

Which library is the main tool for tabular data analytics?
- Pandas
- tkinter
- socket
* Correct answer: Pandas
Pandas can load, filter, and group data.

Which library lets you create desktop windows without installation?
- tkinter
- pygame
- Kivy
* Correct answer: tkinter
tkinter is built into Python and creates windows with buttons and labels.

What does hashlib.sha256(text.encode()).hexdigest() do?
- Returns the text's hash as a string
- Encrypts text so it can be decrypted later
- Compresses text
* Correct answer: Returns the text's hash as a string
A hash is an irreversible "fingerprint" of data; the text cannot be restored from it.

Which Python framework does Instagram run on?
- Django
- Flask
- Kivy
* Correct answer: Django
Instagram is one of the largest projects on Django.

What does the letter M in SMART mean?
- Measurable — a measurable goal
- More
- Memory
* Correct answer: Measurable — a measurable goal
A goal should have a sign of success that shows whether it's achieved.
