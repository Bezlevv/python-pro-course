Какой модуль стандартной библиотеки разбирает аргументы командной строки?
- argparse
- getopt
- click
* Правильный ответ: argparse
argparse входит в стандартную библиотеку и позволяет гибко описывать аргументы.

Что вернёт subprocess.run(["echo", "hi"], capture_output=True, text=True).stdout?
- "hi\n"
- "hi"
- b"hi\n"
* Правильный ответ: "hi\n"
text=True возвращает строку, а capture_output=True собирает вывод; перевод строки сохраняется.

Какой формат конфигов читает tomllib?
- TOML
- JSON
- YAML
* Правильный ответ: TOML
tomllib появился в Python 3.11 для чтения TOML-файлов.

Почему лучше использовать yaml.safe_load вместо yaml.load?
- Потому что safe_load не создаёт произвольные объекты при разборе
- Потому что safe_load быстрее
- Потому что load устарел и удалён
* Правильный ответ: Потому что safe_load не создаёт произвольные объекты при разборе
safe_load защищает от выполнения опасных объектов из ненадёжных файлов.

Что вернёт re.findall(r"\d+", "2026 год, 3 задачи")?
- ['2026', '3']
- '20263'
- ['2026', '0', '3']
* Правильный ответ: ['2026', '3']
findall возвращает список всех совпадений шаблона.

Как получить код возврата команды в paramiko?
- stdout.channel.recv_exit_status()
- client.returncode
- stderr.read()
* Правильный ответ: stdout.channel.recv_exit_status()
recv_exit_status() ждёт завершения и возвращает код возврата команды.

Что означает запись 0 3 * * * в crontab?
- Выполнение в 03:00 каждый день
- Выполнение каждые 3 минуты
- Выполнение в 00:03 каждый час
* Правильный ответ: Выполнение в 03:00 каждый день
Поля: минута 0, час 3, день месяца *, месяц *, день недели *.

Чем отличаются schedule и cron?
- schedule живёт внутри Python-процесса, cron — системный планировщик
- schedule работает только в Windows, cron — только в Linux
- Это одно и то же
* Правильный ответ: schedule живёт внутри Python-процесса, cron — системный планировщик
cron переживает перезагрузку системы, schedule исчезает вместе с процессом.

Что делает schedule.run_pending()?
- Запускает задачи, чьё время наступило
- Останавливает все задачи
- Спит одну секунду
* Правильный ответ: Запускает задачи, чьё время наступило
run_pending() нужно вызывать в цикле, чтобы задачи выполнялись.

Какой код возврата должен вернуть скрипт в CI при провале проверки?
- 1
- 0
- 2
* Правильный ответ: 1
Ненулевой код означает провал: CI остановит пайплайн и пометит сборку красной.

Что делает Path("data").rglob("*.log")?
- Ищет файлы .log рекурсивно во всех подпапках data
- Ищет файлы .log только в самой папке data
- Создаёт файлы .log
* Правильный ответ: Ищет файлы .log рекурсивно во всех подпапках data
rglob обходит всё дерево каталога, glob — только текущий уровень.

Как прочитать JSON-файл в Python?
- json.load(f)
- json.dump(f)
- json.read(f)
* Правильный ответ: json.load(f)
json.load читает JSON из файла-объекта и возвращает словарь.
