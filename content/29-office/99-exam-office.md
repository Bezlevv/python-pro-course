Какой класс создаёт новую книгу Excel в openpyxl?
- Workbook
- Worksheet
- Cell
* Правильный ответ: Workbook
Workbook() создаёт книгу; листы внутри — объекты Worksheet.

Что вернёт load_workbook("f.xlsx", data_only=True) для формулы, если файл не открывался в Excel?
- None
- Строку формулы
- 0
* Правильный ответ: None
Кэшированные значения появляются только после пересчёта и сохранения в Excel.

Как задать жирный шрифт в ячейке?
- cell.font = Font(bold=True)
- cell.bold = True
- cell.style = "bold"
* Правильный ответ: cell.font = Font(bold=True)
Шрифт назначается объектом Font через свойство font ячейки.

Что делает ws.merge_cells("A1:C1")?
- Объединяет ячейки A1, B1 и C1
- Разделяет ячейки
- Скрывает колонку A
* Правильный ответ: Объединяет ячейки A1, B1 и C1
После слияния диапазон становится одной ячейкой, а данные хранятся в верхней левой.

Как добавить столбчатую диаграмму на лист?
- Создать BarChart, описать Reference и вызвать ws.add_chart(chart, "E2")
- Вызвать ws.bar_chart("E2")
- Вставить картинку с суммой
* Правильный ответ: Создать BarChart, описать Reference и вызвать ws.add_chart(chart, "E2")
Диаграмма собирается из объектов chart, Reference и прикрепляется методом add_chart.

Из чего состоит параграф в python-docx?
- Из run-ов с единым форматированием
- Из ячеек
- Из разделов
* Правильный ответ: Из run-ов с единым форматированием
Именно на run-ах задаются жирность, размер и цвет шрифта.

Как добавить таблицу 3×2 в Word-документ?
- doc.add_table(rows=3, cols=2)
- doc.table(3, 2)
- doc.add_rows(3, 2)
* Правильный ответ: doc.add_table(rows=3, cols=2)
add_table принимает количество строк и колонок.

Что такое story в reportlab?
- Список флоуаблов для сборки PDF
- Текстовый файл
- Папка с картинками
* Правильный ответ: Список флоуаблов для сборки PDF
doc.build(story) собирает PDF из абзацев, таблиц и других элементов.

Как извлечь текст из PDF для проверки?
- reader.pages[0].extract_text()
- pdf.text()
- reader.content
* Правильный ответ: reader.pages[0].extract_text()
PdfReader из библиотеки pypdf возвращает текст страницы методом extract_text().

Какой инструмент даёт тесту временную папку?
- Фикстура tmp_path в pytest
- os.mkdir
- tempfile всегда автоматически
* Правильный ответ: Фикстура tmp_path в pytest
tmp_path — встроенная фикстура; папка уникальна для теста и очищается после него.
