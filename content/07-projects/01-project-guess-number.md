Привет! До сих пор мы писали маленькие примеры. Сегодня всё будет по-настоящему: мы соберём законченную программу — игру «Угадай число». Она простая, но в ней используются почти все базовые конструкции Python: переменные, условия, циклы, функции и случайные числа.

## О проекте

Компьютер загадывает случайное число от 1 до 100. Игрок вводит свои варианты, а программа говорит, больше или меньше загаданное число. Когда число угадано, программа поздравляет и показывает, сколько попыток потрачено. В конце можно сыграть ещё раз.

Что ты получишь в итоге:

- консольную игру, которую можно запустить командой `python guess_number.py`;
- опыт сборки программы по шагам.

## План сборки

1. Научиться получать случайные числа.
2. Выводить текст и читать ввод с клавиатуры.
3. Сравнивать числа и выводить подсказки.
4. Повторять игру, пока число не угадано; считать попытки.
5. Добавить повторную игру и обработку неверного ввода.

## Шаг 1. Случайные числа

Для случайных чисел в Python есть модуль `random`. Функция `random.randint(a, b)` возвращает целое число от `a` до `b` включительно:

```python
import random

secret = random.randint(1, 100)
print(secret)  # например, 42
```

Не забудь сначала выполнить `import random` — иначе Python не найдёт модуль.

## Шаг 2. Читаем ввод игрока

Функция `input()` ждёт, пока пользователь введёт строку и нажмёт Enter. Важно: `input()` всегда возвращает строку, даже если введены цифры. Чтобы получить число, используй `int()`:

```python
guess_text = input("Твоя догадка: ")
guess = int(guess_text)
```

Если пользователь введёт не число, `int()` кинет ошибку `ValueError`. Как справиться с этим, разберём в шаге 5.

## Шаг 3. Сравниваем числа

Теперь сравним догадку с загаданным числом. Здесь нужны `if`, `elif` и `else`:

```python
if guess < secret:
    print("Загаданное число больше.")
elif guess > secret:
    print("Загаданное число меньше.")
else:
    print("Поздравляю, ты угадал!")
```

## Шаг 4. Цикл и счётчик попыток

Игрок может промахиваться много раз, поэтому процесс нужно повторить. Удобнее всего цикл `while True` с выходом через `break`, когда число угадано. Попытки посчитаем переменной, которую увеличиваем на 1 после каждого ввода:

```python
attempts = 0
while True:
    guess = int(input("Твоя догадка: "))
    attempts += 1
    if guess < secret:
        print("Загаданное число больше.")
    elif guess > secret:
        print("Загаданное число меньше.")
    else:
        print(f"Поздравляю! Ты угадал за {attempts} попыток.")
        break
```

Обрати внимание на f-строку `f"..."`: внутри фигурных скобок подставляются значения переменных.

## Шаг 5. Обработка ошибок и повторная игра

Если пользователь введёт «abc», программа упадёт с ошибкой. Это лечится конструкцией `try/except`: пробуем перевести строку в число, а при `ValueError` выводим предупреждение и начинаем итерацию заново.

Чтобы можно было играть несколько раз, весь игровой процесс вынесем в функцию `play_game()`, а после одной игры спросим: продолжаем или нет.

```python
def play_game():
    secret = random.randint(1, 100)
    attempts = 0
    while True:
        try:
            guess = int(input("Твоя догадка: "))
        except ValueError:
            print("Это не число. Попробуй ещё раз.")
            continue
        attempts += 1
        if guess < secret:
            print("Загаданное число больше.")
        elif guess > secret:
            print("Загаданное число меньше.")
        else:
            print(f"Поздравляю! Ты угадал за {attempts} попыток.")
            break
```

<!--SOLUTION-->
Полное решение:

```python
import random


def play_game():
    """Одна партия игры."""
    secret = random.randint(1, 100)
    attempts = 0
    print("Я загадал число от 1 до 100.")
    while True:
        try:
            guess = int(input("Твоя догадка: "))
        except ValueError:
            print("Это не число. Попробуй ещё раз.")
            continue
        attempts += 1
        if guess < secret:
            print("Загаданное число больше.")
        elif guess > secret:
            print("Загаданное число меньше.")
        else:
            print(f"Поздравляю! Ты угадал за {attempts} попыток.")
            break


while True:
    play_game()
    answer = input("Сыграем ещё раз? (да/нет): ").lower()
    if answer != "да":
        break

print("Спасибо за игру!")
```

Разбор по шагам:

- `import random` — подключаем модуль случайных чисел.
- Функция `play_game()` — вся логика партии. Это удобно: каждая новая игра начинается с вызова функции.
- `random.randint(1, 100)` — загаданное число.
- Бесконечный цикл `while True` — пока игрок не угадает, вопрос задаётся снова.
- `try/except ValueError` — если `input()` вернул нечисловую строку, перевести её в число не получится; ловим ошибку, печатаем предупреждение, а `continue` перезапускает итерацию без увеличения `attempts`.
- `attempts += 1` — счётчик попыток растёт только на корректных ходах.
- Блок `if/elif/else` — подсказка или победа; `break` завершает цикл при победе.
- Главная часть: вызываем `play_game()`, затем спрашиваем, хочет ли игрок продолжить. `.lower()` приводит ответ к нижнему регистру, чтобы «Да» и «да» работали одинаково. Если ответ не «да» — выходим из внешнего цикла и прощаемся.

Запуск: `python guess_number.py`.
