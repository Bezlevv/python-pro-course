Какую функцию использует игра «Угадай число», чтобы загадать число от 1 до 100?
- random.randint(1, 100)
- random.choice(range(100))
- int(random.random() * 100)
- random.sample(1, 100)
* Правильный ответ: random.randint(1, 100)
random.randint(a, b) возвращает целое число от a до b включительно.

Что произойдёт, если игрок введёт «abc», а программа вызовет int(input(...))?
- Программа продолжит работать и подставит 0
- Возникнет исключение ValueError
- Будет напечатано «abc»
- Программа сама переспросит игрока
* Правильный ответ: Возникнет исключение ValueError
input() всегда возвращает строку, и int("abc") не может её преобразовать. Поэтому ввод оборачивают в try/except и просят повторить.

На каком стеке построен ToDo-менеджер?
- Flask + Jinja2 + SQLite
- Django + PostgreSQL
- FastAPI + MongoDB
- Streamlit + Pandas
* Правильный ответ: Flask + Jinja2 + SQLite
Flask — веб-фреймворк, Jinja2 — шаблоны, а SQLite — встроенная база данных для хранения задач.

Зачем в API на FastAPI нужна модель Pydantic?
- Чтобы рисовать интерфейс пользователя
- Чтобы описать структуру данных и автоматически валидировать входные данные
- Чтобы хранить данные в базе
- Чтобы ускорить ответы сервера
* Правильный ответ: Чтобы описать структуру данных и автоматически валидировать входные данные
Аннотации типов и Field(ge=..., le=...) задают ограничения; если данные не проходят проверку, FastAPI сам возвращает ошибку 422.

Что описывает модель Post в блоге на Django?
- Пользователя сайта
- Статью: заголовок, текст, дату
- Комментарий к статье
- Настройки блога
* Правильный ответ: Статью: заголовок, текст, дату
Модель — это таблица в базе данных; после её описания создаются миграции, а управлять статьями можно через админку.

Какой вызов Streamlit выводит ключевую метрику (например, общую выручку)?
- st.metric("Выручка", value)
- st.text(value)
- st.write_metric(value)
- st.show(value)
* Правильный ответ: st.metric("Выручка", value)
st.metric показывает значение с подписью — стандартный способ вывести метрику на дашборде.

Зачем кэшировать загрузку данных в Streamlit-дашборде?
- Чтобы данные не пересчитывались при каждом изменении фильтра
- Чтобы уменьшить размер файла с данными
- Чтобы графики были цветными
- Чтобы виджеты не отображались
* Правильный ответ: Чтобы данные не пересчитывались при каждом изменении фильтра
Streamlit перезапускает скрипт при каждом взаимодействии; кэширование (st.cache_data) позволяет выполнять тяжёлые операции только один раз.

Какие HTTP-методы образуют CRUD в API на FastAPI?
- GET, POST, PUT, DELETE
- OPEN, CLOSE, READ, WRITE
- SELECT, INSERT, UPDATE, DELETE
- GET, SET, PUSH, POP
* Правильный ответ: GET, POST, PUT, DELETE
CRUD — это создание (POST), чтение (GET), обновление (PUT) и удаление (DELETE) ресурса.

Как сохранить обученную модель PyTorch в файл?
- torch.save(model.state_dict(), "model.pth")
- model.save("model.pth")
- pickle.dump(model, "model.pth")
- torch.export(model, "model.pth")
* Правильный ответ: torch.save(model.state_dict(), "model.pth")
state_dict содержит веса модели; при загрузке нужно создать модель той же архитектуры и вызвать load_state_dict().

Зачем для проекта создают виртуальное окружение?
- Чтобы ускорить выполнение кода
- Чтобы изолировать зависимости проекта от системы и других проектов
- Чтобы код работал без Python
- Чтобы автоматически деплоить проект
* Правильный ответ: Чтобы изолировать зависимости проекта от системы и других проектов
Виртуальное окружение хранит свои пакеты отдельно, поэтому разные проекты не конфликтуют версиями библиотек.
