Что делает параметр scope="module" у фикстуры pytest?
- Создаёт фикстуру заново для каждого теста
- Создаёт фикстуру один раз на весь файл
- Запрещает использовать фикстуру
* Правильный ответ: Создаёт фикстуру один раз на весь файл
При scope="module" фикстура создаётся один раз и переиспользуется всеми тестами файла.

Что вернёт вызов MagicMock, если задать mock.get.side_effect = [1, 2]?
- Всегда 1
- 1 при первом вызове и 2 при втором
- Случайное число
* Правильный ответ: 1 при первом вызове и 2 при втором
side_effect со списком раздаёт значения по одному на каждый вызов.

Какую строку нужно патчить, если модуль app написал import requests и вызывает requests.get?
- app.requests.get
- requests.get
- app.get
* Правильный ответ: app.requests.get
Патчится место использования — имя requests.get в пространстве имён модуля app.

Какой порядок фаз в TDD?
- Реализация → тесты → рефакторинг
- Тест (красный) → реализация (зелёный) → рефакторинг
- Рефакторинг → тест → реализация
* Правильный ответ: Тест (красный) → реализация (зелёный) → рефакторинг
Сначала падающий тест, затем минимальная реализация, затем улучшение кода.

Что делает флаг --cov-fail-under=80?
- Завершает прогон с ошибкой, если покрытие ниже 80%
- Ограничивает покрытие 80 строками
- Показывает только первые 80% отчёта
* Правильный ответ: Завершает прогон с ошибкой, если покрытие ниже 80%
Это порог качества: при покрытии ниже 80% pytest завершится с ошибкой.

Как исключить точку входа из подсчёта покрытия?
- Поставить # pragma: no cover в конце строк
- Переименовать файл
- Запустить pytest с флагом --no-main
* Правильный ответ: Поставить # pragma: no cover в конце строк
Комментарий исключает строку из оценки покрытия.

Что делает assume(b != 0) в property-тесте?
- Бросает исключение при b == 0
- Отбрасывает примеры с нулевым b
- Округляет b
* Правильный ответ: Отбрасывает примеры с нулевым b
assume фильтрует входные данные, для которых свойство не определено.

Что произойдёт, если property-свойство нарушится?
- Hypothesis найдёт контрпример и сократит его до минимального
- Тест пропустится
- Hypothesis перестанет генерировать данные
* Правильный ответ: Hypothesis найдёт контрпример и сократит его до минимального
Автоматическое сокращение (shrinking) — ключевая функция hypothesis.

Какой маркер нужен для теста-корутины?
- @pytest.mark.asyncio
- @pytest.mark.async
- @pytest.mark.await
* Правильный ответ: @pytest.mark.asyncio
Маркер говорит pytest-asyncio запустить тест в событийном цикле.

Почему AsyncMock нужен для асинхронных зависимостей?
- Потому что MagicMock не возвращает awaitable, и await упадёт
- Потому что AsyncMock быстрее
- Потому что MagicMock нельзя импортировать
* Правильный ответ: Потому что MagicMock не возвращает awaitable, и await упадёт
AsyncMock возвращает awaitable, поэтому await client.get(url) работает.
