Привет! Часто нужные данные лежат на сайтах, а официального API у них нет. Тогда на помощь приходит парсинг — извлечение данных из HTML-страниц. Сегодня освоим два инструмента: связку requests + BeautifulSoup для обычных страниц и Selenium для «живых» сайтов, где контент подгружается скриптами.

## HTTP и requests

Когда браузер открывает страницу, он делает HTTP-запрос. Библиотека requests повторяет это из Python:

```python
import requests

resp = requests.get("https://quotes.toscrape.com/", timeout=10)
print(resp.status_code)   # 200 — всё хорошо
html = resp.text
```

`status_code` — код ответа: 200 — успех, 404 — страница не найдена, 403 — доступ запрещён. Для JSON-API есть метод `resp.json()`.

## BeautifulSoup

Сырой HTML разбирается в дерево тегов:

```python
from bs4 import BeautifulSoup

soup = BeautifulSoup(html, "html.parser")
```

Для поиска есть `find()` (первое совпадение), `find_all()` (все совпадения) и `select()` — CSS-селекторы, которые удобнее для вложенных структур:

```python
quotes = soup.select(".quote")
for q in quotes[:2]:
    text = q.select_one(".text").get_text()
    author = q.select_one(".author").get_text()
    print(author, ":", text)
```

`get_text()` вытаскивает текст без тегов, а `attrs` даёт доступ к атрибутам, например `tag["href"]`.

## Кратко об этике

Прежде чем парсить чужой сайт: проверь `robots.txt` (обычно лежит по адресу `site.ru/robots.txt`), не дёргай сервер слишком часто — ставь паузы между запросами, представляйся User-Agent'ом и не публикуй чужие данные без разрешения. Парсинг — техническое действие, но ответственность за его применение лежит на тебе.

## Selenium для динамических страниц

Если данные подгружаются JavaScript'ом, в `resp.text` их не будет — нужен настоящий браузер. Selenium управляет Chrome программно:

```python
from selenium import webdriver
from selenium.webdriver.chrome.options import Options

options = Options()
options.add_argument("--headless=new")  # работать без окна
driver = webdriver.Chrome(options=options)
driver.get("https://example.com")
print(driver.title)
driver.quit()
```

Кликнуть кнопку или ввести текст можно так:

```python
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

button = WebDriverWait(driver, 10).until(
    EC.element_to_be_clickable((By.CSS_SELECTOR, ".btn"))
)
button.click()
```

`WebDriverWait` ждёт появления элемента до 10 секунд — это надёжнее, чем `time.sleep`. Готовый HTML берётся через `driver.page_source` и дальше может быть скормлен BeautifulSoup.

## Какой инструмент выбрать?

- Страница отдаёт данные сразу → requests + BeautifulSoup (быстро и дёшево).
- Данные появляются после скриптов или кликов → Selenium.
- Есть официальный API → используй API, а не парсинг.

### Разбор 1
Полное решение:

```python
import requests
from bs4 import BeautifulSoup

url = "https://quotes.toscrape.com/"
resp = requests.get(url, timeout=10)
print(resp.status_code)

soup = BeautifulSoup(resp.text, "html.parser")
quotes = soup.select(".quote")

print(f"Всего цитат: {len(quotes)}")

for q in quotes[:3]:
    text = q.select_one(".text").get_text()
    author = q.select_one(".author").get_text()
    print(f"{author}: {text}")
```

Разбираем по шагам. `requests.get` загружает страницу; `resp.status_code` — проверка, что запрос прошёл успешно (200). `BeautifulSoup(resp.text, "html.parser")` превращает HTML в дерево, по которому можно искать элементы.

`select(".quote")` выбирает все элементы с классом `quote` — каждый такой блок содержит одну цитату. Внутри блока `select_one(".text")` берёт первый элемент с классом `text` (сама цитата), а `select_one(".author")` — автора. `get_text()` достаёт видимый текст без HTML-тегов: убирает открывающие и закрывающие теги и оставляет только содержимое.

Длина списка `quotes` — число цитат на странице, их 10. Первые три выводятся в формате `Автор: текст`. Этот же паттерн работает на любом сайте: найди селекторы блоков через инструменты разработчика в браузере и повтори алгоритм. Для многостраничного сайта осталось бы добавить цикл по ссылкам «Next», но начинать всегда стоит с одной страницы — сначала убедись, что парсер вытаскивает данные верно.

### Разбор 2
Полное решение:

```python
import requests
from bs4 import BeautifulSoup

base = "https://quotes.toscrape.com"
urls = [base + "/", base + "/page/2/"]

quotes = []
for url in urls:
    resp = requests.get(url, timeout=10)
    soup = BeautifulSoup(resp.text, "html.parser")
    quotes.extend(soup.select(".quote"))

print("Всего цитат за две страницы:", len(quotes))
print("Первая цитата на странице 1:", quotes[0].select_one(".author").get_text())
```

Разберём по шагам. `urls` — список адресов первой и второй страниц. Цикл по ним загружает каждую, разбирает HTML и добавляет найденные блоки цитат в общий список через `quotes.extend(...)`. Метод `extend` дописывает элементы одного списка в конец другого — в отличие от `append`, который добавил бы список как один элемент.

После цикла в `quotes` лежат 20 блоков: 10 с первой страницы и 10 со второй. `len(quotes)` — их общее количество. Автор первой цитаты находится внутри первого блока: `quotes[0].select_one(".author").get_text()` возвращает «Albert Einstein».

Такой паттерн — собирать данные с нескольких страниц в общий список — основа любого серьезного парсера. Дальше список можно превратить в DataFrame pandas, сохранить в CSV или проанализировать.

### Разбор 3
Полное решение:

```python
import requests
from bs4 import BeautifulSoup

resp = requests.get("https://quotes.toscrape.com/", timeout=10)
soup = BeautifulSoup(resp.text, "html.parser")

next_link = soup.select_one(".next a")
print("Ссылка на следующую страницу:", next_link["href"])
print("Текст ссылки:", next_link.get_text(strip=True))
```

Разберём по шагам. На сайте кнопка «Next» находится в блоке с классом `next` и представляет собой тег `<a>`. Селектор `.next a` означает «элемент `<a>` внутри элемента с классом next».

`next_link["href"]` читает атрибут `href` тега — это и есть адрес следующей страницы: `/page/2/`. Обрати внимание, что ссылка относительная: её нужно объединить с базовым адресом сайта, чтобы получить полный URL. `get_text(strip=True)` возвращает видимый текст ссылки («Next»), а `strip=True` убирает пробелы и переносы строк по краям.

Умение извлекать атрибуты — ключевой навык парсинга: именно через `href` строятся пагинация, ссылки на товары, страницы новостей и всё остальное, что связывает страницы сайта в единую структуру.

### Разбор 4
Полное решение:

```python
import requests
from bs4 import BeautifulSoup

resp = requests.get("https://quotes.toscrape.com/", timeout=10)
soup = BeautifulSoup(resp.text, "html.parser")

first = soup.select_one(".quote")
print("Автор первой цитаты:", first.select_one(".author").get_text())

tags = [t.get_text() for t in first.select(".tag")]
print("Теги первой цитаты:", tags)
```

Разберём по шагам. `soup.select_one(".quote")` возвращает первый блок цитаты — аналог `find`, но с CSS-селектором. Внутри блока `first.select_one(".author")` находит автора, а `get_text()` достаёт его имя.

`first.select(".tag")` возвращает список всех элементов с классом `tag` внутри первой цитаты — это теги, которыми помечена цитата. Списковое включение `[t.get_text() for t in ...]` превращает список тегов в список строк: `['changes', 'deep-thoughts', 'thinking', 'world']`.

Такой вложенный поиск — «сначала блок, потом элементы внутри блока» — важнейший приём: он надёжнее глобальных селекторов, потому что не захватывает лишние элементы с других частей страницы. Внутри каждого блока можно находить сколько угодно полей: текст, автор, теги, даты, ссылки.

### Разбор 5
Полное решение:

```python
import requests
from bs4 import BeautifulSoup

base = "https://quotes.toscrape.com"
url = base + "/"
total = 0

while url:
    resp = requests.get(url, timeout=10)
    if resp.status_code != 200:
        print(f"Ошибка {resp.status_code} на {url}")
        break

    soup = BeautifulSoup(resp.text, "html.parser")
    total += len(soup.select(".quote"))

    nxt = soup.select_one(".next a")
    url = base + nxt["href"] if nxt else None

print("Парсинг завершён. Всего цитат:", total)
```

Разберём по шагам. Цикл `while url` выполняется, пока есть адрес для загрузки. На каждой странице мы проверяем статус: если он не 200, печатаем ошибку и выходим через `break` — так парсер не будет молча обрабатывать битые страницы.

Затем считаем цитаты на текущей странице и прибавляем к `total`. После этого ищем ссылку «Next»: если она есть, собираем полный URL через `base + nxt["href"]` и продолжаем цикл; если нет — присваиваем `url = None`, и цикл завершается.

В учебной песочнице 10 страниц по 10 цитат, поэтому итоговый счётчик равен 100. Такой цикл — универсальный шаблон пагинации: он работает на любом сайте со ссылками «дальше», пока парсер не доберётся до последней страницы. Важно помнить про этику: между запросами стоит ставить паузы (`time.sleep`), чтобы не нагружать сервер.
