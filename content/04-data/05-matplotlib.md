## Подключение Matplotlib

Matplotlib работает по принципу «фигура» (figure) и «оси» (axes). Проще всего подключить модуль `pyplot`:

```python
import matplotlib.pyplot as plt
```

Самый простой график — линейный:

```python
plt.plot([1, 2, 3, 4], [10, 20, 15, 25])
plt.show()
```

`plt.show()` открывает окно с графиком. Если ты работаешь в Jupyter Notebook, окно не нужно — график появится прямо под ячейкой.

## Фигура и оси

Для профессиональных графиков лучше создавать фигуру и оси явно. Это даёт контроль над размером и позволяет разместить несколько графиков:

```python
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot([1, 2, 3], [10, 20, 15])
ax.set_title("Продажи по дням")
ax.set_xlabel("День")
ax.set_ylabel("Продажи")
plt.show()
```

Обрати внимание: теперь методы вызываются у объекта `ax`, а не у `plt`. Это современный стиль, который мы будем использовать дальше.

## Построение графиков

**Линейный график** — `plot()`. Он отлично показывает изменения во времени:

```python
days = ["пн", "вт", "ср", "чт"]
sales = [120, 95, 110, 130]
ax.plot(days, sales, marker="o", color="green", linestyle="--", label="Продажи")
```

Параметры: `marker` — маркер точек, `color` — цвет, `linestyle` — стиль линии, `label` — подпись для легенды.

**Столбчатая диаграмма** — `bar()`. Она хороша для сравнения категорий:

```python
ax.bar(days, sales, color="steelblue")
```

**Гистограмма** — `hist()`. Она показывает распределение числовых данных:

```python
import numpy as np
values = np.random.normal(100, 15, 200)  # 200 случайных значений
ax.hist(values, bins=20, color="orange", edgecolor="black")
```

**Точечный график** — `scatter()` — для связи двух числовых переменных:

```python
ax.scatter([1, 2, 3], [2, 4, 3])
```

## Легенда и сетка

Несколько линий на одном графике подписываются легендой, а сетка делает чтение точнее:

```python
ax.plot(days, sales, label="Продажи")
ax.plot(days, [x * 1.2 for x in sales], label="План")
ax.legend()
ax.grid(True)
```

## Несколько графиков в одной фигуре

Функция `subplots(rows, cols)` создаёт сетку из графиков. Вернётся массив осей:

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 4))
axes[0].bar(days, sales)
axes[1].plot(days, sales, marker="o")
plt.show()
```

Каждая ось оформляется независимо.

## Сохранение графика

Вместо `plt.show()` можно сохранить рисунок в файл:

```python
fig.savefig("sales.png", dpi=150)
```

`dpi` — качество (dots per inch). Сохранённый файл можно вставить в отчёт или презентацию.

products = ["Кофе", "Чай", "Сок", "Печенье"]

fig, ax = plt.subplots(figsize=(8, 5))

Список в `color=[...]` задаёт цвет каждому столбцу индивидуально: кофе — синий, чай — оранжевый, сок — зелёный, печенье — красный. Такая раскраска помогает быстро выделить «лидеров» и «аутсайдеров». Подписи осей поясняют единицы измерения (рубли), а `fig.savefig()` сохраняет результат.

Горизонтальная столбчатая диаграмма — лучший выбор для ранжирования категорий: глаз мгновенно считывает, какой столбец длиннее, и сравнивает порядок сверху вниз.

### Разбор 5
Полное решение:

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(1)
months = ["Янв", "Фев", "Мар", "Апр", "Май"]
values = [120, 135, 142, 128, 155]
x = np.arange(50)
y = np.random.normal(0, 1, 50)
heights = np.random.randint(5, 50, 7)

fig, axes = plt.subplots(2, 2, figsize=(10, 8))

axes[0][0].plot(months, values, marker="o")
axes[0][0].set_title("Продажи по месяцам")

axes[0][1].bar(np.arange(len(heights)), heights)
axes[0][1].set_title("Заказы по дням")

axes[1][0].hist(y, bins=15, color="orange", edgecolor="black")
axes[1][0].set_title("Распределение случайных величин")

axes[1][1].scatter(x, y)
axes[1][1].set_title("Точечный график")

fig.suptitle("Дашборд кафе")
fig.tight_layout()
fig.savefig("dashboard.png")
print("Дашборд сохранён в dashboard.png")
```

Разберём по шагам. `plt.subplots(2, 2, figsize=(10, 8))` создаёт сетку 2×2 и возвращает фигуру и двумерный массив осей. Каждая ось доступна по паре индексов: `axes[0][0]` — верхний левый угол, `axes[0][1]` — верхний правый, `axes[1][0]` — нижний левый, `axes[1][1]` — нижний правый.

На четырёх осях мы строим разные типы графиков: линейный (динамика продаж), столбчатый (заказы), гистограмму (распределение) и точечный (связь двух переменных). `fig.suptitle()` добавляет общий заголовок над всей сеткой, а `fig.tight_layout()` автоматически раздвигает графики, чтобы подписи не пересекались.

`fig.savefig("dashboard.png")` сохраняет всю фигуру целиком. Такой дашборд — типичный итог анализа: четыре взгляда на данные на одном листе, который можно вставить в отчёт или презентацию.
