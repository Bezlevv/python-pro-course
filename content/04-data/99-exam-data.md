Что выведет (np.array([1, 2, 3]) + 1)?
- [1, 2, 3, 1]
- [2, 3, 4]
- Ошибку
- [[2], [3], [4]]
* Правильный ответ: [2, 3, 4]
Операции над массивом NumPy применяются поэлементно ко всем значениям сразу.

Сколько чисел вернёт np.linspace(0, 1, 5)?
- 4
- 5
- 6
- 10
* Правильный ответ: 5
linspace создаёт указанное количество равноудалённых чисел, включая оба конца диапазона.

Какой метод DataFrame покажет первые 5 строк?
- df.first()
- df.head()
- df.top()
- df.begin()
* Правильный ответ: df.head()
df.head() по умолчанию возвращает первые 5 строк таблицы.

Как проверить, где в DataFrame есть пропуски?
- df.nan()
- df.isna()
- df.zeros()
- df.empty()
* Правильный ответ: df.isna()
df.isna() возвращает таблицу из True/False: True стоит там, где значение отсутствует.

Что делает df.dropna()?
- Удаляет столбцы с пропусками
- Удаляет строки с пропусками
- Заполняет пропуски нулями
- Ничего не меняет
* Правильный ответ: Удаляет строки с пропусками
dropna() удаляет строки, в которых есть хотя бы одно пропущенное значение.

Какой вызов строит линейный график?
- plt.bar(x, y)
- plt.plot(x, y)
- plt.scatter(x, y)
- plt.hist(y)
* Правильный ответ: plt.plot(x, y)
plt.plot соединяет точки линией — классический линейный график.

Что делает plt.show()?
- Сохраняет график в файл
- Отображает построенные графики в окне
- Закрывает все окна
- Очищает фигуру
* Правильный ответ: Отображает построенные графики в окне
Без plt.show() график не появится на экране в обычных скриптах.

Какой интерфейс Seaborn связан с Pandas?
- Работает только с чистыми списками
- Принимает DataFrame напрямую для статистических графиков
- Требует конвертации в NumPy
- Несовместим с Python
* Правильный ответ: Принимает DataFrame напрямую для статистических графиков
Seaborn построен поверх Matplotlib и принимает DataFrame, например: sns.countplot(data=df, x="city").

Как прочитать таблицу из CSV-файла в DataFrame?
- pd.read_csv("data.csv")
- pd.open("data.csv")
- pd.from_csv("data.csv")
- pd.load("data.csv")
* Правильный ответ: pd.read_csv("data.csv")
pd.read_csv — основной способ загрузки табличных данных из CSV.

Какой вызов делит данные на обучающую и тестовую выборки?
- train_test_split(X, y, test_size=0.2)
- split_data(X, y, 0.2)
- divide(X, y, 0.2)
- model.split(X, y, 0.2)
* Правильный ответ: train_test_split(X, y, test_size=0.2)
train_test_split из scikit-learn случайно делит данные: 80% на обучение и 20% на проверку.
