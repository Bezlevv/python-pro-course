Что делает оператор := (walrus)?
- Присваивает значение переменной внутри выражения и сразу возвращает его
- Сравнивает два значения
- Объявляет глобальную переменную
- Ничем не отличается от обычного =
* Правильный ответ: Присваивает значение переменной внутри выражения и сразу возвращает его
Например, while (line := input()) != "": читает строку и сразу проверяет её в условии.

Что означает образец case _ в match/case?
- Ошибку компиляции
- «Дикую карту»: ловит всё, что не подошло предыдущим веткам
- Комментарий
- Повторение предыдущей ветки
* Правильный ответ: «Дикую карту»: ловит всё, что не подошло предыдущим веткам
case _ — это финальная ветка по умолчанию, как else в if/elif/else.

Какую пользу даёт Enum по сравнению с обычными строками или числами?
- Он ускоряет выполнение программы
- Он даёт именованные константы: опечатка в имени сразу даёт AttributeError, а не ошибку значения позже
- Он уменьшает количество импортов
- Он автоматически сортирует значения
* Правильный ответ: Он даёт именованные константы: опечатка в имени сразу даёт AttributeError, а не ошибку значения позже
Члены перечисления сравниваются по идентичности, а документация по именам читается лучше магических чисел.

Что делает ruff?
- Запускает программу с отладчиком
- Ищет ошибки и проблемы стиля в коде, умеет исправлять их автоматически
- Компилирует Python-код в машинный
- Приводит код к единому стилю оформления
* Правильный ответ: Ищет ошибки и проблемы стиля в коде, умеет исправлять их автоматически
Ruff — быстрый линтер: он находит неиспользуемые импорты, неопределённые имена и стилевые нарушения.

Что делает black?
- Запускает тесты
- Приводит оформление кода к единому стилю автоматически
- Проверяет типы
- Оптимизирует скорость выполнения программы
* Правильный ответ: Приводит оформление кода к единому стилю автоматически
Black — «бескомпромиссный» форматтер: он переписывает код в едином стиле, убирая споры об оформлении.

Что делает mypy?
- Проверяет соответствие значений аннотациям типов
- Измеряет время выполнения функций
- Деплоит код на сервер
- Сортирует импорты
* Правильный ответ: Проверяет соответствие значений аннотациям типов
Mypy — статическая проверка типов: она ловит, например, функцию, которая обещает вернуть str, а возвращает float.

Когда срабатывают хуки pre-commit?
- При каждом запуске программы
- При каждом git commit
- При каждом сохранении файла
- При каждом установке зависимостей
* Правильный ответ: При каждом git commit
Хуки выполняются перед коммитом, и если проверка провалилась — коммит блокируется.

Что делает фабричный метод как паттерн проектирования?
- Предоставляет общий интерфейс для создания объектов, оставляя конкретный класс подклассам
- Запрещает создание объектов
- Синхронизирует доступ к общим данным
- Кэширует результаты вызовов функций
* Правильный ответ: Предоставляет общий интерфейс для создания объектов, оставляя конкретный класс подклассам
Фабричный метод — порождающий паттерн: код работает с интерфейсом, а какой именно объект создать, решает подкласс.

Какова временная сложность бинарного поиска по отсортированному массиву?
- O(n)
- O(log n)
- O(n²)
- O(1)
* Правильный ответ: O(log n)
Каждый шаг делит область поиска пополам, поэтому количество шагов растёт логарифмически от размера массива.

В каком файле описываются метаданные современного Python-пакета?
- setup.py
- pyproject.toml
- requirements.txt
- Pipfile
* Правильный ответ: pyproject.toml
Это единый стандарт (PEP 621) для метаданных, сборки и настроек инструментов; команда python -m build создаёт sdist и wheel.
