Python развивается, и вместе с новыми версиями приходят удобные конструкции, которые делают код короче и понятнее. В этом уроке разберём три вещи: оператор `:=` (walrus, появился в Python 3.8), сопоставление с образцом `match/case` (Python 3.10) и перечисления `Enum`. Даже если ты уже писал на Python — эти инструменты стоит знать, потому что они встречаются в реальных проектах повсюду.

## Оператор walrus: :=

Обычное присваивание — это оператор `=`, который сам по себе не возвращает значение. Walrus-оператор `:=` (по форме похож на глаза и бивни моржа) присваивает значение **внутри выражения** и сразу возвращает его.

Классический пример — чтение строк в цикле. Раньше приходилось писать так:

```python
line = input("> ")
while line != "":
    print("Ты написал:", line)
    line = input("> ")
```

С `:=` это превращается в одну аккуратную строку:

```python
while (line := input("> ")) != "":
    print("Ты написал:", line)
```

Обрати внимание на скобки: они нужны, потому что `:=` имеет низкий приоритет, и без них условие прочиталось бы неверно. Важное правило: не злоупотребляй walrus. Если конструкция становится сложной для чтения — лучше вернуться к обычному присваиванию.

## Сопоставление с образцом: match/case

Оператор `match` — это «прокачанный» аналог `switch` из других языков. Он сравнивает значение с несколькими шаблонами (образцами) и выполняет код первого подходящего:

```python
def handle_command(command: str) -> None:
    match command.split():
        case ["go", direction]:
            print(f"Идём на {direction}")
        case ["go", *route]:
            print(f"Маршрут: {' → '.join(route)}")
        case []:
            print("Пустая команда")
        case _:
            print("Не понял команду")
```

Здесь мы сопоставляем **список слов** с шаблонами: `["go", direction]` ловит ровно два слова, `["go", *route]` — команду `go` и любое число следующих слов, а `_` — всё остальное (это «дикая карта»). В шаблон можно подставлять не только списки, но и числа, строки, кортежи, типы. А с помощью **защиты** (`if` после шаблона) можно добавить уточняющее условие:

```python
def describe_http(code: int) -> str:
    match code:
        case 200:
            return "200 OK"
        case 404:
            return "404 Not Found"
        case int(c) if 500 <= c < 600:
            return f"{c} — ошибка сервера"
        case int(c) if 400 <= c < 500:
            return f"{c} — ошибка клиента"
        case _:
            return f"{code} — неизвестный статус"
```

`match` не отменяет обычные `if/elif` — но когда веток много и они похожи на шаблоны, код с `match` читается заметно лучше.

## Перечисления: Enum

`Enum` позволяет описать набор именованных констант. Вместо магических чисел (1, 2, 3) ты получаешь понятные имена:

```python
from enum import Enum, auto


class Direction(Enum):
    NORTH = auto()
    EAST = auto()
    SOUTH = auto()
    WEST = auto()


print(Direction.NORTH.name)   # NORTH
print(Direction.NORTH.value)  # 1
for d in Direction:
    print(d)
```

Члены перечисления сравниваются по идентичности: `Direction.NORTH is Direction.NORTH` — истина, а с обычной строкой `"NORTH"` они не равны. Это защищает от опечаток: если написать `Direction.NORHT`, Python сразу бросит `AttributeError`, тогда как ошибка в строке `"NORHT"` обнаружится только на этапе проверки значения.

### Разбор 1
Одно из возможных решений:

```python
from enum import Enum


class StatusClass(Enum):
    INFORMATIONAL = range(100, 200)
    SUCCESS = range(200, 300)
    REDIRECT = range(300, 400)
    CLIENT_ERROR = range(400, 500)
    SERVER_ERROR = range(500, 600)


def describe_http(code: int) -> str:
    match code:
        case 200:
            return "200 OK"
        case 404:
            return "404 Not Found"
        case int(c) if 500 <= c < 600:
            return f"{c} — ошибка сервера"
        case int(c) if 400 <= c < 500:
            return f"{c} — ошибка клиента"
        case _:
            return f"{code} — неизвестный статус"


def status_class(code: int) -> str:
    for cls in StatusClass:
        if code in cls.value:
            return cls.name
    return "UNKNOWN"


def main() -> None:
    while (line := input("> ").strip()) != "":
        if line.startswith("!статус "):
            try:
                code = int(line.split()[1])
            except (ValueError, IndexError):
                print("Неверный код")
                continue
            print(describe_http(code))
        elif line.startswith("!класс "):
            try:
                code = int(line.split()[1])
            except (ValueError, IndexError):
                print("Неверный код")
                continue
            print(status_class(code))
        elif line == "!выход":
            print("До встречи!")
            break
        else:
            print("Не понял команду")


if __name__ == "__main__":
    main()
```

Что здесь происходит? В `main()` walrus-оператор присваивает введённую строку переменной `line` и проверяет её на пустоту — цикл идёт, пока пользователь не нажмёт Enter на пустой строке. `describe_http()` демонстрирует `match/case`: сначала точные коды (200, 404), затем диапазоны через защиту `if`, а `case _` ловит всё, что не подошло. `status_class()` перебирает члены `Enum` и сравнивает значение кода с `range` внутри каждого члена. Обрати внимание на `try/except`: пользователь может ввести не число, и мы должны ответить понятным сообщением, а не уронить программу с `ValueError`.

### Разбор 2
Решение:

```python
def evaluate(expr: str) -> int | None:
    match expr.split():
        case ["add", a, b]:
            return int(a) + int(b)
        case ["sub", a, b]:
            return int(a) - int(b)
        case ["mul", a, b]:
            return int(a) * int(b)
        case ["div", a, b]:
            return int(a) // int(b)
        case _:
            return None


tests = ["add 2 3", "div 9 2", "mul 3 4", "pow 2 3", "sub 10"]
for t in tests:
    print(f"{t} = {evaluate(t)}")
```

`expr.split()` превращает строку в список слов. Шаблон `case ["add", a, b]` требует ровно трёх элементов, поэтому `"pow 2 3"` (нет такой ветки) и `"sub 10"` (только два элемента) попадут в `case _` и вернут `None`. В теле ветки `a` и `b` — строки, поэтому перед арифметикой их нужно преобразовать через `int()`. `div` использует `//` — целочисленное деление, поэтому `9 // 2` даёт `4`. Такой разбор через `match` читается лучше, чем цепочка `if/elif` с проверкой `parts[0]`.

### Разбор 3
Решение:

```python
from enum import Enum, auto


class Weekday(Enum):
    MONDAY = auto()
    TUESDAY = auto()
    WEDNESDAY = auto()
    THURSDAY = auto()
    FRIDAY = auto()
    SATURDAY = auto()
    SUNDAY = auto()


def next_day(day: Weekday) -> Weekday:
    match day:
        case Weekday.MONDAY:
            return Weekday.TUESDAY
        case Weekday.TUESDAY:
            return Weekday.WEDNESDAY
        case Weekday.WEDNESDAY:
            return Weekday.THURSDAY
        case Weekday.THURSDAY:
            return Weekday.FRIDAY
        case Weekday.FRIDAY:
            return Weekday.SATURDAY
        case Weekday.SATURDAY:
            return Weekday.SUNDAY
        case Weekday.SUNDAY:
            return Weekday.MONDAY


for day in Weekday:
    print(f"{day.name} -> {next_day(day).name}")
```

Значения `auto()` присваивают членам числа 1..7 — они нам даже не нужны, потому что мы сопоставляем сами члены. `match/case` здесь работает с перечислением как с обычными значениями: `case Weekday.SUNDAY:` ловит ровно воскресенье. Замыкание недели реализовано отдельной веткой. Цикл `for day in Weekday` перебирает все члены в порядке объявления, и каждый шаг печатает пару. Обрати внимание, что `next_day(Weekday.SUNDAY) is Weekday.MONDAY` — истина: члены Enum сравниваются по идентичности.

### Разбор 4
Решение:

```python
def read_numbers() -> list[int]:
    numbers = []
    while (line := input("> ").strip()) != "":
        try:
            numbers.append(int(line))
        except ValueError:
            print(f"Пропускаю: {line}")
    return numbers


def main() -> None:
    nums = read_numbers()
    if nums:
        avg = sum(nums) / len(nums)
    else:
        avg = 0.0
    print(f"Числа: {nums}")
    print(f"Сумма: {sum(nums)}")
    print(f"Количество: {len(nums)}")
    print(f"Среднее: {avg:.1f}")


if __name__ == "__main__":
    main()
```

Условие `while (line := input("> ").strip()) != ""` присваивает прочитанную строку и сразу сравнивает её с пустой: как только пользователь введёт пустую строку, цикл завершится. `strip()` убирает случайные пробелы, чтобы строка `"   "` тоже считалась пустой. Попытку `int(line)` обёртываем в `try/except ValueError` — так строка `"abc"` не уронит программу, а будет пропущена с сообщением. После цикла считаем статистику; среднее считается только при непустом списке, иначе деление на ноль. Формат `{avg:.1f}` даёт один знак после запятой.

### Разбор 5
Решение:

```python
def main() -> None:
    numbers = []
    while (line := input("> ").strip()) != "":
        match line.split():
            case ["!sum"]:
                print(f"Сумма: {sum(numbers)}")
            case ["!count"]:
                print(f"Количество: {len(numbers)}")
            case ["!avg"]:
                if numbers:
                    print(f"Среднее: {sum(numbers) / len(numbers):.1f}")
                else:
                    print("Нет чисел")
            case [value] if value.lstrip("-").isdigit():
                numbers.append(int(value))
            case _:
                print("Не понял команду")


if __name__ == "__main__":
    main()
```

Здесь соединены все три приёма. Walrus в условии цикла читает строки до пустой. `line.split()` превращает строку в список, а `match` разбирает его по шаблонам: `case ["!sum"]` — ровно один элемент `!sum`; защита `if value.lstrip("-").isdigit()` отсекает мусор, но пропускает отрицательные числа (`lstrip("-")` убирает минус, после чего `isdigit()` проверяет цифры). Число добавляется в общий список `numbers`. `case _` ловит всё остальное — команды с опечатками, лишние слова, текст. Обрати внимание: сумма и среднее считаются «на лету» из накопленного списка, поэтому новые команды не требуют переписывания логики накопления.
