До сих пор мы работали в консоли: текст на вход, текст на выход. Но пользователям удобнее нажимать кнопки, чем печатать команды. Сегодня научимся делать настоящие оконные приложения на встроенной библиотеке `tkinter`. Её главный плюс — она уже есть в Python, ничего устанавливать не нужно, а это значит, что программы будут работать у любого, у кого есть Python.

## Что такое tkinter

`tkinter` — это интерфейс Python к библиотеке Tk, которая умеет рисовать окна, кнопки, поля ввода и другие элементы — их называют **виджетами** (widget). Наша программа — это иерархия: главное окно, внутри него — элементы. Каждый элемент — маленький объект, у которого есть методы для изменения текста, цвета, положения.

Простейшее окно выглядит так:

```python
import tkinter as tk

root = tk.Tk()
root.title("Моё окно")
root.geometry("400x300")
root.mainloop()
```

`tk.Tk()` создаёт главное окно. `title` задаёт заголовок, `geometry("400x300")` — размер окна (ширина×высота). И последняя строка — `mainloop()`: она запускает **главный цикл обработки событий**. С этого момента tkinter начинает слушать мышь и клавиатуру и «оживляет» приложение. Программа закроется, когда пользователь закроет окно.

## Виджеты: Label, Button, Entry

### Label — надпись

`Label` показывает текст или картинку:

```python
label = tk.Label(root, text="Привет, мир!")
label.pack()
```

### Button — кнопка

Кнопка умеет выполнять функцию при нажатии. Эта функция называется **обработчиком** (callback):

```python
def say_hello():
    print("Кнопка нажата!")

btn = tk.Button(root, text="Нажми меня", command=say_hello)
btn.pack()
```

Обрати внимание: в `command` передаётся имя функции **без скобок** — Python не вызывает её сразу, а передаёт tkinter ссылку на неё. Вызовёт её tkinter при нажатии.

### Entry — поле ввода

`Entry` — однострочное поле для текста. Чтобы прочитать, что пользователь ввёл, лучше всего использовать переменную `StringVar`:

```python
name_var = tk.StringVar()
entry = tk.Entry(root, textvariable=name_var)
entry.pack()

def show_name():
    print("Привет,", name_var.get())

tk.Button(root, text="Поздороваться", command=show_name).pack()
```

`StringVar` — специальный объект, который хранит текст и умеет оповещать tkinter об изменениях. Метод `.get()` возвращает текущее значение, `.set()` — устанавливает новое.

## Раскладки: pack и grid

Чтобы расставить виджеты по окну, есть три менеджера геометрии. Самые ходовые — `pack` и `grid`.

`pack` укладывает элементы друг за другом — сверху вниз или слева направо:

```python
tk.Label(root, text="Имя:").pack()
tk.Entry(root).pack()
tk.Button(root, text="OK").pack()
```

`grid` расставляет элементы по строкам и столбцам — как таблицу:

```python
tk.Label(root, text="Имя:").grid(row=0, column=0)
tk.Entry(root).grid(row=0, column=1)
tk.Label(root, text="Возраст:").grid(row=1, column=0)
tk.Entry(root).grid(row=1, column=1)
```

Это удобно для форм: подписи — в одном столбце, поля — в другом.

## Диалоговые окна: messagebox

Иногда нужно показать сообщение или спросить подтверждение. Для этого есть модуль `messagebox`:

```python
import tkinter.messagebox as mb

mb.showinfo("Готово", "Данные сохранены!")
mb.showwarning("Внимание", "Поле пустое")
mb.askyesno("Вопрос", "Точно закрыть?")
```

Эти окна не требуют настройки — они модальные, то есть блокируют работу с главным окном, пока пользователь их не закроет. `askyesno` возвращает `True` или `False` в зависимости от ответа.

### Разбор 1
Решение:

```python
import tkinter as tk

root = tk.Tk()
root.title("Моё приложение")
root.geometry("400x200")

label = tk.Label(root, text="Привет, мир!")
label.pack()

root.mainloop()
```

Что здесь происходит? `tk.Tk()` создаёт главное окно — корневой виджет. `geometry` задаёт его размер. `Label` — это виджет-надпись; первый аргумент — родительский виджет (`root`), затем параметры. `pack()` размещает надпись в окне и автоматически центрирует её. Наконец, `mainloop()` запускает цикл обработки событий — именно он «держит» окно открытым, слушает закрытие и обрабатывает перерисовку. Без `mainloop()` окно мигнуло бы и закрылось, так как программа дошла бы до конца и завершилась.

### Разбор 2
Решение:

```python
import tkinter as tk

root = tk.Tk()
root.title("Счётчик")
root.geometry("300x150")

count = 0
counter_var = tk.StringVar()
counter_var.set("Нажато: 0")

def increment():
    global count
    count += 1
    counter_var.set(f"Нажато: {count}")

label = tk.Label(root, textvariable=counter_var)
label.pack(pady=10)
button = tk.Button(root, text="Счётчик", command=increment)
button.pack()

root.mainloop()
```

Что здесь происходит? `counter_var` — это `StringVar`: мы не меняем текст надписи напрямую, а меняем переменную, и tkinter сам обновляет виджет. В функции `increment` мы увеличиваем `count` и перезаписываем текст. `global count` нужна, потому что `count` объявлена вне функции, а без `global` Python решил бы, что мы создаём локальную переменную, — и счётчик не менялся бы. `pady=10` добавляет вертикальный отступ. Обрати внимание: в `command=increment` функция передаётся без скобок.

### Разбор 3
Решение:

```python
import tkinter as tk
import tkinter.messagebox as mb

root = tk.Tk()
root.title("Приветствие")
root.geometry("300x200")

name_var = tk.StringVar()
result_var = tk.StringVar()

def greet():
    name = name_var.get().strip()
    if name == "":
        mb.showwarning("Внимание", "Введите имя")
    else:
        result_var.set(f"Привет, {name}!")

tk.Label(root, text="Ваше имя:").pack(pady=5)
tk.Entry(root, textvariable=name_var).pack(pady=5)
tk.Button(root, text="Поздороваться", command=greet).pack(pady=5)
tk.Label(root, textvariable=result_var).pack(pady=5)

root.mainloop()
```

Что здесь происходит? Функция `greet` срабатывает при каждом нажатии кнопки. `name_var.get()` читает то, что ввёл пользователь, `.strip()` убирает лишние пробелы по краям. Пустое поле — частый сценарий, поэтому мы его обрабатываем отдельно: `showwarning` показывает жёлтое предупреждение и завершает функцию через `else`. Если имя есть — формируем строку и кладём её в `result_var`; надпись с `textvariable=result_var` обновится автоматически. Такой подход — «данные в переменных, виджеты их отражают» — стандартный для tkinter.

### Разбор 4
Решение:

```python
import tkinter as tk
import tkinter.messagebox as mb

root = tk.Tk()
root.title("Вход")
root.geometry("300x150")

login_var = tk.StringVar()
password_var = tk.StringVar()

def login():
    mb.showinfo("Данные", f"Логин: {login_var.get()}, пароль: {password_var.get()}")

tk.Label(root, text="Логин:").grid(row=0, column=0, padx=10, pady=5)
tk.Entry(root, textvariable=login_var).grid(row=0, column=1)
tk.Label(root, text="Пароль:").grid(row=1, column=0, padx=10, pady=5)
tk.Entry(root, textvariable=password_var, show="*").grid(row=1, column=1)
tk.Button(root, text="Войти", command=login).grid(row=2, column=0, columnspan=2, pady=10)

root.mainloop()
```

Что здесь происходит? `grid` строит таблицу: строка 0 — логин, строка 1 — пароль, строка 2 — кнопка. `padx` и `pady` задают отступы вокруг ячеек — без них элементы слипнутся. `columnspan=2` растягивает кнопку на оба столбца. Аргумент `show="*"` скрывает вводимый пароль точками — это требование безопасности даже в учебном проекте. Обработчик `login` просто собирает значения и показывает их в информационном окне. Эту форму можно легко расширить: добавить проверку длины пароля, сохранение и т. д.

### Разбор 5
Решение:

```python
import tkinter as tk
import tkinter.messagebox as mb

root = tk.Tk()
root.title("Калькулятор")
root.geometry("300x200")

a_var = tk.StringVar()
b_var = tk.StringVar()
result_var = tk.StringVar()

def add():
    try:
        a = int(a_var.get())
        b = int(b_var.get())
    except ValueError:
        mb.showerror("Ошибка", "Введите числа")
        return
    result_var.set(f"Результат: {a + b}")

tk.Label(root, text="Первое число:").grid(row=0, column=0, padx=10, pady=5)
tk.Entry(root, textvariable=a_var).grid(row=0, column=1)
tk.Label(root, text="Второе число:").grid(row=1, column=0, padx=10, pady=5)
tk.Entry(root, textvariable=b_var).grid(row=1, column=1)
tk.Button(root, text="Сложить", command=add).grid(row=2, column=0, columnspan=2, pady=10)
tk.Label(root, textvariable=result_var).grid(row=3, column=0, columnspan=2)

root.mainloop()
```

Что здесь происходит? Главная новинка — обработка ошибок. `int()` бросает `ValueError`, если строка не является числом (например, «абв»). Мы ловим это исключение в `try/except`, показываем красное окно ошибки через `showerror` и выходим из функции через `return` — результат не обновляется. Если же числа введены корректно — складываем и пишем результат. Обрати внимание на порядок: сначала валидация (проверка), потом вычисление. Это правильная структура любого обработчика ввода: попытаться получить данные, обработать ошибку, затем делать полезную работу.
