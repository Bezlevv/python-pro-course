Когда код начинает расти, одних встроенных типов часто не хватает. Стандартная библиотека Python включает сотни модулей, и среди них есть три настоящих «ударных»: `collections`, `itertools` и `functools`. Их называют китами функционального стиля — они позволяют писать меньше кода, который при этом работает быстрее и читается лучше.

## collections: умные контейнеры

Модуль `collections` предоставляет расширенные варианты встроенных коллекций.

**Counter** — счётчик для подсчёта любых элементов:

```python
from collections import Counter

words = ["питон", "код", "питон", "данные", "код", "питон"]
counter = Counter(words)
print(counter)                    # Counter({'питон': 3, 'код': 2, 'данные': 1})
print(counter.most_common(2))     # [('питон', 3), ('код', 2)]
```

**defaultdict** — словарь, который сам создаёт значение для отсутствующего ключа:

```python
from collections import defaultdict

groups = defaultdict(list)
for num in [1, 2, 3, 4, 5, 6]:
    groups[num % 2].append(num)
print(dict(groups))   # {1: [1, 3, 5], 0: [2, 4, 6]}
```

**deque** — двухсторонняя очередь; вставка и удаление с обоих концов выполняются быстро:

```python
from collections import deque

queue = deque([1, 2, 3])
queue.append(4)      # добавить справа
queue.appendleft(0)  # добавить слева
print(queue.pop())       # 4
print(queue.popleft())   # 0
```

**namedtuple** — кортеж с именованными полями:

```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(3, 5)
print(p.x, p.y)   # 3 5
```

## itertools: комбинаторика и ленивые последовательности

Модуль `itertools` — это фабрики итераторов. Они не хранят данные в памяти целиком, а выдают элементы по одному, поэтому идеально работают с длинными последовательностями.

`count`, `cycle` и `repeat` создают бесконечные или повторяющиеся последовательности. Вместе с `islice` их легко обрезать:

```python
from itertools import count, cycle, islice

print(list(islice(count(10), 4)))   # [10, 11, 12, 13]
print(list(islice(cycle("ab"), 5))) # ['a', 'b', 'a', 'b', 'a']
```

`chain` склеивает несколько итераторов в один, `product` даёт декартово произведение, а `permutations` и `combinations` — все перестановки и сочетания:

```python
from itertools import chain, product, permutations

print(list(chain([1, 2], [3, 4])))        # [1, 2, 3, 4]
print(list(product("AB", [1, 2])))        # [('A', 1), ('A', 2), ('B', 1), ('B', 2)]
print(list(permutations("ABC", 2)))       # все упорядоченные пары
```

`groupby` группирует соседние равные элементы — перед вызовом данные обычно сортируют:

```python
from itertools import groupby

data = sorted([3, 1, 3, 2, 1, 3])
for key, group in groupby(data):
    print(key, len(list(group)))   # 1 2 / 2 1 / 3 3
```

## functools: функциональные помощники

`lru_cache` кэширует результаты функции: если её вызвать повторно с теми же аргументами, тело не выполнится заново, а вернётся сохранённый результат:

```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

print(fib(35))          # 9227465
print(fib.cache_info()) # CacheInfo(hits=..., misses=..., ...)
```

`partial` фиксирует часть аргументов функции, а `reduce` сворачивает последовательность в одно значение:

```python
from functools import partial, reduce

power = partial(pow, 2)              # 2 в степени n
print(power(10))                     # 1024
print(reduce(lambda a, b: a + b, range(1, 6)))  # 15
```

### Разбор 1
Одно из возможных решений:

```python
import re
from collections import Counter
from functools import lru_cache

text = (
    "Питон — язык программирования, который читается почти как английский текст. "
    "Питон прост, мощен и очень востребован. Изучайте Питон каждый день, "
    "и тогда Питон станет вашим главным инструментом."
)

@lru_cache(maxsize=128)
def count_words(text):
    words = re.findall(r"[а-яё]+", text.lower())
    return Counter(words)

stats_first = count_words(text)
stats_second = count_words(text)  # тот же текст — попадание в кэш

for word, freq in stats_first.most_common(5):
    print(f"{word} — {freq} раз")

print(count_words.cache_info())
```

Результат:

```
питон — 4 раз
и — 2 раз
язык — 1 раз
программирования — 1 раз
который — 1 раз
CacheInfo(hits=1, misses=1, maxsize=128, currsize=1)
```

Разбор шагов. Регулярное выражение `[а-яё]+` вырезает только последовательности букв, поэтому знаки препинания и кавычки пропадают автоматически; `lower()` приводит всё к нижнему регистру, чтобы «Питон» и «питон» считались одним словом. Функция `count_words` обёрнута в `@lru_cache`: при первом вызове тело выполняется, результат кладётся в кэш, а при втором вызове с тем же текстом Python возвращает сохранённый `Counter`, не выполняя функцию повторно — об этом говорят `hits=1` (одно попадание) и `misses=1` (один промах). Наконец, `most_common(5)` возвращает пять пар «слово — частота», которые мы печатаем в цикле. Кэширование тяжёлых вычислений особенно полезно при обработке больших объёмов данных — например, когда один и тот же файл анализируется несколько раз.

### Разбор 2
Одно из возможных решений:

```python
from collections import defaultdict

words = ["арбуз", "банан", "ананас", "вишня", "абрикос",
         "гранат", "виноград", "апельсин"]

groups = defaultdict(list)
for word in words:
    groups[word[0]].append(word)

for letter in sorted(groups):
    print(f"{letter}: {groups[letter]}")

print(groups["я"])  # нет такой буквы — вернётся пустой список
```

Результат:

```
а: ['арбуз', 'ананас', 'абрикос', 'апельсин']
б: ['банан']
в: ['вишня', 'виноград']
г: ['гранат']
[]
```

Разбор шагов. Обычный словарь бросил бы `KeyError` при обращении к букве, которой нет в списке, — `defaultdict(list)` вместо этого сам создаёт новое значение по умолчанию (пустой список) и возвращает его. В цикле `for word in words` мы добавляем каждое слово в список своей буквы: `word[0]` — это первый символ слова, он и служит ключом. Итерация по `sorted(groups)` даёт буквы в алфавитном порядке, а внутри f-строки мы печатаем готовый список слов. Последняя строка `print(groups["я"])` наглядно демонстрирует главное преимущество `defaultdict`: вместо ошибки программа печатает `[]`. Это очень удобно при агрегации данных — например, при раскладке записей по категориям, когда заранее не известно, какие категории встретятся.

### Разбор 3
Одно из возможных решений:

```python
from collections import deque

history = deque(maxlen=3)

while True:
    line = input("Введи команду: ").strip()
    if line == "выход":
        break
    if line == "история":
        print("Последние команды:")
        for cmd in history:
            print(cmd)
        continue
    history.append(line)
```

Пример сессии:

```
Введи команду: a
Введи команду: b
Введи команду: c
Введи команду: d
Введи команду: история
Последние команды:
b
c
d
Введи команду: выход
```

Разбор шагов. `deque(maxlen=3)` — двухсторонняя очередь с ограничением длины: при добавлении четвёртого элемента самый старый автоматически выталкивается с другого конца. Поэтому в истории всегда ровно три последние команды, и нам не нужно вручную удалять лишние элементы. Команды `выход` и `история` обрабатываются до добавления в очередь, чтобы они не попадали в сам журнал. Важно, что `deque` сохраняет порядок элементов: итерация `for cmd in history` идёт от самого старого к самому новому, поэтому вывод `b`, `c`, `d` соответствует порядку ввода. Если бы мы использовали обычный список, нам пришлось бы писать дополнительную логику для сдвига элементов и обрезания хвоста — `deque` делает это за нас и при этом работает быстро на обоих концах.

### Разбор 4
Одно из возможных решений:

```python
from itertools import combinations

players = ["Аня", "Боря", "Витя", "Галя", "Дима"]

pairs = list(combinations(players, 2))

for first, second in pairs:
    print(f"{first} + {second}")

print(f"Всего пар: {len(pairs)}")
```

Результат:

```
Аня + Боря
Аня + Витя
Аня + Галя
Аня + Дима
Боря + Витя
Боря + Галя
Боря + Дима
Витя + Галя
Витя + Дима
Галя + Дима
Всего пар: 10
```

Разбор шагов. `combinations(players, 2)` генерирует все неупорядоченные выборки по 2 элемента из списка: для пяти игроков это 10 пар. Ключевое отличие от `permutations` — порядок не важен: пара `Аня + Боря` встречается один раз, а не дважды. Генератор ленивый, поэтому мы оборачиваем его в `list(...)`, чтобы можно было и итерироваться по нему, и посчитать длину через `len(pairs)`. Обрати внимание: количество сочетаний из n по k равно n! / (k! × (n − k)!), то есть для 5 и 2 это 5 × 4 / 2 = 10 — ровно столько строк мы и видим. Такой код полезен везде, где нужны все возможные пары: расписание матчей, сопоставление людей, тестирование комбинаций параметров. `permutations` же понадобился бы, если бы порядок играл роль — например, при переборе всех вариантов расстановки.

### Разбор 5
Одно из возможных решений:

```python
from collections import namedtuple
from itertools import groupby

Sale = namedtuple("Sale", ["month", "amount"])

sales = [
    Sale("январь", 400), Sale("январь", 350),
    Sale("февраль", 500), Sale("февраль", 200),
    Sale("январь", 450),
    Sale("март", 600), Sale("март", 150), Sale("март", 250),
]

sales.sort(key=lambda s: s.month)

for month, group in groupby(sales, key=lambda s: s.month):
    total = sum(item.amount for item in group)
    print(f"{month}: {total}")
```

Результат:

```
январь: 1200
февраль: 700
март: 1000
```

Разбор шагов. `namedtuple` создаёт лёгкий тип записи с именованными полями: `Sale("январь", 400)` можно читать как `sale.month` и `sale.amount` — это понятнее, чем обращаться к индексам обычного кортежа. Ключевой приём с `groupby`: он группирует только **соседние** равные элементы, поэтому перед вызовом мы обязательно сортируем записи по месяцу — иначе одинаковые месяцы разъедутся по разным группам. Сортировка выполняется через `sales.sort(key=lambda s: s.month)`. Далее `groupby` возвращает пары «ключ, итератор группы», и для каждой группы мы суммируем `amount` через генераторное выражение `sum(item.amount for item in group)`. Заметь: итератор `group` одноразовый — его нужно потребить внутри цикла, что мы и делаем. В результате получаем аккуратную сводку по месяцам: три строки с суммами, которые легко проверить вручную.
