Какой класс из collections удобен для подсчёта количества элементов?
- Counter
- ChainMap
- OrderedDict
- namedtuple
* Правильный ответ: Counter
Counter считает частоту элементов: Counter("abracadabra") покажет, сколько раз встречается каждая буква.

Что вернёт itertools.product([1, 2], ["a", "b"])?
- 2 элемента
- 4 элемента
- 8 элементов
- Ошибку
* Правильный ответ: 4 элемента
product создаёт декартово произведение: пары (1, "a"), (1, "b"), (2, "a"), (2, "b").

Чему равен Path("docs/report.txt").suffix?
- "report"
- ".txt"
- "docs"
- "txt"
* Правильный ответ: ".txt"
Атрибут suffix возвращает расширение файла вместе с точкой.

Какой метод записывает сообщение в журнал?
- print("...")
- logging.info("...")
- log("...")
- journal.write("...")
* Правильный ответ: logging.info("...")
logging.info() отправляет сообщение уровня INFO в настроенный обработчик журнала.

Как pytest находит тесты?
- По имени файла, начинающемуся с pytest_
- По именам функций вида test_*
- По аннотации @test
- Только если их явно перечислить
* Правильный ответ: По именам функций вида test_*
pytest автоматически собирает функции, имена которых начинаются с test_.

Что будет при провале assert 2 + 2 == 5 в тесте?
- Тест пройдёт
- Тест упадёт с ошибкой
- Программа остановится
- Ничего
* Правильный ответ: Тест упадёт с ошибкой
Неверное утверждение assert вызывает исключение AssertionError, и тест помечается как проваленный.

Какая последовательность команд зафиксирует изменения в Git?
- git commit && git push
- git add . && git commit -m "сообщение"
- git push origin main
- git diff && git status
* Правильный ответ: git add . && git commit -m "сообщение"
Сначала изменения добавляются в индекс командой git add, затем фиксируются командой git commit.

Какая команда показывает текущее состояние репозитория?
- git log
- git status
- git show
- git branch
* Правильный ответ: git status
git status показывает изменённые файлы, новые файлы и другие незакоммиченные изменения.

Какой класс из argparse разбирает аргументы командной строки?
- argparse.Parser
- argparse.ArgumentParser
- argparse.Args
- argparse.Parse
* Правильный ответ: argparse.ArgumentParser
ArgumentParser() создаёт парсер, в который добавляют аргументы через add_argument().

Что произойдёт при обращении к отсутствующему ключу defaultdict(list)?
- KeyError
- Создастся пустой список для этого ключа
- Вернётся None
- Ключ проигнорируется
* Правильный ответ: Создастся пустой список для этого ключа
defaultdict автоматически создаёт значение по умолчанию (здесь — пустой список) при первом обращении к отсутствующему ключу.
