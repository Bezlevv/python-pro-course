Какой инструмент подходит для поиска узких мест по функциям?
- timeit
- cProfile
- asyncio
- queue
* Правильный ответ: cProfile
cProfile показывает время и число вызовов каждой функции, включая вложенные.

Что показывает колонка cumtime в выводе cProfile?
- Время внутри самой функции без учёта вложенных вызовов
- Суммарное время с учётом вложенных вызовов
- Число вызовов функции
- Размер памяти функции
* Правильный ответ: Суммарное время с учётом вложенных вызовов
cumtime = tottime + время дочерних вызовов; по нему сортируют sort_stats("cumulative").

Что делает tracemalloc?
- Замеряет скорость функций
- Отслеживает выделения памяти и показывает, где они происходят
- Компилирует код в C
- Управляет потоками
* Правильный ответ: Отслеживает выделения памяти и показывает, где они происходят
Снимки tracemalloc помогают находить утечки и крупные выделения по строкам.

Почему проверка item in set быстрее, чем item in list?
- set хранит элементы в хеш-таблице: поиск в среднем O(1), список перебирает элементы — O(n)
- set меньше весит
- list запрещён для больших данных
- Разницы нет
* Правильный ответ: set хранит элементы в хеш-таблице: поиск в среднем O(1), список перебирает элементы — O(n)
Хеш-таблица даёт константный поиск; список требует линейного прохода.

Что делает @njit из Numba?
- Запускает функцию в отдельном процессе
- Компилирует функцию в машинный код при первом вызове (JIT)
- Переписывает функцию на Cython
- Добавляет кэширование
* Правильный ответ: Компилирует функцию в машинный код при первом вызове (JIT)
Первый вызов — «прогрев» (компиляция), дальше код исполняется в машинном виде.

Что такое Cython?
- Библиотека для профилирования
- Язык-надмножество Python, компилируемый в C-расширение
- Альтернативный интерпретатор
- Менеджер пакетов
* Правильный ответ: Язык-надмножество Python, компилируемый в C-расширение
Файлы .pyx собираются через cythonize в импортируемые модули.

Что делает free-threading (PEP 703)?
- Убирает GIL: потоки могут исполняться на нескольких ядрах одновременно
- Ускоряет однопоточный код всегда
- Запрещает потоки
- Заменяет процессоры
* Правильный ответ: Убирает GIL: потоки могут исполняться на нескольких ядрах одновременно
Сборка без GIL ценой накладных расходов и требований к C-расширениям.

Почему counter += 1 в нескольких потоках может дать неверный результат?
- Операция не атомарна: чтение и запись могут перемежаться между потоками
- Числа не складываются в потоках
- Потоки не видят переменные
- Результат всегда больше ожидаемого
* Правильный ответ: Операция не атомарна: чтение и запись могут перемежаться между потоками
Гонка данных: два потока могут прочитать одно значение и записать одинаковый результат; защита — threading.Lock.

Что произойдёт, если вызвать time.sleep(1) внутри корутины?
- Цикл событий заблокируется целиком на 1 секунду
- Задача уйдёт в отдельный поток
- Ничего
- Sleep автоматически станет await
* Правильный ответ: Цикл событий заблокируется целиком на 1 секунду
Блокирующие вызовы запрещены в корутинах; для них есть asyncio.to_thread и run_in_executor.

Что показывает перцентиль p95?
- Время, в которое уложились 95% запросов
- Среднее время ответа
- Максимальное время
- Число запросов в секунду
* Правильный ответ: Время, в которое уложились 95% запросов
p95 — стандарт цели по задержке: виден «хвост» медленных запросов.
