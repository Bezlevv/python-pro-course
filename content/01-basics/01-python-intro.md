Привет! Это первый урок курса. Здесь мы пойдём от самого нуля: разберёмся, что такое Python, как его установить и как написать первую программу. Ничего страшного, если ты никогда не программировал — этот урок написан специально для тебя.

## Что такое Python

Python — это язык программирования, на котором можно делать почти всё:

- простые скрипты и автоматизацию,
- сайты и веб-приложения (Flask, FastAPI, Django),
- анализ данных (Pandas, NumPy),
- нейросети и искусственный интеллект (PyTorch, TensorFlow),
- игры, ботов, утилиты.

Почему именно Python? Он читается почти как английский текст, у него огромное сообщество и тысячи готовых библиотек. Именно поэтому его рекомендуют как первый язык для новичков — и при этом он один из самых востребованных в индустрии.

## Установка Python

1. Зайди на официальный сайт [python.org](https://www.python.org/) и скачай последнюю версию.
2. Установи, обязательно отметь галочку **«Add Python to PATH»** при установке (это важно!).
3. Проверь, что всё получилось: открой терминал (на Windows — PowerShell, на macOS/Linux — Terminal) и введи:

```bash
python --version
```

Если ты увидишь что-то вроде `Python 3.13.x` — отлично, Python установлен! Если нет — перезапусти терминал и попробуй ещё раз.

## Взаимодействие с Python

У Python есть два основных режима работы.

**1. Интерактивный режим.** Введи в терминале `python` — откроется приглашение `>>>`. Можно сразу писать команды:

```bash
>>> 2 + 2
4
>>> print("Привет, мир!")
Привет, мир!
```

Чтобы выйти из интерактивного режима, введи `exit()`.

**2. Файлы с программами.** Настоящие программы хранятся в файлах с расширением `.py`. Создай файл `hello.py` с таким содержимым:

```python
print("Привет, мир!")
```

И запусти его:

```bash
python hello.py
```

В терминале появится `Привет, мир!`. Поздравляю — это твоя первая программа на Python! 🎉

## Функция print()

`print()` — это встроенная функция, которая выводит текст на экран. То, что ты хочешь напечатать, кладётся в скобки:

```python
print("Привет, мир!")
print("Я учу Python!")
```

Можно вывести несколько значений через запятую — они напечатаются через пробел:

```python
print("Меня зовут", "Аня")
```

Текст в Python обязательно берётся в кавычки — одинарные `'...'` или двойные `"..."`. Для Python они не отличаются, главное — не смешивать их в одной строке.

Строки можно объединять с помощью знака `+`:

```python
print("Привет, " + "мир!")
```

## Комментарии

Комментарии — это заметки для людей, которые читают код. Python их игнорирует. Комментарий начинается с символа `#`:

```python
# Это комментарий — Python его не выполнит
print("Это выполнится")  # а это комментарий после кода
```

Комментарии помогают объяснить, зачем нужен тот или иной кусок кода. Хорошая привычка — комментировать непонятные места, но не писать комментарий к каждой строчке.

## Читаем ошибки

Не бойся ошибок — они будут, и это нормально. Например, если забыть закрывающую кавычку:

```python
print("Привет)
```

Python покажет примерно такое:

```
  File "hello.py", line 1
    print("Привет)
                 ^
SyntaxError: unterminated string literal
```

Разбор ошибки:

- `File "hello.py", line 1` — в каком файле и на какой строке ошибка;
- `SyntaxError` — тип ошибки (здесь: синтаксическая, то есть нарушен синтаксис языка);
- `^` — стрелочка указывает на место, где Python «споткнулся».

Главное правило: **читай текст ошибки**, а не паникуй. В 90% случаев там написано, что именно не так.

### Разбор 1
Одно из возможных решений:

```python
print("Меня зовут Аня")
print("Мой любимый язык — Python")
print("Я сделаю свой первый проект!")
```

Запускаем:

```bash
python about_me.py
```

Результат:

```
Меня зовут Аня
Мой любимый язык — Python
Я сделаю свой первый проект!
```

Что здесь происходит? Каждая строка — это вызов функции `print()` со строковым аргументом в кавычках. Python выполняет команды сверху вниз, по одной. Если убрать кавычку, получится `SyntaxError` — Python не сможет понять, где заканчивается строка, и укажет стрелочкой на проблемное место.

Также обрати внимание: текст в кавычках может содержать русские буквы, пробелы и знаки препинания — это нормально, Python умеет работать с юникодом (то есть практически с любыми символами).

### Разбор 2
Решение:

```python
print("2 + 2 =", 2 + 2)
print("10 - 4 =", 10 - 4)
print("6 * 7 =", 6 * 7)
print("50 / 5 =", 50 / 5)
```

Результат:

```
2 + 2 = 4
10 - 4 = 6
6 * 7 = 42
50 / 5 = 10.0
```

Что здесь происходит? Внутри `print()` через запятую передаются два значения: строка-подпись и выражение. Python сначала вычисляет выражение (например, `2 + 2` даёт `4`), а затем печатает оба значения через пробел. Обрати внимание на последнюю строку: `50 / 5` даёт `10.0` — с точкой, потому что деление в Python всегда возвращает дробное число. Так мы незаметно встретились с двумя типами данных: текстом и числами — подробнее о них в следующем уроке.

### Разбор 3
Решение:

```python
print("Меня зовут", "Аня")
print("Я живу в " + "Москве")
```

Результат:

```
Меня зовут Аня
Я живу в Москве
```

Что здесь происходит? В первом вызове `print()` получает два отдельных значения через запятую и печатает их через пробел — нам не пришлось добавлять пробел вручную. Во втором вызове знак `+` склеивает две строки в одну, и тут важно, что пробел стоит в конце первой части: `"Я живу в "`. Если бы мы написали `"Я живу в" + "Москве"`, получилось бы «Я живу вМоскве». Запомни правило: запятая в `print()` добавляет пробелы автоматически, а `+` работает ровно с тем текстом, который ты указал.

### Разбор 4
Решение:

```python
# Комментарий: выводим приветствие
print("Привет, мир!")

# Этот комментарий объясняет следующую строку
print("Я учу Python")
```

Результат:

```
Привет, мир!
Я учу Python
```

Что здесь происходит? Обе строки с `#` — комментарии. Python их игнорирует, поэтому на экран попадает только результат `print()`. Комментарии помогают читателю кода понять замысел автора. Главное — писать их по делу: объяснять «почему», а не повторять очевидное. Например, комментарий `# печатаем приветствие` полезен новичку, а вот `# print` был бы бесполезен. Постепенно ты выработаешь собственный стиль комментирования.

### Разбор 5
Исправленный код:

```python
print("Привет, мир!")
print("Я учу Python")

# Ошибка была в том, что в первой строке не хватало
# закрывающей кавычки — Python не мог понять, где
# заканчивается строка, и выдал SyntaxError.
```

Результат:

```
Привет, мир!
Я учу Python
```

Что здесь происходит? Изначально первая строка `print("Привет, мир!)` не имела закрывающей кавычки. Python дошёл до конца строки и не нашёл её, поэтому сообщил: `SyntaxError: unterminated string literal` — «незавершённый строковый литерал». Стрелочка `^` показывает место, где Python «споткнулся». Такие ошибки называются синтаксическими: нарушен синтаксис языка, и программа вообще не запустится. Исправление простое — добавить недостающую кавычку. Запомни: при любой ошибке сначала читай её текст, там почти всегда написано, что именно не так.
