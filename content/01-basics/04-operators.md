## Арифметические операторы

В Python есть семь основных арифметических операторов:

| Оператор | Что делает | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 3` | `10` |
| `-` | вычитание | `7 - 3` | `4` |
| `*` | умножение | `7 * 3` | `21` |
| `/` | деление | `7 / 2` | `3.5` |
| `//` | целочисленное деление | `7 // 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |
| `**` | возведение в степень | `2 ** 10` | `1024` |

Обрати внимание на разницу между `/` и `//`:

```python
print(10 / 4)    # 2.5 — обычное деление, всегда float
print(10 // 4)   # 2 — целая часть от деления
print(10 % 4)    # 2 — остаток от деления
```

Сочетание `//` и `%` позволяет раскладывать числа на целую часть и остаток. Это часто пригождается, например, когда надо разменять деньги или посчитать время:

```python
minutes = 135
hours = minutes // 60   # 2 часа
rest = minutes % 60     # 15 минут
print(f"{hours} ч {rest} мин")  # 2 ч 15 мин
```

Оператор `%` также удобно использовать для проверки чётности: число чётное, если `number % 2 == 0`.

## Приоритет операций

Как в обычной математике, у операторов есть порядок выполнения. Сначала выполняются операции в скобках, затем `**`, потом `*`, `/`, `//`, `%`, и в последнюю очередь `+` и `-`:

```python
print(2 + 3 * 4)     # 14, а не 20 — умножение раньше
print((2 + 3) * 4)   # 20 — скобки меняют порядок
```

Не уверен в порядке — ставь скобки, это безопаснее и читается лучше.

## Операторы сравнения

Сравнения возвращают булевы значения `True` или `False` (вспоминаем урок про типы):

| Оператор | Значение |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `<` | меньше |
| `>` | больше |
| `<=` | меньше или равно |
| `>=` | больше или равно |

```python
print(5 == 5)    # True
print(5 != 5)    # False
print(3 < 7)     # True
print(10 >= 11)  # False
```

Частая ошибка новичков — путать `==` (сравнение) и `=` (присваивание). Помни: один знак равенства кладёт значение в переменную, два — проверяет равенство.

Важно: сравнивать числа и строки напрямую нельзя (например, `10 < "5"` приведёт к ошибке), но строки можно сравнивать между собой — тогда сравнивается их алфавитный порядок.

## Логические операторы

Логические операторы работают с булевыми значениями: `and` (и), `or` (или), `not` (не).

- `a and b` — истинно, когда оба значения истинны;
- `a or b` — истинно, когда хотя бы одно истинно;
- `not a` — инвертирует значение.

```python
age = 20
has_ticket = True
print(age >= 18 and has_ticket)   # True — оба условия выполнены
print(age < 18 or has_ticket)     # True — второе выполнено
print(not has_ticket)             # False
```

В логическом выражении сначала выполняется `not`, затем `and`, и в последнюю очередь `or`. Этого легко забыть, поэтому лучше ставить скобки:

```python
print((age >= 18) and has_ticket)
```

Логические операторы позволяют записывать сложные проверки одной строкой — например, что температура в комфортном диапазоне:

```python
t = 22
print(15 <= t and t <= 28)  # True
```

<!--TASK-->
**Задача.** Напиши программу, которая высчитывает и выводит:

1. Сумму скидки и итоговую цену товара за 1200 руб. со скидкой 15%;
2. Сколько полных часов и минут в 205 минутах;
3. Результат проверки: чётное ли число 46 (через `%`);
4. Результат проверки: число 46 больше 10 и меньше 100 (через логический оператор).

Программа должна вывести пять строк: сумму скидки, итоговую цену, часы и минуты, слово `Чётное` или `Нечётное`, и булев результат проверки диапазона.
<!--/TASK-->

<!--HINT-->
Скидка — это `1200 * 15 / 100` или `1200 * 0.15`. Часы — `205 // 60`, минуты — `205 % 60`. Чётность: `46 % 2 == 0`. Диапазон: `46 > 10 and 46 < 100`.
<!--/HINT-->

<!--SOLUTION-->
Одно из возможных решений:

```python
price = 1200
discount_percent = 15

discount = price * discount_percent / 100
final_price = price - discount
print(f"Скидка: {discount} руб.")
print(f"Итоговая цена: {final_price} руб.")

minutes_total = 205
hours = minutes_total // 60
minutes = minutes_total % 60
print(f"{hours} ч {minutes} мин")

number = 46
if number % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")

print(number > 10 and number < 100)
```

Результат:

```
Скидка: 180.0 руб.
Итоговая цена: 1020.0 руб.
3 ч 25 мин
Чётное
True
```

Что здесь происходит? Скидка считается как процент от цены: `1200 * 15 / 100 = 180`. Итоговая цена — цена минус скидка. Для времени `205 // 60` даёт 3 полных часа, а `205 % 60` — 25 оставшихся минут. Чётность проверяется остатком от деления на 2: если остаток ноль — число чётное. Последняя строка комбинирует два сравнения через `and`: `46 > 10` — True, `46 < 100` — True, поэтому результат `True`.

Обрати внимание на `if` в четвёртом пункте — эту конструкцию мы детально разберём в следующем уроке, а пока просто посмотри, как она работает на примере.
<!--/SOLUTION-->
