Строки — один из самых часто используемых типов данных. Мы уже видели, как создавать строки и склеивать их через `+`. Но возможности строк гораздо шире: у них есть десятки встроенных методов, их можно резать на кусочки и красиво подставлять значения в текст. Об этом — сегодняшний урок.

## Индексы и срезы

Каждый символ строки имеет номер — индекс. Первый символ имеет индекс 0, второй — 1 и так далее. Обратиться к символу можно через квадратные скобки:

```python
s = "Python"
print(s[0])   # P
print(s[2])   # t
print(s[-1])  # n — минус значит «с конца»
```

Срезы позволяют взять часть строки: `s[start:stop]` — символы от start до stop (не включая stop):

```python
s = "Программирование"
print(s[0:6])   # Програм
print(s[:6])    # Програм — от начала
print(s[6:])    # мирование — до конца
print(s[::2])   # Погмиеае — каждый второй символ
```

Если пропустить одну из границ, срез возьмёт всё до начала или до конца. Второе двоеточие задаёт шаг.

## Основные методы строк

Метод — это функция, «привязанная» к объекту. Вызывается она через точку: `строка.метод()`. Важно: методы не меняют исходную строку, а возвращают новую — строки в Python неизменяемы.

```python
word = "  Привет, Python!  "
print(word.strip())            # убирает пробелы по краям
print(word.lower())            # всё в нижнем регистре
print(word.upper())            # всё в верхнем регистре
print(word.replace("Python", "мир"))  # замена части
```

Метод `split()` разбивает строку на список по разделителю, а `join()` — собирает список в строку:

```python
text = "яблоко, банан, вишня"
fruits = text.split(", ")
print(fruits)                  # ['яблоко', 'банан', 'вишня']

joined = " | ".join(fruits)
print(joined)                  # яблоко | банан | вишня
```

Проверки и поиск:

```python
email = "user@example.com"
print(email.startswith("user"))   # True
print(email.endswith(".com"))     # True
print(email.find("@"))            # 4 — индекс символа
print("@" in email)               # True
```

А `len()` возвращает длину строки:

```python
print(len("Python"))   # 6
```

## Форматирование: f-строки

Подставлять значения в строку «по-старому» приходилось муторно — склейкой через `+`:

```python
name = "Аня"
age = 25
print("Меня зовут " + name + ", мне " + str(age) + " лет.")
```

Гораздо удобнее f-строки (от английского format): перед кавычками ставится буква `f`, а внутрь в фигурных скобках кладутся выражения:

```python
print(f"Меня зовут {name}, мне {age} лет.")
print(f"Через 5 лет мне будет {age + 5} лет.")
```

Внутри фигурных скобок можно писать любые выражения, даже вызывать методы:

```python
city = "msk"
print(f"Город: {city.upper()}")   # Город: MSK
```

## Метод format() и спецификаторы

Более старый способ форматирования — метод `format()`:

```python
print("{} + {} = {}".format(2, 3, 2 + 3))
```

С его помощью можно задавать ширину поля и выравнивание:

```python
for i in range(1, 4):
    print(f"Квадрат {i} равен {i ** 2:>5}")
```

Числа выровняются по правому краю в поле ширины 5.

**Задача.** Напиши программу, которая запрашивает у пользователя имя (через `input()`) и выводит:

1. Приветствие вида `Привет, <имя>!` с помощью f-строки;
2. Имя в верхнем регистре;
3. Количество букв в имени (без учёта пробелов).

Для проверки запусти программу и введи имя `Аня`. Ожидаемый результат:

```
Привет, Аня!
АНЯ
3
```

Обрати внимание: не передавай текст-приглашение в `input()`, иначе он появится в выводе и результат не совпадёт с ожидаемым. Для подсчёта букв используй `len()` — она считает все символы, включая пробелы, поэтому если имя с пробелом, сначала уберь их методом `replace()`.

<!--HINT-->
Сохрани результат `input()` в переменную. Для приветствия используй f-строку: `f"Привет, {name}!"`. Регистр меняет метод `upper()`. Для длины сначала убери пробелы: `name.replace(" ", "")`, и уже к результату примени `len()`. Печатай через `print()`.

<!--SOLUTION-->
Одно из возможных решений:

```python
name = input()

greeting = f"Привет, {name}!"
print(greeting)

upper_name = name.upper()
print(upper_name)

without_spaces = name.replace(" ", "")
letters_count = len(without_spaces)
print(letters_count)
```

Запускаем и вводим `Аня`:

```
Аня
Привет, Аня!
АНЯ
3
```

Что здесь происходит? В первой строке `input()` ждёт, пока пользователь введёт текст и нажмёт Enter. Значение сохраняется в переменную `name`. Затем f-строка подставляет имя в шаблон — так мы не склеиваем строки вручную, и код читается легче.

`name.upper()` возвращает новую строку со всеми заглавными буквами, исходная строка при этом не меняется. Для подсчёта букв мы убираем пробелы методом `replace(" ", "")`, потому что `len()` считает вообще все символы, включая пробелы. Для имени «Аня» получается 3.

Обрати внимание: если бы мы вызвали `len(name)` без удаления пробелов, для имени «Аня Петрова» получилось бы 12, а не 10. Поэтому порядок действий важен. И ещё один нюанс: `input()` всегда возвращает строку, поэтому никакое преобразование типа перед `len()` не нужно.
<!--/SOLUTION-->
