Строки — один из самых часто используемых типов данных. Мы уже видели, как создавать строки и склеивать их через `+`. Но возможности строк гораздо шире: у них есть десятки встроенных методов, их можно резать на кусочки и красиво подставлять значения в текст. Об этом — сегодняшний урок.

## Индексы и срезы

Каждый символ строки имеет номер — индекс. Первый символ имеет индекс 0, второй — 1 и так далее. Обратиться к символу можно через квадратные скобки:

```python
s = "Python"
print(s[0])   # P
print(s[2])   # t
print(s[-1])  # n — минус значит «с конца»
```

Срезы позволяют взять часть строки: `s[start:stop]` — символы от start до stop (не включая stop):

```python
s = "Программирование"
print(s[0:6])   # Програм
print(s[:6])    # Програм — от начала
print(s[6:])    # мирование — до конца
print(s[::2])   # Погмиеае — каждый второй символ
```

Если пропустить одну из границ, срез возьмёт всё до начала или до конца. Второе двоеточие задаёт шаг.

## Основные методы строк

Метод — это функция, «привязанная» к объекту. Вызывается она через точку: `строка.метод()`. Важно: методы не меняют исходную строку, а возвращают новую — строки в Python неизменяемы.

```python
word = "  Привет, Python!  "
print(word.strip())            # убирает пробелы по краям
print(word.lower())            # всё в нижнем регистре
print(word.upper())            # всё в верхнем регистре
print(word.replace("Python", "мир"))  # замена части
```

Метод `split()` разбивает строку на список по разделителю, а `join()` — собирает список в строку:

```python
text = "яблоко, банан, вишня"
fruits = text.split(", ")
print(fruits)                  # ['яблоко', 'банан', 'вишня']

joined = " | ".join(fruits)
print(joined)                  # яблоко | банан | вишня
```

Проверки и поиск:

```python
email = "user@example.com"
print(email.startswith("user"))   # True
print(email.endswith(".com"))     # True
print(email.find("@"))            # 4 — индекс символа
print("@" in email)               # True
```

А `len()` возвращает длину строки:

```python
print(len("Python"))   # 6
```

## Форматирование: f-строки

Подставлять значения в строку «по-старому» приходилось муторно — склейкой через `+`:

```python
name = "Аня"
age = 25
print("Меня зовут " + name + ", мне " + str(age) + " лет.")
```

Гораздо удобнее f-строки (от английского format): перед кавычками ставится буква `f`, а внутрь в фигурных скобках кладутся выражения:

```python
print(f"Меня зовут {name}, мне {age} лет.")
print(f"Через 5 лет мне будет {age + 5} лет.")
```

Внутри фигурных скобок можно писать любые выражения, даже вызывать методы:

```python
city = "msk"
print(f"Город: {city.upper()}")   # Город: MSK
```

## Метод format() и спецификаторы

Более старый способ форматирования — метод `format()`:

```python
print("{} + {} = {}".format(2, 3, 2 + 3))
```

С его помощью можно задавать ширину поля и выравнивание:

```python
for i in range(1, 4):
    print(f"Квадрат {i} равен {i ** 2:>5}")
```

Числа выровняются по правому краю в поле ширины 5.

### Разбор 1

Одно из возможных решений:

```python
name = input()

greeting = f"Привет, {name}!"
print(greeting)

upper_name = name.upper()
print(upper_name)

without_spaces = name.replace(" ", "")
letters_count = len(without_spaces)
print(letters_count)
```

Запускаем и вводим `Аня`:

```
Аня
Привет, Аня!
АНЯ
3
```

Что здесь происходит? В первой строке `input()` ждёт, пока пользователь введёт текст и нажмёт Enter. Значение сохраняется в переменную `name`. Затем f-строка подставляет имя в шаблон — так мы не склеиваем строки вручную, и код читается легче.

`name.upper()` возвращает новую строку со всеми заглавными буквами, исходная строка при этом не меняется. Для подсчёта букв мы убираем пробелы методом `replace(" ", "")`, потому что `len()` считает вообще все символы, включая пробелы. Для имени «Аня» получается 3.

Обрати внимание: если бы мы вызвали `len(name)` без удаления пробелов, для имени «Аня Петрова» получилось бы 12, а не 10. Поэтому порядок действий важен. И ещё один нюанс: `input()` всегда возвращает строку, поэтому никакое преобразование типа перед `len()` не нужно.

### Разбор 2

Решение:

```python
s = "Python"
print(s[-1])
print(s[1:3])
print(s[::-1])
```

Что здесь происходит? Отрицательные индексы отсчитываются от конца строки: `s[-1]` — это последний символ, «n» (индекс −1 — это первый символ с конца). Срез `s[1:3]` берёт символы с индексами 1 и 2: «y» и «t», а символ с индексом 3 («h») не включается — правая граница среза всегда исключена. Это ключевое правило: `s[start:stop]` включает start, но не включает stop. Наконец, `s[::-1]` — это срез с шагом −1: отрицательный шаг заставляет Python идти по строке с конца к началу, поэтому мы получаем «nohtyP». Соглашение про срезы единообразно работает и для списков, и для кортежей, так что этот навык пригодится тебе ещё много раз.

### Разбор 3

Решение:

```python
text = " Привет, МИР! "
print(text.strip())
print(text.lower())
print(text.replace("МИР", "мир"))
print(len(text.strip()))
```

Что здесь происходит? `text.strip()` убирает пробелы по краям и возвращает «Привет, МИР!» — именно эту строку печатает первый `print`. `text.lower()` переводит все буквы в нижний регистр: «привет, мир!». Метод `replace("МИР", "мир")` находит первое вхождение подстроки «МИР» и заменяет его на «мир», поэтому третья строка вывода — «Привет, мир!». Исходная переменная `text` при этом не изменилась — все методы вернули новые строки, потому что строки в Python неизменяемы.

Последняя строка самая хитрая: `len(text.strip())`. Мы не сохраняем очищенную строку в переменную, а сразу передаём её в `len()`. Длина строки «Привет, МИР!» — 12 символов: 11 букв и знаков плюс пробел между «Привет,» и «МИР!». Если бы мы написали `len(text)`, получилось бы 14 — крайние пробелы тоже посчитались бы. Поэтому порядок операций здесь критичен.

### Разбор 4

Решение:

```python
fruits = "яблоко банан вишня апельсин"
words = fruits.split()
print(len(words))

joined = " - ".join(words)
print(joined)
```

Что здесь происходит? Метод `split()` без аргументов разбивает строку по любому набору пробельных символов и возвращает список слов: `['яблоко', 'банан', 'вишня', 'апельсин']`. Функция `len()` возвращает длину этого списка — 4, это и есть количество слов. Первый `print` выводит четвёрку.

Затем метод `join()` собирает список обратно в строку. Обрати внимание, на чём он вызывается: `" - ".join(words)` — разделитель `" - "` стоит слева от точки, а список передаётся в скобках. Именно так и запоминается логика: разделитель «склеивает» элементы списка, поэтому он и является объектом, на котором вызывается метод. В результате получается строка «яблоко - банан - вишня - апельсин». Пара `split()` / `join()` — одна из самых часто используемых в обработке текста.

### Разбор 5

Решение:

```python
price = 49.95
discount = 0.2
print(f"Цена после скидки: {price * (1 - discount):.2f}")
```

Что здесь происходит? Переменная `price` хранит исходную цену, `discount` — скидку в виде доли: 20% = 0.2. Цена со скидкой — это `price * (1 - discount)`: умножая на `(1 - 0.2)` = 0.8, мы оставляем 80% цены. Внутри f-строки можно писать не только имя переменной, но и целое выражение — Python вычислит его и подставит результат. 49.95 × 0.8 = 39.96.

Но вот незадача: из-за особенностей двоичной арифметики результат может получиться «грязным», например 39.96000000000001. Спецификатор `:.2f` решает эту проблему: он говорит Python «покажи число как дробное с ровно двумя знаками после запятой». Поэтому на экране появляется аккуратное значение 39.96. Спецификаторы формата — мощный инструмент: с их помощью можно задавать и ширину поля, и выравнивание, и разделители тысяч.
