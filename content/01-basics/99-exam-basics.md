Какой тип имеет результат выражения 3.14?
- int
- float
- complex
- Decimal
* Правильный ответ: float
Любое число с десятичной точкой в Python имеет тип float.

Что выведет print(7 // 2)?
- 3.5
- 3
- 4
- Error
* Правильный ответ: 3
Оператор // выполняет целочисленное деление и отбрасывает дробную часть.

Как проверить, что две переменные a и b равны?
- a = b
- a == b
- a is equal b
- a.equals(b)
* Правильный ответ: a == b
Оператор == сравнивает значения, а = присваивает значение переменной.

Как превратить строку "42" в число 42?
- number("42")
- int("42")
- str(42)
- cast("42")
* Правильный ответ: int("42")
Функция int() преобразует строку в целое число.

Что выведет print(len([10, 20, 30]))?
- 3
- 10
- 30
- Error
* Правильный ответ: 3
Функция len() возвращает количество элементов в коллекции.

Какой цикл напечатает числа 0, 1, 2?
- for i in range(3): print(i)
- for i in range(1, 3): print(i)
- for i in [3]: print(i)
- for i in range(4): print(i)
* Правильный ответ: for i in range(3): print(i)
range(3) порождает числа 0, 1, 2 — третий элемент в range не включается.

Как добавить элемент в конец списка?
- list.push(item)
- list.append(item)
- list.add(item)
- list.insert_end(item)
* Правильный ответ: list.append(item)
Метод append() добавляет элемент в конец списка.

Как объявить функцию, которая принимает аргумент x?
- function f(x): ...
- def f(x): ...
- define f(x): ...
- fn f(x): ...
* Правильный ответ: def f(x): ...
Функции объявляются ключевым словом def, за которым следует имя и параметры в скобках.

Какой блок перехватывает ошибки при выполнении кода?
- catch / except
- try / except
- throw / catch
- handle / error
* Правильный ответ: try / except
Код внутри try выполняется, а при возникновении исключения управление передаётся в блок except.

Какой способ открытия файла гарантирует его закрытие?
- f = open("data.txt"); ...
- with open("data.txt") as f: ...
- open("data.txt", "auto"); ...
- file = read("data.txt"); ...
* Правильный ответ: with open("data.txt") as f: ...
Контекстный менеджер with сам закрывает файл после выполнения блока, даже если случится ошибка.
