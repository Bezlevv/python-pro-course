Когда программа разрастается, держать весь код в одном файле неудобно. Python решает эту задачу модулями: модуль — это обычный файл `.py` с кодом, который можно подключать в другие файлы. Так же, как детали лего, модули собираются в большую программу.

## Импорт: import

Чтобы использовать код из другого модуля, нужна команда `import`. Например, модуль `math` содержит математические функции:

```python
import math

print(math.sqrt(16))      # 4.0
print(math.pi)            # 3.141592653589793
print(math.floor(2.7))    # 2
```

После `import math` мы получаем доступ к именам внутри модуля через точку: `math.sqrt`, `math.pi`. Точка показывает, откуда «пришёл» идентификатор — это удобно читается и не путает имена.

## from import

Если нужна только одна функция, можно импортировать её напрямую:

```python
from math import sqrt, pi

print(sqrt(25))   # 5.0
print(pi)         # 3.141592653589793
```

Такой способ короче, но есть риск конфликта имён: если ты сам определишь функцию `sqrt`, она перекроет импортированную.

## Псевдонимы: as

Длинные имена модулей можно сокращать псевдонимом:

```python
import random as rnd

print(rnd.randint(1, 6))    # случайное число от 1 до 6
```

Часто так сокращают `numpy` (np), `pandas` (pd), `matplotlib` (plt) — ты ещё встретишь эти имена в курсах по анализу данных.

## Стандартная библиотека

В Python уже есть огромный набор встроенных модулей — этого достаточно для большинства задач без установки чего-либо. Ещё несколько примеров:

```python
import datetime

today = datetime.date.today()
print(today)                    # дата сегодня
print(today.year)               # год
```

```python
import os

print(os.getcwd())              # текущая рабочая папка
```

```python
import sys

print(sys.version)              # версия Python
```

Заглядывай в документацию: почти для любой повседневной задачи найдётся модуль в стандартной библиотеке.

## Создаём свой модуль

Свой модуль — это обычный файл Python. Создадим файл `helpers.py`:

```python
# helpers.py
def shout(text):
    return text.upper() + "!"

def double(number):
    return number * 2
```

Теперь в другом файле в той же папке можно его импортировать:

```python
import helpers

print(helpers.shout("Привет"))   # ПРИВЕТ!
print(helpers.double(21))         # 42
```

Важно: файл программы и модуль должны лежать рядом (или модуль — в пути поиска Python).

## Защита от выполнения при импорте

Когда Python импортирует модуль, он выполняет весь его код сверху вниз. Но часть кода — например, самопроверки функций — запускать при импорте не хочется. Помогает специальная проверка:

```python
# helpers.py
def shout(text):
    return text.upper() + "!"

if __name__ == "__main__":
    print(shout("Проверка"))
```

Если запустить `helpers.py` напрямую, проверка выполнится. Если импортировать — нет, потому что в этом случае переменная `__name__` равна имени модуля, а не строке `"__main__"`. Это стандартный способ отделить исполняемую часть от библиотечной.

### Разбор 1

Файл `converters.py`:

```python
def miles_to_km(miles):
    return miles * 1.609

def kg_to_pounds(kg):
    return kg * 2.205
```

Файл `main.py`:

```python
from converters import miles_to_km, kg_to_pounds

print(f"5 миль = {miles_to_km(5)} км")
print(f"10 миль = {miles_to_km(10)} км")
print(f"70 кг = {kg_to_pounds(70)} фунтов")
print(f"100 кг = {kg_to_pounds(100)} фунтов")
```

Запуск:

```bash
python main.py
```

Результат:

```
5 миль = 8.045 км
10 миль = 16.09 км
70 кг = 154.35 фунтов
100 кг = 220.5 фунтов
```

Что здесь происходит? `converters.py` — самый простой модуль: две функции, каждая принимает число и возвращает результат пересчёта. В `main.py` строка `from converters import miles_to_km, kg_to_pounds` берёт нужные имена прямо в пространство имён программы — теперь их можно вызывать без префикса `converters`. Если бы мы написали `import converters`, вызывать пришлось бы так: `converters.miles_to_km(5)`. Оба варианта рабочие, выбор зависит от того, хочешь ли ты видеть имя модуля при каждом вызове.

F-строки подставляют результаты вызовов прямо в текст. Обрати внимание, что запускать нужно `main.py`, а не `converters.py`: если запустить `converters.py`, просто нечего будет печатать — он только определяет функции.

### Разбор 2

Файл `text_utils.py`:

```python
def count_words(text):
    return len(text.split())

def reverse(text):
    return text[::-1]
```

Файл `main.py`:

```python
from text_utils import count_words, reverse

print(count_words("Python учит нас думать"))
print(reverse("Python"))
```

Что здесь происходит? В модуле две функции. `count_words` работает в два шага: `text.split()` разбивает строку по пробелам и возвращает список слов — для «Python учит нас думать» это список из четырёх элементов. Затем `len()` возвращает длину этого списка, то есть количество слов — 4. Функция `reverse` использует срез с шагом −1: `text[::-1]` разворачивает строку, и «Python» превращается в «nohtyP».

В `main.py` мы импортируем обе функции через `from text_utils import ...` — после этого они доступны по своим коротким именам. Обрати внимание: модуль `text_utils.py` не содержит никакого исполняемого кода, кроме определений функций, поэтому при импорте ничего лишнего не печатается. Весь вывод — заслуга `main.py`.

### Разбор 3

Файл `greetings.py`:

```python
def hello(name):
    return f"Привет, {name}!"

if __name__ == "__main__":
    print(hello("Проверка"))
```

Файл `main.py`:

```python
from greetings import hello

print(hello("Аня"))
```

Что здесь происходит? Ключевая строка — `if __name__ == "__main__":`. Когда Python запускает файл напрямую (например, `python greetings.py`), встроенная переменная `__name__` внутри этого файла равна строке `"__main__"`. Поэтому проверка истинна, и печатается «Привет, Проверка!». Когда же этот файл импортируется (`from greetings import hello`), Python присваивает `__name__` значение `"greetings"` — имя модуля. Проверка становится ложной, и блок не выполняется: при импорте подгружается только функция `hello`, без побочных эффектов.

Запустив `main.py`, ты увидишь только «Привет, Аня!». Запустив `greetings.py` напрямую — увидишь «Привет, Проверка!». Этот приём — стандарт для всех Python-программ: он позволяет одному и тому же файлу быть и библиотекой, и самостоятельной программой.

### Разбор 4

Решение:

```python
import statistics
import math

numbers = [1, 2, 3, 4, 5]
print(f"Среднее: {statistics.mean(numbers):.1f}")
print(f"Медиана: {statistics.median(numbers)}")
print(f"НОД: {math.gcd(24, 36)}")
```

Что здесь происходит? Мы подключаем два модуля стандартной библиотеки через `import`. После этого доступ к их функциям идёт через точку: `statistics.mean`, `statistics.median`, `math.gcd` — так сразу видно, откуда пришла каждая функция.

`statistics.mean(numbers)` вычисляет среднее арифметическое: (1 + 2 + 3 + 4 + 5) / 5 = 3.0. Благодаря спецификатору `:.1f` мы видим ровно один знак после запятой. `statistics.median(numbers)` возвращает медиану — для списка из пяти чисел это средний элемент после сортировки, то есть 3. `math.gcd(24, 36)` находит наибольший общий делитель: 24 и 36 делятся на 12, и это наибольшее такое число. Стандартная библиотека избавляет нас от написания этих алгоритмов вручную — достаточно знать, какой модуль импортировать.

### Разбор 5

Решение:

```python
import math as m
from math import pi

print(m.floor(pi))
print(round(pi, 2))
```

Что здесь происходит? Первый способ импорта — `import math as m`. Ключевое слово `as` задаёт псевдоним: теперь модуль доступен под коротким именем `m`, и мы вызываем `m.floor(pi)`. `floor` округляет число вниз до ближайшего целого: π ≈ 3.14159…, поэтому результат — 3. Как бы близко π ни было к 3.14, `floor` всегда округляет вниз.

Второй способ — `from math import pi`: мы импортируем само значение π как обычную переменную. Для округления используем встроенную функцию `round(pi, 2)` — она округляет до двух знаков после запятой, и получается 3.14. Разница двух способов видна сразу: в первом случае имя функции вызывается через префикс `m.` (мы всегда знаем, откуда она), во втором — напрямую. Выбор зависит от количества импортируемых имён и риска конфликтов с собственными переменными.
