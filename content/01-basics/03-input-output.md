Привет! Программы становятся по-настоящему полезными, когда они общаются с пользователем: спрашивают что-то и отвечают. В этом уроке мы научимся принимать ввод с клавиатуры, превращать его в числа и аккуратно форматировать вывод с помощью f-строк.

## Функция input()

Функция `input()` ждёт, пока пользователь что-то введёт и нажмёт Enter, а затем возвращает введённый текст в виде строки:

```python
name = input("Как тебя зовут? ")
print("Привет,", name, "!")
```

Когда программа выполнит `input()`, в терминале появится вопрос. Пользователь вводит ответ, и он попадает в переменную `name`.

**Важный момент:** `input()` всегда возвращает строку, даже если пользователь ввёл число:

```python
age = input("Сколько тебе лет? ")  # пользователь ввёл 25
print(type(age))  # <class 'str'> — это строка, а не число!
```

Поэтому перед арифметическими действиями строку нужно превратить в число.

## Преобразование ввода в число

Вспоминаем предыдущий урок: для превращения строки в число служат функции `int()` и `float()`. Чаще всего их используют сразу вместе с `input()`:

```python
age = int(input("Сколько тебе лет? "))
print("Через 10 лет тебе будет", age + 10)
```

Функции выполняются изнутри наружу: сначала `input()` получает строку, потом `int()` превращает её в число, и уже число попадает в переменную `age`. Теперь с ним можно считать.

Подойдёт и `float()` для дробных чисел:

```python
price = float(input("Цена товара: "))
```

⚠️ Если пользователь введёт не число (например, «привет»), программа упадёт с ошибкой `ValueError`. Пока будем считать, что пользователь вводит корректные данные — способы защиты изучим позже.

## F-строки: красивый вывод

Собирать сообщения через `+` и запятые быстро надоедает. Гораздо удобнее использовать **f-строки**. Перед строкой пишется буква `f`, а внутрь строки в фигурных скобках `{}` подставляются выражения:

```python
name = "Аня"
age = 25
print(f"Меня зовут {name}, мне {age} лет.")
```

Что произойдёт? Вместо `{name}` подставится значение переменной, вместо `{age}` — её значение. Получится: `Меня зовут Аня, мне 25 лет.`

Внутри фигурных скобок можно писать не только переменные, но и целые выражения:

```python
price = 1200
discount = 0.15
print(f"Цена со скидкой: {price * (1 - discount)} руб.")
```

F-строки — это современный стандарт Python, старайся использовать именно их вместо склейки через `+`.

## Дополнительные возможности print()

У `print()` есть параметры, которые делают вывод гибче:

- `sep` — разделитель между значениями (по умолчанию пробел);
- `end` — что печатать в конце (по умолчанию перевод строки).

```python
print("Python", "JavaScript", "Go", sep=" | ")
print("Первый абзац", end=" ")
print("продолжается в той же строке")
```

Первый вызов выведет `Python | JavaScript | Go`. Второй и третий напечатают текст в одну строку, потому что второй `print()` закончился пробелом вместо перевода строки.

### Разбор 1
Одно из возможных решений:

```python
name = input("Как тебя зовут? ")
year = int(input("В каком году ты родился? "))
number = int(input("Назови любимое число: "))

print(f"Привет, {name}!")
print(f"Тебе {2026 - year} лет.")
print(f"Квадрат числа {number} равен {number * number}.")
```

Результат при вводе `Аня`, `2010`, `7`:

```
Привет, Аня!
Тебе 16 лет.
Квадрат числа 7 равен 49.
```

Что здесь происходит? Первая строка получает имя и сохраняет его как строку. Вторая и третья — сразу превращают ввод в целое число через `int(input())`. Дальше в f-строке внутри фигурных скобок стоят выражения: `{name}` подставляет имя, `{2026 - year}` вычисляет возраст, а `{number * number}` — квадрат числа. Все вычисления происходят прямо при печати, дополнительные переменные не нужны.

Если пользователь введёт что-то нечисловое в год рождения, программа упадёт с `ValueError` — это нормально для текущего уровня, скоро мы научимся такие случаи обрабатывать.

### Разбор 2
Решение:

```python
name = input("Как тебя зовут? ")
dish = input("Какое у тебя любимое блюдо? ")

print(f"Привет, {name}! Твоё любимое блюдо — {dish}.")
```

Результат при вводе `Маша` и `борщ`:

```
Привет, Маша! Твоё любимое блюдо — борщ.
```

Что здесь происходит? Оба ввода остаются строками — преобразовывать их не нужно, и мы используем `input()` без обёрток. Переменные `name` и `dish` подставляются в одно f-строку через фигурные скобки. Обрати внимание, что весь текст, включая пробелы и знаки препинания, написан в самой строке — f-строки позволяют видеть итоговое сообщение целиком, а не «склеивать» его из кусочков. Это главное преимущество перед `+` и запятыми.

### Разбор 3
Решение:

```python
print("Python", "JavaScript", "Go", sep=" | ")

print("Скоро", end=" ")
print("я буду писать программы!")
```

Результат:

```
Python | JavaScript | Go
Скоро я буду писать программы!
```

Что здесь происходит? В первом вызове параметр `sep` заменяет разделитель по умолчанию (пробел) на строку `" | "`, поэтому между названиями языков печатается вертикальная черта. Во втором вызове `end=" "` говорит Python: вместо перевода строки в конце напечатай пробел. Поэтому третий `print()` начинает с той же строки, и оба куска текста оказываются в одной строке. Если бы мы не задали `end`, каждая фраза оказалась бы на своей строке.

### Разбор 4
Решение:

```python
length = float(input("Длина прямоугольника: "))
width = float(input("Ширина прямоугольника: "))

print(f"Площадь: {length * width}")
```

Результат при вводе `7` и `3.5`:

```
Площадь: 24.5
```

Что здесь происходит? `float(input())` — комбинация, которую мы уже знаем: сначала `input()` возвращает строку, затем `float()` превращает её в дробное число. Без преобразования `length * width` оказалось бы перемножением строк, и Python выдал бы ошибку. Внутри f-строки мы сразу считаем произведение: `7 * 3.5 = 24.5`. Обрати внимание на вывод `5.0` для `0.5` и `10`: Python всегда показывает дробное число с точкой, даже если дробная часть нулевая.

### Разбор 5
Решение:

```python
a = int(input("Первое число: "))
b = int(input("Второе число: "))

print(f"{a} + {b} = {a + b}")
```

Результат при вводе `15` и `27`:

```
15 + 27 = 42
```

Что здесь происходит? Оба ввода превращаются в целые числа через `int()`. Если этого не сделать, `"15" + "27"` дало бы строку `"1527"` — ведь для строк знак `+` означает склейку. В f-строке `{a}` и `{b}` подставляют значения, а `{a + b}` вычисляет сумму прямо при печати. Такой формат — выражение целиком — очень удобен для программ-калькуляторов: результат виден вместе с введёнными числами.
