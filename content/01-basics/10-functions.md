Функции — кирпичики любой программы. Функция — это именованный блок кода, который можно вызвать много раз. Мы уже пользовались готовыми функциями: `print()`, `len()`, `input()`. Сегодня научимся создавать свои.

## Зачем нужны функции

Представь: нужно трижды посчитать площадь разных прямоугольников. Можно писать одну и ту же формулу три раза, а можно один раз написать функцию и вызывать её с разными числами. Функции делают код:

- короче — не надо дублировать один и тот же код;
- понятнее — имя функции объясняет, что она делает;
- безопаснее — исправить ошибку можно в одном месте, а не в десяти.

## Первая функция

Функция объявляется ключевым словом `def`, затем идёт имя, круглые скобки с параметрами и двоеточие. Тело функции — блок с отступом:

```python
def say_hello():
    print("Привет, мир!")

say_hello()
say_hello()
```

Обрати внимание: определение функции само по себе ничего не печатает — код внутри выполнится только при вызове. Вызов — это имя функции со скобками: `say_hello()`.

## Параметры

Параметры — это данные, которые функция принимает «на вход». Их пишут внутри скобок при объявлении:

```python
def greet(name):
    print(f"Привет, {name}!")

greet("Аня")
greet("Петя")
```

Выведет:

```
Привет, Аня!
Привет, Петя!
```

Параметров может быть несколько:

```python
def rectangle_area(width, height):
    print("Площадь равна", width * height)
```

## Возврат значений: return

Функция может не просто печатать, а возвращать результат — тогда её можно использовать в выражениях. Ключевое слово `return` завершает выполнение функции и отдаёт значение тому, кто её вызвал:

```python
def square(number):
    return number * number

result = square(7)
print(result)          # 49
print(square(4))       # 16
```

Разница принципиальна: функция с `return` не печатает сама — она отдаёт значение, а решать, что с ним делать, будет вызывающий код.

`return` можно использовать в нескольких местах функции — сработает первый встреченный:

```python
def max_of(a, b):
    if a > b:
        return a
    return b

print(max_of(10, 5))   # 10
print(max_of(3, 8))    # 8
```

## Значения по умолчанию

Параметру можно задать значение по умолчанию: если вызывающий код его не передал, используется оно:

```python
def greet(name, greeting="Привет"):
    print(f"{greeting}, {name}!")

greet("Аня")                    # Привет, Аня!
greet("Аня", "Здравствуй")      # Здравствуй, Аня!
```

Параметры со значениями по умолчанию должны идти после обычных.

## Область видимости

Переменные, созданные внутри функции, живут только внутри неё. Снаружи их не видно, и наоборот:

```python
def add_one(x):
    y = x + 1
    return y

print(add_one(5))   # 6
print(y)            # NameError: переменная y не существует снаружи
```

Это защищает программу от случайных конфликтов имён: функция — это изолированный «мирок».

- что такое параметры со значениями по умолчанию;

### Разбор 1

Одно из возможных решений:

```python
def triangle_area(base, height):
    return base * height / 2

def is_even(number):
    return number % 2 == 0

print(f"Площадь треугольника: {triangle_area(5, 6)}")
print(f"Площадь треугольника: {triangle_area(8, 6)}")
print(f"Число 10 чётное? {is_even(10)}")
print(f"Число 7 чётное? {is_even(7)}")
```

Результат:

```
Площадь треугольника: 15.0
Площадь треугольника: 24.0
Число 10 чётное? True
Число 7 чётное? False
```

Что здесь происходит? Первая функция принимает два параметра и вычисляет площадь треугольника: полупроизведение основания и высоты. В Python деление `/` всегда возвращает дробное число, поэтому получается `15.0`, а не `15`. Сама функция ничего не печатает — она возвращает результат, а печать мы делаем в основной части через f-строки.

Вторая функция возвращает результат сравнения `number % 2 == 0`. Оператор `%` даёт остаток от деления: у чётного числа остаток от деления на 2 равен нулю. Сравнение вернёт `True` или `False`, и мы подставляем это булево значение прямо в f-строку.

Почему так делать правильно? Функции с `return` универсальны: одну и ту же `triangle_area` можно использовать и для печати, и для вычислений в других выражениях. Если бы `print` был внутри функции, такая гибкость была бы потеряна.

### Разбор 2

Решение:

```python
def max_of_three(a, b, c):
    biggest = a
    if b > biggest:
        biggest = b
    if c > biggest:
        biggest = c
    return biggest

print(f"Максимум: {max_of_three(3, 7, 5)}")
print(f"Максимум: {max_of_three(10, 3, 9)}")
print(f"Максимум: {max_of_three(1, 1, 1)}")
```

Что здесь происходит? Мы начинаем с предположения, что максимум — это `a`. Затем последовательно сравниваем с оставшимися аргументами: если `b` больше текущего максимума, обновляем его; то же самое с `c`. После двух сравнений в `biggest` гарантированно лежит наибольшее число. Такой подход не требует вложенных условий и легко расширяется на любое количество аргументов.

Для набора (3, 7, 5): сначала `biggest = 3`, потом 7 > 3, значит `biggest = 7`, а 5 > 7 ложно — ответ 7. Для (10, 3, 9): 10 уже максимум, оба сравнения неудачны — ответ 10. Для (1, 1, 1): ни одно сравнение не срабатывает, потому что числа равны, и возвращается исходное `a` — единица. Обрати внимание: при равенстве функция корректно возвращает одно из равных значений.

### Разбор 3

Решение:

```python
def power(base, exponent=2):
    return base ** exponent

print(f"5 в степени 2 = {power(5)}")
print(f"2 в степени 10 = {power(2, 10)}")
print(f"3 в степени 3 = {power(3, 3)}")
```

Что здесь происходит? Параметр `exponent` объявлен со значением по умолчанию 2. Когда мы вызываем `power(5)`, передавая только один аргумент, Python видит, что для `exponent` значения нет, и подставляет значение по умолчанию — 2. Поэтому `power(5)` возвращает 5² = 25. В остальных вызовах оба аргумента переданы явно: `power(2, 10)` считает 2¹⁰ = 1024, а `power(3, 3)` — 3³ = 27.

Значения по умолчанию делают функцию гибкой: её можно использовать и как «возвести в квадрат» (самый частый случай), и как «возвести в произвольную степень». Важно помнить правило из теории: параметры со значениями по умолчанию должны идти после обычных — иначе Python не поймёт, где кончаются обязательные аргументы, и выдаст ошибку.

### Разбор 4

Решение:

```python
def is_palindrome(word):
    return word == word[::-1]

print(f"radar — палиндром? {is_palindrome('radar')}")
print(f"python — палиндром? {is_palindrome('python')}")
```

Что здесь происходит? Срез `word[::-1]` с шагом −1 возвращает строку, прочитанную задом наперёд: для «radar» это будет «radar», а для «python» — «nohtyp». Затем мы сравниваем исходное слово с перевёрнутым. Сравнение строк возвращает булево значение: `True`, если строки равны, и `False`, если нет. Именно это значение функция и возвращает через `return` — она не печатает ничего сама, а отдаёт результат вызывающему коду.

Для «radar» перевёрнутая версия совпадает с исходной, поэтому возвращается `True` — слово действительно читается одинаково в обе стороны. Для «python» строки различаются, поэтому возвращается `False`. Обрати внимание: булевы значения `True` и `False` подставляются в f-строку как есть, поэтому в выводе мы видим именно слова True/False без кавычек.

### Разбор 5

Решение:

```python
def sum_list(numbers):
    total = 0
    for n in numbers:
        total += n
    return total

print(sum_list([1, 2, 3, 4]))
print(sum_list([10, -5, 3]))
```

Что здесь происходит? Функция принимает список чисел. До цикла мы заводим переменную `total = 0` — в ней будет накапливаться сумма. Цикл `for n in numbers` перебирает элементы списка по очереди, и на каждом витке мы прибавляем очередной элемент к `total` оператором `+=`. После того как цикл закончился, `return total` возвращает накопленную сумму.

Для [1, 2, 3, 4] получается 1 + 2 + 3 + 4 = 10. Для [10, -5, 3] — 10 + (−5) + 3 = 8. Обрати внимание на важную деталь: `return` стоит после цикла, а не внутри него. Если бы мы написали `return total` внутри цикла, функция завершилась бы на первом же элементе и вернула бы 1 — сумму первого элемента и нуля. Возврат после цикла — распространённая ошибка новичков, и теперь ты знаешь, как её избежать.
