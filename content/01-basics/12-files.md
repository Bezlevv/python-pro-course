Программы часто должны сохранять данные между запусками: настройки, логи, результаты вычислений. Простейший способ — файлы на диске. Сегодня научимся читать и писать текстовые файлы.

## Открываем файл: open()

Чтобы поработать с файлом, его нужно открыть функцией `open()`, передав имя файла и режим:

- `"r"` — чтение (режим по умолчанию);
- `"w"` — запись; файл создастся, если его нет, а если есть — содержимое сотрётся;
- `"a"` — добавление в конец существующего файла;
- `"r+"` — чтение и запись одновременно.

```python
file = open("notes.txt", "w")
file.write("Первая строка\n")
file.close()
```

После работы файл обязательно нужно закрыть методом `close()`. Иначе данные могут не записаться на диск, а в Windows файл может остаться занятым другими программами. Но и про `close()` легко забыть, поэтому в Python есть конструкция получше.

## Конструкция with

Конструкция `with` автоматически закрывает файл, даже если внутри произошла ошибка:

```python
with open("notes.txt", "w") as file:
    file.write("Привет!\n")
    file.write("Это вторая строка.\n")
```

Как только блок закончился, файл закрыт. Это идиоматичный способ работы с файлами — используй именно его.

## Запись: write() и writelines()

Метод `write()` записывает одну строку. Перенос строки нужно указывать явно — символом `\n`:

```python
with open("numbers.txt", "w") as f:
    for i in range(1, 4):
        f.write(f"{i}\n")
```

`writelines()` записывает сразу список строк:

```python
lines = ["один\n", "два\n", "три\n"]
with open("words.txt", "w") as f:
    f.writelines(lines)
```

## Чтение: read(), readline(), readlines()

Самый простой способ — прочитать весь файл целиком методом `read()`:

```python
with open("notes.txt", "r") as f:
    content = f.read()
print(content)
```

`readline()` читает по одной строке за раз:

```python
with open("notes.txt", "r") as f:
    first_line = f.readline()
    print(first_line)
```

`readlines()` возвращает список всех строк:

```python
with open("notes.txt", "r") as f:
    lines = f.readlines()
print(lines)
```

Для больших файлов лучше не читать всё сразу, а итерироваться по файлу — каждая строка появится на своём витке цикла:

```python
with open("notes.txt", "r") as f:
    for line in f:
        print(line.strip())
```

`strip()` убирает перевод строки в конце, чтобы при печати не получалось пустых строк.

## Кодировка

Почти все современные тексты — юникод. Чтобы русский текст читался корректно, указывай `encoding="utf-8"`:

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Привет!\n")
```

Без этой опции на некоторых системах запись кириллицы приведёт к ошибкам или «кракозябрам».

<!--SOLUTION-->
Одно из возможных решений:

```python
with open("poem.txt", "w", encoding="utf-8") as f:
    f.write("У лукоморья дуб зелёный\n")
    f.write("Златая цепь на дубе том\n")
    f.write("И днём и ночью кот учёный\n")

count = 0
with open("poem.txt", "r", encoding="utf-8") as f:
    for number, line in enumerate(f, start=1):
        print(f"{number}: {line.strip()}")
        count += 1

print(f"Всего строк: {count}")
```

Результат:

```
1: У лукоморья дуб зелёный
2: Златая цепь на дубе том
3: И днём и ночью кот учёный
Всего строк: 3
```

Что здесь происходит? Первый блок `with` открывает файл на запись. Режим `"w"` создаст файл, если его нет, и сотрёт старое содержимое, если он есть. Каждая строка записывается методом `write()`; символ `\n` добавляет перенос строки. По окончании блока `with` файл закрывается автоматически.

Второй блок открывает файл на чтение. Мы итерируемся по файлу — каждая строка становится значением переменной `line`. `enumerate(f, start=1)` добавляет номер строки, начиная с единицы, поэтому счётчик вести вручную не нужно. `line.strip()` убирает перевод строки из конца, чтобы при печати не получалось пустых строк. Переменная `count` всё равно нужна для итогового числа строк.

Обрати внимание на кодировку: без `encoding="utf-8"` кириллица на некоторых системах запишется некорректно. А ещё попробуй заменить блок чтения на `lines = f.readlines()` — тогда длина списка и станет количеством строк.
<!--/SOLUTION-->
