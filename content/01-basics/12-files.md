Программы часто должны сохранять данные между запусками: настройки, логи, результаты вычислений. Простейший способ — файлы на диске. Сегодня научимся читать и писать текстовые файлы.

## Открываем файл: open()

Чтобы поработать с файлом, его нужно открыть функцией `open()`, передав имя файла и режим:

- `"r"` — чтение (режим по умолчанию);
- `"w"` — запись; файл создастся, если его нет, а если есть — содержимое сотрётся;
- `"a"` — добавление в конец существующего файла;
- `"r+"` — чтение и запись одновременно.

```python
file = open("notes.txt", "w")
file.write("Первая строка\n")
file.close()
```

После работы файл обязательно нужно закрыть методом `close()`. Иначе данные могут не записаться на диск, а в Windows файл может остаться занятым другими программами. Но и про `close()` легко забыть, поэтому в Python есть конструкция получше.

## Конструкция with

Конструкция `with` автоматически закрывает файл, даже если внутри произошла ошибка:

```python
with open("notes.txt", "w") as file:
    file.write("Привет!\n")
    file.write("Это вторая строка.\n")
```

Как только блок закончился, файл закрыт. Это идиоматичный способ работы с файлами — используй именно его.

## Запись: write() и writelines()

Метод `write()` записывает одну строку. Перенос строки нужно указывать явно — символом `\n`:

```python
with open("numbers.txt", "w") as f:
    for i in range(1, 4):
        f.write(f"{i}\n")
```

`writelines()` записывает сразу список строк:

```python
lines = ["один\n", "два\n", "три\n"]
with open("words.txt", "w") as f:
    f.writelines(lines)
```

## Чтение: read(), readline(), readlines()

Самый простой способ — прочитать весь файл целиком методом `read()`:

```python
with open("notes.txt", "r") as f:
    content = f.read()
print(content)
```

`readline()` читает по одной строке за раз:

```python
with open("notes.txt", "r") as f:
    first_line = f.readline()
    print(first_line)
```

`readlines()` возвращает список всех строк:

```python
with open("notes.txt", "r") as f:
    lines = f.readlines()
print(lines)
```

Для больших файлов лучше не читать всё сразу, а итерироваться по файлу — каждая строка появится на своём витке цикла:

```python
with open("notes.txt", "r") as f:
    for line in f:
        print(line.strip())
```

`strip()` убирает перевод строки в конце, чтобы при печати не получалось пустых строк.

## Кодировка

Почти все современные тексты — юникод. Чтобы русский текст читался корректно, указывай `encoding="utf-8"`:

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Привет!\n")
```

Без этой опции на некоторых системах запись кириллицы приведёт к ошибкам или «кракозябрам».

### Разбор 1

Одно из возможных решений:

```python
with open("poem.txt", "w", encoding="utf-8") as f:
    f.write("У лукоморья дуб зелёный\n")
    f.write("Златая цепь на дубе том\n")
    f.write("И днём и ночью кот учёный\n")

count = 0
with open("poem.txt", "r", encoding="utf-8") as f:
    for number, line in enumerate(f, start=1):
        print(f"{number}: {line.strip()}")
        count += 1

print(f"Всего строк: {count}")
```

Результат:

```
1: У лукоморья дуб зелёный
2: Златая цепь на дубе том
3: И днём и ночью кот учёный
Всего строк: 3
```

Что здесь происходит? Первый блок `with` открывает файл на запись. Режим `"w"` создаст файл, если его нет, и сотрёт старое содержимое, если он есть. Каждая строка записывается методом `write()`; символ `\n` добавляет перенос строки. По окончании блока `with` файл закрывается автоматически.

Второй блок открывает файл на чтение. Мы итерируемся по файлу — каждая строка становится значением переменной `line`. `enumerate(f, start=1)` добавляет номер строки, начиная с единицы, поэтому счётчик вести вручную не нужно. `line.strip()` убирает перевод строки из конца, чтобы при печати не получалось пустых строк. Переменная `count` всё равно нужна для итогового числа строк.

Обрати внимание на кодировку: без `encoding="utf-8"` кириллица на некоторых системах запишется некорректно. А ещё попробуй заменить блок чтения на `lines = f.readlines()` — тогда длина списка и станет количеством строк.

### Разбор 2

Решение:

```python
with open("squares.txt", "w", encoding="utf-8") as f:
    for i in range(1, 6):
        f.write(f"{i ** 2}\n")

total = 0
with open("squares.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()

for line in lines:
    total += int(line.strip())

print(total)
```

Что здесь происходит? Первый блок записывает квадраты: цикл проходит по числам от 1 до 5, и каждое число, возведённое в квадрат, попадает в файл отдельной строкой. Внутри f-строки мы сразу вычисляем `i ** 2`, а `\n` в конце каждого вызова `write()` переносит следующее число на новую строку. В файле оказывается: 1, 4, 9, 16, 25.

Второй блок читает файл методом `readlines()` — он возвращает список строк: `["1\n", "4\n", ...]`. Дальше мы проходим по этому списку циклом. Каждая строка содержит число и перевод строки, поэтому сначала применяем `line.strip()`, чтобы убрать `\n`, а затем `int()` превращает текст в число. Сумма накапливается в `total`: 1 + 4 + 9 + 16 + 25 = 55. Этот путь — «записали данные, прочитали, обработали» — основа настоящих программ, работающих с файлами.

### Разбор 3

Решение:

```python
with open("data.txt", "w", encoding="utf-8") as f:
    for n in [10, 20, 30, 40]:
        f.write(f"{n}\n")

total = 0
count = 0
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        total += int(line.strip())
        count += 1

print(f"Сумма: {total}")
print(f"Среднее: {total / count:.1f}")
```

Что здесь происходит? Запись ничем не отличается от предыдущих задач: цикл по списку чисел пишет каждое в отдельной строке. А вот чтение устроено интереснее: мы итерируемся прямо по файловому объекту — `for line in f` по очереди отдаёт строки файла, не загружая его целиком в память. Такой способ предпочтителен для больших файлов: сколько бы строк ни было в файле, в памяти одновременно находится только одна.

Внутри цикла мы одновременно решаем две задачи: накапливаем сумму (числа после `strip()` превращаются в `int` и прибавляются к `total`) и считаем количество строк. После цикла сумма равна 10 + 20 + 30 + 40 = 100, а `count` равен 4. Среднее — это `total / count` = 25.0. Спецификатор `:.1f` гарантирует ровно один знак после запятой, поэтому мы видим «25.0».

### Разбор 4

Решение:

```python
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("Первый запуск\n")
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("Второй запуск\n")

with open("log.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content, end="")
```

Что здесь происходит? Ключевая деталь — режим `"a"` (append, добавление). В отличие от `"w"`, он не стирает существующее содержимое, а открывает файл и позиционирует курсор записи в конец. Поэтому первый вызов `write()` дописывает «Первый запуск\n», а второй — «Второй запуск\n» уже после него. Если бы мы использовали `"w"`, второй блок затёр бы первую строку, и в файле остался бы только «Второй запуск».

После двух записей мы читаем файл целиком методом `read()`: он возвращает одну большую строку со всем содержимым. Мы печатаем её с параметром `end=""`, чтобы не добавлять лишний перевод строки: текст в файле уже заканчивается на `\n`. В выводе появляются обе строки — значит, режим `"a"` сработал как задумано. Такой режим удобен для логов и журналов, куда нужно дописывать новые записи, не трогая старые.

### Разбор 5

Решение:

```python
with open("source.txt", "w", encoding="utf-8") as f:
    f.write("Первая строка\n")
    f.write("Вторая строка\n")

with open("source.txt", "r", encoding="utf-8") as src, \
     open("copy.txt", "w", encoding="utf-8") as dst:
    for line in src:
        dst.write(line)

with open("copy.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

Что здесь происходит? Сначала мы создаём исходный файл с двумя строками. Затем открываем сразу два файла в одном выражении `with`: источник на чтение (`"r"`), копию на запись (`"w"`). Python позволяет перечислять несколько файлов через запятую — оба будут закрыты автоматически после блока. Внутри цикла `for line in src` мы читаем строку из источника и тут же записываем её в копию через `dst.write(line)`. Так строка за строкой происходит копирование, причём в памяти в любой момент находится только одна строка — это эффективно даже для огромных файлов.

Затем мы читаем копию и выводим её строки, применяя `strip()`, чтобы убрать переводы строк. Результат совпадает с содержимым исходного файла. Этот приём — чтение из одного файла и запись в другой — лежит в основе множества реальных задач: конвертация форматов, фильтрация строк, создание резервных копий.
