Streamlit — библиотека для быстрых веб-дашбордов. Ты пишешь обычный Python-скрипт, а Streamlit превращает его в страницу с виджетами и графиками. Не нужно знать HTML или JavaScript — идеально для аналитики и машинного обучения.

## Установка и первое приложение

```bash
pip install streamlit pandas
```

Создай файл `dashboard.py`:

```python
import streamlit as st

st.title("Мой первый дашборд")
st.write("Привет, это Streamlit!")
```

Запуск:

```bash
streamlit run dashboard.py
```

Откроется браузер на `http://localhost:8501`. Обрати внимание: Streamlit **перезапускает весь скрипт** при каждом действии пользователя — это ключевая идея. Состояние держать не надо: просто описываешь, что рисовать, а библиотека сама всё обновит.

## Виджеты

Любой виджет — это функция, возвращающая текущее значение:

```python
name = st.text_input("Как тебя зовут?")
age = st.slider("Возраст", min_value=0, max_value=100, value=25)
happy = st.checkbox("Я доволен жизнью")
```

Если пользователь подвинет слайдер, скрипт выполнится заново, и `age` получит новое значение. Выведем их:

```python
st.write(f"Привет, {name}! Тебе {age} лет.")
if happy:
    st.success("Здорово!")
else:
    st.info("Ничего, всё наладится.")
```

Есть и другие удобные виджеты: `st.selectbox` (выпадающий список), `st.radio`, `st.button`, `st.multiselect`, `st.date_input`.

## Данные и графики

Streamlit дружит с pandas. Сделаем дашборд по книгам:

```python
import pandas as pd

df = pd.DataFrame({
    "title": ["Война и мир", "1984", "Цветы для Элджернона"],
    "year": [1869, 1949, 1966],
    "rating": [4.8, 4.7, 4.9],
})

st.dataframe(df)
```

`st.dataframe` — интерактивная таблица: сортировка по колонкам, просмотр. А вот так рисуются графики:

```python
st.line_chart(df.set_index("year")["rating"])
st.bar_chart(df.set_index("title")["rating"])
```

`st.line_chart` и `st.bar_chart` принимают DataFrame и строят графики автоматически.

## Кэширование

Если данные тяжело загружать (например, из файла), повесь декоратор — тогда повторные запуски скрипта не будут грузить их заново:

```python
@st.cache_data
def load_data():
    return pd.read_csv("books.csv")
```

## Боковая панель

Дополнительные элементы управления удобно прятать слева:

```python
with st.sidebar:
    min_rating = st.slider("Минимальный рейтинг", 0.0, 5.0, 4.5)
```

### Разбор 1
Полный код `books_dashboard.py`:

```python
import pandas as pd
import streamlit as st

df = pd.DataFrame({
    "title": ["Война и мир", "1984", "Цветы для Элджернона", "Мастер и Маргарита"],
    "author": ["Л. Толстой", "Дж. Оруэлл", "Д. Киз", "М. Булгаков"],
    "year": [1869, 1949, 1966, 1967],
    "popularity": [88, 95, 91, 93],
})

st.title("Книги")

min_year = st.slider(
    "Минимальный год издания",
    min_value=int(df["year"].min()),
    max_value=int(df["year"].max()),
    value=int(df["year"].min()),
)

filtered = df[df["year"] >= min_year]

st.subheader("Отфильтрованная таблица")
st.dataframe(filtered)

st.subheader("Популярность")
st.bar_chart(filtered.set_index("title")["popularity"])
```

Запуск:

```bash
streamlit run books_dashboard.py
```

Разбор: DataFrame создаётся в коде — источник данных можно потом заменить на чтение файла. Слайдер `st.slider` возвращает выбранный год; его границы берутся из данных через `df["year"].min()` и `max()`. Затем DataFrame фильтруется стандартной операцией pandas: `df[df["year"] >= min_year]`. Таблица `st.dataframe` выводит результат, а `st.bar_chart` строит столбчатую диаграмму, используя названия книг как подписи осей. Так как каждый запуск скрипта пересчитывается, движение слайдера мгновенно меняет и таблицу, и график. Итог: ты видишь заголовок, слайдер, таблицу и диаграмму, которые реагируют на ввод.

import streamlit as st

sales_df = pd.DataFrame({

st.line_chart(sales_df.set_index("month")["sales"])

Оба виджета автоматически подписывают оси по индексу и названию серии. Итог: страница содержит одну таблицу и два графика; при наведении на точки/столбцы Streamlit показывает точные значения.

### Разбор 4
Полный код `cached.py`:

```python
import time
import pandas as pd
import streamlit as st

@st.cache_data
def load_data():
    print("loading...")
    time.sleep(2)
    return pd.DataFrame({
        "title": ["Война и мир", "1984", "Мастер и Маргарита"],
        "year": [1869, 1949, 1967],
    })

st.write("rerun")
df = load_data()
st.dataframe(df)
st.slider("Просто слайдер", 0, 100, 50)
```

Разбор: при первом запуске вызов `load_data()` реально выполнится: в терминале появится `loading...`, и скрипт «зависнет» примерно на 2 секунды. При любом следующем действии (движение слайдера, клик) Streamlit перезапускает весь скрипт, но декоратор `@st.cache_data` видит, что аргументы не изменились (их нет вообще) — и возвращает закэшированный DataFrame, не выполняя тело функции. Поэтому `loading...` больше не печатается, а таблица появляется мгновенно. Строка `st.write("rerun")` показывает, что скрипт действительно перезапускается: она перерисовывается при каждом действии. Это ключевой приём: тяжёлую загрузку (файлы, сетевые запросы, вычисления) выносят в кэшируемые функции, чтобы страница оставалась отзывчивой.

### Разбор 5
Полный код `sidebar_dashboard.py`:

```python
import pandas as pd
import streamlit as st

df = pd.DataFrame({
    "title": ["Война и мир", "1984", "Цветы для Элджернона", "Мастер и Маргарита", "Дюна"],
    "author": ["Л. Толстой", "Дж. Оруэлл", "Д. Киз", "М. Булгаков", "Ф. Герберт"],
    "year": [1869, 1949, 1966, 1967, 1965],
    "popularity": [88, 95, 91, 93, 90],
})

st.title("Книги")

with st.sidebar:
    min_year = st.slider(
        "Минимальный год издания",
        min_value=int(df["year"].min()),
        max_value=int(df["year"].max()),
        value=int(df["year"].min()),
    )
    authors = ["Все авторы"] + sorted(df["author"].unique().tolist())
    author = st.selectbox("Автор", authors)

filtered = df[df["year"] >= min_year]
if author != "Все авторы":
    filtered = filtered[filtered["author"] == author]

st.subheader("Отфильтрованная таблица")
st.dataframe(filtered)

st.subheader("Популярность")
st.bar_chart(filtered.set_index("title")["popularity"])
```

Разбор: блок `with st.sidebar:` размещает оба виджета в левой панели, но их значения доступны и в основном коде — это обычные переменные. `st.selectbox` получает список опций: первый пункт — строка «Все авторы», дальше — уникальные авторы, отсортированные через `sorted(...)`. После получения значений применяем фильтрацию в два шага: сначала по году, затем — если выбран конкретный автор — ещё и по `author`. График и таблица используют уже отфильтрованный DataFrame, поэтому согласованно меняются при любом изменении фильтров. Итог: слева панель управления, справа данные; комбинация фильтров работает мгновенно.
