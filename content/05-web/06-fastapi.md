FastAPI — это современный Python-фреймворк для создания веб-API. Он работает быстро, поддерживает асинхронность и, главное, сам валидирует данные и генерирует документацию. В этом уроке ты научишься описывать эндпоинты и использовать Pydantic для строгой проверки данных.

## Установка и первое приложение

Установи FastAPI и сервер Uvicorn:

```bash
pip install fastapi "uvicorn[standard]"
```

Создай файл `main.py`:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "Привет, мир!"}
```

Запусти сервер:

```bash
uvicorn main:app --reload
```

Открой `http://127.0.0.1:8000/` — увидишь JSON `{"message":"Привет, мир!"}`. Флаг `--reload` автоматически перезапускает сервер при изменении файла.

## Пути и параметры пути

Эндпоинт может принимать часть URL как параметр. В FastAPI достаточно указать тип — он валидирует значение автоматически:

```python
@app.get("/items/{item_id}")
def get_item(item_id: int):
    return {"item_id": item_id, "name": f"Товар {item_id}"}
```

Если отправить `/items/abc`, получишь ответ 422 Unprocessable Entity: FastAPI не смог превратить `abc` в число.

## Query-параметры

Параметры после `?` (например, `/items/1?q=хороший`) описываются обычными аргументами функции. Значение по умолчанию делает параметр необязательным:

```python
@app.get("/items/")
def list_items(limit: int = 10, category: str | None = None):
    # limit — сколько записей вернуть, category — фильтр
    return {"limit": limit, "category": category}
```

Вызов `GET /items/?limit=5&category=books` вернёт `{"limit":5,"category":"books"}`.

## Pydantic: модели данных

Для тела запроса (POST/PUT) используют модели Pydantic:

```python
from pydantic import BaseModel, Field

class Book(BaseModel):
    title: str
    author: str
    year: int = Field(gt=0, description="Год издания")
    pages: int = Field(gt=0)
```

FastAPI сам разберёт JSON, проверит типы и правила `Field` — при нарушении вернёт 422 с описанием ошибки. Хранить книги будем в списке в памяти (для настоящего проекта нужна база данных — об этом в одном из следующих уроков):

```python
books: list[Book] = []

@app.post("/books/")
def create_book(book: Book):
    books.append(book)
    return book
```

Обрати внимание: в функции `create_book` параметр `book` имеет тип `Book`, поэтому внутри мы работаем с объектом модели, а не со словарём.

## Документация — бесплатно

FastAPI автоматически создаёт интерактивную документацию: открой `http://127.0.0.1:8000/docs` — там будет Swagger UI, где можно прямо в браузере отправлять запросы к каждому эндпоинту (кнопка «Try it out»). Есть и альтернативная версия — `/redoc`.

<!--SOLUTION-->
Полный код `library.py`:

```python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()


class Book(BaseModel):
    title: str
    author: str
    year: int = Field(gt=0, description="Год издания")
    pages: int = Field(gt=0)


books: list[Book] = []


@app.get("/books/")
def list_books():
    return books


@app.post("/books/")
def create_book(book: Book):
    books.append(book)
    return book
```

Запуск:

```bash
uvicorn library:app --reload
```

Разбор по шагам:

1. **Импорты.** `FastAPI` создаёт приложение, `BaseModel` — основу модели, `Field` позволяет добавить ограничения.
2. **Модель `Book`.** Четыре поля; `year` и `pages` получают правило `gt=0` — значение обязано быть больше нуля. Если это правило нарушено, FastAPI вернёт 422, а в ответе будет список `detail` с описанием ошибки.
3. **Список `books`.** Глобальная переменная — имитация хранилища. В реальном проекте здесь была бы база данных.
4. **`GET /books/`.** Возвращает весь список. Изначально он пустой — ожидай `[]`.
5. **`POST /books/`.** Принимает JSON, автоматически превращает его в объект `Book` (или отдаёт 422 при ошибке валидации), добавляет в список и возвращает добавленную книгу.

Проверка в `/docs`: открой раздел POST /books/, нажми «Try it out», вставь `{"title":"Война и мир","author":"Лев Толстой","year":1869,"pages":1225}` — ответ 200 и та же книга. Затем поменяй `year` на `-5` — ответ 422. Теперь GET /books/ покажет одну книгу. Так выглядит минимальный, но рабочий API.
<!--/SOLUTION-->
