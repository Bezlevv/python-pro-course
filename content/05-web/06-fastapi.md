FastAPI — это современный Python-фреймворк для создания веб-API. Он работает быстро, поддерживает асинхронность и, главное, сам валидирует данные и генерирует документацию. В этом уроке ты научишься описывать эндпоинты и использовать Pydantic для строгой проверки данных.

## Установка и первое приложение

Установи FastAPI и сервер Uvicorn:

```bash
pip install fastapi "uvicorn[standard]"
```

Создай файл `main.py`:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "Привет, мир!"}
```

Запусти сервер:

```bash
uvicorn main:app --reload
```

Открой `http://127.0.0.1:8000/` — увидишь JSON `{"message":"Привет, мир!"}`. Флаг `--reload` автоматически перезапускает сервер при изменении файла.

## Пути и параметры пути

Эндпоинт может принимать часть URL как параметр. В FastAPI достаточно указать тип — он валидирует значение автоматически:

```python
@app.get("/items/{item_id}")
def get_item(item_id: int):
    return {"item_id": item_id, "name": f"Товар {item_id}"}
```

Если отправить `/items/abc`, получишь ответ 422 Unprocessable Entity: FastAPI не смог превратить `abc` в число.

## Query-параметры

Параметры после `?` (например, `/items/1?q=хороший`) описываются обычными аргументами функции. Значение по умолчанию делает параметр необязательным:

```python
@app.get("/items/")
def list_items(limit: int = 10, category: str | None = None):
    # limit — сколько записей вернуть, category — фильтр
    return {"limit": limit, "category": category}
```

Вызов `GET /items/?limit=5&category=books` вернёт `{"limit":5,"category":"books"}`.

## Pydantic: модели данных

Для тела запроса (POST/PUT) используют модели Pydantic:

```python
from pydantic import BaseModel, Field

class Book(BaseModel):
    title: str
    author: str
    year: int = Field(gt=0, description="Год издания")
    pages: int = Field(gt=0)
```

FastAPI сам разберёт JSON, проверит типы и правила `Field` — при нарушении вернёт 422 с описанием ошибки. Хранить книги будем в списке в памяти (для настоящего проекта нужна база данных — об этом в одном из следующих уроков):

```python
books: list[Book] = []

@app.post("/books/")
def create_book(book: Book):
    books.append(book)
    return book
```

Обрати внимание: в функции `create_book` параметр `book` имеет тип `Book`, поэтому внутри мы работаем с объектом модели, а не со словарём.

## Документация — бесплатно

FastAPI автоматически создаёт интерактивную документацию: открой `http://127.0.0.1:8000/docs` — там будет Swagger UI, где можно прямо в браузере отправлять запросы к каждому эндпоинту (кнопка «Try it out»). Есть и альтернативная версия — `/redoc`.

### Подсказка 1

Приложение создаётся одной строкой: `app = FastAPI()`. Эндпоинты — это функции с декораторами `@app.get("/")`. Запуск — `uvicorn main:app --reload`: имя файла без `.py`, двоеточие, имя переменной приложения. Документация живёт на `/docs`.

### Подсказка 2

Параметр пути пишется в фигурных скобках: `/items/{item_id}`. Тип указывается аннотацией: `item_id: int`. FastAPI сам попытается превратить строку из URL в число — при неудаче вернёт 422, а не 500.

### Подсказка 3

Query-параметры — это обычные аргументы функции: `limit: int = 10`. Значение по умолчанию делает параметр необязательным. Тип `str | None = None` означает «строка или ничего». В Swagger UI эти параметры появятся в форме запроса.

### Подсказка 4

Модель наследуется от `BaseModel`. Правило «больше нуля» задаёт `Field(gt=0)`: `gt` — greater than. Для POST-эндпоинта тело запроса — это параметр функции с типом модели: `def create_book(book: Book)`. Не забудь сохранить книгу в глобальный список.

### Подсказка 5

Глобальный список `books: list[Book] = []` объявляется один раз, вне функций. GET возвращает `books` напрямую — FastAPI сам сериализует список моделей в JSON. Сначала в `/docs` выполни POST, потом GET — порядок важен, иначе список будет пуст.

### Разбор 1

`main.py`:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "Привет, мир!"}
```

Разбор по шагам:

- `FastAPI()` создаёт экземпляр приложения. Он отвечает за маршрутизацию, валидацию и генерацию документации.
- Декоратор `@app.get("/")` регистрирует функцию как обработчик GET-запроса на корневой адрес.
- Функция возвращает словарь — FastAPI сам превратит его в JSON-ответ: `{"message":"Привет, мир!"}`.
- Запуск: `uvicorn main:app --reload`. После двоеточия — имя переменной приложения (`app`), а не имя функции. `--reload` перезапускает сервер при изменении файла.
- `http://127.0.0.1:8000/docs` — Swagger UI: интерактивный список эндпоинтов, где можно отправлять тестовые запросы прямо из браузера.

### Разбор 2

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}")
def get_item(item_id: int):
    return {"item_id": item_id, "name": f"Товар {item_id}"}
```

Разбор по шагам:

- Параметр пути объявляется фигурными скобками в строке адреса: `/items/{item_id}`.
- Аннотация `item_id: int` — заявка на тип. FastAPI читает её и ещё до вызова функции пытается привести строку из URL к целому числу.
- Для `/items/7` функция получит `item_id = 7` (число, а не строку) и вернёт `{"item_id":7,"name":"Товар 7"}`.
- Для `/items/abc` приведение невозможно: FastAPI отвечает 422 Unprocessable Entity с деталями ошибки. Это валидация на уровне фреймворка — без единой строки проверочного кода.
- Обрати внимание: без аннотации типа значение пришло бы как строка, и f-строка работала бы, но сравнения и арифметика — нет.

### Разбор 3

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/")
def list_items(limit: int = 10, category: str | None = None):
    return {"limit": limit, "category": category}
```

Разбор по шагам:

- Query-параметры — это обычные аргументы функции. FastAPI сам решает, какой параметр откуда брать: пути или query-строки.
- `limit: int = 10` — значение по умолчанию делает параметр необязательным. Если клиент не передаст `limit`, возьмётся 10.
- `category: str | None = None` — позволяет либо строку, либо ее отсутствие. Так фильтры становятся опциональными.
- Запрос `GET /items/?limit=5&category=books` вызовет функцию с `limit=5`, `category="books"` — ответ `{"limit":5,"category":"books"}`.
- Значения по умолчанию — это и документация (их видно в Swagger), и безопасность: неожиданные типы дадут 422 вместо падения сервера.

### Разбор 4

```python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()

class Book(BaseModel):
    title: str
    author: str
    year: int = Field(gt=0, description="Год издания")
    pages: int = Field(gt=0)

books: list[Book] = []

@app.post("/books/")
def create_book(book: Book):
    books.append(book)
    return book
```

Разбор по шагам:

- `BaseModel` — основа Pydantic-моделей. Поля объявляются аннотациями.
- `Field(gt=0)` добавляет ограничение: значение обязано быть больше нуля. `gt` — greater than.
- FastAPI принимает JSON-тело POST-запроса и создаёт объект `Book`: проверяет наличие обязательных полей, типы и правила `Field`. Любое нарушение — 422 с описанием.
- `books: list[Book] = []` — глобальный список для хранения; для реального проекта нужна база данных.
- Функция возвращает добавленную книгу — FastAPI сериализует модель обратно в JSON.

### Разбор 5

`library.py`:

```python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()

class Book(BaseModel):
    title: str
    author: str
    year: int = Field(gt=0, description="Год издания")
    pages: int = Field(gt=0)

books: list[Book] = []

@app.get("/books/")
def list_books():
    return books

@app.post("/books/")
def create_book(book: Book):
    books.append(book)
    return book
```

Разбор по шагам:

- `GET /books/` возвращает текущее содержимое списка. Изначально это `[]`.
- `POST /books/` принимает тело запроса, автоматически валидирует его и добавляет книгу в список.
- В Swagger UI (`/docs`) открой нужный эндпоинт, нажми «Try it out», вставь валидный JSON: `{"title":"Война и мир","author":"Лев Толстой","year":1869,"pages":1225}` — ответ 200 и та же книга.
- Поменяй `year` на `-5` — ответ 422: правило `gt=0` нарушено.
- После POST выполни GET — книга появилась в списке. Так выглядит минимальный, но рабочий API: валидация, документация и хранение — из коробки.
