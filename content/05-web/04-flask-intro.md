Привет! Ты уже умеешь делать HTTP-запросы как клиент. Теперь поменяем сторону: напишем свой сервер, который будет отвечать на запросы. В этом поможет Flask — самый популярный микрофреймворк для веба на Python.

## Что такое Flask

Flask — маленький и понятный фреймворк. Он отдаёт HTML-страницы, обрабатывает формы и умеет работать как полноценный API. Его философия — «явное лучше неявного»: никакой магии, просто функции Python.

## Установка

```bash
pip install flask
```

## Первое приложение

Минимальное приложение занимает несколько строк:

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "Привет, мир!"

if __name__ == "__main__":
    app.run(debug=True)
```

- `Flask(__name__)` создаёт приложение;
- `@app.route("/")` — декоратор, связывающий адрес `/` с функцией;
- функция возвращает ответ, который увидит клиент.

## Запуск

Сохрани код в `app.py` и выполни:

```bash
python app.py
```

В терминале появится адрес `http://127.0.0.1:5000` — открой его в браузере. Флаг `debug=True` даёт автоперезагрузку при изменении кода и подробные страницы ошибок.

## Динамические маршруты

Адреса могут содержать переменные части. Их пишут в угловых скобках:

```python
@app.route("/user/<name>")
def user(name):
    return f"Привет, {name}!"
```

По адресу `/user/Аня` функция получит `name = "Аня"`. По умолчанию это строка, но тип можно указать конвертером:

```python
@app.route("/square/<int:n>")
def square(n):
    return str(n * n)
```

`<int:n>` гарантирует, что `n` придёт как целое число, а не строка.

## Методы запроса

По умолчанию маршрут отвечает только на GET. Чтобы разрешить остальные методы, добавь аргумент `methods`:

```python
from flask import request

@app.route("/echo", methods=["GET", "POST"])
def echo():
    if request.method == "POST":
        return "Это был POST"
    return "Это был GET"
```

Объект `request` содержит данные текущего запроса.

### Подсказка 1

Каждая функция-обработчик помечается декоратором `@app.route("/")`. Экземпляр приложения создаётся один раз: `app = Flask(__name__)`. Импорт — `from flask import Flask`. Запуск — `python app.py`; сервер поднимется на `http://127.0.0.1:5000`.

### Подсказка 2

Новый маршрут — это новая функция с собственным декоратором: `@app.route("/about")` и `def about(): return "..."`. Возвращаемое значение — строка — и будет ответом сервера. Не забудь перезапустить сервер или сохранить файл — при `debug=True` он перезагрузится сам.

### Подсказка 3

Переменная часть URL пишется в угловых скобках: `<name>`. Имя переменной внутри скобок должно совпадать с именем параметра функции: `def user(name):`. Текст ответа собирай f-строкой: `return f"Привет, {name}!"`.

### Подсказка 4

Конвертер указывается внутри скобок с двоеточием: `<int:n>`. Тогда Flask сам превратит строку из адреса в число, и внутри функции можно сразу складывать или умножать. Не забудь, что ответ должен быть строкой: оборачивай результат в `str()`.

### Разбор 1

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "Привет, мир!"

if __name__ == "__main__":
    app.run(debug=True)
```

Разбор по шагам:

- `from flask import Flask` — импорт класса приложения. Если импорт падает, проверь, что `pip install flask` выполнен в том же окружении, где запускается код.
- `app = Flask(__name__)` создаёт экземпляр приложения. Аргумент `__name__` помогает Flask находить ресурсы — шаблоны и статику — относительно текущего модуля.
- `@app.route("/")` — декоратор: он регистрирует функцию как обработчик адреса `/`. Когда браузер запрашивает главную страницу, Flask вызывает `index()`.
- Функция возвращает строку. Это самый простой возможный ответ: Flask отправляет её клиенту как HTTP-ответ.
- Блок `if __name__ == "__main__"` запускает встроенный сервер только при прямом запуске файла (`python app.py`), а не при импорте.
- `debug=True` включает режим разработки: перезагрузку при изменении кода и подробные страницы ошибок.

### Разбор 2

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "Привет, мир!"

@app.route("/about")
def about():
    return "Меня зовут Аня, я учу Python и делаю свои первые сайты."

if __name__ == "__main__":
    app.run(debug=True)
```

Разбор по шагам:

- Второй маршрут — это просто вторая функция со своим декоратором: `@app.route("/about")` связывает адрес `/about` с функцией `about()`.
- Так принято в Flask: каждый маршрут — своя функция, имена функций должны осмысленно отражать содержимое.
- Возвращаемое значение функции отправляется клиенту дословно. Длинные строки можно разбивать — Python сам склеит их при выполнении, но здесь строка умещается в одну строку.
- Связь «адрес → функция» хранится внутри приложения: при запросе `/about` вызывается `about()`, при запросе `/` — `index()`, и они не мешают друг другу.
- С `debug=True` можно не перезапускать сервер вручную: сохрани файл — и Flask перезагрузит приложение сам.

### Разбор 3

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "Привет, мир!"

@app.route("/user/<name>")
def user(name):
    return f"Привет, {name}!"

if __name__ == "__main__":
    app.run(debug=True)
```

Разбор по шагам:

- `@app.route("/user/<name>")` — динамический маршрут: угловые скобки объявляют переменную часть адреса.
- Имя в скобках и имя параметра функции должны совпадать: `<name>` и `def user(name)`. Flask подставит значение из URL в вызов функции.
- Для адреса `/user/Аня` функция получит `name = "Аня"`, для `/user/Петя` — `name = "Петя"`. Одна функция обслуживает бесконечное число адресов.
- По умолчанию переменная часть — строка. Поэтому f-строку можно использовать напрямую: `f"Привет, {name}!"`.
- Если бы мы написали `<int:name>`, Flask попытался бы привести значение к числу и вернул бы 404 для нечисловых адресов.

### Разбор 4

```python
from flask import Flask

app = Flask(__name__)

@app.route("/square/<int:n>")
def square(n):
    return str(n * n)

@app.route("/sum/<int:a>/<int:b>")
def add(a, b):
    return str(a + b)

if __name__ == "__main__":
    app.run(debug=True)
```

Разбор по шагам:

- Конвертер `<int:n>` сообщает Flask: значение в этой части URL надо превратить в целое число. Flask делает это автоматически до вызова функции.
- Благодаря этому внутри функции `n` — уже число, и `n * n` работает как умножение, а не как повторение строки.
- Маршрут может содержать несколько переменных частей: `/sum/<int:a>/<int:b>` — два параметра, разделённых слешем. Функция принимает оба.
- HTTP-ответ — это текст, поэтому результат арифметики надо превратить в строку: `str(a + b)`. Без `str()` Flask может не понять, как сериализовать число.
- Проверка: `/square/7` покажет `49`, `/sum/4/7` — `11`.

### Разбор 5

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "Добро пожаловать на мой сайт!"

@app.route("/about")
def about():
    return "Меня зовут Аня, я учу Python и делаю свои первые сайты."

@app.route("/repeat/<int:n>")
def repeat(n):
    return "Хоп! " * n

@app.route("/sum/<int:a>/<int:b>")
def add(a, b):
    return str(a + b)

if __name__ == "__main__":
    app.run(debug=True)
```

Разбор по шагам:

- Финальный файл объединяет четыре маршрута: статичные `/` и `/about`, динамический `/repeat/<int:n>` и двухпараметровый `/sum/<int:a>/<int:b>`.
- `"Хоп! " * n` — умножение строки на число: Python повторяет строку `n` раз. Для `n=3` получается `Хоп! Хоп! Хоп! ` — с пробелом в конце, потому что он есть в самой строке.
- В `/sum` функция складывает числа и возвращает `str(a + b)` — строку, ведь ответ сервера это текст.
- Каждый маршрут живёт в своей функции, поэтому править один не мешает другим.
- Проверяем в браузере: `http://127.0.0.1:5000/repeat/3` покажет «Хоп! Хоп! Хоп! », `http://127.0.0.1:5000/sum/4/7` — `11`. Приложение работает как настоящий мини-сайт.
