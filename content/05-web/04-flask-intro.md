Привет! Ты уже умеешь делать HTTP-запросы как клиент. Теперь поменяем сторону: напишем свой сервер, который будет отвечать на запросы. В этом поможет Flask — самый популярный микрофреймворк для веба на Python.

## Что такое Flask

Flask — маленький и понятный фреймворк. Он отдаёт HTML-страницы, обрабатывает формы и умеет работать как полноценный API. Его философия — «явное лучше неявного»: никакой магии, просто функции Python.

## Установка

```bash
pip install flask
```

## Первое приложение

Минимальное приложение занимает несколько строк:

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "Привет, мир!"

if __name__ == "__main__":
    app.run(debug=True)
```

- `Flask(__name__)` создаёт приложение;
- `@app.route("/")` — декоратор, связывающий адрес `/` с функцией;
- функция возвращает ответ, который увидит клиент.

## Запуск

Сохрани код в `app.py` и выполни:

```bash
python app.py
```

В терминале появится адрес `http://127.0.0.1:5000` — открой его в браузере. Флаг `debug=True` даёт автоперезагрузку при изменении кода и подробные страницы ошибок.

## Динамические маршруты

Адреса могут содержать переменные части. Их пишут в угловых скобках:

```python
@app.route("/user/<name>")
def user(name):
    return f"Привет, {name}!"
```

По адресу `/user/Аня` функция получит `name = "Аня"`. По умолчанию это строка, но тип можно указать конвертером:

```python
@app.route("/square/<int:n>")
def square(n):
    return str(n * n)
```

`<int:n>` гарантирует, что `n` придёт как целое число, а не строка.

## Методы запроса

По умолчанию маршрут отвечает только на GET. Чтобы разрешить остальные методы, добавь аргумент `methods`:

```python
from flask import request

@app.route("/echo", methods=["GET", "POST"])
def echo():
    if request.method == "POST":
        return "Это был POST"
    return "Это был GET"
```

Объект `request` содержит данные текущего запроса.

<!--SOLUTION-->
Код `my_site.py`:

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "Добро пожаловать на мой сайт!"

@app.route("/about")
def about():
    return "Меня зовут Аня, я учу Python и делаю свои первые сайты."

@app.route("/repeat/<int:n>")
def repeat(n):
    return "Хоп! " * n

@app.route("/sum/<int:a>/<int:b>")
def add(a, b):
    return str(a + b)

if __name__ == "__main__":
    app.run(debug=True)
```

Разбор по шагам:

- `Flask(__name__)` создаёт приложение; `__name__` помогает Flask находить ресурсы относительно модуля.
- Декоратор `@app.route("/")` регистрирует функцию как обработчик адреса. Когда браузер запрашивает `/`, Flask вызывает `index()`, а её возвращаемое значение отправляется клиенту как ответ. Строка — самый простой возможный ответ.
- `/about` устроен аналогично: отдельная функция на отдельный адрес. Так принято: каждый маршрут — своя функция.
- `@app.route("/repeat/<int:n>")` — динамический маршрут. Конвертер `<int:n>` объявляет переменную `n` целого типа: Flask сам приводит строку из URL к числу. Если попробовать `/repeat/abc`, будет ошибка 404, потому что `abc` не является числом.
- `"Хоп! " * n` — умножение строки на число: повторяет строку `n` раз. Для `n=3` получается `Хоп! Хоп! Хоп! `.
- В `/sum/<int:a>/<int:b>` два параметра. Функция складывает числа и возвращает `str(a + b)` — обязательно строку, так как HTTP-ответ — это текст.
- Блок `if __name__ == "__main__"` запускает сервер при прямом запуске файла. `debug=True` включает удобный режим разработки.

Проверь в браузере: `http://127.0.0.1:5000/sum/4/7` покажет `11`.
<!--/SOLUTION-->
