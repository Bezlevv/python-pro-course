Для чего предназначен HTTP-метод GET?
- Для отправки данных на сервер
- Для получения данных с сервера
- Для обновления ресурса
- Для удаления ресурса
* Правильный ответ: Для получения данных с сервера
GET запрашивает ресурс (страницу, JSON, картинку) без изменения состояния сервера.

Что означает HTTP-статус 404?
- Сервер работает
- Ресурс не найден
- Требуется авторизация
- Внутренняя ошибка сервера
* Правильный ответ: Ресурс не найден
404 означает, что запрошенный адрес не существует на сервере.

Как узнать код ответа на запрос requests.get("https://example.com")?
- response.code
- response.status_code
- response.status
- response.http_code
* Правильный ответ: response.status_code
У объекта Response есть атрибут status_code с HTTP-статусом.

Как в Flask связать функцию с адресом "/"?
- @app.route("/") над функцией
- app.url("/", func)
- @route("/") над функцией
- app.add_url("/")
* Правильный ответ: @app.route("/") над функцией
Декоратор @app.route("/") регистрирует функцию как обработчик главной страницы.

Как в шаблоне Jinja2 вывести значение переменной name?
- <% name %>
- {{ name }}
- ${name}
- [[ name ]]
* Правильный ответ: {{ name }}
Двойные фигурные скобки подставляют значение переменной в HTML.

Где FastAPI показывает автоматическую интерактивную документацию?
- /docs
- /api
- /swagger.json
- /help
* Правильный ответ: /docs
FastAPI генерирует Swagger UI по адресу /docs — там можно запускать запросы прямо в браузере.

Что делает Django ORM?
- Пишет CSS-стили
- Позволяет работать с базой данных через классы-модели вместо SQL
- Рендерит HTML-шаблоны
- Настраивает веб-сервер
* Правильный ответ: Позволяет работать с базой данных через классы-модели вместо SQL
ORM транслирует обращения к моделям в SQL-запросы, например User.objects.filter(age=25).

Какой вызов выведет текст в Streamlit?
- sl.print("Привет!")
- st.write("Привет!")
- stream.write("Привет!")
- st.show("Привет!")
* Правильный ответ: st.write("Привет!")
st.write универсально выводит текст, числа, DataFrame и графики в приложение Streamlit.

Какой SQL-запрос вернёт все записи из таблицы users?
- SELECT * FROM users
- GET ALL FROM users
- FETCH * FROM users
- SHOW * FROM users
* Правильный ответ: SELECT * FROM users
SELECT выбирает данные, а звёздочка означает все столбцы.

Что такое JWT?
- Язык разметки страниц
- Формат токена для аутентификации
- База данных
- Фреймворк для тестов
* Правильный ответ: Формат токена для аутентификации
JWT (JSON Web Token) — компактный подписанный токен, который подтверждает личность пользователя.
