Привет! До сих пор мы общались с Python только через терминал. Но настоящие сайты состоят из страниц, которые видит человек. Чтобы понять, как устроен веб-фронтенд, начнём с языка разметки HTML и языка стилей CSS. Это не языки программирования, но без них не обходится ни один сайт.

## Что такое HTML

HTML (HyperText Markup Language) — это способ описать структуру страницы. Текст размечается **тегами** — командами в угловых скобках. Теги обычно парные: `<h1>Заголовок</h1>` — открывающий и закрывающий.

## Структура документа

Любая страница начинается с каркаса:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="utf-8">
    <title>Моя страница</title>
</head>
<body>
    <h1>Привет, мир!</h1>
</body>
</html>
```

- `<!DOCTYPE html>` — сообщает браузеру, что это HTML5;
- `<html>` — корневой тег;
- `<head>` — служебная часть: заголовок вкладки, мета-данные;
- `<body>` — всё, что видно на странице.

## Основные теги

- `<h1>`…`<h6>` — заголовки разных уровней;
- `<p>` — абзац;
- `<a href="...">` — ссылка;
- `<img src="..." alt="...">` — картинка (одиночный тег);
- `<ul>` / `<li>` — маркированный список;
- `<strong>`, `<em>` — жирный и курсивный текст;
- `<div>` — универсальный блок, `<span>` — строчный контейнер.

Пример страницы-визитки:

```html
<h1>Аня Иванова</h1>
<p>Я изучаю Python и делаю сайты.</p>
<ul>
    <li>Python</li>
    <li>Flask</li>
</ul>
<a href="https://t.me/anya">Мой Telegram</a>
```

## Атрибуты

Атрибуты — дополнительные настройки тегов: `href` у ссылки, `src` и `alt` у картинки, `class` — для стилей. Например, `<img src="ava.png" alt="Фото Ани">`.

## Что такое CSS

HTML описывает содержание, CSS — внешний вид: цвета, шрифты, отступы. Стили можно подключить тремя способами: атрибутом `style`, тегом `<style>` в `<head>` и внешним файлом. Лучшая практика — внешний файл `style.css`:

```html
<head>
    <link rel="stylesheet" href="style.css">
</head>
```

## Селекторы и свойства

CSS-правило состоит из селектора (кого красим) и свойств (что меняем):

```css
h1 {
    color: tomato;
    font-size: 32px;
}
.profile-card {
    background-color: #f0f0f0;
    border-radius: 12px;
    padding: 20px;
    margin-bottom: 15px;
}
```

Селектор `h1` выбирает все заголовки, `.profile-card` — элементы с классом `profile-card` (обрати внимание на точку перед именем класса). Свойства: `color` — цвет текста, `background-color` — фон, `padding` — внутренние отступы, `margin` — внешние, `border-radius` — скругление углов, `font-size` — размер шрифта.

## Итог

Ты знаешь каркас HTML-страницы, основные теги, атрибуты и как подключить стили. Теперь соберём первую полноценную страницу.

В `profile.html`:

В `style.css`:

4. Задай `.card` белый фон, скруглённые углы, внутренние отступы и ширину 320px;
5. Сделай `h1` синим.

Открой `profile.html` в браузере: должна получиться аккуратная карточка.

<!--HINT-->
Подключение стилей выглядит так: `<link rel="stylesheet" href="style.css">` внутри `<head>`. В CSS класс пишется с точкой — `.card { ... }`, а ширину ограничивают свойством `width: 320px;`.
<!--/HINT-->

<!--SOLUTION-->
`profile.html`:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="utf-8">
    <title>Моя карточка</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="card">
        <h1>Аня Иванова</h1>
        <p>Учу Python и интересуюсь веб-разработкой.</p>
        <ul>
            <li>Программирование</li>
            <li>Музыка</li>
        </ul>
    </div>
</body>
</html>
```

`style.css`:

```css
.card {
    background-color: white;
    border-radius: 12px;
    padding: 20px;
    width: 320px;
}

h1 {
    color: steelblue;
}
```

Разбор по шагам:

- Каркас документа — обязательная часть любой страницы: `<!DOCTYPE html>` говорит браузеру о версии HTML, а `<meta charset="utf-8">` отвечает за корректный показ кириллицы.
- Тег `<link>` в `<head>` подключает внешнюю таблицу стилей: `rel="stylesheet"` указывает роль файла, `href` — путь к нему. Файлы лежат рядом, поэтому путь — просто `style.css`.
- `<div class="card">` — контейнер. Класс — это метка, по которой CSS найдёт элемент, поэтому в стилях ему соответствует `.card` (с точкой). Именно классы позволяют красить разные блоки по-разному.
- Свойства `.card`: `background-color` — фон, `border-radius: 12px` — скругление углов, `padding` — пространство внутри рамки, `width: 320px` — фиксированная ширина. Границы у блока нет, поэтому карточка выглядит «плавающей».
- Селектор `h1` действует на все заголовки первого уровня, им задан синий `color`.

Открой `profile.html` двойным кликом — страница откроется прямо в браузере, без запуска серверов.
<!--/SOLUTION-->
