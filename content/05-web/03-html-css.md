Привет! До сих пор мы общались с Python только через терминал. Но настоящие сайты состоят из страниц, которые видит человек. Чтобы понять, как устроен веб-фронтенд, начнём с языка разметки HTML и языка стилей CSS. Это не языки программирования, но без них не обходится ни один сайт.

## Что такое HTML

HTML (HyperText Markup Language) — это способ описать структуру страницы. Текст размечается **тегами** — командами в угловых скобках. Теги обычно парные: `<h1>Заголовок</h1>` — открывающий и закрывающий.

## Структура документа

Любая страница начинается с каркаса:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="utf-8">
    <title>Моя страница</title>
</head>
<body>
    <h1>Привет, мир!</h1>
</body>
</html>
```

- `<!DOCTYPE html>` — сообщает браузеру, что это HTML5;
- `<html>` — корневой тег;
- `<head>` — служебная часть: заголовок вкладки, мета-данные;
- `<body>` — всё, что видно на странице.

## Основные теги

- `<h1>`…`<h6>` — заголовки разных уровней;
- `<p>` — абзац;
- `<a href="...">` — ссылка;
- `<img src="..." alt="...">` — картинка (одиночный тег);
- `<ul>` / `<li>` — маркированный список;
- `<strong>`, `<em>` — жирный и курсивный текст;
- `<div>` — универсальный блок, `<span>` — строчный контейнер.

Пример страницы-визитки:

```html
<h1>Аня Иванова</h1>
<p>Я изучаю Python и делаю сайты.</p>
<ul>
    <li>Python</li>
    <li>Flask</li>
</ul>
<a href="https://t.me/anya">Мой Telegram</a>
```

## Атрибуты

Атрибуты — дополнительные настройки тегов: `href` у ссылки, `src` и `alt` у картинки, `class` — для стилей. Например, `<img src="ava.png" alt="Фото Ани">`.

## Что такое CSS

HTML описывает содержание, CSS — внешний вид: цвета, шрифты, отступы. Стили можно подключить тремя способами: атрибутом `style`, тегом `<style>` в `<head>` и внешним файлом. Лучшая практика — внешний файл `style.css`:

```html
<head>
    <link rel="stylesheet" href="style.css">
</head>
```

## Селекторы и свойства

CSS-правило состоит из селектора (кого красим) и свойств (что меняем):

```css
h1 {
    color: tomato;
    font-size: 32px;
}
.profile-card {
    background-color: #f0f0f0;
    border-radius: 12px;
    padding: 20px;
    margin-bottom: 15px;
}
```

Селектор `h1` выбирает все заголовки, `.profile-card` — элементы с классом `profile-card` (обрати внимание на точку перед именем класса). Свойства: `color` — цвет текста, `background-color` — фон, `padding` — внутренние отступы, `margin` — внешние, `border-radius` — скругление углов, `font-size` — размер шрифта.

### Разбор 1

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="utf-8">
    <title>Моя первая страница</title>
</head>
<body>
    <h1>Привет, мир!</h1>
</body>
</html>
```

Разбор по шагам:

- `<!DOCTYPE html>` — служебная строка, которая сообщает браузеру, что документ написан по стандарту HTML5. Без неё браузер включит «режим совместимости» и может отрисовать страницу непредсказуемо.
- `<html lang="ru">` — корневой тег, внутри которого живёт весь документ. Атрибут `lang` указывает язык содержимого — это важно для поисковиков и программ чтения с экрана.
- `<head>` — контейнер служебной информации: `<meta charset="utf-8">` задаёт кодировку (без неё кириллица отобразится искажённо), а `<title>` — заголовок вкладки браузера.
- `<body>` — всё, что находится внутри, видно на странице. Пока там один `<h1>` — заголовок первого уровня.
- Браузер не исполняет HTML-код, как Python, — он парсит структуру и рисует страницу. Поэтому результат проверяется визуально: открываешь файл и видишь заголовок.

### Разбор 2

```html
<body>
    <h1>Привет, мир!</h1>
    <p>Меня зовут Аня, я учу Python и делаю сайты.</p>
    <a href="https://t.me/your_login">Мой Telegram</a>
    <img src="https://picsum.photos/200" alt="Случайная картинка">
    <ul>
        <li>Программирование</li>
        <li>Музыка</li>
    </ul>
</body>
```

Разбор по шагам:

- `<p>` — абзац: блок текста, отделённый отступами сверху и снизу.
- `<a href="...">` — ссылка. Атрибут `href` хранит адрес перехода; между открывающим и закрывающим тегами — видимый пользователю текст.
- `<img>` — одиночный тег, закрывающего варианта у него нет. `src` — путь к картинке, `alt` — альтернативный текст: он показывается, если картинка не загрузилась, и читается программами экранного доступа.
- `<ul>` — маркированный список, а каждый `<li>` — его пункт. Список — это парный контейнер: открыть `<ul>`, вложить `<li>`, закрыть `</ul>`.
- Вложенность критична: пункты `<li>` должны находиться внутри `<ul>`, иначе структура документа сломается.

### Разбор 3

`first_page.html` (фрагмент):

```html
<head>
    <meta charset="utf-8">
    <title>Моя первая страница</title>
    <link rel="stylesheet" href="style.css">
</head>
```

`style.css`:

```css
body {
    background-color: #f0f8ff;
    font-family: sans-serif;
}

h1 {
    color: tomato;
}
```

Разбор по шагам:

- Тег `<link rel="stylesheet" href="style.css">` подключает внешний файл стилей. `rel="stylesheet"` говорит браузеру, что это таблица стилей, а `href` — путь к файлу. Файлы лежат рядом, поэтому путь — просто `style.css`.
- Свойство `background-color` красит фон: для `body` — всю страницу. Цвет можно задать именем (`tomato`), hex-кодом (`#f0f8ff`) или rgb().
- `font-family: sans-serif` задаёт семейство шрифтов; `sans-serif` — «гротеск», шрифт без засечек, который легко читается на экране.
- Селектор `h1` применяет правила ко всем заголовкам первого уровня на странице.
- Если стили не применились, первое, что проверяют, — совпадает ли имя файла в `href` с реальным именем файла на диске.

### Разбор 4

`profile.html`:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="utf-8">
    <title>Моя карточка</title>
    <link rel="stylesheet" href="style.css">
</head>

    <div class="card">

            <li>Программирование</li>
            <li>Музыка</li>
        </ul>
    </div>
</body>
</html>
```

`style.css` (дополнение):

```css
.card {
    background-color: white;
    border-radius: 12px;
    padding: 20px;
    width: 320px;
}

h1 {
    color: steelblue;
}
```

Разбор по шагам:

- `<div class="card">` — универсальный блок-контейнер. Атрибут `class` — это метка, по которой CSS находит элемент, поэтому в стилях ему соответствует `.card` — с точкой перед именем.
- Свойства `.card`: `background-color` — белый фон, `border-radius: 12px` — скругление углов, `padding: 20px` — внутренние отступы (пространство между рамкой и содержимым), `width: 320px` — фиксированная ширина.
- Благодаря `width` карточка не растягивается на всю ширину окна, а выглядит компактным блоком.
- Селектор `h1` с `color: steelblue` красит имя в синий. Правила для разных элементов не конфликтуют: `h1` отвечает за заголовок, `.card` — за контейнер.

### Разбор 5

`style.css` (финальный вид):

```css
body {
    background-color: #f0f8ff;
    font-family: sans-serif;
}

.card {
    background-color: white;
    border-radius: 12px;
    padding: 20px;
    width: 320px;
    margin: 20px auto;
}

h1 {
    color: steelblue;
}

li {
    color: #444;
}

a:hover {
    color: red;
}
```

`profile.html` — внутри карточки после списка:

```html
<a href="#">Мой профиль</a>
```

Разбор по шагам:

- `margin: 20px auto` — сокращённая запись: первое значение задаёт вертикальные отступы (20px сверху и снизу), второе — горизонтальные. Значение `auto` по горизонтали выравнивает блок по центру.
- `li { color: #444; }` — пункты списка становятся тёмно-серыми, а не чёрными: мелкая деталь, которая делает страницу мягче.
- `a:hover` — псевдокласс: правило срабатывает только в момент наведения курсора на ссылку. Так мы добавляем обратную связь — пользователь видит, что элемент кликабелен.
- Ссылка `href="#"` — «пустая» ссылка, ведущая на ту же страницу; она удобна для тренировки стилей.
- Итог: карточка по центру, пункты тёмные, ссылка реагирует на курсор. Это уже полноценный маленький макет.
