# 🐍 PythonПро — платформа-курс по Python с нуля до Senior

Полноценное веб-приложение-курс: подробная теория, живые примеры, задачи с подсказками и разборами. Семь модулей — от объявления переменных до нейросетей, сайтов и собственных проектов.

## Возможности

- **60+ уроков** в 7 модулях: основы → продвинутый Python → стандартная библиотека → анализ данных → веб → нейросети → проекты.
- **Теория + практика**: каждый урок содержит блок теории, задачу, скрытую подсказку и полный разбор решения.
- **Прогресс ученика**: регистрация, отметка пройденных уроков, проценты по модулям и по курсу в целом.
- **Поиск** по урокам (название, описание, текст теории).
- **Красивый адаптивный интерфейс**: тёмная/светлая тема, кнопка «Копировать» у блоков кода, поддержка мобильных.
- **Админ-панель Django** для управления модулями и уроками.
- **Контент в Markdown**: файлы в `content/` — легко дополнять курс без программирования.

## Технологии

- Backend: **Django 5** + SQLite
- Рендер уроков: **Markdown** (python-markdown)
- Фронтенд: чистый HTML/CSS/JS (без внешних CDN), тёмная и светлая темы
- Внутри курса изучаются: Flask, FastAPI, Django, Jinja2, Streamlit, pandas, NumPy, Matplotlib, PyTorch, pytest, Git и др.

## Быстрый старт

Требуется Python 3.10+ и Git.

```bash
# 1. Склонировать репозиторий
git clone https://github.com/Bezlevv/python-pro-course.git
cd python-pro-course

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Подготовить базу данных
python manage.py migrate

# 4. Загрузить контент курса
python manage.py load_content

# 5. Запустить сервер
python manage.py runserver
```

На Windows можно просто запустить `start.bat` — он сделает всё за вас.

Открой **http://127.0.0.1:8000/** — курс готов! 🎉

### Админка

```bash
python manage.py createsuperuser
```

Затем зайди на **http://127.0.0.1:8000/admin/**.

## Как добавить новый урок

1. Создай файл `content/<модуль>/<номер>-<слаг>.md`.
2. Заполни front-matter (`title`, `summary`, `order`, `duration`, `difficulty`).
3. Напиши теорию в Markdown, задачу — внутри `<!--TASK--> ... <!--/TASK-->`, подсказку — `<!--HINT--> ... <!--/HINT-->`, разбор — `<!--SOLUTION--> ... <!--/SOLUTION-->`.
4. Выполни `python manage.py load_content`.

Полная спецификация формата — в [`content/FORMAT.md`](content/FORMAT.md).

## Структура проекта

```
├── manage.py                # точка входа Django
├── smoke_test.py            # смоук-тест всех страниц
├── validate_content.py      # валидатор контента
├── courseproj/              # настройки проекта
├── learn/                   # приложение: модели, вьюхи, загрузчик контента
├── content/                 # уроки курса (Markdown)
├── templates/               # шаблоны страниц
├── static/                  # CSS и JS
└── requirements.txt
```

## Проверки

```bash
python manage.py check          # проверка проекта Django
python validate_content.py      # проверка контента уроков
python smoke_test.py            # проверка, что все страницы отвечают 200
```
